# 「들리게」 노인 사용자 테스트 설계 (실제 실행은 대표님/현장에서)

## 목적
"난청 어르신과 대화하는 사람"이 설명 없이 30초 안에 앱을 켜고, 어르신이 자막을 읽고 대답할 수 있는가.

## 대상 (총 6쌍, 2주)
| 쌍 | 어르신 | 대화 상대 | 모집처 |
|---|---|---|---|
| 1–2 | 70대, 보청기 미착용, 난청 자각 | 40–50대 자녀 | 구독자 공지 |
| 3–4 | 75세 이상, 보청기 착용 | 배우자 (60–70대) | 경로당·노인복지관 |
| 5 | 80세 이상, 저시력 동반 (노안+백내장) | 요양보호사 | 재가요양센터 |
| 6 | 65–70대, 경도 난청, 스마트폰 능숙 | 손주/자녀 | 구독자 공지 |

핵심 조건: **폰을 누가 드는가**를 쌍마다 기록 (어르신 본인 / 대화 상대). 이게 UI 방향을 결정.

## 과제 (설명 없이, 링크만 전달)
1. 링크 열고 [듣기 시작] 누르기 — 목표 30초 이내
2. 대화 상대가 아래 문장을 평소 속도로 말함. 어르신이 자막만 보고 되말하기
   - "다음 진료는 **10월 14일 오후 3시**예요" (날짜·시간)
   - "이 약은 **하루 세 번, 식후 30분**에 드세요" (숫자·복약)
   - "이체 금액이 **48만 5천 원** 맞으세요?" (금액 — 사/팔 혼동)
   - "요즘 잠은 잘 주무세요?" (일상)
3. 글자 크기 바꾸기 (요청 없이 스스로 찾는지 관찰)
4. 종료 후 요약 화면 읽고 "오늘 약속이 언제였죠?" 답하기

## 측정
| 지표 | 통과 기준 |
|---|---|
| 첫 자막까지 시간 | 30초 이내, 5/6쌍 |
| 숫자 문장 3개 정확 되말하기 | 3/3, 5/6쌍 |
| 도움 요청 횟수 | 쌍당 1회 이하 |
| 글자 크기 스스로 변경 | 4/6쌍 |
| 요약에서 날짜 정답 | 6/6쌍 |
| SUS(시스템 사용성 척도) 10문항 — 대화 상대만 | 평균 70 이상 |
| 어르신 한 마디 소감 (녹음 아님, 메모) | 정성 |

## 환경
- 조용한 방 1회 + 소음(TV 켜둠) 1회. 병원 소음은 v2에서.
- 기기: 어르신 본인 폰(갤럭시 비중 높음 예상) + 대화 상대 폰(아이폰 1대 이상 확보)
- 삼성 인터넷 vs 크롬 각각 1회 이상 (Web Speech API 지원 차이 확인)

## 윤리
- 녹음·녹화 없음. 관찰자 메모만. 화면 저장 없음.
- 대화 내용 저장 안 됨을 시작 전 구두 고지.
- 참여 사례: 소정의 상품권. 유튜브 출연은 별도 동의서.

## 결과 처리
- 5/6 통과 못 한 지표 → 기능 추가가 아니라 **뺄 것**부터 찾는다 (CLAUDE.md 10장).
- 폰을 대화 상대가 든 쌍이 4/6 이상 → UI를 "상대방 화면"으로 설계 (어르신 쪽으로 돌려 보여주기 = 화면 뒤집기 버튼 검토)
