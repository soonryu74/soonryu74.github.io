② 실거래가 자동 연결 (한 번만 설정)

무료 절차 한 번이면, 이후 구리시 실거래가가 매일 새벽 자동으로 갱신되어 갈매동 카드·구리 표·분석·홍보글 시세가 늘 최신이 됩니다.

  1. 공공데이터포털 무료 서비스키 발급
    data.go.kr → 「아파트 매매 실거래가」(오픈API) → 활용신청 → 인증키 발급.
  2. GitHub 비밀값(Secret) 등록
    저장소 → Settings → Secrets and variables → Actions → New repository secret → 이름 DATA_GO_KR_KEY, 값=인증키. (키는 코드가 아니라 반드시 이 Secret에만 저장)
  3. 자동 실행
    매일 새벽 자동 작업이 구리시(41310) 실거래가를 받아 data/complexes.js·data/guri-complexes.js를 재생성 → 화면에 자동 반영. Actions 탭에서 「Run workflow」로 즉시 실행도 가능.
🖐 수동 갱신(키 없이도 가능) rt.molit.go.kr에서 구리시 아파트 매매 엑셀을 받아 관리자(Claude)에게 전달 → 즉시 갱신.
