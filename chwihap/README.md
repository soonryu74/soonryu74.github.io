# 업무망 취합도우미 (MVP)

인터넷이 안 되는 업무망에서 **지침·규정 개정 의견을 부서별로 받아 → 조문별로 채택/불채택 → 신구대비표를 자동으로 만드는** 도구입니다.
PC 한 대에서 켜 두면, 같은 망의 다른 PC들은 **브라우저(크롬·엣지·웨일)로 주소만 열면** 됩니다.

- 추가 프로그램 설치 없음: Node.js 하나만 있으면 됩니다. npm 설치 과정도 없습니다.
- 데이터는 이 폴더의 `data/`에만 저장됩니다. 밖으로 나가는 통신은 없습니다.

---

## 1. 설치 준비 (최초 1회)

Node.js(노드제이에스)를 설치해야 합니다. 업무망은 인터넷이 안 되므로 **인터넷 PC에서 받아 반입**합니다.

1. 인터넷 PC에서 https://nodejs.org 에 접속해 **LTS** 버전을 받습니다. Node.js 18 이상이면 동작하고, 24 LTS를 권장합니다.
2. 기관의 자료 반입 절차(망연계)로 업무망 PC에 옮깁니다.
3. 이 `chwihap` 폴더도 같은 방법으로 옮깁니다.

| | 윈도우 | 맥 |
|---|---|---|
| 받을 파일 | `node-v24.x.x-x64.msi` (Windows Installer) | `node-v24.x.x.pkg` (macOS Installer) |
| 관리자 권한이 없을 때 | `node-v24.x.x-win-x64.zip`을 받아 압축을 풀고, 그 안의 `node.exe`를 `chwihap\node\node.exe`에 넣습니다 | `node-v24.x.x-darwin-arm64.tar.gz`(M1~M4 칩) 또는 `darwin-x64`(인텔 칩)를 받아 압축을 풀고, 푼 폴더 이름을 `node`로 바꿔 `chwihap/node/`에 넣습니다 |
| 설치 확인 | 명령 프롬프트에서 `node -v` 입력 | 터미널에서 `node -v` 입력 |

## 2. 실행

| | 윈도우 | 맥 |
|---|---|---|
| 켜기 | `시작-윈도우.bat` 더블클릭 | `시작-맥.command` 더블클릭. 처음 한 번은 "확인되지 않은 개발자" 창이 뜹니다. **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**를 누르세요 |
| 명령어로 켜기 | `cd C:\chwihap` 입력 후 `node server.js` | `cd ~/chwihap` 입력 후 `node server.js` |
| 끄기 | 까만 창에서 `Ctrl + C`, 또는 창 닫기 | 터미널에서 `Control + C` |
| 방화벽 | 처음 켤 때 "Windows 보안 경고"가 뜨면 **개인/도메인 네트워크 허용** | "들어오는 연결을 허용하시겠습니까?"가 뜨면 **허용** |

켜지면 창에 주소가 두 개 나옵니다.

```
이 PC에서 열기  : http://localhost:8080
다른 PC에서 열기: http://10.1.2.34:8080   ← 이 주소를 부서 PC들이 씁니다
```

- 8080 포트를 이미 다른 프로그램이 쓰고 있으면 포트를 바꿔 켭니다.
  - 윈도우: `set PORT=9090 && node server.js`
  - 맥: `PORT=9090 node server.js`
- 켜 둔 PC가 꺼지면 다른 사람들도 접속할 수 없습니다. 취합 기간에는 이 PC를 켜 두세요.

## 3. 사용 순서

### 취합 담당자
1. `http://localhost:8080`에 접속해 처음 한 번 **담당자 비밀번호**를 정합니다.
2. **[+ 새 취합 만들기]**를 누릅니다.
   - 제목, 마감일, 부서 목록(한 줄에 한 부서)을 적습니다.
   - 한글 파일에서 본문 전체를 복사해 붙여 넣습니다(윈도우 `Ctrl+A` → `Ctrl+C`, 맥 `⌘+A` → `⌘+C`).
   - **[조문 나누기]**를 누르면 "제1조", "제2조의2" 기준으로 조문이 나뉩니다. 조문별로 담당 부서를 체크합니다.
3. **현황판 → [전체 링크 한 번에 복사]**를 눌러 메신저나 메일로 부서에 보냅니다.
4. **조문별 검토**에서 부서 의견마다 **[채택] [고쳐서 채택] [보류] [불채택]**을 누르고 사유를 적습니다.
   - 여러 부서가 같은 조문을 고쳤으면 빨간 "충돌" 표시가 뜹니다.
   - 누가 언제 무엇을 바꿨는지는 **[이력]**에서 보고, 필요하면 되돌릴 수 있습니다.
5. **신구대비표·내보내기**에서 파일을 받습니다.
   - 한글(HWPX), 워드(DOCX), 엑셀(XLSX)로 받을 수 있습니다.
   - PDF는 [인쇄 · PDF 저장]을 눌러 만듭니다.
6. 중간중간 **버전·기록 → [버전 저장]**으로 "1차 취합안" 같은 이름을 붙여 두면, 버전끼리 비교할 수 있습니다.

### 부서 수정자
1. 받은 링크를 엽니다. 로그인은 없고, 처음에 이름만 한 번 적습니다.
2. **우리 부서 담당 조문**만 보입니다. 칸 안에서 바로 고치면 자동 저장됩니다. 추가된 부분은 파란 밑줄, 지운 부분은 빨간 취소선으로 표시됩니다.
3. 고친 이유를 한 줄 적습니다. 조문 삭제나 새 조문 신설도 제안할 수 있습니다.
4. **[제출하기]**를 누르고 부서장 이름을 적으면 끝입니다. 담당자가 처리하면 결과와 사유가 같은 화면에 보입니다.

## 4. 백업 · 보안

- 모든 데이터는 `data/db.json` 한 파일에 있습니다. 하루 한 번 `data/backup/`에 자동으로 복사되고, 30일치를 보관합니다.
- `data/audit.log`에 누가, 언제, 어느 PC(IP)에서 무엇을 했는지가 쌓입니다. 화면의 **버전·기록** 탭에서도 볼 수 있습니다.
- 부서 링크가 잘못 전달됐으면 **설정 → 링크 재발급**을 누르세요. 예전 링크는 바로 막힙니다.
- 담당자 비밀번호를 잊었으면 프로그램을 끄고 `data/db.json`에서 `"admin"` 항목을 `null`로 바꾼 뒤 다시 켜면 새로 정할 수 있습니다. 편집 전에 파일을 복사해 두세요.
- 이 도구는 기관 보안성 검토를 받기 전의 시범(MVP) 버전입니다. 정식으로 운영하려면 기관 정보보안 담당자의 승인을 먼저 받으세요.

## 5. 알려진 한계

- **한글 파일 호환**
  - HWPX는 한컴 표준 뼈대를 기반으로 만들고, 문서 구조 검사(python-hwpx 스키마 검증)를 통과했습니다.
  - 다만 실제 한글 프로그램에서 여는 시험은 하지 못했습니다. 반드시 한 번 열어 확인하세요.
  - 열리지 않으면 DOCX로 받아 한글에서 여세요. 한글은 DOCX를 열 수 있습니다.
- **원문 입력**: 붙여넣기 방식이라 표·그림·각주는 글자만 들어옵니다.
- **동시 편집**
  - 같은 부서 두 사람이 같은 조문을 동시에 고치면 나중에 저장한 사람에게 "먼저 고친 사람이 있다"는 안내가 뜨고, 최신 내용으로 바뀝니다.
  - 누가 어느 조문을 고치고 있는지는 "✎ ○○ 님이 고치는 중"으로 표시됩니다.
