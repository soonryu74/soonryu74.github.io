# vibe-edit — 말로 자르고 · 더빙 · 자막 · 음악 · 쇼츠

> 출처: 미드저니 코리아 조남경 «말로 자르고·더빙·자막·음악·쇼츠까지 다 된다고? | 바이브 모션 3편»(youtu.be/rVzuYY91kGs),
> 그리고 그 영상이 보여 주는 motion-studio v0.13.0(github.com/nk-mjk/motion-studio, MIT).
> ⚠️ 영상 본편은 이 서버에서 열리지 않아(유튜브 429 차단) **제목 · 썸네일 · 스킬 원본 문서**를 기준으로 정리했다.
> 본편에만 나오는 팁이 있으면 유저가 받아쓰기나 요약을 주면 이 문서에 보탠다.

## 0. 핵심 생각 — 세 줄
1. **유저는 대충 짚는다, 정확한 자리는 AI가 찾는다.** «19초쯤 이상해»가 오면 앞뒤 ±1초 프레임 시트와 소리 크기로 정확한 프레임을 찾는다.
2. **말 → 표 → ⏸ 확인 → 굽기.** 말을 바로 굽지 않고, 먼저 «제가 이해한 것» 표(정확한 타임코드 · 고칠 방법 · ★AI가 정한 것)를 보이고 OK 뒤에만 고친다.
3. **시각은 전부 원본 시각으로 적는다.** 중간 조각을 빼도 자막 · 짚기 표시 · 대사가 따라온다(컷 안 초로 적으면 다 어긋난다).

## 1. 다섯 가지 — 이렇게 말하면 이 도구로

| 하고 싶은 것 | 유저가 하는 말 | motion-studio v0.13 (설치됨) | 우리 공장 대안 | ⏸ 확인 지점 |
|---|---|---|---|---|
| **말로 자르기** | «1:20~1:45 빼 줘», «로딩은 빨리 감기로», «여기 멈추고 동그라미» | `reference/rec-cut.md` 컷 표(`a·b·sp·keep·freeze·marks·mask`) → `core/cut.py` Reel | `video-factory/scripts/highlight.py`(cuts + 쉼에 맞춰 자르기 snap) | 컷 표 초안 |
| **더빙** | «이 원고로 나레이션 넣어 줘» | ⛔ 음성 합성 안 함 — 문장 단위 원고 → 유저 녹음 → 앞뒤 빈 소리 정리 → 영상을 녹음 길이에 맞춤(`review-voice.md` §⑥) | Gemini TTS(자식 세션 · `[warm, calm]` 대괄호 태그 · 문장 지시는 소리 내 읽어 버리니 금지) 또는 유저 녹음 | 원고 · 녹음 문장 수 |
| **자막** | «자막 달아 줘», «받아써 줘» | `scripts/transcribe.py 영상.mp4` → `확인표.md` → `apply` → `burn` (sherpa-onnx Whisper turbo + silero VAD, 모델 약 560MB) | `video-factory/scripts/transcribe.py` + `subs.py draft/burn`(핵심 단어 금색) | **확인표** — AI는 소리를 못 듣는다. 이상한 줄에 ★짐작을 달아 보이고 유저가 고친 뒤 굽는다 |
| **음악** | «배경음만 바꿔 줘 — 로파이로» | `scripts/rebgm.py 영상.mp4 --style 로파이`(화면은 다시 안 굽는다) · motion-studio 영상이면 `scenes.py --rebgm 장르` | Suno 곡 + 목소리 밑으로 자동 덕킹(`typo.py`) | 없음(장르만 고르면 됨) |
| **쇼츠** | «이 행사 영상 쇼츠로 이쁘게» | `reference/video-shorts.md`(세로 처리 3가지 · 멈춤 이름표 · 글귀 튀기 · 예능 자막 · 회상) · `scripts/wrap.py` 껍데기(1:1/4:5 창 + 위아래 띠) | `highlight.py` stack/center/fit + `cover.py` 표지 | 묻는 건 두 가지뿐: 무슨 자리·언제·어디 / 인물 이름표 |

배경음 13장르(`rebgm.py --list`): 경쾌 팝 · 밝은 설명 · 일렉/테크 · 시네마틱 · 동화 · 로파이 · 어쿠스틱 · 재즈 라운지 · 펑키 · 레트로 게임 · 긴장/미스터리 · 감성 피아노 · 축하/행사. 곡은 사운드폰트로 코드가 작곡한다(저작권 걱정 없음).

## 2. 말로 자르기 — 컷 표 한 장
화면 녹화(사용법 · 시연)처럼 길고 기다리는 영상용. 표에 원본 시각으로 적는다.

| 컷 | 원본 구간 | 배속 | 보여 줄 곳(crop) | 짚을 것 | 대사 |
|---|---|---|---|---|---|
| c01 | 0:00–0:12 | 1 | 전체 | — | «오늘은 …» |
| c02 | 0:12–1:40 | ×20 | 전체 | «빨리 감기 ×20» 배지 자동 | — |
| c03 | 1:40–1:55 + 1:52 멈춤 2초 | 1 | 입력 창 쪽으로 다가가기 | 1:52 동그라미 | «여기만 누르면 …» |

- 배속 3 이상이면 «빨리 감기 ×N», 100 이상이면 «건너뛰기» 배지가 저절로 붙는다.
- 오타 · 머뭇거림은 `keep` 조각으로 들어낸다. 이름 · 이메일 · 토큰이 보이면 `mask`(바탕색 칠 + `user@mac` 같은 대신 글) — **가린 곳 목록을 유저에게 보인다.**
- 짚기 표시(동그라미 · 밑줄 · 상자 · 체크 · X)는 화면이 바뀌면 같이 지운다.
- 샘플: `motion-studio/examples/rec_cut_example.py`.

## 3. 굽고 나서 «말로 고치기» — 피드백 뷰어
굽기가 끝나면 작업 폴더에 `피드백뷰어.html` 이 생긴다(브라우저로 연다 · 영상이 커서 아티팩트로는 안 올린다).

| 키 | 하는 일 |
|---|---|
| `N` | 여기 문제 — 시각 + 종류(화면 표시 · 글씨 · 카메라 · 타이밍 · 소리·대사 · 전환) + 메모 + 화면 위치 % |
| `I` / `O` | 범위 — 들어내기 · 빠르게 · 느리게 · 멈춰서 보여 주기 · «✂ 빼고 이어 보기»로 미리 보기 |
| `[` / `]` | 앞 · 다음 대사로(자막이 있을 때) |
| `C` | 뷰어 자막 켬/끔 |
| 목록 복사 | `[피드백]` 으로 시작하는 글 → 대화창에 붙여 넣기 |

받으면: `feedback.py sheet`(앞뒤 프레임 시트) · `feedback.py loud`(소리 튀는 자리)로 자리 찾기 → **«제가 이해한 것» 표 ⏸** → 고침 → 전후 스틸 + 새 타임코드표 → 다시 굽기.
- **시간 · 무엇**(타이밍 · 길이 · 빼기 · 글귀 · 소리) = 장면 코드에서 고친다.
- **모양**(위치 · 글꼴 · 크기 · 색 · 새로 얹는 글자) = 캔버스에서 고친다. 좌표를 코드에 박지 않는다.
- 범위 들어내기는 기계적으로 자르지 않는다 — 말한 시각 근처의 **화면이 바뀌는 순간**에서 자르고, 대사가 잘리지 않는지 본다.
- 피드백 여러 개는 한 회차로 모아서 한 번에 굽는다.

## 4. 주문 문장 — 복사해서 쓰기
```
[말로 자르기] 녹화/설치.mp4 를 설명 영상으로. 0:30~2:10 설치 대기는 빨리 감기, 2:40에서 2초 멈추고 «저장» 버튼에 동그라미. 이메일 보이면 가려 줘.
[더빙] 이 원고 5문장으로 나레이션 넣어 줘. 목소리는 차분하게. 영상 길이는 목소리에 맞춰.
[자막] 이 영상 받아써서 확인표 먼저 보여 줘. 세로 영상이라 한 줄 15자.
[음악] 배경음만 감성 피아노로 바꿔 줘. 화면은 그대로.
[쇼츠] 어제 북토크 영상 쇼츠로. 서울 ○○서점, 10월 16일. 가운데 분은 ○○○ 작가님.
[피드백] (뷰어에서 «목록 복사»한 내용 그대로 붙여 넣기)
```

## 5. 설치 — Windows · Mac 비교 (2026-10 기준)
| 할 일 | Windows (PowerShell) | Mac (터미널) |
|---|---|---|
| ffmpeg | `winget install Gyan.FFmpeg` | `brew install ffmpeg` |
| 파이썬 패키지 | `py -m pip install Pillow numpy tinysoundfont pedalboard` | `python3 -m pip install Pillow numpy tinysoundfont pedalboard` |
| 첫 점검 + 빠진 것 받기 | `py <스킬>\scripts\check.py <작업폴더> --fix` | `python3 <스킬>/scripts/check.py <작업폴더> --fix` |
| 받아쓰기 모델(약 560MB, 처음 한 번) | `py <스킬>\scripts\transcribe.py --fetch` | `python3 <스킬>/scripts/transcribe.py --fetch` |
| 배경음만 바꾸기 | `py <스킬>\scripts\rebgm.py 영상.mp4 --style 로파이` | `python3 <스킬>/scripts/rebgm.py 영상.mp4 --style 로파이` |

- `tinysoundfont` 설치가 pyaudio 오류로 멈추면 `--no-deps` 를 붙인다. `pedalboard` 가 실행 중 죽으면 `pedalboard==0.9.16`.
- 사운드폰트(GeneralUser-GS.sf2, 약 31MB)는 작업 폴더 `sf2/` 에 둔다. 없으면 배경음 없이 굽는다.
- <스킬> = `.claude/skills/motion-studio`(우리 저장소에 v0.13.0 설치됨 · LICENSE 포함).
