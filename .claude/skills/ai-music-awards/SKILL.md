# AI 음악 어워즈 출품 (ai-music-awards)

NEXT SOUND Awards 2026 출품을 **기획부터 제출까지** 한 흐름으로 돕는다.
근거 자료는 두 가지다.

- `references/rules.md` — 공식 규정 요약 (2026-11-23 확인본)
- `references/top-tracks.md` — TOP RATED 상위 25곡 청취 분석 (2026-11-23 스냅샷)

> **먼저 할 일**: 규정·마감은 바뀔 수 있다(이미 한 번 연장됨). 작업 시작 시
> https://nextsoundawards.com/competition-rules 를 다시 확인하고, `rules.md`와 다르면 사이트가 우선이다.

## 진행 순서

사용자에게 한 번에 다 설명하지 말고, 단계마다 **선택지로 물어본 뒤** 다음으로 넘어간다.

### 1단계 · 자격 확인 (하나라도 "아니오"면 멈추고 알린다)

- 만 18세 이상, 계정은 **1인 1개**
- 음악 **자체**의 제작에 AI 도구를 1개 이상 사용 (작곡·편곡·사운드·보컬·믹싱·마스터링 중 어디든). 커버 그림·메타데이터에만 AI를 쓴 것은 해당 없음
- 녹음·가사·보컬·샘플·아트워크의 권리를 본인이 갖거나 허락받음. 커버·리믹스는 허락이 있어야 함
- 사용한 AI 음악 툴의 **요금제 약관**상 본인에게 이용 권리가 있는지 확인 (무료 플랜은 조건이 다른 경우가 많다 → 해당 툴 약관을 직접 확인하도록 안내)
- 유통사·레이블·저작권단체와 계약이 있다면 NEXT SOUND 스트리밍·홍보 이용이 가능한지 확인

### 2단계 · 엔트리 종류

| 종류 | 비용 | 내용 |
|---|---|---|
| 싱글 | 첫 1곡 **무료** | MP3 1곡 |
| LP 패스 | $10 | 8~16곡 1개 릴리스. 수록곡은 싱글 부문에도 자동 출품 |
| 무제한 패스 | $20 | 서로 다른 싱글·LP 추가 출품. 중복·사소한 버전 차이·도배는 제외 대상 |

처음이면 **무료 싱글 1곡**을 권한다. 패스를 사도 점수에는 이점이 없다.

### 3단계 · 카테고리 (1곡당 정확히 1개)

Pop / Electronic / Cinematic / Experimental 중 하나. 스냅샷 기준 관찰:

- 상위 25곡: Cinematic 14 · Pop 8 · Electronic 3 · Experimental 0
- 최신 100곡: Cinematic 35 · Experimental 29 · Pop 27 · Electronic 9
- Cinematic에는 재즈·포크·로파이·중동 악기곡까지 폭넓게 들어가 있다 (오케스트라만이 아님)

경쟁이 덜한 곳을 고르기보다 **곡이 실제로 속한 장르**를 고른다. 명백한 오분류는 주최 측이 정정할 수 있다.
위 순위는 청중 평점 기준이며, 최종 점수는 **심사위원 80% + 청중 20%** 다.

### 4단계 · 곡 기획과 프롬프트

`references/top-tracks.md` 의 패턴을 기획서에 반영한다. 핵심만:

1. **길이 3:00~4:30** (25곡 중앙값 3:24, 범위 2:23~6:07)
2. **도입 15초 안팎** 후 주제·보컬 진입 (중앙값 16초). 30초를 넘기면 이유가 있어야 한다
3. **첫 후렴·메인 테마는 1분 이내**
4. **조용함 → 큼의 낙차**를 설계한다. 상위곡의 강점으로 가장 자주 꼽힌 요소
5. **한 줄로 기억되는 훅** — 가사 한 줄 또는 악기 리드 멜로디 하나
6. **고유한 색** — 지역 악기(얼후·네이·우드·돌), 2개 언어 보컬, 뜻밖의 장르 결합
7. 연주곡이면 **리드 멜로디**를 반드시 둔다 (없으면 "배경음악 같다"는 약점이 됨)

기획서 양식:

```
제목 / 아티스트명 / 카테고리
한 줄 콘셉트:
장르·서브장르 / BPM / 분위기:
보컬(성별·질감·언어) 또는 리드 악기:
악기 4~6개:
구성(시간표): 0:00 인트로 → 0:15 벌스 → 0:50 후렴 → … → 아웃트로
훅(가사 한 줄 또는 멜로디 설명):
낙차 포인트(어디서 터지는가):
```

기획서가 확정되면 사용자가 쓰는 툴(Suno·Udio 등)에 맞춰
**스타일 프롬프트**(장르·BPM·악기·보컬 질감·분위기)와 **구성 태그 포함 가사**(`[Intro] [Verse] [Chorus] [Bridge] [Outro]`)를 따로 써 준다.
실존 아티스트 이름·기존 곡 가사는 프롬프트에 넣지 않는다(권리 문제).

### 5단계 · 제출 전 품질 점검

상위곡에서도 반복된 약점이므로 하나씩 들어 보며 확인한다.

- [ ] 큰 소리·고음 구간에서 보컬이 깨지거나 기계음이 나지 않는가
- [ ] 클라이맥스에서 악기가 뭉개지지 않는가 (저음 뭉침 포함)
- [ ] 같은 루프가 변화 없이 반복되지 않는가
- [ ] 끝맺음이 어색하게 잘리지 않는가 (페이드 또는 마지막 화음)
- [ ] 제목이 파일명 그대로가 아닌가 (`(1)`, `_MASTERED`, 전부 대문자 등 정리)
- [ ] 파일이 **MP3, 128kbps 이상**인가 (상위 25곡 중 10곡이 320kbps)

파일 확인 명령(맥·윈도우 동일, ffmpeg 설치 필요):

```
ffprobe -v error -show_entries format=duration,bit_rate -of default=nw=1 "내곡.mp3"
```

| | 맥(Mac) | 윈도우(Windows) |
|---|---|---|
| 터미널 여는 법 | Spotlight(⌘+Space) → "터미널" | 시작 → "PowerShell" |
| ffmpeg 설치 | `brew install ffmpeg` | `winget install Gyan.FFmpeg` |
| WAV → 320k MP3 | `ffmpeg -i in.wav -b:a 320k out.mp3` | 동일 |

### 6단계 · 제출 폼 작성 (https://nextsoundawards.com/submit)

로그인(구글 또는 이메일 링크) 후 입력 항목:

| 항목 | 메모 |
|---|---|
| Artist name | 앞으로 계속 쓸 이름 |
| Track title | 정리된 제목 |
| Country | 표기 통일 (예: `South Korea`) |
| MP3 | 128kbps 이상 |
| Category | 1개 |
| Artwork | 선택. 없으면 기본 커버가 붙는다 (최신 100곡 중 14곡이 기본 커버). 직접 올리기를 권함 |
| Process | **필수 성격**. 어떤 AI 툴이 무엇을 했는지 |
| Process evidence | 선택, 5MB 이하 (프롬프트 캡처·작업 화면 등) |
| 규정 동의 체크 | 사용자가 직접 읽고 체크 |

Process 문구는 **사실대로** 영어로 써 준다. 툴 종류나 AI 사용량은 점수에 유불리가 없으므로 부풀릴 이유가 없다.
수상 후보가 되면 이 내용의 검증을 요청받는다.

```
Lyrics: written by me, edited with [tool].
Composition / vocals / arrangement: generated with [tool, version] from my own prompts and lyrics; [n] generations, selected and extended by me.
Editing / mixing / mastering: [tool or DAW], done by me.
No third-party samples or voices were used.
```

실제 제출·결제·동의 체크는 **사용자가 직접** 한다. 대신 눌러 주지 않는다.

### 7단계 · 제출 후

- 다른 곡 **100곡을 평가**하면 싱글 무료 엔트리 +1 (곡당 30초 이상 청취, 계정당 1회)
- 보상 사실을 밝힌 공개 공유 1회 → +1, 유료 추천 성사 시마다 +1
- **자기 곡 평가, 다중 계정, 평점 조작 금지** — 실격 사유
- 일정: 출품 마감 2026-12-31 23:59 UTC(한국시간 2027-01-01 08:59) · 청중 평가 마감 2027-01-15 23:59 UTC · 수상 발표 2027-03-31까지

## 꼭 알려 줄 것 (과장 없이)

- 출품하면 주최 측에 **5년간 비독점 라이선스**(사이트 스트리밍·어워즈 홍보용)를 준다. 소유권은 넘어가지 않는다
- 상금은 부문당 $1,000(총 10개 부문), 세전 금액이며 세금은 수상자 부담
- 패스 환불은 구매 후 14일 이내 이메일 요청
- 수상은 보장되지 않는다. 이 스킬의 패턴은 **상위곡의 공통점 관찰**이지 당선 공식이 아니다
