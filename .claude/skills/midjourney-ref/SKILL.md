# midjourney-ref — 미드저니 참고 (2026-10 기준)

> 공식 문서(docs.midjourney.com)는 이 환경에서 403으로 못 읽었다. 아래는 공식 업데이트 블로그(updates.midjourney.com)와 보도 기사에서 확인한 것만 적었고, 확인 못 한 것은 «미확인»으로 표시했다. 새 버전이 나오면 §1부터 다시 확인한다.

## 1. 지금 상태 (2026-10)
- **alpha.midjourney.com** = V8 계열 실험 사이트. 첫 화면은 회사 소개 페이지(가입/로그인 버튼만)라 기능 설명은 없다. 실제 작업은 로그인 후 Create · Edit · Organize 탭.
- **V8.0 (2026-03 알파)** → 생성 속도 약 5배. `--hd`(네이티브 2K) · `--q 4`(일관성↑) 추가(기사 기준, 공식 노트엔 이름 없음 → 미확인). sref · 무드보드 · 개인화 V7 것 호환.
- **V8.1 (2026-04 알파 → 06-10 기본값)** → V7 느낌의 안정된 미학. HD 모드 3배 빠르고 3배 싸져 기본값. 이미지 프롬프트·이미지 가중치 복귀. 긴 프롬프트 자동 축약(Prompt Shortener). Describe가 V8식 긴 프롬프트를 내놓음.
- **V8.2 에디트 모델 (2026-08-27 → 알파 라이트박스 내장 09-02)** → 문장으로 편집 · 참조 이미지 최대 4장으로 새 이미지(omni-reference 대체) · 인페인팅 · 아웃페인팅 · «Change Style» 실험. 라이트박스 우하단 edit · 프롬프트 바에 드래그 · Discord `--edit url…`.
- **비용 감각**: `--hd` · `--q 4` · sref · 무드보드 작업은 표준보다 약 4배 느리고 4배 비쌈(기사). 비디오는 이미지의 약 8배(5초 ×4개 한 작업).

## 2. 파라미터 치트시트
| 파라미터 | 뜻 | 메모 |
|---|---|---|
| `--ar 16:9` / `9:16` / `1:1` | 비율 | 유튜브 배경 16:9 · 쇼츠 9:16 · 썸네일 16:9 |
| `--v 8.1` | 모델 버전 | 알파에서 기본. 안 쓰면 설정값 |
| `--hd` | 네이티브 2K | 최종본만. 초안은 빼고 돌린다 |
| `--q 4` | 일관성↑ (느림·비쌈) | 사람 손·글자 깨짐 줄일 때 |
| `--s 0~1000` | 스타일라이즈 | 실사·문서용 100~250 · 일러스트 400~700 |
| `--raw` | 미드저니 손맛 빼기 | 실사 · 사진풍 필수 |
| `--c 0~100` | 변주 폭(chaos) | 탐색 20~40 · 확정 0 |
| `--sref <코드 또는 URL>` `--sw 0~1000` | 스타일 참조 · 세기 | 채널 톤 통일. 한 번 찾은 코드는 §5에 기록 |
| `--p` | 개인화 프로필 | 켜면 내 취향으로 기운다 — 공익·기관 영상은 끈다 |
| `--no 텍스트` | 빼기 | `--no text, watermark, logo` 기본 추천 |
| `--tile` | 패턴 타일 | 배경 텍스처 |
| `--niji 7` | 애니 풍 | 손그림 느낌 필요할 때 |
| 이미지 URL + `--iw 0~3` | 이미지 프롬프트 · 가중치 | V8.1에서 복귀 |
| `--exp` · `--weird` | 실험 미학 | 보통 안 씀 |
| `--motion low/high` · `--video` | 비디오 | §4 |

글자를 그림 안에 넣으려면 **따옴표로 감싼다** (`"사랑의 베이커리"`). 한글은 깨지기 쉬우니 글자는 그림에 넣지 말고 파이프라인(PIL · motion-studio)에서 얹는 것이 원칙.

## 3. 프롬프트 레시피 — 이 채널 용도별
구조: **[피사체·행동] , [장소·시간·조명] , [카메라·렌즈] , [분위기·색] , [스타일 지시] --ar … --s … --raw --no text**

- **영상 배경(1분칼럼 · 설교 · 칼럼 낭독)** — 사람 얼굴 없이, 여백 큰 구도(글자 자리). `wide empty foreground, soft morning light, calm, muted warm palette, photographic --ar 16:9 --raw --s 150 --no people, text`
- **썸네일 바탕** — 한쪽 여백 50% 비우기: `subject on the right third, left half plain soft background for title text --ar 16:9 --raw`
- **공익·기관 영상(사랑의 베이커리류)** — 과장·낚시 금지. `honest documentary photo, natural light, real workplace, no stylization --raw --s 80`
- **역사·고문헌(직지류)** — `ink wash illustration on aged hanji paper, muted sepia, minimal lines --s 300` 또는 `--niji 7`로 손그림. 실존 인물 얼굴은 그리지 않는다(기획서 규칙).
- **일관된 시리즈** — 첫 장이 마음에 들면 `--sref <그 이미지 URL> --sw 300`으로 다음 장을 뽑는다. 더 강하게는 무드보드.
- **편집(V8.2)** — 라이트박스 edit에 문장으로: «왼쪽 절반을 비우고 같은 조명으로 확장» · «간판 글자를 지워» · «계절을 가을로» . 참조 4장까지 첨부 가능.

## 4. 비디오(V1) 워크플로 — 이미지 → 짧은 클립
1. 이미지(미드저니 생성 또는 업로드 → 프롬프트 바에 드래그 → **start frame**)에서 **Animate**.
2. **자동**(모션 프롬프트를 시스템이 작성) / **수동**(움직임을 문장으로: «카메라가 천천히 밀고 들어간다, 커튼이 흔들린다»).
3. **low motion**(카메라 거의 고정, 잔잔 — 아예 안 움직일 수도) / **high motion**(피사체·카메라 모두 — 왜곡 가능). 배경·B롤용은 low.
4. 한 작업 = **5초 ×4개**. 마음에 드는 것을 **extend** → 약 4초씩 최대 4번 → **최대 21초**.
5. 비용은 이미지의 약 8배. Pro/Mega는 relax 무제한(2025-06 기준, 변동 가능). 해상도·현재 모델명은 미확인 → 받아 온 mp4를 ffprobe로 확인한다.
6. 쓰임새: 1분칼럼 배경을 «정지 이미지 켄번스» 대신 5초 루프 클립으로 · motion-studio `video.md`의 영상 재료로.

## 5. 이 저장소 파이프라인에 넘기기
- **motion-studio**: 받은 png/jpg/mp4를 작업 폴더 `재료/`에 **의미 있는 파일명**으로(`bakery_counter.jpg`). 보드에서 `<img src="재료/bakery_counter.jpg">`. 영상 클립은 `video.md` 규칙.
- **1분칼럼(radiocol)**: `jobs/1분칼럼/{key}_bg/` 에 16:9 이미지 넣으면 `run.py`가 projects bg/로 복사한다. Gemini 생성 대신 미드저니 결과를 쓸 때 이 경로.
- 썸네일 바탕은 `yt-studio/pipeline`의 썸네일 스크립트에 바탕으로 전달(글자는 코드로 얹는다).
- 기록: 잘 나온 **sref 코드 · 프롬프트**는 이 파일 아래 «채널 sref 노트»에 적어 둔다.

### 채널 sref 노트
- (아직 없음) — 형식: `용도 | sref 코드/URL | --sw | 메모`

## 6. 주의
- 실존 인물 얼굴·브랜드 로고 생성 금지(채널 규칙 · 초상권). 기관 로고는 원본 파일을 쓴다.
