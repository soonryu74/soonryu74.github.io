# 테마 (주제별 포인트색)

종이·잉크·선·여백은 **모든 책이 같다**(공통 뼈대). 주제에 따라 바뀌는 건 포인트색 4개뿐이다.

| 변수 | 역할 |
|---|---|
| `--ac` | 포인트색. 번호 원·규칙선·버튼·진행바·인용 왼쪽선 |
| `--ac-deep` | 포인트색 짙게. 작은 글자(eyebrow·차례 번호·표 머리글)용 — 종이 위 대비 4.5:1 이상 |
| `--ac-soft` | 포인트색 아주 연하게. note·blockquote·표 머리글 배경 |
| `--ac-ink` | 포인트색 위에 올리는 글자색(보통 흰색) |

## 내장 테마

| theme | 주제 | 포인트색 | 자동 매칭 키워드(일부) |
|---|---|---|---|
| `default` | 범용·에세이 | 앰버 `#c8811f` | (매칭 없을 때) |
| `estate` | 부동산·집·계약 | 딥그린 `#2e7d64` | 부동산 아파트 전세 매매 청약 등기 |
| `ai` | AI·IT·코딩·업무 자동화 | 인디고 `#3d5ae0` | AI 챗GPT 클로드 자동화 엑셀 PPT 바이브코딩 |
| `money` | 창업·돈·재테크·수익화 | 골드 `#b8860b` | 창업 수익 부업 마케팅 유튜브 스마트스토어 |
| `health` | 건강·의료·돌봄 | 코랄 `#d4574e` | 건강 병원 돌봄 운동 식단 요양 |
| `edu` | 교육·입시·공부 | 블루 `#1f6fb2` | 교육 입시 공부 자녀 수능 |
| `life` | 생활·여행·취미 | 틸 `#0f8a8a` | 생활 여행 취미 요리 정리 |
| `law` | 법·행정·세금·제도 | 버건디 `#7a2e4a` | 법 세금 계약 제도 지원금 연금 |
| `mind` | 마음·신앙·관계·습관 | 바이올렛 `#6b4fbb` | 마음 신앙 기도 관계 습관 에세이 |

- 자동 매칭: `theme: auto` 면 `build.py` 가 원고 전체에서 키워드 출현 수를 세어 가장 많은 테마를 고른다. 결과는 빌드 출력에 "테마: ai (자동)" 로 표시.
- 지정: front matter `theme: estate` 또는 `python3 build.py book.md --theme estate`.
- 엑셀·PPT 자동화처럼 "업무+AI" 주제는 `ai`, "수익화·창업" 이 중심이면 `money`.

## 야간 모드
화면 오른쪽 위 ☾ 버튼. 뼈대(종이·잉크)만 뒤집고 포인트색은 유지한다. `--ac-soft` 와 `--ac-deep` 은 `color-mix()` 로 자동 보정. 선택은 `localStorage` 에 저장되고 PDF 에는 영향 없음(인쇄는 항상 밝은 종이).

## 테마 추가하기
1. `template.html` 의 `[data-theme="…"]` 줄을 복사해 4개 변수를 정한다.
   - `--ac-deep` 은 `#fdfcfa` 종이 위에서 **대비 4.5:1 이상**, `--ac` 는 3:1 이상(큰 요소용).
   - `--ac-soft` 는 종이와 거의 같은 밝기(본문 위 배경으로 써도 글자가 잘 읽혀야 함).
2. `build.py` 의 `THEMES` 에 키워드를 추가한다.
3. `themes.md` 이 표에 한 줄 추가.
