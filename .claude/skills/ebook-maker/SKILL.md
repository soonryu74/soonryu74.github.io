# 읽는 이북 메이커 (ebook-maker)

강의·글을 **"읽는 이북"** — 한 장씩 넘겨 보는 삽화형 전자책 — 으로 만든다.
포맷은 AI City Builders "이북 서재"의 읽는 이북 구조를 그대로 재현한다.

## 이 스킬이 만드는 결과물

- **단일 HTML 파일** 하나 = 책 한 권(보통 한 챕터). 자바스크립트로 한 페이지씩 넘긴다.
- **좌우 키 / 스와이프 / 차례 점프 / 쪽 이동 드롭다운** 네비게이션 내장.
- **영상 페이지**: 클릭하면 유튜브가 그 자리에서 재생. 선택적으로 **QR**.
- **프린트 → PDF**: 브라우저 인쇄 시 A4 한 페이지씩 끊겨 그대로 전자책 PDF가 된다.
- 글자는 **HTML 텍스트**로 렌더링(그림 속에 글자를 넣지 않는다 → 뭉개짐·수정불가 방지).

## 포맷의 핵심 — "한 섹션 = 한 페이지"

`#deck` 안에 `<section class="s ...">` 가 쭉 들어간다. **한 섹션이 화면 한 장(종이 1쪽).**
종이는 **A4 세로 비율(0.707)**. 폰트는 본문 **Noto Serif KR(명조)**, 제목·UI **Pretendard**.
색은 따뜻한 종이 팔레트(배경 `#eceae5`, 종이 `#fdfcfa`, 잉크 `#15130f`, 포인트 앰버 `#c8811f`).

### 페이지(섹션) 7유형

| 유형 | 클래스 | 용도 | 핵심 요소 |
|---|---|---|---|
| 표지 | `s cover on` | 책 첫 장 | `kick`·`covfig`(커버 이미지)·`h1`·`rule`·`lede`·`by` |
| 차례 | `s alt` | "이 챕터에서" | `tochead`·`toclist`>`tocrow`(번호+제목+부제, `data-go`) |
| 챕터 오프너 | `s open` | 절 시작 | `chopen`>`chnum`(번호)·`h2`·`chsub`·`rule mid` |
| 본문(글) | `s ` | 설명 한 쪽 | `h3` + `prose`(짧은 문단 2~4개) |
| 본문(그림+글) | `s ` | 삽화 한 쪽 | `h3` + `fig`(이미지) + `prose` + 선택 `note` |
| 영상 | `s alt` | 절 끝 영상 | `vidpg`>`vwrap`(`data-v`=유튜브ID) + 선택 `vqr`(QR) |
| 맺음/CTA | `s open` | 다음 챕터 안내 | `kick`·`h2`·`chsub`·`cta`(링크) |

> `alt` = 배경이 살짝 다른(wash) 종이. 차례·영상 페이지에 쓴다.
> 모든 섹션에 `data-label="절 이름"` 을 넣으면 쪽 이동 드롭다운에 그 이름이 뜬다.
> `.foot` 의 `.pnum` 과 드롭다운 옵션은 **JS가 자동으로 채운다**(직접 번호 안 매겨도 됨).

본문 안에서 쓸 수 있는 블록(따옴표·수식·코드·표·콜아웃 등)은 `assets/page-blocks.md` 참고.

## 콘텐츠 작성 원칙 ⭐ (포맷보다 이게 더 중요)

읽는 이북은 **강의 녹취록이 아니다.** 빽빽한 설명을 쪼개 **한 쪽에 한 가지 생각만** 담는다.

1. **한 페이지 = 한 메시지.** 문단 2~4개, 한 문단 2~3문장. 여백이 많아야 "읽힌다".
2. **이야기 톤.** "이 강의를 만들면서 계속 한 가지 생각을 했습니다…" 처럼 말 걸듯. 정의 나열 금지.
3. **짧게, 굵게.** 핵심 단어만 `<b>`. 문장은 짧게 끊는다. `word-break:keep-all`(한국어 어절 단위 줄바꿈)이 기본.
4. **그림과 글을 번갈아.** 글만 2~3쪽 → 그림+글 1쪽 리듬. 그림은 개념의 비유/다이어그램.
5. **절 구조:** 표지 → 차례 → (챕터오프너 → 본문 여러 쪽 → 영상) × 절 → 맺음.
6. **절 끝에 영상.** 그 절 내용을 영상으로 한 번 더. 영상 없으면 생략 가능.
7. **제목은 후킹.** "인공지능은 함수다", "빌리는 쪽과 가진 쪽" 처럼 한 줄로 궁금하게.

## 제작 워크플로우

1. **재료 모으기** — 원 강의/글(요약·필기·대본), 책 제목, 저자, 브랜드, 절(챕터) 구성, 이미지, 영상 유튜브ID.
   - ⚠️ **저작권**: 남의 유료 강의 본문을 그대로 베끼지 않는다. **내 말로 다시 쓴 요약·정리**(2차적 학습자료)로 만든다. 이미지도 내가 만들거나 라이선스가 되는 것만.
2. **페이지 콘티** — 내용을 쪽 단위로 쪼갠다(위 7유형에 배치). "표지 / 차례 / 1절 오프너 / 1절-본문1 / 1절-본문2(그림) / 1절-영상 / 2절…".
3. **본문 다시쓰기** — 각 쪽을 이야기 톤 짧은 문단으로. (작성 원칙 준수)
4. **템플릿 채우기** — `assets/ebook-template.html` 을 복사해 `{{…}}` 를 채우고, 섹션을 콘티대로 늘린다. 각 섹션 `data-label` 지정.
5. **이미지 넣기** — 책 폴더 `img/` 에 두고 `src="img/파일.webp"`. (webp 권장)
6. **영상 넣기** — `.vwrap data-v="유튜브ID"`, 썸네일 `https://i.ytimg.com/vi/ID/hqdefault.jpg`.
7. **(선택) QR** — `python3 assets/qr.py 내책.html` (segno 필요). 안 쓰면 `.vqr` 블록 삭제.
8. **검증** — 브라우저로 열어 넘김·차례 점프·영상 재생 확인. (로컬 파일은 네트워크 없이 렌더됨)
9. **PDF** — 브라우저 **인쇄 → PDF로 저장** (A4). 그 파일 경로를 `#dl` 의 `href` 에 넣거나 `#dl` 삭제.

## 파일 구조(한 권)

```
mybook/
  index.html        ← 템플릿에서 복사해 채운 책
  img/
    cover.webp
    figure1.webp ...
  mybook.pdf        ← (선택) 인쇄로 만든 PDF
```

## assets

- `assets/ebook-template.html` — 바로 복사해 쓰는 완성 템플릿(전체 CSS·네비·JS·7유형 예시 포함). 그대로 열면 데모가 렌더된다.
- `assets/page-blocks.md` — 본문 블록 스니펫 모음(따옴표/수식/코드/표/콜아웃/출처/2단 차례/다중 챕터).
- `assets/qr.py` — 영상 페이지 QR 자동 생성(선택, `pip install segno`).

## 하면 안 되는 것

- AI 그림 안에 글자를 그려 넣기(뭉개지고 수정 불가). → 글자는 HTML 텍스트로.
- 남의 유료 강의 본문·이미지 그대로 복붙 재배포. → 내 말로 다시 쓴 학습자료로.
- 한 쪽에 내용 몰아넣기. → 쪼갠다. 여백이 포맷의 핵심.
