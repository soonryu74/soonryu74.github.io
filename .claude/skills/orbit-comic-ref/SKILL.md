# orbit-comic-ref — 돌려 보는 만화 (2026-10-13 분석)

레퍼런스: eternityspring.github.io/ai-explorations/lost-cat-comic/ («寻猫 Lost Cat», 2026-10-11) · 같은 방식 «The Feed»(10-12).
**저장소에 라이선스 파일 없음 → 코드·그림을 복사하지 않는다. 구조만 참고하고 뷰어는 우리가 새로 짠다.**

## 1. 무엇인가
- 6컷 만화 한 페이지(3컷×2줄, 칸 경계가 비스듬). 각 컷이 사진이 아니라 **360° 회전 영상**이다.
- 컷을 **좌우로 끌면 인물 주위를 빙 돌아** 뒷모습까지 본다. 클릭하면 그 컷으로 확대, ↑↓ 로 다음 컷, 자동 회전 버튼.
- 망점(印刷 網點) 효과 토글, 해설 상자·말풍선·외침·의성어(중문+영문 2줄), 숨은 장난(전봇대 전단지를 누르면 날아와 «찾았음» 도장, 가방 밖 꼬리를 누르면 «야옹»).

## 2. 만든 순서
1. **컷 그림**: Qwen Image 2.1 로 6컷. 같은 인물·고양이 유지(인물 일관성). **인물 뒤에 벽·간판을 붙이지 말 것** — 돌아가면 가려서 뒷모습이 안 나옴.
2. **컷마다 360° 회전 영상**: MiniMax H3 (첫·끝 프레임 → 영상, «FLF2V/Ref2VA») + **360 Orbit LoRA**(커뮤니티, Pablo Dawson, 2026-09-27 공개, ComfyUI 워크플로).
   - 같은 그림을 **첫 프레임 = 끝 프레임**으로 → 한 바퀴 돌아 제자리(반복 재생 가능).
   - 공개 권장값: 768×768, 73프레임, 28스텝, CFG 없음, LoRA 세기 1.0. (레퍼런스는 컷당 123프레임 사용)
   - 학습: 가우시안 스플랫 회전 렌더 28개 → 기하가 안정. 정사각 비율 전제. 대상 범위(사람만? 제품·음식·건물도?)는 출처마다 다름 → 직접 시험.
3. **프레임 꺼내기**: 컷마다 JPG 123장(`000.jpg…`) 또는 «모든 프레임이 키프레임»인 mp4 1개. 레퍼런스는 둘 다 지원해 비교.
4. **웹페이지(three.js 0.160)**: 컷 = 평면 사각형, 드래그 각도 → 프레임 번호(각도/360×프레임수) → 그 장면을 텍스처로. 칸 테두리·망점은 셰이더, 글자는 캔버스에 그려 텍스처로 붙임. 마우스 위치로 페이지 전체가 살짝 기울고, 처음엔 여섯 컷이 차례로 살짝 흔들려 «돌릴 수 있다»를 알려 줌. 거친 프레임부터 받아(coarse→fine) 빨리 뜨게.

## 3. 그들이 적어 둔 교훈 (그대로 옮김)
- 매 컷 회전은 성립했다: 한 바퀴 돌면 원래 그림으로, 뒷모습도 그럴듯, 두 사람도 같이 돈다.
- **기본 프롬프트는 실내를 실외(풀밭·눈밭)로 바꿔 버린다** → 컷마다 «주변 360° 환경»(침실·시장)을 글로 적어 주면 고쳐진다.
- 그림 속 가림막(뒤의 벽·광고판)은 프롬프트로 못 없앤다 → **그릴 때부터 인물 뒤를 비워 둔다.**
- (The Feed) 넓은 맨바닥(테니스장)은 약점: 4번 중 3번 카메라가 머리 위로 올라가 뒤집힘, «카메라 수평 유지» 문구로도 안 됨 → 시드만 바꿔야. 인물 옆 소품이 몸에 «붙어» 따라 도는 일이 있음 → 시드 교체.

## 4. 우리 채널에서 — 할 수 있는 것 / 못 하는 것
| 단계 | 어디서 | 메모 |
|---|---|---|
| 컷 그림 | 미드저니 V8.2 Edit 모델(참조 4장으로 같은 인물 유지, midjourney-ref §4) · Gemini 이미지 | 인물 뒤를 비운 구도 · 정사각 |
| 360° 회전 영상 | **대표님 PC 의 ComfyUI** 또는 Floyo 같은 클라우드 ComfyUI | 이 서버는 GPU 가 없고 외부 모델 실행이 막혀 있음. 필요한 VRAM·요금은 미확인 → 쓸 때 확인 |
| 프레임 → 뷰어 | 이 서버(우리 코드) | mp4 를 받으면 ffmpeg 로 프레임 추출, three.js 페이지를 **새로 작성**해 GitHub Pages 에 올림 |
| 쇼츠 영상화 | 이 서버 | 회전 영상 자체를 9:16 으로 + 자막·말풍선(talk-studio 자막 방식) · 또는 뷰어 화면을 Playwright 로 녹화 |

**콘텐츠 각도(노모어매뉴얼)**: «사진 한 장 → 360도 돌려 보는 만화» = 남들이 안 다룬 조합 + «이런 것도 되는 줄 몰랐다». 50대 이상: 손주·반려동물 사진으로(본인 사진만, 동의 받은 사진만). 30~40대: 제품 사진 360° 상세페이지, 1인 창업 쇼핑몰.
**주의**: 실존 인물 사진은 본인 동의 필수 · 미드저니 Edit 결과는 Stealth 아니면 공개 · 레퍼런스 코드·그림 복사 금지(라이선스 없음).
