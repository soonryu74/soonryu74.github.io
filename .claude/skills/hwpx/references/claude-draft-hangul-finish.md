# 클로드 원고 작성 → 한글 마감 워크플로우 규칙

"클로드로 원고를 쓰고, 한글(한컴오피스)에서 마감한다." 이 스킬이 만드는 HWPX와 사용자가 한컴에서 마감하는 결과가 같은 서식 규칙을 따르도록, 공무원 현장 표준 도구인 범정부오피스의 결과물 규칙을 정리한다.

범정부오피스는 행정안전부 이경수 주무관(간호직, 유튜브 「공무원코딩」 @publicCoding)이 만든 한컴오피스 자동화 도구로, 중앙부처·지자체·공공기관 20여 곳에 배포되어 공무원이 "버튼 하나로" 만드는 서식이 사실상의 현장 표준이 되었다. 이 스킬이 만든 HWPX가 같은 규칙을 따라야 사용자가 한글에서 마감 편집을 해도 서식이 튀지 않는다.

근거 자료(2026-09-21 수집):

- 공식 매뉴얼 「범정부오피스 1100일차 매뉴얼」(2025. 11, 91쪽, 소통24 배포) — 1차 근거
- 「범정부오피스 가이드 Ver1.0」(youtu.be/k5wYQGSEIJ8, 2024-07, 조회 4만) 자동 자막 + 상위 댓글
- 채널 영상 204편 제목·설명 목록, 서울신문 인터뷰(2025-11), 행안부 「행정업무 자동화 안내서」 사례편
- 대부분의 영상은 음성 없이 BGM + 화면 녹화라 자막이 없다. 버튼 이름·수치는 매뉴얼을 우선하고, 자막에서만 나온 값은 "추정"으로 표시했다.

## 1. 텍스트 → 서식 DSL ("G서식변신") — 최우선 반영

범정부오피스의 핵심은 **접두 키워드만 붙인 평문**을 한 번에 행안부 서식으로 바꾸는 것이다. AI 답변을 이 형식으로 받아 붙여넣고 버튼 한 번으로 마감하는 흐름이 매뉴얼 4.5절에 있다. 댓글에서도 "클로드로 작성 → 한글에 붙여넣고 서식 변신 = 최고의 궁합"이라는 사용 사례가 확인된다. 이것이 「클로드 원고 작성 → 한글 마감」 워크플로우다.

| 접두 키워드 | 결과 서식 | 서체·크기(매뉴얼) | 비고 |
|---|---|---|---|
| `제목:` | 제목 띠(회색 배경 박스, 가운데) | 굵게 | 한 페이지 보고서 제목 |
| `배경:` | 글상자(테두리 박스) | 본문 | 요약·배경 박스 |
| `소제목:` | 번호 소제목 `1 ▍카페 개요` (파란 번호 블록 + 밑줄) | 굵게 | 장 구분 |
| `네모:` | `□ 내용` | HY헤드라인M 16 | □ 뒤 한 칸 |
| `원:` | `  ○ 내용` | 휴먼명조 15 | 내어쓰기 |
| `바:` | `    - 내용` | 휴먼명조 15 | 내어쓰기 |
| `당구장:` | `      ※ 내용` | 맑은 고딕 12 | 참고 |
| `별:` | `      * 내용` | 맑은 고딕 12 | 주석 |
| (버튼) 윗첨 | `단어*` 윗첨자 별표 | | 각주 표시 |

스킬 반영 방향:

- 이 스킬의 요약보고 글머리 표([yoyak-bogo-style.md](yoyak-bogo-style.md))와 단계 구조가 같다. 차이는 ※·* 크기(범정부오피스 12 / 스킬 13)뿐이므로 공무원 문서 기본값을 **12**로 맞추거나 프로파일 옵션으로 둔다.
- 새 입력 경로 후보: `제목:/배경:/소제목:/네모:/원:/바:/당구장:/별:` 접두 원고를 그대로 받아 v2 블록으로 변환한다. 모델이 이 형식으로 원고를 쓰면 (1) 스킬로 HWPX 생성, (2) 사용자가 한글에서 마감, 두 경로가 모두 열린다.
- 출력도 같은 형식으로 내보낼 수 있으면 사용자가 한글 안에서 버튼으로 이어서 마감할 수 있다.

## 2. 미세 서식 규칙 ("딸깍정리 / 범위정리")

범정부오피스 「딸깍정리」는 커서가 있는 줄 하나, 「범위정리」는 블록 전체를 아래 규칙으로 정리한다. 스킬 생성 단계에서 같은 규칙을 적용하면 사용자의 후편집이 줄어든다.

| 규칙 | 내용 |
|---|---|
| 괄호 안 글자 | `(글자들)`는 본문보다 **-2pt** (공문서 규정의 "2포인트 이내 축소"와 일치) |
| 강조 (진) | `(강조내용)` 괄호 + 굵게 |
| 강조 배경 | 연노란 배경 + 굵게 (표 밖 강조 허용 범위: 글자색·밑줄·굵게. 배경색은 범정부오피스 관행이며 규정상 표 안 강조에 해당하므로 남용하지 않는다) |
| 어절 단위 | 줄 끝에서 어절이 잘리지 않게(BreakNonLatinWord 해제) + **자간 -10** |
| 내어쓰기 | 글머리 뒤 첫 글자에 둘째 줄을 맞춘다 (스킬의 "접두 공백과 내어쓰기는 짝" 규칙과 동일) |
| 기본글자 | 굵게·이탤릭·밑줄·색을 모두 걷어낸 초기화 상태를 기준으로 서식을 다시 입힌다 |
| 글자 간격 자동 조절 | 채널 초기 명칭 "자간헌터": 한 줄 넘침을 자간 축소로 흡수 (최대 -10, 규정 한도) |

## 3. 숫자·날짜·금액 표기 (버튼 결과 = 표기 규칙)

| 기능 | 입력 → 출력 | 스킬 반영 |
|---|---|---|
| 금액 한글화 | `12340` → `금12,340원(금일만이천삼백사십원)` | 공문서 규정과 동일. 계약·품의 문서 lint 항목으로 추가 가능 |
| 만나이 | `930705` → `930705(31)` | 생년월일 뒤 괄호 만나이 |
| 날짜 | `20260101` → `2026. 1. 1.(목)` | 연월일 뒤 마침표+공백, 요일 괄호. 스킬 날짜 정규화 기본형 |
| 오늘/다음주간/다음월간 | `2025. 6. 27.(금)`, 기간 `~` 표기 | 주간보고·월간계획 자동 기간 |
| 콤마 | 세 자리 콤마 | 표 셀 숫자 기본 |
| 순번 | 좌상단 값 기준 +1 채움 | 연번 열 |
| 역방향 합계 | 아래→위 방향 합계 | 합계행이 위에 있는 행안부 표 관행 |
| 단위 캡션 | 표 우측 상단 `(단위: 원)` / 날짜 캡션 | 표 캡션 위치·형식 기본값 |
| 증감 B-A | `'24년 - '23년` 값을 증감 열에 | 증감 열 자동 계산 |
| 음수 표기 | 음수는 `△30` (△ 접두), 양수는 부호 없음 | 행안부 표 관행. `-` 대신 △ |
| 증감률 | `50.0%`, 음수 `△15.0%` | 소수 첫째 자리 기본 |
| %p | `50.0%p` | 비율의 차이는 %p |
| 방향 기호 | `▲▽`, `↑↓` 옵션 | 증감 시각화 |
| 단위 증감 | `2.5→3.5 단위 정수`, `68.7kg>73.1kg 단위 소수` | 단위 유지한 증감 문장 |
| 다중 비율 | 항목별 비율 자동 계산 | 표 후처리 |
| 표 대량계산 | 나누기(만 단위 환산), 반올림(소수 첫째 자리) | 인구통계 표 만들기 사례 |
| 직제순 정렬 | 엑셀에서 직제 순서대로 정렬 | 기관 명단 표 |

## 4. 표 서식 ("행안부 서식")

「표서식」·「표정리 All In One」 버튼의 결과:

- 머리행: 연한 파랑 배경 + 굵게, 본문 셀 흰색. (스킬 요약보고 표의 `#DFE6F7`과 같은 계열. 정확한 색값은 실측 필요.)
- 글꼴 맑은 고딕, 가운데 정렬, 엑셀에서 온 공백·색·표선 제거.
- 셀 너비를 문서 여백에 맞게 자동 조정("알아서 맞춤"), 여백을 넘어간 표를 여백 안으로.
- 표 변형 프리셋(표탭·표세부탭, 가이드 영상 자막 기준 — 추정):
  - **겉바속촉**: 바깥 테두리 굵게, 안쪽 선 얇게. 범정부오피스의 대표 표 스타일.
  - **투명표**: 선 없음(조직도·배치도·사진표 뼈대).
  - **샌드위치**: 위·아래 굵은 선만, 세로선 없음. 하단선만 진하게 변형도 있음.
  - **점선 아랫줄**, **줄 늘리기/지우기/반으로 가르기**, **같은 너비/같은 높이**, **셀 여백 0**, **상·중·하 정렬**, **한 줄 설정/취소**.
  - **셀 높이 복사/붙여넣기**, **단(칸) 번갈아 색칠**, **자주 쓰는 표 배경색 모음**.
  - **다리 모양 굵은선**(ㄷ자 연결선) — 조직도 연결.
- **사진표**: 사진 2·3장 선택 → 위·아래 진한 선 사진표. `<설명>` 행이 있는 표는 **파일명의 괄호 안 내용**이 캡션으로 들어간다(파일명 규약). 투명표 소·중·대, 점선표, 2단·3단 변형. "사진 배경 넣기(셀 배경으로 채움)"와 "사진 비율 넣기(비율 유지 삽입)"를 구분한다.
- **보고자 표(머리말)**: 우측 상단 머리말에 `날짜 | 국장(폰) / 과장(폰)` 등 3종 형태. `~과/사무관(010)`, `실장·과장·과장(폰번호)` 세로형. 머리말 여백 조정·제거 버튼 동반.
- **회의명판·참석자 명단·회의실 배치도**: 참석자 명단 표 → 명판(PPT/150×70/200×80) 및 배치도(1315호 회의실 등) 자동 생성. 명단 표 → 배치 도식은 v2 `diagram` 블록 입력으로 적합.
- **조직도**: 14칸 투명표 → 범위 병합 + 진한 테두리 + 다리 모양 선 + 파스텔 배경(연녹·연파·연주황 등 8색 템플릿). N단 M층 지정. 스킬의 표 기반 도식([visual-elements.md](visual-elements.md))과 같은 원리이므로 "조직도" 프리셋으로 추가 가능.
- **시간계획표**(매뉴얼 4.5 예): `시간 | 주요 내용 | 비고`, 소요시간 `5'` `20'` 표기, 내용 셀은 `·` 글머리, 머리행 음영.
- 그 밖의 표 서식 버튼: 순서도, 행사계획표, 진행표, 핵심표, 예산금액표, 추진일정표, 글상자, 참고 박스, 행정안전부 로고.

## 5. 한 페이지 보고서 골격 (매뉴얼 4.5 결과물)

```
[제목 띠] 범정부오피스를 활용한 공무원 업무자동화 영상회의 개최 계획
◇ 요약 박스(글상자)                          ← 선택
□ 회의개요
  ○ 목적: …
  ○ 일시/방식: 2025. 8. 11.(월) 14:00~16:00(120') / 영상회의(온나라이음)
  ○ 참석: 정부혁신국장, 행정제도과장, 관련 과장, 담당부서장 등
      * 중앙행정기관 및 지방자치단체(17개 시·도, 226개 시·군·구)
      ※ 온나라 PC영상회의 인원수 제한으로 기관별 1명 참석 가능
  ○ 주요내용
    - …
□ 시간계획
  [시간 | 주요 내용 | 비고] 표, 5'/20'/60' 소요시간
```

일시 표기 `2025. 8. 11.(월) 14:00~16:00(120')`, 소요시간 `(120')`, 참석 범위 `*` 주석 + `※` 참고의 조합이 전형이다. 스킬 brief-report 예시와 lint 기대값에 반영할 수 있다.

## 6. 붙여넣기 정리 규칙

- **엑셀 → 한컴**: 불필요한 공백·배경색·표선 제거 → 행안부 표 서식 → 맑은 고딕·가운데·머리행 굵게 → 셀 너비 여백 맞춤. 스킬이 HTML/CSV 표를 받을 때 같은 정규화를 기본으로 한다.
- **PDF → 한컴**: 줄 끝 강제 엔터 제거, 이중 공백 제거, 자간 정리. 스킬의 원문 보존 조립기에서 PDF 추출 텍스트를 넣을 때 같은 전처리를 둔다.
- **다중 날짜 변환**: 표 안 여러 날짜를 `2026. 1. 1.` / `'26. 1. 1.` / `1. 1.(목)` 등 한 서식으로 일괄 통일. 보고서 안 날짜 서식 혼재는 lint 항목 후보.
- **다중 교체**: 열 단위 `"충청북도"→""`, `"시"→""` 같은 접두·접미 일괄 제거.
- **용량 축소 저장**: 사진 포함 문서 11MB → 1.3MB. 스킬 이미지 삽입 시 해상도 상한을 두는 근거.

## 7. AI 초안 워크플로우와 보안 주의 (매뉴얼 4.4~4.5)

- 흐름: 「편리탭 → ChatGPT 프롬프트」에서 문서 유형 버튼(예: 영상회의 개최계획) → `[입력내용]`만 채운 프롬프트 복사 → 답변을 한컴에 붙여넣기 → 전체 블록 → G서식변신.
- 프롬프트는 문서 유형별 골격(개요·목적·일시·참석·주요내용·시간계획)을 고정하고 사용자는 사실만 채운다. 스킬의 "사실은 추측하지 않고 unknowns로" 원칙과 같다.
- 보안 주의: 비공개 정보·개인정보·의사결정 미완료 정보·미공포 정보·외부 반출 불가 정보를 AI에 입력 금지. 생성 답변은 사실 검증 없이 사용 금지. 스킬 안내문에 같은 문구를 둘 수 있다.

## 8. 기관별 버전(프로파일)

행안부(기본서식 탭), 서울교통공사, 경상남도, 충청남도, 인천국제공항, 한국산업인력공단, 한국농어촌공사, 제주교육청, 남해군, KISA 등 기관별 빌드가 따로 있다. 차이는 전용 글머리·전용 서체·점선 번호·문서 여백·서식 모음(약식보고서, 표지, 보고서, 보도자료, 의원요구자료 등)이다.

- 문서 여백(가이드 영상 자막, 추정): "여백 10/20 표준화"와 "12.7/18" 두 세트가 버튼으로 있다. 정확한 상하좌우 대응은 실측 전까지 확정하지 않는다.
- 스킬 반영: 프로파일(`profiles/*.json`)에 기관별 글머리·서체·여백·서식 모음을 두는 구조가 범정부오피스의 배포 방식과 일치한다. 기관 프로파일이 없으면 행안부 기본을 쓴다.

## 9. 사용자 요구(댓글·채널 반응)에서 읽는 우선순위

- 가장 반응이 큰 기능: 엑셀표 정리, 금액 한글화, 글머리 일괄 지정, 조직도, 보고자 표, 증감 계산, 사진표. 스킬도 이 순서로 품질을 검증하는 것이 효율적이다.
- 반복 질문: "사진 배경 넣기 vs 사진 비율 넣기 차이", "버튼 설명 툴팁", "자주 쓰는 기능 북마크". 스킬 문서도 기능 이름만이 아니라 결과 예시를 함께 보여야 한다.
- 워드 → 한글 변환 수요: "Claude가 워드로만 만들어 한글로 옮기느라 스타일 변환" 댓글. 이 스킬의 존재 이유와 정확히 겹친다.

## 10. 스킬 구현 후보 (분석 단계, 미구현)

| 우선 | 항목 | 형태 |
|---|---|---|
| 1 | 한글 마감용 접두 원고(`제목:/네모:/원:/바:/당구장:/별:`) → v2 블록 변환기 | `scripts/hangul_finish_text.py` 신규, one_shot 입력 유형 추가 |

## 미확인·주의

- 색상 코드, 문서 여백 수치, 표 선 굵기는 매뉴얼에 수치가 없고 화면 캡처와 자동 자막에 의존한다. 반영 전 실제 범정부오피스 산출 HWPX를 한 부 받아 실측하는 것이 맞다.
- 범정부오피스는 배포판 실행 파일(PyInstaller)이며 이용약관이 리버스 엔지니어링을 금지한다. 내부 템플릿을 추출해 쓰지 않는다. 규칙은 공개 매뉴얼·영상에서 관찰한 결과물로만 정리했다.
- 한글 마감 결과와 스킬 결과가 같은 규칙을 따르더라도 "같은 파일"은 아니다. 한글에서 마감 편집한 문서는 `linesegarray`가 다시 생기므로 스킬로 재편집 시 제거 규칙(SKILL.md)을 적용한다.
