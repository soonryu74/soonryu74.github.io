# 디자인 시스템 — 포스터 분석과 수치

## 참고 포스터("2026 청렴한 달") 해부

| 포스터 요소 | 느낌 | 템플릿에서의 대응 |
|---|---|---|
| 맑은 하늘 + 흰 구름 배경(위 진하고 아래 밝음) | 투명·정직·희망 | `sky` 그라데이션 `6B9BD2 → DCE9F6` + PIL로 만든 알파 구름 PNG(가장자리 페이드) |
| 좌상단 흰 테두리 박스 "Integrity Month / 2026" (가운데 점선) | 공식·신뢰 | `badge_box()` — 표지 `badge_label` / `badge_value` |
| 우상단 날짜 "2026.11.2(월) ~ 27(금)" | 정보는 조용히 | 표지 `date`, 흰색 18pt |
| 초대형 남색 제목 "청렴한 달" | 한 번에 읽히는 메시지 | `display` 76pt(1줄) / 62pt(2줄), 남색 `0D1F6B` |
| 네잎클로버 풍선 4개(노·초·파·분) + "1주~4주" | 순서·단계·친근함 | `balloon_cluster()` — 겹친 원 4개, 그림자, `tags` 라벨 |
| 아이콘 + 날짜 + 행사명, 점선 리더로 풍선에 연결 | 항목 → 대상 매핑 | `dotted()` 점선, `agenda`·`rows`의 점선 구분선 |
| 하단 남색 라벨 칩 "2026 청렴한 달 4week" + 4줄 목록(점선 구분) | 요약 카드 | `agenda` 타입 흰 카드 + 파스텔 칩 + 메타 + 텍스트 |
| 작은 사람 실루엣이 풍선을 끌고 감, 우하단 기관 로고 | 여백·겸손 | 브랜드명/태그라인(좌하), `brand.logo`(우하) |

핵심은 **"큰 제목 하나 + 색으로 구분되는 4개의 순서 + 나머지는 작고 조용하게"** 다. 정보가 많아도 위계가 3단(제목 / 순서 칩 / 설명)을 넘지 않는다.

## 색 토큰 (`PALETTE`, 스펙 `palette`로 덮어쓰기 가능)

| 토큰 | HEX | 쓰임 |
|---|---|---|
| navy | `0D1F6B` | 모든 제목·본문 글자, 칩 바탕 |
| navy_soft | `4A5A8F` | 설명 글자 |
| muted | `7C88AD` | 캡션·메타·푸터 |
| sky_top / sky_bot | `6B9BD2` / `DCE9F6` | 표지·마무리 배경 |
| (sky_light) | `AFCBE8 → DCE9F6` | 섹션·인용 배경 |
| (sky_strong) | `4F88C6 → C9DDF2` | 썸네일 배경(피드에서 눈에 띄게 조금 진함) |
| paper | `F4F8FD` | 본문 배경 |
| card | `FFFFFF` | 카드 |
| yellow / yellow_d | `EBD96E` / `C9A82A` | 1번째 순서. 위 글자는 **navy** |
| green / green_d | `A9CF6F` / `5F9A2F` | 2번째 |
| blue / blue_d | `7BB0DA` / `1F7FB5` | 3번째 |
| pink / pink_d | `EFA3B6` / `D9456B` | 4번째. `_d`는 기본 강조색(accent) |

대비 기준: 남색 글자는 `paper`·`sky_bot`·흰 카드 위에서 7:1 이상. `sky_top`(6B9BD2) 위에서는 약 4.5:1이라 **큰 글자(36pt+)만** 둔다. 작은 글자는 흰색으로(표지 날짜·배지).

## 레이아웃 격자

- 캔버스 13.333 × 7.5 in (1280×720 px와 동일 비율). 여백 `M = 0.7in`. 카드 간격 0.35~0.45in.
- 본문 제목 기준선: y 0.48~1.28in(30pt, 번호 원과 수직 중앙 정렬). 본문 시작 y 1.75in. 푸터 y 7.0in.
- 왼쪽 글 / 오른쪽 그림 비율 6.0in : 5.4in.
- 카드 모서리 반경 0.05~0.12(adjust 값), 칩은 0.5(알약). 그림자 `blur 9pt, dist 3pt, navy 16%`.
- 점선: `ROUND_DOT`, 두께 1.2pt(구분선, 색 `D3DCEC`) / 2.2pt(단계 연결, 남색).

## 하지 않는 것

- 제목 밑줄, 색 띠, 사이드바 스트라이프, 테두리만 있는 사각형 장식
- 글자색 3가지 이상, 슬라이드당 강조색 2곳 이상
- 글자를 이미지에 굽기(수정 불가·뭉개짐). 글자는 항상 pptx 텍스트
- 썸네일 글자에 외곽선·그림자·형광 하이라이트
- 파스텔 순서 뒤섞기(1=노랑 … 4=분홍)
- 크림/베이지 배경(이 템플릿의 "맑음"이 사라진다)

## 변형 팁

- 브랜드색이 따로 있으면 `palette.navy`만 바꾸는 것으로 시작한다. 파스텔 4색은 그대로 두는 편이 안전하다.
- 어두운 버전이 필요하면 `sky_top/sky_bot`을 `1B2A6B / 2F4A8F`로, 글자 `navy`를 `FFFFFF`로 — 단 본문 `paper`는 유지해 샌드위치 구조를 지킨다.
- 세로 포스터(1080×1920)가 필요하면 `W, H`를 7.5 × 13.333으로 바꾸고 `s_cover`만 세로 배치로 다시 짠다(현재 지원 범위 밖, 요청 시 확장).
