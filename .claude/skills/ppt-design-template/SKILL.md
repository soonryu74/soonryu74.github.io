# PPT 디자인 템플릿 (ppt-design-template)

참고 포스터("2026 청렴한 달")의 분위기 — **맑은 하늘 배경, 진한 남색 큰 제목, 노랑·초록·파랑·분홍 파스텔 풍선, 점선 리더, 둥근 라벨 박스** — 를
16:9 슬라이드와 유튜브 썸네일로 옮긴 템플릿이다. 글자는 전부 **편집 가능한 pptx 텍스트**이고, 폰트는 전부 **상업적 이용 가능한 무료 폰트**다.

## 결과물

| 결과물 | 만드는 법 | 비고 |
|---|---|---|
| 강의·발표용 `.pptx` (16:9, 13.333×7.5in) | 스펙 JSON → `scripts/build_deck.py` | 11가지 슬라이드 타입 조합 |
| 유튜브 썸네일 PNG 1280×720 | `type: "thumbnail"` 슬라이드 1장 → `scripts/render.py --thumb N` | pptx에도 남아 글자 수정 가능 |
| QA용 슬라이드 PNG / 요약 이미지 | `scripts/render.py deck.pptx --sheet` | 눈으로 넘침·겹침 확인 |

## 작업 순서

1. **내용 콘티부터.** 디자인보다 먼저 "한 장 = 한 메시지"로 쪼갠다. 강의 10~15분 분량 ≈ 8~12장. 흐름 예:
   표지 → 목차(agenda) → 섹션 → 숫자/문제 제기(stats) → 핵심 3가지(rows/cards) → 실습(two_col/steps) → 전후 비교(compare) → 한마디(quote) → 마무리 CTA(closing).
   사용자가 준 글이 길면 **요약·재서술**한다. 슬라이드에 문단을 붙여 넣지 않는다.
2. **스펙 JSON 작성.** 형식은 `references/spec-format.md`. 예시 `assets/example-lecture.json`, `assets/example-thumbnail.json`을 복사해 바꾸는 게 가장 빠르다.
   - 글자 수 한도(아래 표)를 지킨다. 넘으면 빌드 시 "경고(넘침 위험)"가 뜬다 — 경고는 **무시하지 말고 줄바꿈(`\n`)이나 축약**으로 해결한다.
   - 썸네일은 별도 스펙(1장짜리)으로 만들면 PNG 추출이 깔끔하다.
3. **빌드.**
   ```bash
   python3 <skill>/scripts/build_deck.py spec.json -o 결과.pptx --fonts-check
   ```
   `--fonts-check`에서 "✗ 미설치"가 보이면 `bash <skill>/scripts/install_fonts.sh` 를 먼저 실행한다(미리보기 폭이 달라지는 걸 막기 위함. pptx 자체에는 폰트 이름만 기록된다).
4. **렌더링 QA(필수).**
   ```bash
   python3 <skill>/scripts/render.py 결과.pptx --outdir qa --sheet     # 전체 요약 1장 + 장별 PNG
   python3 <skill>/scripts/render.py 썸네일.pptx --thumb 1 --outdir qa  # 1280×720 PNG
   ```
   요약 이미지를 **직접 열어 본다**. 체크: 글자가 상자 밖으로 나가는가 / 단어가 어색하게 끊기는가 / 카드끼리 닿는가 / 남색 글자가 진한 하늘 위에 있어 안 읽히는가. 문제가 있으면 스펙을 고쳐 다시 빌드한다(코드 수정이 아니라 스펙 수정이 먼저).
5. **전달.** pptx(+썸네일 PNG)를 사용자가 열 수 있는 위치에 저장하고, 쓴 폰트 4종 이름과 설치 안내(`references/fonts.md` 하단, 윈도우·맥 각각)를 한 줄로 덧붙인다. 받는 사람 PC에 폰트가 없으면 '맑은 고딕'으로 바뀌어 보이기 때문이다.

## 글자 수 한도 (한 줄 기준, 넘기면 경고)

| 자리 | 한도 | 이유 |
|---|---|---|
| 표지 제목 | 12자 × 최대 2줄 | 76pt 디스플레이체. 포스터처럼 "청렴한 달" 수준으로 짧게 |
| 썸네일 제목 | 8자 × 2줄 | 휴대폰 피드에서 읽히는 한계. 강조는 `[[단어]]` 한 곳만 |
| 슬라이드 제목 | 22자 | 30pt 한 줄 |
| 섹션 제목 | 16자 | 42pt |
| 행/카드 제목 | 28자 / 16자(3열) | 소제목은 한 호흡 |
| 단계(steps) 제목 | 12자 | 원 아래 2.9in 폭 |
| 인용문 | 24자 × 2~3줄 | 30pt |
| 본문 불릿 | 한 줄 30자 안팎, 4개 이하 | 16pt. 넘치면 장을 나눈다 |

## 디자인 원칙 (왜 이렇게 생겼나)

- **하늘 배경은 표지·섹션·인용·마무리·썸네일에만.** 본문은 아주 옅은 하늘색(`F4F8FD`) 종이. "샌드위치" 구조라 흐름이 생기고, 본문의 글자 대비가 보장된다.
- **남색 한 가지로 글자를 통일.** 제목·본문 모두 `0D1F6B`, 보조는 `4A5A8F`, 캡션 `7C88AD`. 글자색이 여러 개면 "정직하고 차분한" 톤이 깨진다. 강조색(기본 분홍 `D9456B`)은 **슬라이드당 한 곳**.
- **파스텔 4색은 '순서'를 뜻한다.** 1=노랑, 2=초록, 3=파랑, 4=분홍. 목차의 칩, 카드 번호, 단계 원, 표지 풍선이 같은 순서로 색을 쓰기 때문에 시청자가 "지금 3주차구나"를 색으로 안다. 임의로 색을 바꾸지 않는다. 노란 원 위 글자는 남색(흰색은 안 읽힘).
- **선 대신 점선·그림자·여백.** 제목 밑줄, 색 띠, 사이드바 같은 장식은 쓰지 않는다. 구분은 점선 리더(`dotted`)와 카드 그림자, 0.35in 간격으로 한다.
- **풍선 클러스터는 장식이자 목차.** `tags`에 "1주, 2주…" 또는 핵심 키워드 4개를 넣으면 표지·마무리·썸네일에 겹친 원 4개로 나타난다. 내용과 무관한 장식이 되지 않게 꼭 의미 있는 4개를 넣는다(없으면 숫자 1~4).
- **이미지 자리는 비워 두지 말고 자리표시자로.** `two_col`에 `image`가 없으면 파스텔 패널 + 캡션이 들어간다. 실제 화면 캡처 경로를 받으면 그 자리에 비율 유지로 들어간다.
- 전체 톤은 사용자의 브랜드 원칙과 같다: **신뢰·정직, 과장 없음, 따뜻한 선생님 말투.** 제목에 "기본기/총정리/사용법/기초/완벽 정리"를 쓰지 않고 "숨겨진/자동화/꿀조합/이거면 끝/몰랐죠?/무료" 중 어울리는 걸 쓰되 내용이 뒷받침될 때만 쓴다. 영어 용어는 한글 발음 병기("클로드 코워크(Claude Cowork)").

색·레이아웃 수치·포스터 요소 분석은 `references/design-system.md`.

## 폰트 (전부 무료·상업용 가능)

| 역할 | 폰트 | 용도 |
|---|---|---|
| display | Paperlogy 9 Black (페이퍼로지) | 표지·썸네일 큰 제목, 큰 숫자 |
| title | Paperlogy 8 ExtraBold | 슬라이드 제목 |
| head | Pretendard SemiBold (프리텐다드) | 소제목·칩 |
| body | Pretendard | 본문·캡션 |
| number | Gmarket Sans TTF Bold (지마켓 산스) | 숫자 칩·날짜·페이지 |
| impact | Black Han Sans (검은고딕) | 썸네일 `"impact": true`일 때 |

바꾸려면 스펙에 `"fonts": {"display": "Cafe24 Ssurround", ...}`. 라이선스 원문 요약, 다운로드 주소, **윈도우/맥 설치 명령**, 임베딩 안내는 `references/fonts.md`.

## 자주 생기는 문제

- **미리보기에서 한글과 숫자 사이가 벌어져 보인다** ("주 3 시간"): LibreOffice가 동아시아 문자와 숫자 사이를 자동으로 띄우는 렌더 특성. PowerPoint에서는 붙어 보인다. 무시해도 된다.
- **미리보기 글꼴이 고딕으로 바뀜**: 샌드박스에 폰트가 없다. `scripts/install_fonts.sh` 실행 후 다시 렌더. pptx 파일 자체는 손댈 필요 없다.
- **soffice가 멈춤**: `render.py`는 임시 프로필과 `SAL_USE_VCLPLUGIN=svp`로 실행한다. 직접 `soffice`를 치지 말고 스크립트를 쓴다.
- **`python-pptx` 없음**: `pip install python-pptx pillow`.
- **스펙 외 레이아웃이 필요하다**(예: 표, 차트): `build_deck.py`의 `Deck` 클래스를 import 해 `s_xxx` 메서드를 추가하거나, 가장 가까운 타입(cards/rows)으로 만든 뒤 PowerPoint에서 다듬도록 안내한다. 차트는 python-pptx `add_chart`로 네이티브 차트를 넣고 색은 `PALETTE`의 파스텔 4색을 쓴다.
- **사용자가 pptx가 아니라 "구글 슬라이드/키노트"를 원함**: pptx로 만든 뒤 가져오기(Import)를 안내한다. 폰트는 구글 슬라이드에 Pretendard·Black Han Sans·Do Hyeon·Jua가 기본 내장이라 그쪽을 `fonts`로 지정하면 깨지지 않는다.

## 전자책·강의에 쓸 만한 포인트 ("이 부분은 전자책에!")

- "슬라이드는 글자 수가 아니라 **호흡 수**로 센다 — 한 장에 한 호흡."
- "썸네일은 **4~8자, 두 줄, 한 단어만 강조**. 세 가지를 넘기면 낚시처럼 보인다."
- "무료 폰트도 **배포사 페이지에서 라이선스 원문**을 한 번은 읽자. 그게 신뢰를 파는 사람의 기본."
