# 카메라 · 편집 사전 — 찍는 법과 잇는 법 (메뉴가 아니다)

`scripts/core/camera.py`. 요소가 «나오는» 방식(appear)만으로는 장면마다 같은 리듬(튀어나오고 · 내려앉고 · 끝)이 된다.
영상다움은 **무엇을 어떻게 찍고(카메라) · 어떻게 잇느냐(편집)**에서 나온다. 장면마다 «이 장면은 어떻게 찍을까»를 먼저 정한다.
아래 «잘 맞는 자리»는 출발점이다. 더 나은 움직임은 새로 짜고, 좋으면 camera.py에 보탠다.

## 1. 쓰는 틀
```python
img = canvas.background(root)            # 아트보드 크기로 그린다 (화면보다 큰 아트보드도 된다 — 훑기용 무대)
appear.put(img, e, seg(lt, 0.2, 0.6), 'fade')   # 요소 등장 · fx 효과 …
c = camera.keys(lt, [(0, camera.full(img)), (1.5, camera.on(title, img, fill=0.7), '부드럽게')])
return camera.shoot(img, c, (W, H))     # 찍어서 화면 크기로
```
- 카메라 `Cam(cx, cy, z, rot)` = 아트보드의 (cx, cy)를 화면 가운데에 · z 배 · rot 도 기울기.
- `camera.on(요소, img, fill)` = 그 요소가 화면의 fill 만큼 차는 카메라. `dx · dy`(화면 비율)로 살짝 비켜 두면 삼분할 자리.
- `camera.keys(lt, [(t, Cam, 느낌), …])` — 느낌: `부드럽게`(기본) · `빠르게` · `선형` · `튕김`. **같은 시각을 두 번 적으면 그 순간 컷**.
- 장면 경계는 `frame(t)`에서 `camera.EDITS[이름](a, b, u)` 또는 효과 사전의 전환으로 잇는다(샘플 `examples/scenes_example.py`).

## 2. 찍기 — 장면 안
| 기법 | 쓰는 법 | 잘 맞는 자리 · 주의 |
|---|---|---|
| 밀고 들어가기 (푸시 인) | `keys` full → `on(e)` | 핵심 하나로 시선을 모을 때 · 설명이 끝나 갈 때 |
| 빠지기 (풀 아웃 · 공개) | `on(e, fill>1)` → full | **훅에 좋다** — 정체 모를 한 부분에서 전체가 드러남 · 흐려지지 않는다(아래 함정) |
| 훑기 (팬) | 큰 아트보드 + `at(x1,…)` → `at(x2,…)` | 길게 늘어선 흐름 · 타임라인 · 비교 · 아트보드를 화면보다 넓게/길게 짓는다 |
| 시선 옮기기 | `on(A)` → `on(B)` | A 다음 B (원인 → 결과 · 질문 → 답) · 둘이 같은 화면에 있을 때 |
| 끊어 다가가기 (펀치 인 컷) | 같은 시각 두 번: full → `on(e)` | 목록 항목 · 강조 단어를 «툭» 끊어 크게 · 리듬감 |
| 점프 컷 | 같은 시각 두 번: `on(A)` → `on(B)` | 빠른 나열 · 정보 몰아치기 · 음악 박자에 맞춰 |
| 천천히 흐르기 (드리프트) | `drift(c, lt, dur)` | **다 나온 뒤 머무는 동안** — 멈춘 화면을 살린다 · 가운데로 곧게 다가간다(옆으로 흐르기는 `dir=±1` 을 고를 때만) · ⚠ 이것만으로는 «카메라가 움직였다»가 아니다 |
| 기울기 (더치) | `Cam(…, rot=±5~12)` | 긴장 · 반전 · 장난스러움 · 바로 세우는 순간이 강조가 된다 |
| 손에 든 카메라 | `handheld(c, lt, amp)` | 현장감 · 실제 화면 재현 · 다큐 느낌 · amp 3~6 |
| 빠른 줌 (휙 줌) | `keys` 짧게(0.2~0.3초) + `shoot(…, mblur=직전 카메라)` | 놀람 · 강조 순간 · 효과음과 함께 |
| 초점 옮기기 | `defocus(img, [e])` 대상 바꾸기 | 같은 화면 안에서 A → B · 나머지를 흐려 시선 모으기 |
| 깊이 (패럴랙스) | `appear.put(…, off=camera.parallax(c, depth, img))` | 카메라가 움직일 때 배경 층은 덜(0.6) · 앞 층은 더(1.3) — 입체감 |

## 3. 잇기 — 장면 사이 (또는 장면 안 화면 교체)
| 편집 | 함수 | 잘 맞는 자리 · 주의 |
|---|---|---|
| 컷 | `cut` | 기본이자 가장 힘 있는 편집 — 박자에 맞춘 컷은 어떤 효과보다 세다 |
| 디졸브 | `dissolve` | 시간 흐름 · 부드러운 이어짐 · 비슷한 구도끼리(겹쳐 보이는 순간이 의미가 된다) |
| 딥 (검정 · 흰) | `dip` · `flash` | 큰 단락 · 시간 건너뜀 · flash 는 0.2초 안쪽(깜빡임 안전) |
| 밀어내기 | `push(dir)` | 같은 흐름의 다음 장 · 방향으로 진행감(→ 다음 · ↑ 위로 쌓기) |
| 덮기 · 걷어내기 | `cover` · `reveal` | 카드 넘기듯 · 앞 장이 남아 있는 느낌 |
| 줌 전환 | `zoom_cut(focus=)` | 한 점으로 빨려 들어가 다음 장면 — 다음 장면이 «그 안»일 때 |
| 흐려졌다 바뀜 | `blur_cut` | 생각 · 회상 · 차분한 단락 |
| 돌며 바뀜 | `spin_cut` | 경쾌 · 장난 · 반전 |
| 띠로 갈라짐 | `slice` | 리듬 있는 정보 전환 |
| 매치 컷 | (짓기) 앞 장면 끝과 다음 장면 시작에 **같은 자리 · 같은 모양** 요소를 두고 `cut` | 가장 영상다운 이음 · 캔버스에서 미리 맞춰 짓는다(canvas-rules §2-B 4) |
| 색 갈라짐 | `rgb_split` | 디지털 · AI · 강렬한 순간 — 짧게(0.3~0.4초) |
| 쾅 착지 | `impact` | 큰 단락의 시작 · 결과 공개 — 영상에 한두 번(자주 쓰면 쿵쿵거린다) |
| 방사형 흐림 | `zoom_blur(focus=)` | 한 점으로 빨려 들 듯 빠른 전환 — 줌 전환보다 짧고 세다 |
| 정육면체 | `cube(dir)` | «다음 장» · 같은 흐름의 옆 단계 — 상자를 돌리듯 |
| 블라인드 | `blinds(n, vertical)` | 목록 · 정보 화면 사이 — 정돈된 느낌 |
| 모자이크 | `pixelate` | 게임 · 디지털 · 화면 녹화 느낌 |
| 불타듯 번짐 | `burn(edge=)` | 회상 · 감성 · 필름 느낌 — 경계 색은 분위기에 맞춰 |
| 시계 바늘 | `clock` | 시간 · 단계 · 진행 — «그다음» |
| 늘어나며 밀기 | `stretch(dir)` | 경쾌한 다음 장 — 고무줄처럼 |
| 타일 뒤집기 | `tiles(cols)` | 정보 전환 · 여러 항목이 한꺼번에 바뀔 때 |
| 떨어져 튀기 | `drop` | 새 카드 · 새 화면이 «툭» 떨어질 때 — 장난스럽게 |
| 효과 사전 전환 | `fx.whip_box` · `iris_box` · `split_box` · `glitch_box` · `leak_box` · `bubble_wipe` · `zoom_through` · `page_flip_box` | box=(0, 0, W, H) · t0=0 · t1=1 로 화면 전체에 |

## 3-B. 크기 · 끝 화면 — 움직임이 «보이게»
- **장면마다 화면이 바뀔 만큼 움직이는 카메라를 하나 이상** — 배율이 1.15배 넘게 바뀌거나, 화면 폭의 12% 넘게 옮겨 가거나. 1.04~1.1배 다가가기 · 3% 흐르기만 있는 장면은 보는 사람에게 «카메라 없음»이다. `--check` 표의 «카메라 실제» 칸이 재 준다.
- 크게 움직이려면 **무대가 커야 한다** — 1.5배 넘게 들어가면 흐려지므로, 훑기 · 시선 옮기기 장면은 캔버스에서 아트보드를 화면보다 넓게/길게 짓고(canvas-rules §2-B 7), 들어가는 장면은 빠지는 쪽(on(e, fill>1) → full)으로 쓴다.
- **끝 화면** (다음 편집 직전) = ① 전체(`full`) ② 요소 가운데(`on(e)`) ③ 이유 있는 삼분할(`on(e, dx=…)` + 기획서에 이유). 손으로 찍은 좌표(`at(840, 590, 1.15)`)로 «그 근처»를 향하지 않는다 — 장면 끝이 애매하게 비대칭이 된다. 여러 요소를 함께 보려면 그 무리를 감싸는 상자로 `on((x, y, w, h))`.

## 4. 지난 영상에서 얻은 감 (상한이 아니라 판단 재료)
- **장면마다 찍는 법을 다르게.** 모든 장면이 «요소 차례로 등장 → 정지»면 아무리 효과를 얹어도 같은 영상으로 보인다.
- **움직임이 쉬는 장면도 있어야** 움직이는 장면이 산다 — 다만 «쉰다» = 정지가 아니라 천천히 흐르기.
- 카메라가 움직이는 동안 요소까지 크게 튀어나오면 둘이 서로를 죽인다 — 한 순간에 주인공 움직임은 하나.
- 편집도 같은 것만 이어지면 뻔해진다. 영상 전체에서 장면 경계마다 무엇을 썼는지 한 줄로 보고 고른다.
- 강조(휙 줌 · 펀치 인 · 흔들림 · 집중선)는 «여기가 핵심»일 때만 — 장면마다 쓰면 아무것도 강조되지 않는다.
- 소리를 맞춘다: 컷 · 점프 컷 = 박자 · 휙 줌 = whoosh · 밀어내기 = 짧은 whoosh · 디졸브 = 소리 없이(배경음이 잇는다).

## 5. 함정
- **1.5배 넘게 들어가면 흐려진다**(그려진 화면을 확대하므로). 크게 보여 줄 요소는 캔버스에서 크게 짓고, 카메라는 «빠지는» 쪽으로 쓰거나 그 장면 아트보드를 크게(예: 2배) 지어 `full`이 축소가 되게 한다.
- 카메라가 화면 밖(아트보드 바깥)을 보면 가장자리 색으로 채워진다 — `on(fill<1)`로 너무 빠지지 않게.
- `shoot(mblur=…)`은 n 장을 겹쳐 느리다 — 빠른 이동 순간에만. 다 나온 바탕은 `bake.memo`로 한 번만 그린다(motion-build §2-B).
- 큰 아트보드(훑기용)는 캔버스에서도 그 크기로 짓는다. 요소 좌표는 아트보드 기준 그대로.
