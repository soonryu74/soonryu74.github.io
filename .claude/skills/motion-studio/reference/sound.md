# 소리 — 효과음 · 긴 소리 · 배경음 · 배경음만 새로

소리도 화면처럼 **영상마다 다르게** 간다. 재료는 소리 파일이 아니라 **만드는 코드**라서, 길이를 마음대로 정할 수 있고 같은 이름을 불러도 높이와 결이 조금씩 달라진다.
sf2(GeneralUser-GS.sf2 · 스킬 밖)의 실제 악기와 효과음 뱅크를 쓰고, 필요한 소리는 합성해서 만든다. sf2 가 없으면 효과음은 같은 갈래의 합성 소리로 바뀌고, 배경음은 빠진다(check.py 안내).

| 무엇 | 어디 | 한 줄 |
|---|---|---|
| 효과음 81가지 · 묶음 7개 | `core/sfx.py` | `sfx.Kit('동화').put(트랙, 'enter', 초, g)` · 이름으로 `sfx.put_sfx(트랙, 'harp_up', 초, g)` |
| 긴 소리 | `core/crowd.py` | 함성 · 웅성웅성 · 웃음 · 발소리 · 비 · 바람 · 카페 (길이 마음대로) |
| 배경음 13장르 | `core/music.py` | `audio.bgm(구간, DUR, style='로파이')` |
| 믹스 | `core/audio.py` | `audio.mixdown(DUR, 경로, 배경음, 효과음 트랙, 대사)` |
| 배경음만 새로 | `bake --rebgm` · `scripts/rebgm.py` | §4 |
| 소리 지도 | `out/소리지도.json` · `scripts/soundmap.py` | §6 — 작곡된 음표 · 효과음 시각 · 대사 (화면에 «진짜 소리»를 그릴 때) |

목록 보기: `python3 <스킬>/scripts/core/sfx.py list` · `python3 <스킬>/scripts/rebgm.py --list`(장르)

## 1. 효과음 — 묶음 하나 + 자리
**한 영상 = 묶음 하나**가 출발점이다(키트의 `K.sounds`). 묶음 안에서는 소리 결이 맞고, 영상끼리는 묶음으로 달라진다. 내용에 더 맞는 소리가 묶음 밖에 있으면 이름으로 빌려 쓴다(벌점 아님).

| 묶음 | 어울리는 영상 | 결 |
|---|---|---|
| 경쾌 팝 | 정보 · 홍보 · 사진 쇼츠 | 공기 휙 · 나무 톡 · 물방울 퐁 · 마림바 딩동댕 |
| 시네마 | 발표 · 공개 · 웅장 | 묵직한 바람 · 현악 휘몰이 · 팀파니 쾅 · 금관 빠밤 |
| 동화 | 그림책 · 손그림 · 아이 | 하프 쓸기 · 글로켄 · 첼레스타 반짝 · 오르골 |
| 테크·앱 | 앱 소개 · 사용법 · IT | 칼바람 · 탭 딸깍 · 신스 차임 · 808 둥 · 동전 |
| 코믹 | 웃긴 이야기 · 반전 · 실수 | 슬라이드 휘슬 · 뽁 · 띠요옹 · 퍽 · 빠바밤~ |
| 레트로 게임 | 8비트 · 픽셀 · 게임 | 레이저 · 동전 · 레벨 업 · 삐 |
| 차분 | 감성 · 다큐 · 인터뷰 | 숨결 휙 · 마림바 · 오르골 · 피아노 화음 |

자리(`SETS[묶음][자리]`): `cut` 전환 휙 · `enter` 하나씩 등장 · `emph` 강조 반짝 · `impact` 착지 쾅 · `done` 완성 · 마무리 · `tick` 넘김 · 박자.
- `Kit.put` 은 같은 자리를 부를 때마다 seed 를 바꾸고, 세 번마다 다음 후보로 넘어간다 → 같은 소리가 똑같이 되풀이되지 않는다.
- 옛 이름도 그대로 돌아간다: `audio.use('동화')` 다음 `audio.hit / tick / whoosh / chime` = 그 묶음의 착지 / 넘김 / 전환 / 완성. `mallet · bell` 은 음높이를 직접 정하는 한 음(오르는 음 등)이다.
- 갈래별 재료(81): 휙 · 전환 11 · 쿵 · 착지 11 · 톡 · 등장 12 · 반짝 · 강조 9 · 완성 · 짜잔 8 · 코믹 9 · 긴장 · 경고 6 · 글자 · 종이 6(타자기 · 키보드 · 펜 사각 · 종이 넘김 · 도장 · 셔터) · 현장 · 사람 6 · 숫자 3(오르는 틱틱 · 슬롯 · 계산대).
- 고르는 법: 화면에서 **무슨 일이 일어나는지**를 소리로 — 글자를 쓰면 펜 · 타자, 숫자가 오르면 숫자 소리, 사진이 내려앉으면 툭, 결과가 뜨면 완성. 모든 등장에 소리를 달지 않는다(강조할 곳만 · 2~3초에 하나 안팎).
- 크기 출발점(g): 전환 0.4~0.5 · 등장 0.4~0.5 · 강조 0.5~0.6 · 착지 0.7~0.8 · 완성 0.55~0.65. 나레이션이 있으면 한 단계 낮게.

## 2. 긴 소리 — 길이를 마음대로 (`crowd.py`)
| 함수 | 소리 | 쓰는 곳 |
|---|---|---|
| `cheer(초, 사람)` | «와아—» 함성 | 결과 발표 · 우승 |
| `murmur(초, 사람, far)` | 웅성웅성 (알아들을 수 없는 말소리) | 행사장 · 교실 · 시장 |
| `laugh_crowd(초)` | 여럿이 웃음 | 웃긴 장면 뒤 |
| `whistle_crowd(초, n)` | 휘파람 «휘익~» | 환호에 얹기 |
| `footsteps_walk(초, pace)` | 걷는 발소리 | 다가감 · 이동 |
| `rain(초) · wind(초) · cafe(초)` | 비 · 바람 · 카페 | 분위기 깔기 (작게 · 0.15~0.3) |

- 효과음 트랙에 `audio._put(트랙, crowd.cheer(3.5), 초, 0.5)` 처럼 얹는다.
- ⛔ 박수(`applause*`)는 아직 박수답지 않다(빗소리처럼 들림 · 유저 확인) — 쓰지 않는다. 박수가 꼭 필요하면 영상 원본 소리나 유저가 준 녹음을 쓴다.

## 3. 배경음 — 장르 13가지 · 영상마다 새 곡 (`music.py`)
| 장르 | 빠르기 | 어울리는 영상 |
|---|---|---|
| 경쾌 팝 | 112~124 | 홍보 · 정보 · 사진 쇼츠 |
| 밝은 설명 | 100~112 | 설명 · 기업 · 사용법 (선율이 말을 덮지 않게) |
| 일렉 · 테크 | 122~128 | IT · 앱 · 빠른 소개 |
| 시네마틱 | 84~100 | 발표 · 공개 · 웅장 · 예고 |
| 동화 | 100~112 (3박) | 그림책 · 손그림 · 아이 |
| 로파이 | 72~86 | 공부 · 일상 · 브이로그 · 차분한 정보 |
| 어쿠스틱 | 96~112 | 여행 · 일상 · 따뜻한 이야기 |
| 재즈 라운지 | 118~140 | 카페 · 음식 · 세련된 소개 |
| 펑키 | 100~112 | 재미 · 패션 · 리듬감 |
| 레트로 게임 | 140~160 | 게임 · 픽셀 · 장난 |
| 긴장 · 미스터리 | 92~108 | 반전 · 비밀 · 문제 제기 |
| 감성 피아노 | 70~84 | 감동 · 회고 · 인터뷰 |
| 축하 · 행사 | 118~130 | 축하 · 기념 · 시상 |

- 부르기: `audio.bgm([(시작, 끝, 무드 또는 세기, {hits: [초]}), …], DUR, style='장르')` — 무드는 옛 이름 그대로(sting · intro · calm · groove · bouncy · build · drop · main · tense · outro · hush), 숫자면 세기(0 잔잔 · 1 반주 · 2 선율 · 3 전부 · -1 비우기).
- `hits` = 정확한 순간 쾅(제목 · 결과 공개) · `sting` 구간 시작도 쾅.
- 같은 장르도 **seed 마다** 조 · 선법 · 빠르기 · 진행 · 리듬 · 악기 · 선율이 달라진다. 장르 이름은 앞 글자만 써도 된다(일렉 · 긴장 · 축하).
- 장면 경계 → 가까운 마디에서 세기가 바뀌고, 그 직전 마디에 필인 · 바뀐 첫 박에 심벌. 끝은 으뜸화음으로 닿고 서서히 줄어든다(mixdown 의 끝 페이드와 겹쳐도 된다).
- 장르는 키트의 `K.music` 이 출발점 — **내용과 액션 분위기**(시작 카드)로 고른다. 기획서 §5 «소리» 칸에 장르 · 효과음 묶음을 적는다.
- 나레이션이 있으면 `밝은 설명 · 로파이 · 감성 피아노` 처럼 선율이 성긴 장르가 말을 덜 덮는다(mixdown 이 대사 동안 배경음을 내린다).

## 4. 배경음만 새로 — 이미 만든 영상
유저: «배경음만 바꿔 줘» · «음악만 로파이로» · «다른 곡으로».
**motion-studio 로 만든 영상** (작업 폴더에 scenes.py 가 있다):
```
python3 scenes.py --rebgm 로파이            # 장르를 바꿔 새 곡
python3 scenes.py --rebgm                   # 장르는 그대로 · 다른 곡
python3 scenes.py --rebgm 로파이 --seed 1480  # 마음에 든 곡을 그대로 다시 (끝에 찍히는 seed)
```
- 화면은 다시 굽지 않는다(구운 mp4 의 화면을 그대로 쓴다) — 몇 초면 끝난다. 효과음 · 나레이션 · 원본 영상 소리는 그대로, 배경음만 바뀐다.
- 결과 = `out/<제목>_새배경음.mp4` (원본은 그대로 · 같은 이름이 있으면 _2 · _3). 유저 컴퓨터에서 구웠으면 명령 한 줄을 준다.
- 옛 버전 스킬로 만든 영상도 된다 — 장면 코드의 `audio.bgm` · `hit` · `tick` 이 새 엔진으로 나간다(효과음도 새 소리가 된다는 것을 한 줄 알린다).

**그 밖의 영상** (장면 코드가 없는 mp4):
```
python3 <스킬>/scripts/rebgm.py 영상.mp4 --style 로파이 [--keep 0.9] [--at 5,7.5,24.9] [--seed N]
```
- `--keep 0` = 원래 소리 빼고 배경음만 · 기본 0.9 = 원래 소리 그대로 + 소리가 큰 동안(말 · 박수) 배경음이 내려간다.
- 장면 바뀜은 화면이 확 바뀌는 곳을 찾는다(`--cuts 0.2`) · 시각을 알면 `--at` 이 정확하다.
- ⚠️ 원래 소리에 이미 음악이 섞여 있으면 겹친다 — 그럴 땐 `--keep 0` 이나 motion-studio 작업 폴더의 `--rebgm`.

## 5. 함정
- 같은 효과음을 `sfx.make(이름)` 으로 seed 없이 여러 번 부르면 똑같이 들린다 → `Kit.put` 이나 seed 를 바꿔 부른다.
- 효과음을 모든 요소에 달면 시끄럽다 — 소리를 꺼도 읽혀야 하고, 효과음은 더하기다.
- sf2 가 없으면 배경음은 SystemExit(안내) → 장면 코드는 `try/except SystemExit` 로 배경음 없이 굽는다(예시 코드).
- 장르에 안 맞는 빠르기(bpm)를 주면 무시하고 장르 빠르기로 간다(옛 장면 코드의 bpm=118 같은 값).

## 6. 소리 지도 — 작곡된 음표 · 효과음 시각을 꺼내기
굽기(`--bake` · `--join` · `--draft`) · `--audio` 때 **`out/소리지도.json`** 이 저절로 생긴다(`--rebgm` 은 `소리지도_새배경음.json`). 피아노 롤 · «소리 지도» 같은 화면을 **진짜 값으로** 그릴 때 쓴다(가짜 그림 ⛔).
```
python3 <스킬>/scripts/soundmap.py out/소리지도.json      # 요약 + 한 장 그림 out/소리지도.png (피아노 롤 · 효과음 줄 · 대사 줄)
```
| 키 | 들어 있는 것 |
|---|---|
| `bgm` | 장르 · seed · bpm · 박자(beats) · 마디 길이(bar_sec) · 조(key_name) · 선법 · 진행 · 구간 세기(sections) · 쾅(hits) · 악기(역할 → sf2 이름) |
| `bgm.bars[]` | 마디마다 `t` · 세기 · 화음 · `first`(장면 첫 마디 = 심벌) · `fill`(다음이 장면 첫 마디 = 필인) · `last` |
| `bgm.notes[]` | 음표마다 `t`(초) · `dur` · `key`(건반 번호 · 60 = 가운데 도) · `vel`(세기) · `role`(lead 선율 · comp 반주 · pad · bass · extra 꾸밈 · drums) · 드럼이면 `drum`(킥 · 스네어 …) |
| `sfx[]` | 놓은 효과음마다 `t` · `name` · `role`(자리) · `gain` · `group`(갈래) · `desc`(쉬운 이름) |
| `voices[]` | 대사마다 `t` · `file` · `dur` |
- 효과음은 `sfx.Kit.put` · `sfx.put_sfx` · 옛 이름(hit · tick · chime · whoosh)으로 놓은 것이 다 기록된다(`audio.new_track` 이 기록을 새로 시작).
- 장면 코드에서 쓰기: `m = json.load(open('out/소리지도.json'))` → 영상을 만들 때 그 시각에 블록을 빛나게 · 음표 막대를 그리게. ⚠️ 소리를 먼저 만들어야 지도가 생긴다 — `python3 scenes.py --audio` 를 한 번 돌린 뒤 화면 장면을 짠다.
- 배경음 마디는 «가까운 마디»라 장면 경계와 조금 어긋날 수 있다(지도에 그대로 보인다) · 쾅(hits)은 정확한 시각.
- 코드로 직접: `y, info = music.song(…)` → `info['score']` · `music.export(info, 경로)` · `audio.save_map(경로, DUR)`.
