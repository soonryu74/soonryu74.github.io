# 시간 조작 — 킥 장치 (scripts/core/timewarp.py)

이 엔진은 «시각을 주면 그 순간을 다시 그린다». 그래서 되감기 · 슬로 · 멈춤도 화질 손실 없이 매끄럽다(편집 프로그램처럼 프레임을 지어내지 않는다).
★**효과가 아니라 이야기 구조일 때 산다** — 같은 출발점에서 갈라지는 두 줄기가 있어야 되감기가 «원점»으로 읽힌다. 한 편에 큰 시간 조작은 하나.

## 1. 쓰는 틀
```python
from core import timewarp as TW
WARP = TW.Warp([('play', 3.6), ('stop', 0.2), ('hold', 1.4), ('to', 0.0, 1.4), ('cut', 10.0), ('play', 16.6)])
def frame(t): return TW.render(WARP, t, src_frame, fps=FPS, flash=(255, 40, 70))   # src_frame(원본 시각) = 평소 장면 그리기
DUR = WARP.DUR
# 소리: 원본 시간으로 배경음 · 효과음을 만든 뒤 TW.audio(WARP, 원본소리, sr) → 출력 시각에 사건 소리(TW.buzzer · hit)를 얹는다
```
- 원본 시간에서 갈래를 나눈다: A = 0초부터 · B = 10초부터(겹치지 않게 띄운다) → 지도에서 `('cut', 10.0)`으로 넘어간다.
- 본보기: `examples/rewind_example.py` (아니지~ 다시 — A · B 두 줄기 · ✕ · 경고음)

## 2. 장치 사전
| # | 장치 | 지도 | 잘 맞는 내용 |
|---|---|---|---|
| 1 | 아니지~ 다시 | A play → stop → hold(✕ · 삐) → to(0, 1.2~1.8초) → cut(B) → play | 흔한 실수 vs 바른 방법 · 옛 방식 vs 새 방식 |
| 2 | 결과 먼저 → 되감기 | 완성 play → hold → to(0) → play | 사용법 · 만들기 과정 |
| 3 | 멈추고 짚기 | play → stop → hold(화살표 · 라벨) → start → play | «여기가 포인트» |
| 4 | 쾅 직전 슬로 | play → ramp(0.3배) → speed(0.3) → ramp(1배) | 결과 · 숫자 공개 · 반전 |
| 5 | 빨리 감기 | speed(4~8배) + 시계 · 카운터 | 긴 과정 압축 (수치는 원문 사실만) |
| 6 | 되감고 바꿔 보기 | play → to(0) → cut(옵션 2) → play → … | 옵션 · 스타일 비교 |
| 7 | 멈춘 채 카메라만 | hold 동안 카메라만 움직인다(src_frame 안에서 출력 시각으로 카메라) | 한 순간의 여러 부분 |
| 8 | 끝에서 처음으로 | 마지막 → to(0) → 첫 장면과 이어짐 | 쇼츠 무한 반복 |
| 9 | 앞뒤 흔들기 | to(앞) · to(뒤)를 짧게 두세 번 | «다시 봐 봐» · 리듬 |
| 10 | 편집기 화면과 함께 | 타임라인 · 재생 막대 UI가 지도와 같이 | 영상 · 편집 도구 사용법 |
| 11 | 닿을 듯 → 제자리 | play → ramp(0.1배) 목표 바로 앞 → hold(0.2~0.4) → to(출발, 0.4~0.6 · 짧고 빠르게) | 공개를 한 번 미루는 훅 · «결국 원점» · 반복 시도 → 성공 |

## 3. 지킬 것
- 한 편에 큰 시간 조작은 하나(킥) — 여기저기 쓰면 고급스러움이 사라진다.
- 되감기는 출발 화면이 같아야 읽힌다 → 캔버스 단계부터 A · B 출발 화면을 같게 짓는다.
- 소리가 따라와야 한다 — 배경음 · 효과음은 `TW.audio`로 같은 지도를 따라가게 · 경고음 · 쿵 같은 사건 소리는 출력 시각에 따로.
- ⛔ 나레이션은 지도에 넣지 않는다.
- 길이 출발점: 멈춤 1.2~1.5초 · «다시 한다» 되감기 1.2~1.8초 · «제자리!» 되감기 0.4~0.6초 · 쌓기 간격 0.35~0.4초.
- 되감기 표시는 `rewind_look='vhs'`(줄무늬 · 색 번짐 · ◀◀) 또는 `'clean'`(흐림만) — 키트에 맞게(차분 · 다큐 = clean).
