# 영상 넣기 — 유저가 준 영상(과 자막)을 재료로 쓴다

유저가 영상을 주면 그 영상은 **그림과 같은 재료**다. 구간을 잘라(몇 초~몇 초 · «남자 나오는 장면» 같은 설명 · 자막의 한 대목) 우리 디자인 화면 안에 넣고, 그 위로 카메라 · 전환 · 효과 · 배경음 · 효과음을 얹는다. 원본 소리도 살린다.
엔진은 «시각을 주면 그 순간을 다시 그린다» — 영상도 «시각마다 그림이 바뀌는 요소» 하나라, 여러 개를 동시에 틀고 카메라로 밀고 들어가고 멈추고 되감는 것이 모두 그대로 된다.
흐름은 평소와 같다 — 기획서 → 캔버스(유저 검수 · 메모) → 효과 계획 → 코드 → 굽기. 영상 때문에 단계가 새로 생기지 않는다.

> 바닥: 영상 속 사람 · 사물을 새로 그리거나 바꾸지 않는다(그림 생성 ⛔). 자르고 · 넣고 · 위에 얹는다.
> 권리: 남의 영상(영화 · 방송 · 광고)이면 처음 받을 때 한 줄만 말하고 되풀이하지 않는다.

## 1. 흐름 (기존 단계에 끼워 넣는다)
| 단계 | 할 일 | 도구 |
|---|---|---|
| ② 기획서 | `probe` → 길이 · 크기 · 소리 · `cuts` → 컷 나누기 → `sheet` 컷 모음표를 **Claude가 보고** 쓸 컷을 고른다 · 검은 띠는 `letterbox` | video.py |
| ② 자막이 있으면 | `subtitles` → `digest` 로 흐름을 먼저 읽고(§2-A) 전할 것을 정한 뒤, 포인트마다 근거 자막 줄 → 영상 구간 | video.py |
| ② 기획서 §3-V | **영상 컷 표**: 이름 · 원본 · 구간(초) · 잘라낼 화면(crop) · 보이는 것(고른 근거 · 자막 줄) · 소리(살림/줄임/뺌) · 장면 · 자리 | plan-format.md |
| ②-B | 보여 주는 방법을 고른다(§3 배치). 영상이 주인공이면 우리 디자인은 «틀 · 자막 · 짚기 · 전환»으로 받치고, 설명이 주인공이면 영상은 근거 장면(§3-B) | concept.md |
| ③ 캔버스 | 영상 자리에 **대표 장면 그림**을 올린다 — `poster()` → `재료/영상_<이름>.png`. 캔버스는 영상을 재생하지 못한다 → 이 그림이 «여기에 영상이 들어간다»는 표시. 유저는 칸의 자리 · 크기를 고치고 **메모로 구간을 줄 수 있다**(§2-B) | canvas-rules.md |
| ④ | 메모의 타임코드 · 멈춤 · 소리 지시를 영상 컷 표에 반영 → 바뀐 구간이면 대표 장면 그림도 다시 올려 확인받는다 | video.py `timecode` |
| ⑦ 코드 | `Clip(원본, a, b, crop)` → 장면 그리기 · 카메라로 찍은 **뒤에** `paste_on_screen` → 그 위에 글 · 짚기 · 화면 겹 | video.py |
| ⑦ 소리 | 원본 발언 = 목소리 쪽(배경음이 내려감) · 현장 소리 = 효과음 쪽(낮게 · 배경음은 그대로) | audio.py |
| 굽기 | 영상이 들어가면 무겁다 — **유저 컴퓨터에서 직접 굽기**를 권한다(§6) | bake.py |

설명으로 고르기(«남자 나오는 장면», «폭발하는 곳»): 컷 모음표(`sheet`)를 Read로 보고 컷 번호로 고른다. 한 컷이 길면 그 컷만 1초 간격 모음표를 다시 뽑아 좁힌다. 고른 근거(무엇이 보이는지)를 영상 컷 표에 적는다.

## 2. 쓰는 법 (video.py)
```python
from core import video as V
info = V.probe('재료/원본.mp4')                     # {'dur', 'w', 'h', 'fps', 'audio'}
cs = V.cuts('재료/원본.mp4', th=0.28)               # 컷 바뀌는 시각 (잘게 나오면 th ↑)
shots = V.sheet('재료/원본.mp4', cs, 'out/_shots.jpg')   # [(a, b), …] + 모음표 그림
box = V.letterbox('재료/원본.mp4')                  # 검은 띠 뺀 (x, y, w, h) — 로고 · 자막 띠는 손으로 더 뺀다
V.poster('재료/원본.mp4', 3.2, '재료/영상_첫컷.png', crop=box)   # 캔버스용 대표 장면

CL = V.Clip('재료/원본.mp4', 2.3, 8.2, crop=box)    # 구간 프레임을 .cache/video/ 에 한 번 꺼내 둔다 (동시 굽기에도 안전)
fr = CL.frame(lt)                                    # 구간 안 lt 초 그림 (loop=True 되풀이 · False 끝에서 멈춤)

img = C.shoot(바탕, cam, (W, H))                    # 평소대로 장면을 그리고 찍는다
e = V.find(els, '첫컷')                              # 캔버스에서 재료/영상_첫컷.png 를 쓴 요소 (자리 · 크기)
V.paste_on_screen(img, CL, lt, e, cam, focus=(0.5, 0.4), z=1.0, radius=0, dim=0.0)
#   ★카메라 뒤에 그린다 → 작은 칸을 화면 가득 키워도 원본 화질 (아트보드에 먼저 넣고 찍으면 흐려진다)
#   focus = 칸에 맞춰 자를 때 남길 자리(0~1 · 인물 쪽) · z = 칸 안에서 더 다가가기 · dim = 어둡게(0~1)
#   프레임에 손대려면(멈춤 색 바래기 · 번쩍) 먼저 fr 을 고치고 clip 대신 그 그림을 넘긴다
sig = V.sound('재료/원본.mp4', 2.3, 8.2); V.put_sound(voice, sig, at=4.0, fade=0.012, gain=1.0)
```
- `paste_on_screen` 은 기울기 없는 카메라 기준(`rot=0`). 기운 화면이 필요하면 칸 그림을 따로 만들어 돌려 붙인다.
- 영상 시각은 장면 시각과 따로다 — `clip_t(t)` 같은 작은 함수로 «언제 처음부터 · 언제 멈춤 · 언제 느리게»를 정한다. 멈춤 = 같은 lt 를 붙잡기 · 느리게 = lt × 0.5 · 되감기 = timewarp 지도를 lt 에 건다.
- 원본 발언 경계: 자막 시각은 말보다 앞서거나 겹친다 → 소리 크기를 0.1초 단위로 보고 말 사이 쉼에서 자른다. Claude 는 들을 수 없으니 유저에게 «말이 잘리는지 들어 봐 달라»고 한 줄.

### 2-A. 자막 · ★대용량 입력 (플랜B)
긴 영상 · 긴 자막 · 많은 장면 그림은 **통째로 읽지 않는다** — 줄여서 읽고, 고른 곳만 자세히.
```python
subs = V.subtitles('재료/원본.srt')     # [(시작, 끝, 문장)] — 겹치는 자동 자막 정리 · [음악] [박수] 빼기 (srt · vtt)
print(V.digest(subs, per=60, width=160))   # 분 단위 한 줄씩 → 흐름 · 구간 나누기는 이것으로
V.near(subs, '기초학문')                # 낱말이 나오는 줄 → 원본 발언 후보 시각
```
- 자막: `digest` 로 흐름표(시각 · 구간 · 핵심)를 만든 뒤, 쓸 구간만 `subs` 줄 단위로 다시 본다.
- 장면 그림: 처음엔 간격 넓은 작은 모음표(예: 90초 간격 · 320px) → 고른 구간만 촘촘히.
- 원본 영상: 큰 파일은 필요한 구간만 잘라 쓴다(유저 컴퓨터에서 ffmpeg 로 자르기 · 클라우드로 통째 올리지 않기).
- 자동 자막은 받아쓰기 오류가 많다 — 사람 이름 · 고유명사는 유저에게 확인하고, 화면 글은 뜻을 바로잡아 다시 쓴다(자막을 그대로 붙이지 않는다).
- 자막 파일이 없고 영상 위에 박힌 자막뿐이면 글자로 읽어 내기 어렵다 → 자막 파일을 달라고 한다.

### 2-B. 캔버스 메모로 구간 받기
영상 칸 옆 메모 «영상 3:12~3:15 재생» → `V.timecode(메모)` = `{'a': 192.0, 'b': 195.0, 'file': None}`. 영상이 여럿이면 «원본2 3:12~3:15»(file).
- 같이 오는 말: «3:40에서 멈추고 짚기» · «소리 살림 / 끄기» · «느리게» → Claude 가 읽어 영상 컷 표에.
- 구간이 장면보다 길면 장면 길이만큼 자르거나 장면을 늘린다(한 줄로 알림) · 짧으면 마지막 장면에서 멈춤 또는 느리게.
- 반영한 뒤 대표 장면 그림을 그 구간 장면으로 바꿔 다시 올린다 → 유저가 맞는 장면인지 캔버스에서 확인.

## 4. 소리
- **원본 발언은 목소리 쪽** — `mixdown(..., voices)`에 넘기면 배경음이 그 아래로 내려간다. 경계는 짧은 페이드.
- **현장 소리(말소리 · 박수 · 울림)는 효과음 쪽에 낮게**(gain 0.25~0.3) — 목소리 쪽에 넣으면 배경음이 계속 눌린다. 무음 구간이 길면 어색하다.
- 배경음은 끊기지 않게 — 무드 이름은 `audio.MOODS` 안에서(모르는 이름은 groove 로 바뀌고 알림).
- 원본에 이미 음악이 깔려 있으면 우리 배경음은 빼거나 아주 낮게(bgm_gain 0.2~0.35).
- 화면에 함께 도는 영상이 여럿이면 **집중한 화면 소리만** 낸다.
- 멈춤 구간은 원본 소리도 쉰다 → 그 자리에 쿵(hit).

## 5. 함정
- 영상은 카메라로 찍은 **뒤에** 붙이므로 영상 칸에 걸쳐 놓인 요소(스티커 · 배지)는 영상에 가려진다 → 그 요소만 영상 위에 한 번 더 얹는다(같은 카메라 변환으로).
- 캔버스 그림 src 는 `/_blob/<번호>`라 `video.find(els, '이름')`이 못 찾을 수 있다 → 기획서 §4 «번호 ↔ 원본»으로 번호를 직접 잇는다.
- **화질**: 원본을 화면에서 1.5배 넘게 키우면 뭉개진다(480p 를 1080 폭 4:3 칸에 = 약 1.7배 · 1920 전체 = 2.25배). 저화질이면 칸을 작게(화면 절반 안팎) · 전체 화면은 흐리게 깐 배경으로만.
- **박힌 글자 · 로고**: crop 으로 더 잘라 낸다(모음표로 확인). 좌우를 잘라 4:3 으로 만들 때는 로고 위치부터 잰다 · 칸 안 다가가기는 아래 기준(focus y=1)이면 아래쪽 로고가 남는다.
- **컷 검출**: 어두운 장면 · 빠른 섬광은 컷이 잘게 나온다 → `th` 를 올리거나 짧은 컷을 이웃과 합친다. 디졸브는 못 잡을 수 있다.
- **속도**: 프레임은 처음 한 번 꺼내 두므로(작업 폴더 `.cache/video/`) 두 번째부터 빠르다. 구간 · crop 을 바꾸면 새로 꺼낸다. 다 쓴 뒤 `.cache/` 는 지워도 된다(유저에게 묻고).
- **클라우드**: 영상 첨부는 용량 제한이 있고, 굽기 결과를 컴퓨터로 보낼 때도 파일 크기 한도가 있다 → 필요한 구간만 잘라 받고, 굽기는 §6.
- **캔버스 그림 ≠ 영상**: 그림 칸 크기를 바꾸면 영상도 그 칸에 맞춰 잘린다(focus 로 남길 자리). 비율이 다르면 잘리는 쪽을 기획서에 적는다.
- 제목 글꼴에 `·` `→` 같은 기호가 없으면 빈칸으로 나온다 — 그 글자만 본문 글꼴로 · 도형으로 · 말로 바꾼다.

## 6. 유저 컴퓨터에서 굽기 (영상 작업 권장)
클라우드는 코어가 적어 한 번에 하나씩 굽는다 — 영상이 든 90초 16:9 가 클라우드에서 십수 분, 유저 맥에서는 몇 분. 결과 파일 크기 한도도 없다.
- 설치(한 번): `brew install ffmpeg` · `pip install numpy pillow` · `pip install tinysoundfont --no-deps` · `pip install pedalboard` — pip 는 한 줄에 하나라도 실패하면 나머지도 안 깔리니 나눠서.
- 실행 폴더 = 작업 폴더(`scenes.py` · `재료/` · `fonts/` · `sf2/`) + 스킬 경로(`MOTION_SKILL` 또는 설치된 스킬). 유저에게 줄 것: 폴더로 가는 `cd` 한 줄 + `python3 scenes.py --bake` 한 줄.
- 컴퓨터 폴더가 연결돼 있으면 Claude 가 그 폴더에 다 맞춰 둔다. 결과는 `out/` — 유저가 먼저 본다.
