# 원테이크 줌 · 껍데기 — 사진 속 점에서 점으로 · 다 만든 영상에 띠 씌우기

사진 쇼츠 길(`photo-shorts.md`)의 «보여 주는 방식» 하나. 컷 없이 카메라 하나가 계속 움직인다 —
사진 속 한 점으로 빨려 들어가면 그 점의 색 공간에 다음 사진들이 떠 있다. 엔진 = `core/onetake.py` · 샘플 = `examples/onetake_example.py`.

## 1. 규칙 (어기면 속임수가 보인다)
1. **바탕색은 줌인으로만 바뀐다** — 들어간 점의 색이 다음 공간 바탕. 줌인해도 이전 사진이 뒤에 깔리지 않는다(단색 빈 공간).
2. **줌아웃은 바탕색을 바꾸지 않는다** — 지금 바탕색과 같은 색 점이 있는 사진에서 빠져나와 같은 색 공간에 드러난다(`near_spot`). 노란 공간에서 흰 공간으로 가고 싶으면 노란 공간 안에서 흰 점으로 한 번 더 줌인한다.
3. **설계도 먼저** — 공간마다 바탕 · 사진 · 다음으로 가는 점을 PLAN 으로 적고 `ST.blueprint(PLAN, 'out/설계도.png')` → ⏸ 유저에게 보이고 문제 줄이 없을 때 짠다. 맞는 색 점이 없으면 **사진을 바꾼다**(유저에게 «이 사진으로 바꿔도 될까요?»).
4. **줌 · 팬만 쓰지 않는다** — 공간마다 하나 이상 섞는다: 둘레 돌기(`orbit`) · 툭 떨어지기 + 흔들림(`drop`) · 박자 넘기기(`flip`) · 휙 넘기기(`pan_blur`) · 카드 기울기(`tilt`). 처음부터 안 섞으면 줌 · 팬만 남는다.

## 2. 부품
```python
from core import onetake as OT
ST = OT.Stage(W, H, dirs=['재료'])
A = OT.Card('사진1', x, y, size=1, rot=0)                 # 세상 좌표 — 카드 폭 = 1
uv, col = ST.color_spot('사진1')                          # 들어갈 점: 색이 뚜렷하고 고른 곳 → col = 다음 바탕
uv, col = ST.near_spot('사진7', 지금 바탕)                 # 빠져나올 점
cam = OT.zoom_to(ST.spot_pt(A, uv), 시작 cam, 끝 배율(×90), u)   # 점이 먼저 가운데로 · 배율은 나중에 가속(로그)
cam = OT.arrive((x, y), 배율, u)                          # 새 공간 도착 — 점처럼 작던 사진이 커지며
cam = OT.zoom_from(점, 끝 cam, 시작 배율(×80), u)          # 빠져나오기
img = ST.render(바탕, 카드들, cam) → ST.fill(img, 다음 바탕, k)   # 줌인 끝 28% 동안 그 색으로 덮어 이음매를 없앤다
img = ST.zoom_blur(img, OT.dive_blur(u)) · ST.pan_blur(img, dx, dy)
OT.drop(t, t0) · OT.orbit(카드들, 가운데 카드, t, 자리 잡기, 시작, 끝) · OT.flip(이름들, t, t0) · OT.tilt(카드들, cam)
```
- 길이 감: 공간당 2~6초 · 급줌인 0.8~0.9초 · 도착 0.5~0.7초 · 박자 넘기기 0.25초 · 전체 12~20초.
- 효과음: 급줌인 = 올라가는 휙(enter) · 도착 = 쿵(impact) · 돌기 · 휙 = cut · 떨어지기 = impact · 넘기기 = tick · 끝 = done.

## 3. 장면 짜기
1. 사진을 훑어 색 점 후보를 본다 — 뚜렷한 색(초록 · 빨강)은 드물고 흰 · 노랑 · 회색은 많다 → 드문 색 점이 있는 사진이 순서를 정한다.
2. PLAN → 설계도 → 유저 확인. 공간 수 3~5.
3. 공간 함수마다 «무엇을 섞을지» 먼저 정하고(규칙 4) 시각을 나눈다. 캔버스는 설계도 그림으로 대신한다(배치는 엔진 좌표 — 캔버스 아트보드가 필요 없다).

## 4. 껍데기 — 어떤 영상에도 씌우는 마무리
만든 영상은 손대지 않고 **창(1:1 · 4:5)에 넣고 위아래 띠**를 씌운 9:16. 원테이크 줌만이 아니라 폰 영상 · 설명 영상 · 다른 mp4 에도 쓴다.
- ★**가운데가 주인공** — 띠는 «심심하지 않을 만큼만»(`motion='약하게'` 기본): 지금 색이 어둡게 배어든 바탕 · 옅은 빛 덩어리 · 작은 점이 위로 · 위 이미지가 숨 쉬듯.
- 위 = **받은 타이틀 이미지**(투명 배경)가 있으면 그걸 — 직접 쓴 제목보다 깔끔. 없으면 `title` 글자. + `chip`(«관람기» 같은 칩) + `sub`.
- 아래 = `notes` 한 줄(시각마다 밀려 올라오며 바뀜) + 진행 막대 + `info` 흐르는 정보 줄.
- **글은 유저가 준 것만** — 날짜 · 장소 · 관람기 문장을 지어내지 않는다. 사진을 보고 쓴 초안이면 «초안이에요 — 말로 바꿔 주세요».
```python
from core import shell
SH = shell.Shell(DUR, win='1:1', top='재료/타이틀.png', chip='관람기', sub='…', notes=[(0, '…'), (5.2, '…')], info='…',
                 colors=[(0, 바탕1), (2.0, 바탕2)])     # 또는 colors='auto' = 안쪽 영상 색을 따라
W, H = SH.inner                                         # 안쪽은 이 크기로 그린다
frame(t) = SH.frame(t, 안쪽(t))                          # M.W, M.H = SH.W, SH.H (1080×1920)
```
이미 구운 mp4 에 씌우기: `python3 <스킬>/scripts/wrap.py 영상.mp4 --win 1:1 --chip "관람기" --notes "0:첫 줄|5.2:둘째 줄" --info "…"` → `<이름>_껍데기.mp4`(소리 그대로).

## 5. 함정
- 줌아웃을 다른 색 공간으로 하면(노랑에서 빠져나오며 흰 공간) 바로 티가 난다 — `ST.check(PLAN)` 이 잡는다.
- 아주 크게 다가간 카드는 화면에 보이는 부분만 원본에서 떠서 키운다(가볍다) · 기울어진 카드는 작을 때만 기울인다(크면 기울기 무시).
- 사진 폭이 2000px 를 넘으면 줄여 읽는다 — 점으로 ×90 들어가면 결국 흐려지니 그 순간은 fill(색으로 덮기)이 가린다.
- 껍데기 아래 정보 줄은 한 번 그린 띠를 이어 붙여 흘린다 — 글이 겹치면 info 가 너무 긴 것.
