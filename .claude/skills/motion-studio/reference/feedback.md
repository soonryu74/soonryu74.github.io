# ⑧ 굽기 뒤 피드백 — 보고 짚으면, 스킬이 찾아서 고친다

굽고 나면 유저는 영상을 보며 «여기 이상해»를 남긴다. 유저는 **대충** 짚는다(초 단위 · 손가락으로 찍은 자리). **정확한 자리와 뜻을 찾는 건 스킬의 일이다.**

## 1. 흐름
```
⑦ 굽기 → out/<제목>.mp4  +  작업 폴더 피드백뷰어.html (굽기 끝에 자동 · 다시 만들기 = scenes.py --viewer)
⑧ 유저: 뷰어에서 보며 메모 → «목록 복사» → 대화에 붙여 넣기 ([피드백] 으로 시작)
   스킬: ① 자리 찾기 → ② «제가 이해한 것» 표 → ⏸ OK → ③ 고침 → ④ 전후 확인 → 굽기(유저 컴퓨터면 명령 두 줄) → 뷰어 새로
   (몇 번이든 되풀이 · 메모는 브라우저에 영상 이름별로 남는다 — 이름이 같으면 지난 메모가 그대로 보인다)
```
- 알리는 한 줄: «고칠 곳은 `피드백뷰어.html` 을 열어 보면서 메모하고 «목록 복사»로 붙여 넣어 주세요.» — ★유저 컴퓨터에서 구우면 **굽기 명령을 줄 때 같이**(끝나는 순간을 스킬이 못 본다 · 터미널 끝에도 크게 찍힌다) · 클라우드에서 구우면 완성을 전할 때.
- 뷰어는 로컬 파일로 연다(영상이 커서 아티팩트로 못 올린다) · 클라우드 작업이면 영상 · 뷰어를 같이 보낸다.
- `[피드백]` 으로 시작하는 붙여 넣기 = 이 단계. 기획서 «0. 지금 단계»를 «⑧ 피드백 N회차»로.

### 뷰어로 짚는 것
| 조작 | 남는 것 |
|---|---|
| `N` 여기 문제 | 시각 하나 + 종류(화면 표시 · 글씨 · 카메라 · 타이밍 · 소리·대사 · 전환 · 기타) + 메모 + (선택) 화면 위치 % |
| `I` / `O` 범위 | 시작 ~ 끝 + 종류(들어내기 · 빠르게 · 느리게 · 멈춰서 보여 주기 · 기타) · «✂ 빼고 이어 보기»로 미리 보기 |
| 목록 복사 | `1. 00:19:22 · 화면 표시 이상 · 화면 위치 (가로 51.1%, 세로 39.4%)` + (자막 있으면) `대사: 「…」` 줄 + 메모 — 시간 = 분:초:프레임 |
| `[` / `]` | 앞 · 다음 대사 첫머리로 (자막이 있을 때) |

### ★ 대사 줄 — 자막이 있으면 «어느 대사 때»로 짚는다
- 뷰어를 만들 때 자막(.srt · .vtt)을 찾아 **대사 줄을 뷰어 안에 심는다**(크롬은 내 컴퓨터에서 연 html 이 옆 파일을 못 읽어서). 찾는 순서 = ①`out/<영상이름>.srt` ②`out/자막.srt` ③작업 폴더 `자막.srt` · 직접 주려면 `feedback.py viewer out/<제목>.mp4 --srt 경로`.
- 뷰어: **영상 칸 아래쪽에 크게 자막**(`C` 또는 «자막 켬/끔» — 영상에 자막이 이미 입혀져 있으면 끈다) · 조작부 위 줄에도 지금 대사 · 오른쪽 «대사» 탭에 전체 목록(누르면 그 시각으로) · 메모를 남기면 그때 대사가 같이 적힌다(범위면 걸친 첫 줄 ~ 끝 줄).
- 자막이 없으면 유저가 뷰어의 «자막 열기»로 넣어도 된다(그 영상 이름으로 브라우저에 기억).
- ⚠️ **굽은 영상의 시각**이어야 한다. 받아쓰기 확인표의 `자막.srt` 는 그 원본 영상의 시각이다 — 원본을 그대로 쓴 영상(자막 입히기)이면 맞고, 자르고 붙인 영상이면 `R.srt(…)`(rec-cut)로 굽은 시각 자막을 뽑아 `out/자막.srt` 에 둔다. 영상 길이보다 2초 넘게 긴 자막은 다른 영상 것으로 보고 넣지 않는다(한 줄 알림).
- 붙여 넣기의 `대사: 「…」` 는 **자리 찾기의 단서**다 — 짚은 시각이 어긋나도 그 대사의 자막 시각으로 바로 간다(`feedback.parse` → `line`).

## 2. ★ 역할 나눔 — 무엇으로 고치나
| 피드백 | 고치는 곳 | 예 |
|---|---|---|
| **시간 · 무엇** — 타이밍 · 길이 · 빼기 · 글귀 바꾸기 · 소리 | **장면 코드의 숫자 · 글** | «외침이 나올 때 글자가 튀어나오게» → 등장 시각 · 장면 경계 · 효과음 시각 |
| **모양** — 위치 · 글꼴 · 크기 · 색 · 새로 얹는 글자 · 그림 | **캔버스** (바닥 3 — 화면 모양은 캔버스가 정본) | 판에 있는 요소 = 그 판을 **다시 읽고** 고쳐 올린다 · 판에 없던 것을 얹을 때 = 작은 보드 (§4) |

⛔ 모양을 장면 코드에 좌표 숫자로 박지 않는다 — 다음에 유저가 캔버스에서 못 고친다.

## 3. 처리 순서
**① 자리 찾기** — 짚은 시각은 대략이다. 앞뒤를 보고 뜻을 잡는다.
```
python3 <스킬>/scripts/feedback.py sheet out/<제목>.mp4 --paste 피드백.txt --out 살펴보기/피드백1
python3 <스킬>/scripts/feedback.py loud  out/<제목>.mp4 12 18        # 외침 · 박수 · 대사 시작 = 소리가 튀는 자리
```
- 시트 = 항목마다 앞뒤 ±1초를 0.25초 간격으로 한 줄(가운데 노란 테두리 · 위치 핀은 노란 원). 눈으로 본다.
- 장면 코드의 장면 표(`SCENES`)로 «그 시각 = 몇 번 장면 몇 초»를 바꿔 둔다.
- 「여기에 ○○」처럼 **들어갈 자리**를 짚은 것인지, 「○○가 이상해」처럼 **있는 것**을 짚은 것인지 먼저 가른다.

**범위(들어내기)는 기계적으로 자르지 않는다**
| 단계 | 할 일 |
|---|---|
| 뜻 | 앞뒤 프레임 — «화면만 있고 의미 없음» / «실수(오타 등)» / «너무 느림» 중 무엇인가 |
| 자를 자리 | 말한 시각 근처에서 **화면이 바뀌는 순간**(메뉴가 닫힐 때 · 창이 넘어갈 때 · 입력이 끝날 때) |
| 이음 | 대사가 잘리거나 겹치지 않는가(대사를 옮기거나 녹음을 쉼 자리에서 둘로) · 짚기 표시가 잘린 채 남지 않는가 · 이음새가 튀지 않는가 |

**② «제가 이해한 것» 표 — 고치기 전에 보여 준다**
| # | 정확한 자리 | 이해한 것 | 고칠 방법 |
|---|---|---|---|
- 항목마다 찾은 화면(시트) · 정확한 타임코드 · 고칠 곳(코드 / 캔버스).
- ★**스킬이 정해서 넣은 것**(글꼴 · 색 · 길이 · 움직임 등 유저가 말하지 않은 것)은 ★로 따로 표시.
- 바꾸지 않는 것도 한 줄(«다른 장면 · 소리는 그대로»).
- ⏸ **OK 전에는 고치지 않는다.** 표가 틀렸다고 하면 그 줄만 다시.

**③ 고침**
- 고치기 전 `scenes.py`(와 바꿀 보드 · 지난 영상)는 지우지 말고 `_to_delete/피드백N전/` 으로 옮겨 둔다(유저 규칙이 있으면 그대로).
- 요청한 것만 바꾼다. 장면 하나를 빼거나 늘리면 **다른 경계의 전환 · 효과음이 따라 바뀌지 않는지** 본다(§6).
- 오래 걸리면 중간에 한 번 진행을 알린다.

**④ 고친 뒤**
- 고친 시각의 **전후 스틸**(굽지 않고 `--still`) — 항목마다 한 장씩 · 쓰기처럼 시간 따라 변하는 건 3장.
- **새 타임코드표** — 빼거나 늘려서 시간이 밀렸으면 장면 · 주요 순간의 새 시각(다음 피드백은 새 시간으로 온다).
- 굽기 명령(유저 컴퓨터) 또는 굽기(클라우드) → 뷰어 새로.

## 4. 판에 없던 글자 · 그림을 얹을 때 — 작은 보드
화면 위에 새 글자(예: 영상 위 손글씨 한 마디)를 얹으라는 피드백은 «모양» 일이다 → 작은 캔버스 보드 하나로.
```html
<x-dc>
<div style="position:relative;width:1080px;height:1920px;background:transparent;font-family:'Nanum Pen Script'">
  <div data-t="5.5-7.0" style="position:absolute;left:152px;top:690px;width:800px;font-size:120px;
       line-height:1.2;text-align:center;color:#ffffff;text-shadow:0 2px 3px rgba(0,0,0,0.6)">축하드립니다</div>
</div>
</x-dc>
```
- `canvas/피드백N_<무엇>.html` 로 두고 장면 코드는 한 줄: `for e in bake.memo('fbN', lambda: canvas.read_board(경로)[1]): motion.draw(img, e, lt)` — `data-t` 동안 써지고(글자) · 그려지고(svg) 그 뒤 그대로.
- 자리 = 뷰어의 «화면 위치 %» × 화면 크기에서 시작. 위치 · 크기를 다시 바꾸자고 하면 **그 파일만** 고친다.
- 글꼴이 없으면 묻지 않고 받는다(`check.py --fix --fonts "Nanum Pen Script"`).
- ⚠️ 루트 div 에 width · height · `<x-dc>` 가 없으면 읽지 못한다 · 쓰기(write) 글자의 text-shadow 흐림은 3px 이하(넓으면 안 쓴 글자 그림자가 먼저 비친다).
- 메인 캔버스에도 그 판을 올려 두면 유저가 직접 끌어 옮길 수 있다(원하면).

## 5. 종류별 처방 (실제 피드백에서 모은 것 · 출발점)
| 피드백 | 흔한 뜻 | 처방 |
|---|---|---|
| «여기서 ○○ 소리가 나는 포인트야» | 등장을 소리에 맞추기 | `loud` 로 튀는 자리 → 장면 경계 · 등장 시각 · 효과음을 그 자리로 |
| «○○는 여기에 들어가야 해» | 글귀 · 등장 시각 옮기기 | 짚은 시각 = 등장 시작 · 앞 글귀는 그 직전에 접히며 사라지게 |
| «마지막을 더 길게» | 머무는 시간 | 그 장면 길이만 늘리고 배경음 끝 페이드가 새 끝에 맞는지 |
| «A ~ B 들어내 줘» | 의미 없는 구간 · 실수 | §3 범위 규칙 — 화면 바뀌는 순간에 자르고 대사 · 표시 이음 확인 |
| «동그라미가 남아 있어» | 짚기 표시 끝 | 화면이 바뀌는 순간에 지운다(표시 시간 = 그 대상이 보이는 동안) |
| «필요 없음» · «체크로 바꿔» · «더 두껍게» | 표시 종류 · 굵기 | `label.mark` 종류 · `w` |
| «잠깐 멈추고 보여 줘» | 멈춤 | 그 프레임에서 멈춘 동안 짚기 · 밑줄 → 다시 재생 |
| «화면 변화가 없고 느려» | 빠르게 · 건너뛰기 | 배속 + «▶▶ 건너뛰기» 배지 |
| «줌 돼서 전체가 안 보여» · «○○로 카메라 이동» | 프레이밍 | 틀을 넓히거나 컷 안에서 틀을 옮긴다 |
| «글씨가 작아» | 강조 | 다가가기 · 줄마다 커졌다 돌아오는 등장 |
| «화살표가 이상해» | 기하 도형 · 뭉개진 머리 | `scripts/mark.py` 화살표(큰 강조는 `bold`) — 캔버스 §4 «짚기 표시» |
| «툭 이어져, 표시해 줘» | 이음새 | 꼬리표(«◀ 이전 장면» 등) + 덮는 전환 |
| «여기에 ○○ 글자» (위치 지정) | 새로 얹기 | §4 작은 보드 |
| «화면 2는 B로» · 노트에 ✔ | 캔버스 🎬 효과 노트에서 고름 | `canvas.picks` → 기획서 «다른 효과 표»의 그 효과로 그 장면만 · 노트 «지금:» 고쳐 올리기 (canvas-rules §8-B) |

## 6. 함정
- **장면을 빼면 뒤쪽 전환이 바뀐다** — 경계 전환을 순서 번호로 고르면 하나만 빼도 전부 밀린다. 고치기 전 전환 표(`EDIT`)를 출력해 두고 고친 뒤 같은지 본다 · `kit.cuts(levels, names=장면 이름)` 로 이름 기준.
- **영상 프레임 캐시** — 같은 이름 · 같은 길이로 다시 만든 영상도 파일이 바뀌면 다시 꺼낸다(캐시 키에 파일 크기 · 바뀐 시각). 이상하면 `.cache/video` 를 `_to_delete` 로.
- **스틸은 맞는데 영상이 다르다** — 굽기 전에 지난 `out/_silent.mp4` · `mix.wav` 가 남아 섞이지 않는지(굽기는 새로 만든다).
- **피드백이 여러 개면 한 회차로** — 유저는 다 보고 모아서 준다. 하나 고칠 때마다 굽지 않는다.
