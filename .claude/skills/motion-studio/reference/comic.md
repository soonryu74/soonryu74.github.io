# 만화 페이지 길 (β) — 완성된 페이지 만화를 카메라 · 소리 · 빛 한 겹으로 보여 주기

유저가 **완성된 만화 페이지**(+ 있으면 장면 · 효과음 프롬프트)를 주고 motion-studio 로 보여 달라고 할 때 이 길로 간다.
**그림은 하나도 고치지 않는다** — 카메라 = 어디를 보게 할지 · 소리 = 무엇을 듣게 할지 · 빛 한 겹 = 멈춘 그림에 숨을.
캔버스 초안(②~④)은 건너뛴다 — **페이지가 곧 캔버스**다(바닥 3 = 페이지 그대로).
엔진 = `scripts/core/comic.py` · 샘플 = `examples/comic_example.py`

## 1. 흐름
1. 페이지 이미지(효과음까지 들어간 최종판)와 장면 · 효과음 프롬프트를 작업 폴더에 둔다. 프롬프트가 없으면 페이지를 보고 칸마다 무슨 일인지 적는다.
2. **칸 찾기** — `comic.detect(페이지)`(흰 칸새로 가르기 · 읽는 순서). 효과선 · 효과음 글자 · 칸을 뚫고 나온 인물이 칸새를 건너면 그 칸들이 **붙어 나온다** → 페이지를 보고 그 장만 손으로 상자를 적는다.
3. **⏸ 칸 확인** — `comic.check_image(...)` 번호 그림 한 장 + «칸 N개 · 읽는 순서 맞나요?» (붙은 칸 · 순서 틀린 칸만 고친다)
4. **컷 연출표** — 장면 프롬프트(샷 크기 · 비트 · 대사 · 효과음)를 읽고 칸마다 한 줄(§3 · §4 · §5). `Comic.table()` 로 표를 뽑는다.
5. **⏸ 확인 2** — 연출표 + 점검 모음 한 장 + «컷 N개, 약 M초예요. 굽기 진행할까요?» — 이 길의 유저 확인은 여기까지 두 번.
6. 굽기(시작 카드의 굽기 위치대로) → **컷별 수정**은 유저가 말로 («3장 2컷 더 오래» · «펑은 더 세게» · «이 컷 빛 빼») → 그 줄만 바꿔 다시 굽는다.

## 2. 페이지 다루는 법 (엔진 기본 — 손대지 않아도 된다)
- 페이지는 늘 통째로 있다 — **읽는 칸만 밝고 나머지는 어둡다**(칸 크기 · 모양 · 배치 연출이 살아 있게 · 칸만 잘라 보여 주면 그 연출이 사라진다)
- 페이지에 들어서면 **어둡게 모양만** → 읽는 순서대로 칸 → 끝에 **페이지 전체를 밝혀** 머문다 → 옆으로 넘김(종이 소리)
  - 어둡게 들어서는 이유 = 펀치 칸(폭발 · 반전)을 미리 보이지 않기
- **박자 맞춤** — 칸에 «닿는» 순간 · 넘김 한가운데를 배경음 박자 위에(사이는 직전 칸에 더 머문다 · `bpm` · `beat=False` 로 끔)
- 9:16 에서 넓은 칸은 화면에 작게 남는다 → `hf`(칸 높이가 화면의 0.45~0.55) + `훑기`

## 3. 칸 성격 → 카메라 (`cam` · `move`)
| 칸 성격 | cam | move | 메모 |
|---|---|---|---|
| 넓은 설정 칸 | `훑기` | ease | `hf` 0.5 |
| 대화 | `훑기` / `훑기←` | ease | 먼저 말하는 사람 → 다음 사람 · `pan_at` 으로 대사 읽은 뒤 옮기기 |
| 감정 · 클로즈업 · 결심 | `다가가기` | ease | 아주 천천히 |
| 폭발 · 액션 | `다가가기` / `맞춤` | **snap** | `shake` 20~40 (20 이상 = 번쩍) |
| 반전 · 펀치 | (무엇이든) | snap | 직전 `hush` 0.4~0.6 |
| 코메디컷 · 리액션 | `맞춤` | snap | 통 · 털썩 / 또는 **무음으로 얼빠짐**(`hush` = hold) |
| 큰 장관 | `물러나기` | ease | 바짝 붙었다 물러나며 공개 |
| 세로로 긴 칸 | `올려훑기` / `내려훑기` | ease | 발끝 → 지팡이 끝 · 떨어지는 것 |
| 폭발 뒤 인물 반응 | 튜플 pan(폭발 자리 → 인물 얼굴) | snap | `pan_at` = 터지고 1초 뒤 |
- `hold` = 대사 길이 + 칸 크기 — 대사 없는 칸 1.5~2초 · 한두 줄 2~3초 · 말풍선 셋 4~5초
- 튜플이 더 필요하면 `comic.py` 머리말 · `CAMS` 를 본다

## 4. 소리 (`sfx` · `hush`)
- **페이지에 그려진 효과음 글자 = 카메라가 닿는 순간 실제 소리**(효과음 프롬프트에 글자와 칸이 있다) — 이름은 `comic.SOUNDS`(옛 이름 → 효과음 재료) 또는 효과음 재료 이름(`sfx.LIB` · sound.md) 을 바로
  - swish 붕붕 · twinkle 반짝 · shimmer 촤르르 · aurora 스으으 · boom 펑 · mega 콰과광 · sparkle_rain 흩날림 · thud 털썩 · boing 통 · heart 두근두근 · pop 뻥 · hiss 치이익 · charge 위이잉 · rumble 고오오 · scream 비명 · crowd 웅성 · laugh 술렁 · applause 환호 · clap 박수
  - 맞는 이름이 없으면 비슷한 것 · 없으면 `comic.sound` 에 새로 짠다
- 그림에 없는 소리도 장면에 맞으면 넣는다 — 관객 웅성 · 박수
- **펀치 직전 · 얼빠진 순간 = 배경음 비우기**(`hush`) — 가장 싸고 효과가 크다. 남발하지 않는다(한 장에 하나 안팎)
- 배경음: 앞 장 경쾌 → 고조 장 build → 마지막 장 잔잔 → 끝 (`Comic.audio(sections=…)`)

## 5. 그림 위 빛 한 겹 (`fx`)
칸 안에만 · screen 합성(밝은 쪽만 더해진다) — 그림 선 · 색은 그대로.
| 이름 | 쓰는 자리 | 주요 옵션 |
|---|---|---|
| `sparkle` | 마법 · 눈빛 · 전구 · 별 | area · n · r · col |
| `glow` | 빛나는 물건 · 감정 색(하트 분홍) · 모이는 힘(`rise`) | at · r · amt · pulse · col |
| `sweep` | 빛이 흐르는 장관 · 힘이 감도는 칸 | per · bw · amt · col |
| `rain` | 폭발 뒤 흩날리는 가루 · 파편 | area · n · cols · life |
- 색은 그 칸 그림의 빛 색에서 고른다 · 효과가 그림을 덮으면 amt 를 낮춘다
- 모든 칸에 넣지 않는다 — 빛 · 마법 · 폭발 · 감정이 있는 칸만

## 6. 쓰지 않는 것 · 한계
- 말풍선 · 인물을 떼어 따로 움직이지 않는다(손이 많이 가고 자리가 어긋난다 — 그림은 통째로)
- 목소리 연기는 이 길의 기본이 아니다 — 녹음이 있으면 ⑥ 나레이션처럼 칸에 맞춘다
- 칸 찾기는 흰 칸새가 있는 페이지 기준 — 칸새 없는 펼침 그림 · 세로 웹툰은 칸 상자를 손으로 적는다(세로 웹툰을 위에서 아래로 따라가는 영상은 aitoon-cut-follow)
