# 방송 연출 넷 — 예능 자막 · 회상 · 분할 대담 · 리액션 화면 속 화면 (`core/show.py`)

> 사람이 찍은 영상(모임 · 행사 · 대화 · 화면 녹화)에 **방송처럼** 입히는 연출. 영상이 주인공이고 연출은 받친다.
> 기획서 «효과» 칸에서 골라 쓴다 — 한 편에 둘까지(예능 자막 + 회상처럼). 셋 이상 섞으면 산만하다.

## 0. 언제 무엇을

| 연출 | 이럴 때 | 필요한 재료 |
|---|---|---|
| **예능 자막** | 웃음 · 박수 · 건배 · 놀람이 있는 모임 영상 · «이쁘게 / 재밌게» 요청 | 영상 하나 · 받아쓰기 확인표(말 자막) |
| **회상** | 지금 장면에서 앞 장면(또는 예전 영상 · 사진)을 다시 불러올 때 · 마무리에 «처음 그 순간» | 영상 하나(앞부분이 «그때»)면 된다 |
| **분할 대담** | 두 사람이 주고받는 말 · 인터뷰 · 이임 / 취임처럼 짝이 되는 두 발언 | 영상 둘(같은 대화를 두 폰으로가 제일 좋다) |
| **리액션 화면 속 화면** | 무언가를 보며 반응하는 얼굴 · 화면 녹화 설명에 진행자 얼굴 | 보는 영상 + 얼굴 영상(같은 시간에 녹화) |

⛔ 글은 지어내지 않는다 — 말 자막은 **확인표를 거친 글만**. 받아쓰기가 흐린 줄은 말 자막 대신 상황 자막 · 쾅 자막으로 간다.
⛔ 이름 · 자리 이름을 모르면 딱지 · 도장을 빼거나 상황을 말하는 글로(«(한 분 등장!)»).

## 1. 예능 자막 — `Variety`

```python
from core import show as S
VAR = S.Variety(W, H, 'fonts/BMHANNAPro.ttf', F_TXT,
    caps=[('situ', '(잔 받는 중)', 0.5, 3.4),          # 상황 — 괄호 · 작게 · 회색 상자 · 왼쪽 아래
          ('say', '건강하게 오래오래~', 7.6, 11.3),      # 말 — 흰 글자 + 테두리 + 노란 밑줄 · 한 글자씩
          ('bang', '위하여!!', 11.43, 12.13),            # 쾅 — 크게 튀어나옴 · 집중선 · 기울임
          ('bang', '위하여!!!', 12.13, 13.6),            #   이어지는 쾅 = 마지막 것이 노랑 · 더 크게
          ('mood', '감사합니다 (뭉클)', 13.65, 14.8),     # 분위기 — 분홍 · 떠오름 · 하트
          ('wave', '축하합니다~', 14.8, 17.6)],           # 물결 — 글자마다 통통 · 색 번갈아
    tag='오늘의 뒤풀이', end='축하 완료!', end_at=SRC_DUR,   # 딱지 · 끝 도장(멈춘 화면 위)
    punch=[(11.3, 13.7, (0.52, 0.55), 1.16)])            # 쾅 구간 화면 당김 (쾅 시각마다 흔들림)

def frame(t):
    im = VAR.zoom(clip.frame(t).resize((W, H)), t)      # 당김 · 흔들림
    return VAR.draw(im.convert('RGBA'), t).convert('RGB')
# 소리: VAR.sounds(sfx, SX.Kit('코믹'))  — 현장 소리가 주인공 · 배경음은 낮게(0.2 안팎)
```
- 시각 = **영상 안 시각**. 쾅은 소리가 튀는 자리(`feedback.loud`)에 맞춘다.
- 끝 = 마지막 프레임을 1.5~2초 멈추고 도장(`end_at`). 도장 자리(`end_pos`)는 얼굴을 피해 빈 곳.
- 글꼴 = 굵고 둥근 것(작업 폴더 `fonts/` — 배민 한나 · 지마켓 산스 Bold 등). 캔버스에도 같은 글꼴.

## 2. 회상 — `memory_look` · `ripple` · `cross` · `muffle`

흐름: 지금(한 사람에게 천천히 다가가다) → **멈춤** → `cross(go=True)` 물결 + 하얗게 → 그때(세피아 · 흐린 가장자리 · 입자 · 손글씨 글)
→ `cross(go=False)` → 멈췄던 지금 화면으로 돌아와 물러나며 이어짐(명조 글).
```python
NOW1, MEMORY, NOW2 = (10.6, 14.0), (0.0, 7.0), (14.0, 끝)      # 영상 하나면 앞부분이 그때
# 넘어가기  S.cross(멈춘_지금, 그때_첫_장, u, t, go=True)   (u = 0~1 · 0.8초)
# 그때      S.memory_look(zoom_to(그때_장, 1.04~1.08, (0.5, 0.5)), t)
# 돌아오기  S.cross(멈춘_지금, 그때_끝_장, u, t, go=False)  (0.7초)
# 소리      그때 = S.muffle(현장 소리) × 0.45 + 잔잔한 배경음(그때에만 · audio.bgm_gap) · 넘어갈 때 Kit('동화') cut
```
- 다가갈 자리(`zoom_to(…, 1.4, 얼굴)`) = 멈출 그 프레임에서 사람 얼굴. 1초 모음표로 잡는다.
- 그때 글 = 손글씨(나눔펜) · 지금 글 = 명조(고운바탕). «조금 전…» «그리고 지금»처럼 **사실인 말만**.

## 3. 분할 대담 — `Split`

```python
SP = S.Split(W, H, a=('재료/A.mp4', (250, 0, 440, 480)), b=('재료/B.mp4', None),   # crop = 사람 둘레(원본 픽셀)
             turns=[('A', 5.2, 11.2), ('B', 12.2, 16.8), ('A', 11.2, 14.4)],          # 누가 · 원본 구간 · 이어 붙일 순서
             labels=('이임 인사', '취임 인사'), font=F_TXT)
M = types.SimpleNamespace(W=W, H=H, FPS=30, DUR=SP.DUR, frame=SP.frame, SCENES=SP.SCENES)
# 소리: SP.voice(voice_track) — 말하는 쪽만
```
- 말하는 쪽 60% · 듣는 쪽 40%(`share`) · 듣는 쪽은 회색으로 어둡게 멈춘다 · 말하는 쪽에 테두리 + 소리 막대.
- 원본이 작으면(480p) 확대한 쪽이 흐리다 — crop 을 너무 좁히지 않는다.

## 4. 리액션 화면 속 화면 — `Pip` · `zoom_to`

```python
PIP = S.Pip(W, H, '재료/얼굴.mp4', src=7.0, keys=[(7.0, 0.55, 0.30, 0.26), (10.0, 0.70, 0.33, 0.36)],   # 얼굴 자리 — 원본 시각마다
            t_in=0.8, t_out=8.8, peak=(4.9, 7.0), corner='rb')
def frame(t):
    kp = PIP.kpeak(t)                                                      # 반응 순간 0~1
    im = S.zoom_to(main.frame(t).resize((W, H)), 1 + 0.5 * kp, (0.84, 0.30))  # 큰 화면은 그 순간의 자리로
    return PIP.draw(im.convert('RGBA'), t).convert('RGB')
# 소리: PIP.voice(voice_track, DUR) — 반응하는 쪽 소리 크게 · 보는 영상 소리는 0.3
```
- 창은 구석에 붙은 채 커진다 — 큰 화면에서 짚은 자리(`zoom_to` 초점)와 **반대 구석**에 둔다.
- 얼굴이 움직이면 `keys` 를 몇 점 더 찍는다(1초 모음표 · 얼굴 가운데와 크기).

## 5. 점검

`--still` 로 쾅 · 넘어가기 · 반응 순간 시각을 꼭 찍어 본다 — 글이 얼굴을 덮는지 · 창이 짚은 자리를 덮는지 · 회상 얼굴이 중심에 오는지.
