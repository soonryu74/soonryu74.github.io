# 녹화 컷 편집 — 긴 화면 녹화를 «컷 표» 하나로 설명 영상으로

화면 녹화(사용법 · 튜토리얼 · 시연)는 길고 기다리는 구간이 많다. 컷 표에 «어디를 · 몇 배로 · 무엇을 짚을지»를 원본 시각으로 적으면
엔진(`core/cut.py`)이 잘라 굽고, 그 위에 손그림 짚기 · 빨리 감기 배지 · 컷 안 카메라 · 가리기 · 대사 · 자막을 얹는다.
영상 넣기(`video.md`)와 같은 길 위에 있다 — 녹화가 주인공이고 우리 디자인은 짚기 · 꼬리표 · 전환으로 받친다.

## 1. 흐름
| 단계 | 할 일 |
|---|---|
| 1 | 녹화 받기 → 작업 폴더 `녹화/` · 원본 크기는 엔진이 읽는다(5K · 4K · 1080p 무엇이든) |
| 2 | 녹화 훑기 — 컷 모음표(`video.sheet` · 넓은 간격 → 고른 곳만 촘촘히) · 말소리가 있으면 받아쓰기(`transcribe.md`) |
| 3 | **컷 표 초안** — `녹화_편집표.md` 에 표로(컷 · 원본 구간 · 배속 · 보여 줄 곳 · 짚을 것 · 대사) → ⏸ 유저 확인 |
| 4 | `scenes.py` 에 SHOTS 로 옮김 → `--still` · `--sheet` 로 짚기 자리 확인 (원본 좌표가 맞는지) |
| 5 | 나레이션 녹음 → 대사 길이에 맞춰 keep · hold 조정 → 굽기 (미리 굽기는 굽기가 알아서) |

## 2. 컷 표 필드
| 필드 | 뜻 |
|---|---|
| `id` · `src` | 컷 이름 · 녹화 파일(`녹화/` 안) |
| `a`, `b`, `sp` | 미리 굽는 원본 구간 · 배속(기본 1) |
| `crop` | (가운데 x, 가운데 y, 너비) 원본 좌표 · 높이는 화면 비율대로 · 원본 밖으로 안 나간다 |
| `keep` | 실제로 보여 줄 조각 `[(시작, 끝, 배속) …]` · `('freeze', 원본 시각, 멈출 초)` — 없으면 `[(a, b, sp)]` |
| `view` · `cam` | 처음 틀 · `[(원본 시각, 새 틀, 옮기는 초)]` 컷 안 카메라(입력 창으로 다가가기 등) |
| `marks` | `[(원본 시각, 원본 길이, 종류, 인자…, {옵션})]` — circle · underline · box · check · x · 옵션 `end`(원본 시각에 지움) · `at`/`until`(컷 안 초) · `w` · `col` |
| `vo` | `[(대사, 컷 안 초)]` 또는 `[(대사, {'src': 원본 시각})]` ← 조각을 빼도 따라오니 이쪽을 권한다 |
| `ff` | 빨리 감기 배지(조각 배속 3 이상 «빨리 감기 ×N» · 100 이상 «건너뛰기») |
| `hold` · `skip` · `mask` | 끝 화면 더 머물기 · 안 씀 · 가리기 적용 |

```python
from core import cut
R = cut.Reel(SHOTS, rec='녹화', size=(W, H), masks=[dict(x=…, y=…, w=…, h=…, t=원본 시각, text='user@mac', src='03.mp4')])
TL = R.timeline()                                   # [(id, 시작, 끝)] — 컷 사이에 다른 장면이 끼면 scenes.py 시각을 쓴다
img = R.frame('c03', lt)                            # 짚기 · 배지까지 그린 화면 → 그 위에 꼬리표 · 제목을 더 얹어도 된다
M = types.SimpleNamespace(..., prepare=R.prepare)   # 굽기 전에 빠진 컷만 미리 굽기 (.cache/shots/ · 컷 표를 고친 컷만 다시)
R.vo('c03') · R.mark_time('c03', m) · R.srt(texts, lens, 'out/자막.srt')
```
샘플 = `examples/rec_cut_example.py`.

## 3. 원칙
- **시각은 전부 원본 녹화 시각**으로 적는다. 컷 안 초로 적으면 조각을 빼는 순간 다 어긋난다(손으로 다시 맞추게 된다).
- 짚기는 끝을 안 적어도 **그 조각(화면)이 바뀌면 같이 지운다** — 다음 화면에 동그라미가 남지 않게. 같은 화면에서 일찍 지우려면 `end`.
- 기다리는 구간(설치 · 굽기 · 로딩)은 빨리 감기 + 배지 · 아주 길면(×100 이상) «건너뛰기». 오타 · 머뭇거린 구간은 keep 으로 들어낸다.
- 화면 글이 작으면 crop 을 좁히고 · 넓게 보여 준 뒤 카메라(cam)로 다가간다. 720p 녹화는 1.5배 넘게 키우지 않는다.
- 이름 · 경로 · 이메일 · 토큰처럼 개인 정보가 보이면 **mask** — 원본 좌표 · 나타나는 시각부터 · 바탕색으로 칠하고 대신 글(`user@mac`)을 쓴다. 유저에게 «가린 곳» 목록을 보인다.
- 대사 자막은 `R.srt(문장 사전, 녹음 길이, 경로)` — 긴 문장은 나눠 글자 수 비율로. ★경로를 `out/자막.srt`(또는 `out/<영상이름>.srt`)로 두면 피드백 뷰어에 대사 줄이 같이 뜬다(feedback.md). 받아쓰기 확인표를 거친 문장이면 `stt.final_lines` 를 써도 된다.

## 4. 함정
- 미리 굽기는 처음 한 번 오래 걸린다(긴 녹화 · 높은 배속) — 내 컴퓨터 굽기를 권한다. 클라우드에서 끊기면 `R.prepare(budget=150)` 로 나눠 부른다(이어서 굽는다).
- 원본 좌표는 **녹화 원본 픽셀** 기준이다(화면 배율 2배 맥이면 보이는 것보다 크다) — `--still` 로 짚기가 제자리인지 꼭 본다.
- 아주 빠른 배속(×20 이상)은 키 프레임만 읽어 빠르게 굽는다 — 화면이 뚝뚝 넘어가는 게 정상.
