# 받아쓰기 · 자막 — 말소리를 글로 옮겨 자막을 얹는다

자막 파일이 없는 영상(폰 영상 · 녹화 · 인터뷰)에서 말소리를 글로 옮긴다. 쓰임은 셋이다.
1. **자막 달기**: 영상 그대로 + 아래 자막 (`transcribe.py burn`)
2. **내용 파악**: 무슨 말을 하는지 읽고 기획 · 컷 고르기에 쓴다 (`video.md` §2-A 의 자막 자리에 그대로)
3. **장면 코드 안 자막 · 맞추기**: `stt.final_lines` → `stt.draw` 로 장면 위에 · `stt.speech_spans` 로 말이 있는 구간 찾기

엔진 = Whisper turbo(sherpa-onnx · 내 컴퓨터에서 돈다 · 인터넷으로 보내지 않음) + 말소리 구간 찾기(silero VAD).

## 1. 흐름

| 단계 | 할 일 | 명령 |
|---|---|---|
| 0 | 처음 한 번 — 엔진 · 모델(약 560MB) 받기 | `python3 <스킬>/scripts/transcribe.py --fetch` (점검은 `transcribe.py check` · `check.py --asr`) |
| 1 | 받아쓰기 | `transcribe.py 영상.mp4` → 영상 옆 `<이름>_받아쓰기/` 에 `받아쓰기.json` + `확인표.md` |
| 2 | **⏸ 확인표를 유저에게** | 표를 대화에 붙여 보이고 «틀린 말만 고쳐 주세요» — 유저가 «고친 글» 칸에 적거나 말로 알려 준다(말로 오면 Claude 가 칸을 채운다) |
| 3 | 반영 | `transcribe.py apply <폴더>` → json 에 반영 + `자막.srt` |
| 4 | 굽기 | `transcribe.py burn 영상.mp4 [<폴더>] [--tag "제목"]` → `<이름>_자막.mp4` (원본 그대로) |

긴 영상은 `--from 30 --to 95` 처럼 구간만. 줄 길이는 `--chars 20`(9:16 은 14~16 권장).

## 2. 확인표 — 꼭 거친다
- **Claude 는 소리를 못 듣는다.** 받아쓰기는 짐작이다 — 시끄러운 곳 · 여러 사람 · 사투리 · 이름 · 숫자는 자주 틀린다(받침 · 끝말이 빠지거나 비슷한 소리로 바뀐다 — «감사합니다» → «감사니다»).
- 확인표를 보이기 전에 Claude 가 먼저 훑어 **뜻이 이상한 줄에 ★ 짐작**을 달아 보인다(«2번 «감사니다» → ★«감사합니다»?»). 고치는 건 유저 확인 뒤.
- 칸 규칙: 맞으면 비워 두기 · 틀리면 맞는 글 · 그 줄을 빼려면 `-`.
- 줄을 합치거나 · 나누거나 · 시각을 옮기는 것은 json 의 `lines` 를 Claude 가 고친다(a · b 초).
- 아래 «말소리는 있는데 글이 안 나온 곳» = 웃음 · 잡음 · 너무 작은 말. 필요하면 유저에게 무슨 말인지 묻는다.
- 유저가 확인하지 않은 받아쓰기는 «자동 자막»이다 — 그대로 구울 때는 `--tag "자동 자막"` 으로 표시.

## 3. 자막 모양
- 기본: Pretendard Bold · 흰 글 + 검은 테두리 · 아래 가운데 · 크기 = 화면 짧은 변의 6.7%(가로) / 5.5%(세로) · 세로 영상은 아래 22% 띄워 쇼츠 UI 를 피한다.
- 바꾸기: `--size 72` · `--pos top` · `--color FFE14D` · `--tag` = 왼쪽 위 작은 표시.
- 다른 글꼴: 작업 폴더 `fonts/` 에 파일을 두고 `stt.burn(..., font='파일이름')`.
- motion-studio 영상 안에 자막을 디자인으로 넣을 때는 캔버스에 «자막 판»(글꼴 · 크기 · 자리 · 색)을 그려 확인받고, 장면 코드에서 판 값을 읽어 `stt.draw(img, lines, t, size=, y=, color=, font=)`.

## 4. 장면 코드에서
```python
from core import stt
lines = stt.final_lines('재료/원본_받아쓰기/받아쓰기.json')   # [(a, b, 글)] — 확인표 반영본
stt.draw(img, lines, t)                                      # 지금 시각 t 의 줄 (영상 구간을 잘라 넣었으면 t 를 원본 시각으로 바꿔서)
spans = stt.speech_spans('재료/원본.mp4')                     # [(a, b)] 말이 있는 구간 — 말 사이 쉼에서 자르기 · 나레이션 자리 맞추기
```
- 영상 넣기(`video.md`)에서 «말 끝에서 자르기»는 자막 시각보다 `speech_spans` 의 쉼이 정확하다.
- 나레이션 녹음 맞추기에도 쓸 수 있다(문장 사이 쉼 = `speech_spans` 의 틈).

## 5. 함정
- 짧게 잘라 받아쓰면 엉뚱한 글이 나온다 — 말 구간 통째로 받아쓰고 줄은 뒤에서 나눈다(엔진이 그렇게 한다 · 직접 부를 때도 같은 원칙).
- 큰 모델(large-v3)이 더 낫지 않다 — 느리고 같은 말 반복을 빼먹거나 없는 말을 지어냈다. turbo 가 기본.
- 줄 시각은 글자 수 비율 + 소리가 잦아드는 곳에 맞춘 짐작이다 — 빠른 말 · 겹친 말은 0.3~0.5초 어긋날 수 있다. 구운 뒤 유저에게 «자막이 말보다 빠르거나 늦은 곳»을 물어 json 의 a · b 를 고친다.
- 모델 받기가 막히면(회사망 · 방화벽) 안내 줄의 주소 두 개를 유저가 직접 받아 `~/.cache/motion-studio/asr/` 에 풀면 된다(다른 곳이면 `MOTION_ASR=<폴더>`).
- 처음 부를 때 모델을 읽느라 몇 초 걸린다 · 1분 영상 ≈ 30초~1분(CPU 2개 기준).
