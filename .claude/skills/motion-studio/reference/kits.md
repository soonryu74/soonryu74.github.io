# 키트 — 한 영상의 문법 한 벌

**영상끼리는 키트를 바꿔 다르게, 한 영상 안에서는 키트 안에서 변주한다.** 산만함과 품질 저하를 막는 장치다.
★**키트는 일관성을 지키는 최소한의 바닥이지 제한이 아니다.** 내용에 더 맞는 움직임은 다른 키트에서든 새로 짜서든 가져와 쓴다 — 빌린 장면은 `PLAN`에 `'borrow': '이유'`. 빌림은 벌점이 아니다: 점검 보고는 이유와 함께 보이게만 하고, 빌림이 절반을 넘으면 «다른 키트가 더 맞는가»를 한 번 돌아보게 할 뿐이다.
**기본 움직임은 모든 키트에 들어 있다**(빌림으로 세지 않는다): 카메라 = 천천히 흐르기 · 밀고 들어가기 · 빠지며 공개 · 시선 옮기기 / 등장 = fade · up · pop.
코드: `K = kit.load('팝')` · 경계 편집 `K.cuts(세기 목록)` · `K.edit(...)` · 화면 겹 `K.finish(img, t)` (scripts/core/kit.py)

## 고르는 법
1. 시작 카드 «액션 분위기» → 출발 키트: 경쾌 → 팝 · 강렬 → 시네마 · 차분 → 차분 · 내용 보고 정하기 → 내용대로(디지털 · 기술 = 테크 · 동화 · 손맛 = 손그림 · 사실 · 현장 = 다큐).
2. ②-B 표현 기획에서 키트를 확정하고 기획서 §2-B 에 «키트 · 킥 장치 · 이유 한 줄».
3. 킥 장치는 하나 — 키트 후보는 순서가 우선순위가 아니다. **time.md 장치 사전을 다 보고** 내용에 가장 센 것을 고르고, 고른 이유와 버린 후보 한 줄을 기획서 §2-B에 남긴다(«아니지~ 다시»만 반복해서 고르지 않게).

## 코드 이름
위 표는 읽기 쉬운 이름이다. `PLAN` · `--check` 에는 kit.py 의 이름을 그대로 쓴다 — `python3 <스킬>/scripts/core/kit.py 팝`(바로 실행 가능) 이 그 키트의 이름(전환 · 카메라 · 등장 · 강조 · 화면 겹 · 소리)을 뽑아 준다.

## 강도 지도와 함께
- 장면마다 세기 1~3 을 정한다(기획서 §5). 3은 봉우리(훅 · 결과 공개 · 마무리 한 방)에만 — 연달아 두지 않고, 장면 수의 40%를 넘기지 않는다(짧은 영상일수록 적게).
- 내려앉기(zoom 등장)와 쿵(hit)은 세기 3 장면에만 — 자주 쓰면 «쿵쿵»만 남는다.
- 같은 등장 방식을 장면 절반 넘게 쓰지 않는다 — 키트 안에서도 장면마다 바꾼다.
- 장면 경계의 세기 = **들어오는 장면의 세기**(봉우리 장면은 센 편집으로 들어온다): `EDIT = K.cuts([p['level'] for p in PLAN[1:]])`. 키트 안에서 그 세기의 편집을 고르고 같은 편집이 연달아 나오지 않게 한다.
- β 키트 · β 효과는 써도 된다 — 다만 점검 모음 · 시간 띠를 더 꼼꼼히 본다.
