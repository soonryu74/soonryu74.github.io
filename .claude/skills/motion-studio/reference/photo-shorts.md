# 사진 쇼츠 길 — 행사 · 여행 · 전시에서 찍은 사진 여러 장을 «쇼츠로»

유저가 사진 여러 장(폰 촬영 · 행사 관람 · 여행 · 전시 · 매장)과 짧은 정보를 주고 «쇼츠로 만들어 줘»라고 할 때 읽는다. **사진이 주인공**이고 우리 디자인은 스티커 카드 · 글 · 효과로 받친다.
흐름은 평소와 같다(기획서 → 캔버스 → 확인 → 굽기). 영상이 섞여 있으면 영상 부분은 `video-shorts.md`.

## 1. 묻는 것 — 정보가 없을 때만 한 번
- **무슨 자리 · 언제 · 어디** 한 줄 + 있으면 행사 소개 글 · 타이틀 이미지(홈페이지 타이틀 · 포스터 · 로고 — 배경 있는 판 · 투명 판).
- 받은 소개 글은 그대로 써도 된다(줄이고 나눠서 장면 글로). 지어내지 않는다(바닥 1).
- 인물이 주인공인 사진이면 이름표를 제안한다(video-shorts §1 의 둘째 질문과 같다).

## 2. ★사진은 중복만 빼고 최대한 많이
- 사진을 받으면 **같은 장면 · 거의 같은 구도만 빼고 전부 쓴다** — 몇 장만 골라 쓰면 «사진이 부족한 느낌»이 난다.
- 먼저 모음 그림(장마다 번호)으로 전부 보고 → 중복 묶음을 찾아 하나만 남긴다(같은 벽 · 같은 부스를 다른 각도로 찍은 것) → 나머지는 어디든 쓴다.
- 장면 수를 늘려 길게 만들지 않는다 — **한 장면에 여러 장**을 보여 준다:
  - 쌓기: 2~3장이 툭 · 툭 · 툭 떨어져 겹친다 (`fx.drop` + `fx.photo_card`)
  - 박자 넘기기: 한 자리에서 박자(0.5초)마다 다른 사진 → 마지막 장에 멈춤 (`fx.photo_flip`)
  - 몽타주(«현장 스케치»): 남는 사진을 반 박자(0.25초)씩 빠르게 · 아래 점으로 몇 장째인지 · 넘길 때마다 작은 똑 소리 (`fx.photo_flip(per=0.25, dots=…)` · `fx.flip_times`)
  - 모아 마무리: 끝에서 여러 장이 날아와 격자로 모인다 (`fx.photo_gather`)
- 캔버스 «쓰지 않은 사진» 노트(보라)에는 뺀 사진과 이유(«toy-16 과 같은 벽»)만 남긴다.

## 3. 장면 짜기 (보통 20~30초 · 장면당 3~4초)
- 오프닝: 타이틀 이미지 · 날짜 · 장소 + 대표 사진 한 장(툭 떨어지기)
- 내용 장면: 소개 글을 한 줄씩 나눠 장면마다 한 마디 + 사진 1~3장 (쌓기 · 크게 한 장 + 작게 둘 · 박자 넘기기)
- 몽타주 한 장면: 남는 사진을 다 여기서
- 마무리: 행사 정보(타이틀 · 날짜 · 장소) 또는 모아 마무리
- 장면 배경은 타이틀 이미지의 색에서 2~4색을 돌려 쓴다 · 장면 사이 = 밀어 올리기 + 휙
- 속도 · 글 양은 이 정도면 적당했다(실사용) — 더 빠르게 하지 않는다.
- **다른 방식 — 원테이크 줌**(`onetake.md`): 컷 없이 카메라 하나로 사진 속 색 점에서 다음 색 공간으로. 사진 6~10장 · 12~20초에 맞다(몽타주처럼 전부 쓰기엔 짧다 — 남는 사진은 박자 넘기기로). 설계도(`--plan`)를 먼저 보이고 · 껍데기(1:1 창 + 띠)를 씌우면 행사 쇼츠로 바로 쓴다.

## 4. 캔버스
- 사진 = 스티커 카드(흰 테두리 10 · 검은 선 6 · 그림자 18 · 살짝 기울기) `<img data-photo="이름">` — 엔진 `fx.photo_card` 가 같은 모양.
- 몽타주 판은 마지막 장 + 점 줄로 그리고, 주황 노트에 넘기는 사진 목록 · 박자를 적는다(canvas-rules §8).
- 참고 줄: 사진 보여 주는 법(한 장 가득 · 스티커 카드 · 콜라주) · 효과 예시 줄(툭 떨어지기 · 박자 넘기기 · 쾅 다가가기) — «영상에 안 나와요» · 고르는 건 대화로(video-shorts §4 와 같다).

## 5. 글자
- 제목 글꼴(Jua 등)에 `·` `×` `–` 같은 기호가 없다 → 글은 `canvas.draw_text`(없는 글자만 Pretendard 로 대신)로 그린다. `ImageDraw.text` 로 바로 그리면 빈 네모가 난다.
- 캔버스와 영상은 같은 글꼴 파일(작업 폴더 `fonts/`)로.

## 6. 소리
- 배경음 = 경쾌 팝(또는 행사 분위기면 축하 · 행사) · 효과음 묶음 경쾌 팝 — 떨어질 때 툭(impact) · 넘길 때 똑(tick) · 장면 사이 휙(cut) · 마지막 정보에 딩(done) (sound.md).

예시 코드 = `examples/photo_shorts_example.py`(틀이 아니라 수준의 기준 · 사진은 유저 것만).
