# 아트셀라 ARTSELAH — 온라인 전시장

`soonryu74.github.io/artselah/` 로 공개되는 정적 사이트입니다.
서버도 데이터베이스도 쓰지 않아, 파일만 고쳐 올리면 그대로 반영됩니다.

## 내용 고치기

화면 문구를 빼면 모든 내용은 `data/` 안 네 파일에 있습니다.

| 파일 | 내용 |
|---|---|
| `data/artists.json` | 작가 |
| `data/works.json` | 작품 |
| `data/exhibitions.json` | 전시 |
| `data/site.json` | 사이트 이름, 문의 주소 |

### 작품 사진 넣기

사진을 `assets/works/` 에 넣고, 그 작품에 `"image": "assets/works/파일명.webp"` 한 줄을 적습니다.
사진이 없는 작품은 작가 색과 작품 번호로 그린 자리그림이 대신 들어갑니다.

### 문의 주소

`data/site.json` 의 `contactEmail` 을 채우면 모든 작품의 "메일로 문의" 버튼이 그 주소로 갑니다.
비어 있으면 버튼이 "문의 주소 준비 중" 으로 바뀌고 눌리지 않습니다.

## 지켜야 할 것

- **없는 작가와 없는 작품을 올리지 않습니다.** 이 사이트는 작가의 이력과 권리를
  보증한다고 말하는 곳입니다. 견본 데이터가 공개되면 그 말이 먼저 무너집니다.
- **가격과 크기는 확인된 것만 적습니다.** 모르면 비워 둡니다. 화면에는 "가격 문의"로 나옵니다.
- 작품 사진은 저장소 안에 함께 둡니다. 외부 저장소를 참조하면 그쪽이 멈출 때 그림이 모두 깨집니다.
