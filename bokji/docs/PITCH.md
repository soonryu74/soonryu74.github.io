# 2분 시연 대본 — 모두의 복지 AI

**0:00 문제** — “복지로엔 이미 맞춤안내가 있고 정부24엔 혜택알리미가 있습니다. 그런데 78세 어머니는 그 목록을 보고도 어디에 전화해야 하는지 모릅니다. 우리는 ‘찾아주는’ 서비스가 아니라 ‘신청까지 움직이게 하는’ 서비스를 만들었습니다.”

**0:20 시연 A(독거노인)** — 홈에서 ‘가족을 위한 도움’ 누르고 말하기: *“78세 어머니가 혼자 사시고 무릎이 안 좋아 병원 가기 어렵습니다.”*
→ 질문 화면: 누구·나이·혼자가 **미리 채워져** 있음. ‘다음’만 누름. 장애 없음·등급 없음·병원·급하지 않음.
→ 결과: ① 장기요양 등급 신청(먼저 확인) ② 어르신 돌봄 서비스(조건 확인) ③ 장애인콜택시·휠체어 차량(먼저 확인). “왜 확인하나요”가 카드마다 있음.
→ ‘결과 읽어주기’ 한 번 틀기(3초).

**1:00 오늘 할 일** — “1. 1577-1000에 전화해 장기요양 등급 신청 상담 — 이렇게 말해 보세요 … 2. 129에 전화해 돌봄 서비스 상담 3. 지역 이동지원센터.” 체크 한 개 하고, **카카오톡용 복사** → 미리보기에 이름·나이 없음, 안전문구 있음.

**1:25 시연 C(위기)** — 홈 ‘예시 C’ 클릭: *“혼자 사는데 최근 소득이 줄고 전기요금이 부담됩니다.”* → 긴급복지·기초생활보장·전기요금 할인. 모두 **“조건 확인이 필요합니다”** — “AI는 수급자격을 확정하지 않습니다. 복지로도 맞춤안내는 최종 결정이 아니라고 명시합니다. 같은 원칙입니다.”

**1:45 안전·접근성** — 출처 화면: 21개 제도 모두 담당기관·공식 링크·확인일. 글자·소리에서 ‘아주 크게’ + 고대비 켜기. “서버도 로그인도 없습니다. 이름·주민번호·소득액은 묻지 않습니다.”

**1:55 마무리** — “모두의 복지 AI는 제도를 새로 만들지 않습니다. 기존 공공서비스와 국민 사이의 마지막 1미터를 연결합니다.”
