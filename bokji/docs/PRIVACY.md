# 개인정보 처리 — 모두의 복지 AI (MVP)

## 원칙: 받지 않는다
- 이름, 주민등록번호, 전화번호, 주소(동 단위), 소득 금액, 재산 금액, 계좌 — **입력란 자체가 없다.**
- 질문 7개는 모두 범주형이다: 누구를 위한 도움인지, 연령대, 혼자 지내는지, 장애 등록 여부, 장기요양 등급 여부, 가장 필요한 도움, 급한지.

## 어디에 저장되나
| 데이터 | 저장 위치 | 지워지는 때 | 서버 전송 |
|---|---|---|---|
| 입력 문장, 질문 답변, 할 일 체크 | 브라우저 `sessionStorage` | 탭을 닫으면 자동 삭제, ‘처음부터 다시 하기’로 즉시 삭제 | 없음 |
| 글자 크기·고대비·읽기 속도 | 브라우저 `localStorage` | 사용자가 브라우저 데이터 삭제 시 | 없음 |

- 서버·로그인·쿠키·분석 스크립트가 없다(정적 사이트).
- 음성 입력은 브라우저 내장 음성 인식(Web Speech API)을 쓴다. 브라우저 제조사 정책에 따라 음성이 제조사 서버에서 처리될 수 있으므로, 화면에서 “이름이나 주민번호는 말하지 마세요”라고 안내한다.
- ‘가족에게 보내기’ 글은 제도 이름·전화번호·오늘 할 일·안전문구만 담는다(E2E 테스트로 나이·관계어가 포함되지 않음을 확인).

## AI 엔드포인트를 연결할 때(선택)
- `VITE_AI_ENDPOINT`를 설정하면 입력 문장만 운영자 서버(프록시)로 보내고, 서버는 상황 태그만 돌려준다. API 키는 서버에 둔다.
- 운영 전 필요한 조치: 처리방침 고지, 전송 문장 미보관(또는 보관 기간 명시), 접근 통제. MVP 기본값은 **미연결**이다.

## 운영 시 추가 검토
- 공공기관 도입 시 개인정보 영향평가, 웹 접근성 인증(KWCAG 2.2) 심사.
