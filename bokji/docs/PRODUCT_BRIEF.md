# 모두의 복지 AI — 제품 요약(공모전용)

## 한 줄
**“내 상황을 말하면, 받을 가능성이 있는 복지·돌봄·생활지원 서비스를 쉬운 말로 정리하고, 오늘 무엇을 해야 하는지까지 알려주는 취약계층용 공공서비스 길잡이.”**

- 제출 제목(추천): **모두의 복지 AI — 취약계층의 복지정보를 ‘신청 행동’으로 연결하는 공공 AI 길잡이**
- 대안: 복지 한걸음 AI · 내곁의 복지 AI · 말하는 복지 길잡이

## 왜 하나 더 만드나 — 기존 서비스와의 차이
| | 복지로 맞춤형급여안내(복지멤버십) · 정부24 혜택알리미 | 모두의 복지 AI |
|---|---|---|
| 역할 | 받을 가능성이 있는 서비스를 **찾아 안내** | 찾은 뒤 **이해하고 신청까지 움직이게** 함(last mile) |
| 입력 | 가입·본인 인증, 행정데이터 | 말 한마디(음성·글) + 큰 버튼 질문 최대 7개, 민감정보 없음 |
| 출력 | 서비스 목록 | 먼저 확인할 3가지 → 왜 → 어디에 전화 → 뭐라고 말할지 → 준비물 → 오늘 할 일 1·2·3 → 공식 링크 → 가족에게 보내기 |
| 대상 | 전 국민 | 고령자·장애인·보호자 우선(큰 글씨·음성·고대비·한 화면 한 행동) |
| 관계 | — | **대체가 아니라 연결**: 결과마다 복지로·정부24로 보내고, 복지멤버십 가입을 ‘오늘 할 일’에 넣음 |

## 해결하는 문제
1. 제도 이름이 어렵다 → 쉬운 이름(예: ‘장기요양 등급 신청’)과 한 줄 설명
2. 어디에 신청하는지 모른다 → 기관·전화·방법·준비물을 카드마다
3. 본인 상황을 행정용어로 못 바꾼다 → 자연어를 상황 태그로 바꾸고 큰 버튼으로 확인
4. 보호자가 대신 알아본다 → 보호자 모드, 가족에게 보내기(개인정보 없음)
5. “받을 수 있는지”와 “지금 뭘 해야 하는지”가 분리돼 있다 → 오늘 할 일 1·2·3

## 안전 원칙(심사 핵심)
- AI가 수급자격을 **확정하지 않는다**. 표현은 세 가지뿐: 먼저 확인해 보세요 / 조건 확인이 필요합니다 / 현재 정보만으로 판단하기 어렵습니다.
- **공식 데이터 → 규칙 필터 → 쉬운 설명 → 공식 원문 링크.** 서비스는 화이트리스트(`services.json`)에서만 나온다.
- 공식 URL 미확인 항목은 `null` → “공식 링크 확인 중”. 가짜 번호·URL 없음.
- 의료 진단·소득/재산 자동판정 없음. 긴급 신호(실직·병원비·학대·마음 건강)는 119·129·109를 맨 위에.

## MVP 범위
- 대상군: 노인 + 장애인 + 보호자
- 제도 21종: 노인맞춤돌봄, 장기요양인정, 기초연금, 방문건강관리, 특별교통수단, 무릎인공관절 수술비, 응급안전안심, 치매안심센터, 장애인 활동지원, 발달장애인 주간활동, 부모상담지원, 장애인연금, 장애수당, 보조기기 교부, 긴급복지, 기초생활보장, 에너지바우처, 전기요금 복지할인, 재난적의료비, 복지멤버십, 정부24 혜택알리미
- 데모 3개: A 독거노인(병원 이동·돌봄) · B 장애인 보호자(낮 시간 돌봄) · C 경제·생활 위기(생활비·에너지)

## 사용 흐름(화면)
1. 홈 — 누구를 위한 도움인지(나/가족) · 큰 마이크 · 큰 입력창 · 예시 문장 5개 · 시연 예시 3개
2. 질문 — 최대 7개, 한 화면 한 질문, 말한 내용으로 미리 채움(소득·재산 금액은 묻지 않음)
3. 결과 — 먼저 확인할 지원 3장 + 추가로 확인할 서비스 + 긴급 패널(해당 시) + 읽어주기
4. 상세 — 왜·어디에·어떻게·뭐라고 말할지·준비물·대상 요약·공식 링크·출처/확인일
5. 오늘 할 일 — 전화번호별로 묶은 1·2·3, 체크, 카카오톡/문자용 복사·인쇄·읽어주기
6. 글자·소리 — 18/22/26px, 고대비, 읽기 속도
7. 출처·한계·개인정보 / 급할 때 연락처

## 접근성
기본 18px · 초대형 글자 · 브라우저 TTS · 음성 입력 · 터치 44px 이상(버튼 56~72px) · 키보드 조작 · 화면 전환 시 제목에 초점 · 고대비 · 상태를 색+아이콘+글자로 표시 · 쉬운 한국어 · 한 화면 한 행동 · 뒤로 버튼 · 개인정보 저장 없음
