# 한계와 알려진 제약 — 모두의 복지 AI (MVP)

1. **수급자격 판정 불가**: 소득·재산을 받지 않으므로 소득 기준이 있는 제도는 항상 “조건 확인이 필요합니다”로 표시된다. 이것은 설계된 동작이다.
2. **지역별 제도 미수록**: 시·군·구 자체 지원(교통비, 지역 돌봄, 지자체 긴급복지 등)은 아직 없다. 결과마다 정부24 혜택알리미·행정복지센터로 연결한다. 특별교통수단은 지역마다 대상·요금이 달라 “지역 센터에 확인”으로만 안내한다.
3. **자연어 해석은 키워드 규칙**: 낯선 표현·사투리·오타는 놓칠 수 있다. 그래서 질문 화면에서 반드시 다시 확인하고, 답변이 자연어보다 우선한다. AI 엔드포인트를 연결해도 태그 화이트리스트 밖의 값은 버린다.
4. **공식 링크 검증 방식**: 개발 환경이 정부 사이트 접속을 막아, 공식 주소는 검색 색인(해당 도메인 결과)으로 확인했다(`verification: "search-index"`). 배포 전 `npm run check:links`로 직접 접속 확인이 필요하다. 정부 사이트는 주소 개편이 잦아 `last_checked`를 주기적으로 갱신해야 한다.
5. **제도 기준은 해마다 바뀐다**: 금액·기간(예: 에너지바우처 신청 기간, 기초연금 선정기준액)은 본문에 최소한만 적고 공식 사이트로 보낸다.
6. **전화번호가 지역마다 다른 제도**(보건소, 이동지원센터)는 번호를 싣지 않고 “129에 물으면 알려준다”로 안내한다.
7. **음성 기능은 브라우저 의존**: 음성 입력은 크롬·엣지·사파리 등 Web Speech API 지원 브라우저에서만 동작하고, 지원하지 않으면 안내문을 보여준다. 읽어주기 음색·속도는 기기마다 다르다.
8. **다국어·수어·Easy Read 미지원**: 다음 단계.
9. **오프라인 미지원**: 정적 사이트지만 서비스워커는 넣지 않았다(PWA는 다음 단계).
