## 작품 제목(안)
**돌봄의 빈칸을 보이게 하는 제안 — ‘돌봄 공백 지도’ 한 장**

## 작품 설명(안, 접수 화면 설명란용 · 응모자가 다듬어서 사용)
장기요양 수급자 10명 중 8명이 집에서 돌봄을 받는 시대입니다. 그런데 주 3회 방문요양 9시간을 받아도 나머지 159시간이 어떻게 비어 있는지, 식사·복약·야간 안전 같은 돌봄 기능이 실제로 채워졌는지는 가족도 상담 창구도 한눈에 보지 못합니다.
이 카드뉴스는 통합돌봄(2026.3.27 전국 시행) 신청 ‘전’ 단계에 가족이 작성하는 **‘돌봄 공백 지도’ 한 장**을 공공병원 퇴원 전 상담실·읍면동 통합돌봄 창구·보건소에 두자고 제안합니다. 일주일 돌봄 일정을 적으면 비어 있는 시간과 빠진 돌봄 영역이 표시되고, 그 빈칸에 맞는 공공 서비스(응급안전안심서비스·노인맞춤돌봄·치매안심센터·통합돌봄)로 안내합니다. 판정은 공개된 규칙으로 하고 근거를 함께 보여주며, 진단·예측이 아닌 정리 도구입니다. 지역 공공병원 한 곳의 퇴원 환자 가족부터 작게 시범을 시작해 발견된 공백 수와 서비스 연결 수를 측정하자는 것이 결론입니다.

## 생성형 AI 활용 내역(안) — 지정 양식에 옮겨 적기
- 사용 도구: Claude (Anthropic) — Claude Code 세션
- 활용 범위: 카드 문구 초안 작성, 카드 레이아웃(HTML/CSS) 코드 작성, 공모 요강·통계 검색 보조
- 응모자가 직접 한 것: 핵심 아이디어(돌봄 공백 지도 — 응모자가 개발 중인 CareGap 프로젝트 기반), 사실 확인, 문구 최종 편집, 제출
- 사용하지 않은 것: AI 생성 이미지·사진·음성 (그래픽은 모두 코드로 그린 도형)
- 마지막 컷에 AI 활용 표시 완료(요강 요구사항)
