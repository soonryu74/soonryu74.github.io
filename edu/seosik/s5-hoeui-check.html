통합지원회의 체크 — 참여자의 일

S52026-09 v1

회의는 시군구가 주재한다. 우리는 참여자. 참여자의 일은 준비해 오고, 짧게 말하고, 받아 적고, 돌아가서 하는 것.

개최 사유우리가 준비해 갈 것
신규 (첫 계획)사정표·니즈 정리표·계획서 초안·물을 것 목록
재판정·등급 변경바뀐 것 요약·수정 계획서 초안
퇴원 통보 (협약병원)퇴원 요약 받은 것·첫 주 계획·의료 연계 상태
상황 급변 (입원·낙상·가족 변화)무슨 일이 언제·지금 상태·긴급 필요
지원 곤란 (거부·갈등·복합 과제)시도한 것·막힌 지점·부탁할 것
회의 전
  • 정보 제공 동의 확인(문서)
  • 계획서 초안·사정 근거 2개 준비
  • 물을 것·부탁할 것 목록
  • 다른 기관이 무엇을 하는지 미리 확인
  • 온라인이면 자료 공유·카메라 점검
회의 중
  • 3분 발언: 본 것 → 제안 → 부탁 → 확인
  • 다른 기관 몫을 받아 적기
  • 정합 확인 한 문장 (아래)
  • 결정 사항·기한 확인
  • 금지 표현 안 쓰기
회의 후
  • 남은 과제·다음 회의 기록
  • 배포 자료 회수·폐기
  • 우리 기록(회의 메모 S13-④)
  • 본인·가족에게 결과 설명
정합 확인 한 문장
"우리 (서비스·빈도)가 계획서 단기목표 (번호)와 맞습니까?"
계획서와 각 기관 급여제공계획이 어긋나면 회의에서 잡는다. 확인 의무 규정은 없지만 어긋난 채 두면 한 달 뒤 모니터링에서 드러난다.
금지 표현
"당연히" · "원래" · "그건 저희 일이 아닌데" · "어르신이 고집이 세서" · "치매라서" · 진단하는 말(병명을 단정) · "제가 보기엔 ○○병 같아요" · "보호자가 알아서" · "예산이 없어서" · 본인 앞에서 본인을 3인칭으로
3분 발언 구조: ① 우리가 본 것(사정 근거 2개) ② 우리가 제안하는 것(서비스·빈도·이유) ③ 다른 기관에 부탁하는 것 ④ 확인하고 싶은 것.
