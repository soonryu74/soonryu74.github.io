## 알려진 기술부채

- 비회원 주문은 DB 정책상 막혀 있다 (주문은 로그인 필요). 비회원 결제를 열려면 서버 경로에서 주문을 만들어야 한다.
- 결제대행사 연동은 인터페이스(`src/lib/payments.ts`)만 있고 실제 SDK 호출은 없다.
- 지도 SDK, 공공데이터 수집기, 좌표 변환은 Phase 2.
- 가족 초대는 테이블과 정책만 있고 화면이 없다.
- 콘텐츠 본문 편집기, 상품·로트 관리 화면이 없다 (Supabase 표 편집기로 입력).
- 업로드 파일 악성코드 검사는 연결되어 있지 않다.
