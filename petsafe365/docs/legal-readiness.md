# 법무 준비 상태

이 문서와 앱 안의 약관은 운영 초안이다. 유료 공개 전에 변호사·세무사·보험/위치정보 전문가 검토가 필요하다.

## 기능 플래그 (모두 기본 꺼짐)

켜는 방법: 관리자 화면 `/admin/flags` 에서 사유를 적고 켠다. DB 는 승인자·승인 시각 없이는 켜지지 않게 막고, 변경은 감사로그에 남는다.

| 플래그 | 켜기 전 조건 |
|---|---|
| `paymentsEnabled` | 사업자등록, 통신판매업 신고(구매안전서비스 확인증), 결제대행사 계약·심사, 환불 정책 확정 게시, 판매자·수입자 정보 표시, 시험 결제·환불 확인 |
| `partnerSubscriptionsEnabled` | 위 결제 조건 + 파트너 계약서, 광고·유료 제휴 표시 정책 |
| `insuranceReferralEnabled` | 보험 모집 관련 인가 또는 적법한 제휴 구조, 금융 전문가 검토. 그 전에는 추천·순위·가입 연결을 만들지 않는다 |
| `preciseLocationStorageEnabled` | 위치정보 처리 구조 확정, 별도 동의 화면, 보유기간·삭제 기능 |
| `publicReviewsEnabled` | 게시물 운영정책, 권리 침해 신고 창구, 구매 인증 방식, 협찬 표시 |
| `adsEnabled` | 월 이용자 5천 명, 광고 표시 정책 게시, 금지 화면 점검 (`commerceAllowedOn`) |

## 출시 전에 확정할 문서

- [ ] 서비스 이용약관 (초안 `terms` 0.1-draft)
- [ ] 개인정보 처리방침 (초안 `privacy`) — 보호책임자, 처리 위탁 업체, 국외 이전 여부 기재
- [ ] 위치정보 안내 (초안 `location`)
- [ ] 환불·청약철회 정책 (초안 `refund`)
- [ ] 저작권·게시물 정책 (초안 `copyright`)
- [ ] 광고·협찬 표시 정책 (초안 `ads`)
- [ ] 파트너 입점·광고 계약서
- [ ] 개인정보 사고 대응 절차
- [ ] 데이터·사진·폰트 라이선스 관리대장

## 용품 판매 전 확인 (보고서 참고)

- [ ] 장난감 품목의 관세율·HS 분류 (관세사)
- [ ] 검역 대상 여부 (농림축산검역본부)
- [ ] 안전기준·KC 적용 여부 (국가기술표준원 1381)
- [ ] 로트별 유해물질 시험 (6가 크롬, 아조염료, 폼알데하이드, 중금속)
- [ ] 한글 표시사항, 원산지·수입자 표시
- [ ] 생산물배상책임보험
- [ ] "천연·친환경·무독성" 표현을 쓰지 않고 시험 항목과 결과로만 표시

## 개발에 반영된 통제

- 동의는 문서 버전과 함께 `user_consents` 에 남고, 필수와 선택(마케팅)을 분리했다.
- 탈퇴와 내 데이터 확인은 `/more` 에 있다.
- 건강·보험·위치·신고 데이터는 분석이나 광고에 쓰지 않는다 (분석 도구 자체가 아직 없다).
- 문서 파일은 비공개 버킷, 60초 서명 URL, MIME·크기 서버 검증.
- **악성파일 검사 연결 지점**: `src/lib/repo/supabase.ts` 의 `files.upload`. 업로드 뒤 검사 서비스를 호출하고 통과 전에는 열람을 막는 단계를 여기에 넣는다 (미구현).
- 정밀 위치는 저장하지 않는다. `incident_drafts.location_precision` 은 `none`/`district` 만 허용한다.
