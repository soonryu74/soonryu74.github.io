## 규칙

- 원본(`facilities_raw`)과 서비스용(`facilities`)을 분리한다. 중복 방지 키는 `source_system + source_id`.
- EPSG:5174 좌표는 WGS84 로 변환하고 변환 로그를 남긴다 (Phase 2, 미구현).
- 폐업·휴업은 삭제하지 않고 `business_status` 로 남긴다.
- 24시간·응급·동반 가능은 확인값이 없으면 `unverified` → 화면에 "미확인".
- 검색 포털의 리뷰·사진을 복제하지 않는다.
- 현재 `facilities` 의 5건은 `is_example = true` 인 예시이며 실제 장소가 아니다.
