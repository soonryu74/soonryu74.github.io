# 법무 준비 상태와 기능 플래그

- 작성일: 2026-09-25
- 이 문서는 법률자문이 아니다. 유료 공개 전 변호사·세무사·보험/위치정보 전문가 검토가 필요하다.

## 기능 플래그 (기본값 모두 false)

| 플래그 | 의미 | 현재 | 켜기 전 필요한 것 |
|---|---|---|---|
| `paymentsEnabled` | 결제 | false | 사업자등록·통신판매업 신고·PG 계약·환불 정책·청약철회 흐름 |
| `partnerSubscriptionsEnabled` | 파트너 유료 구독 | false | 파트너 계약서·광고 표시 정책·검증표 |
| `insuranceReferralEnabled` | 보험 추천·모집 연계 | false | 보험대리점 등 인가 또는 인가 파트너 계약, 금융위 비교·추천 가이드 검토 |
| `preciseLocationStorageEnabled` | 정밀 위치 저장 | false | 위치정보사업/위치기반서비스 신고 여부 검토, 별도 동의·보유기간·삭제 기능 |
| `publicReviewsEnabled` | 공개 후기 | false | 게시물 정책·신고/삭제 절차·광고성 후기 표시 기준 |

- 저장 위치: DB `feature_flags` 테이블. 코드에 true를 써도 켜지지 않는다(`resolveFlags`가 DB 값만 읽고 기본은 false).
- 켜는 방법: 관리자가 `approved_by`와 `reason`을 함께 기록해야 한다. DB 트리거가 둘 중 하나라도 없으면 거부하고, `approved_at`을 자동 기록한다.
- 현재 앱에는 플래그를 켜는 UI가 없다(의도). SQL로만 가능하며 그 변경도 `audit_logs`에 수동으로 남긴다.

## 구현된 통제

- 가입 시 필수 4개 문서 동의, 선택 동의(소식 이메일) 분리. 동의한 문서 버전·시각·IP 해시 저장(`user_consents`).
- 새 버전이 게시되면 다음 방문 시 `/consent`로 재동의를 받는다.
- 탈퇴: `/account`에서 확인 문구 입력 후 즉시 삭제. 서비스 롤 키가 없으면 반려동물 데이터는 즉시 삭제하고 계정 삭제는 "요청"으로 기록(운영자 처리 필요).
- 내 데이터 내려받기: `/api/account/export` (JSON).
- 감사로그: 로그인·로그아웃·동의·반려동물 생성/수정/삭제·문서 업로드/열람/삭제·데이터 내려받기·탈퇴·관리자 조회/변경. 수정·삭제 정책 없음(불변).
- 건강문서·보험문서·위치·신고정보는 분석·광고 이벤트에 넣지 않는다(현재 분석 도구 없음).
- 주민등록번호·사람 진단정보 입력란 없음.
- 사진·문서 업로드 전 권리보유·타인 개인정보 비노출 확인 체크.

## 출시 전 사업자가 정해야 할 값

사업자명·대표자·사업자등록번호·주소, 고객센터, 개인정보 보호책임자, 처리위탁 업체(Supabase 리전), 통신판매업 신고, PG 계정, Kakao 앱 키와 허용 도메인, 공공데이터·TourAPI 키, 운영자·검수자 계정, 수의사·법률·보험 검수 체계, 상표·도메인 확인.
