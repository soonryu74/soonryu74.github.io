# 건강·감염병 콘텐츠 검수 흐름

## 상태

`draft(초안) → in_review(검수 중) → approved(승인됨) → published(게시 중) → expired(만료) / archived(보관)`

- 허용 전이는 `src/lib/content-rules.ts`의 `CONTENT_TRANSITIONS`.
- 승인·게시 전 필수: 검수자 이름, 검수자 자격, 검토일, 다음 검토예정일(= 공개 만료일).
- 공개 조건(앱 + DB RLS 이중): 카드 `published` + 현재 버전 `approved/published` + 검수자·검토일 존재 + 만료일 전.
- 만료일이 지나면 자동으로 비공개되고 목록에 "전문가 검수 중"과 공식 출처 링크만 보인다.

## 운영 절차

1. `/admin/content`에서 "새 버전 작성"으로 초안을 만든다(변경 사유·공식 출처 필수, https만).
2. 수의사 검수자가 내용과 출처 원문을 대조한다. 동물 신호/사람 신호, "사람이 의료기관에 갈 때"/"동물병원에 갈 때"가 섞이지 않았는지 확인한다.
3. 검수 정보를 기록하고 `승인됨 → 게시 중`으로 바꾼다. 이전 게시 버전은 자동 보관된다.
4. 모든 변경은 감사로그(`content.reviewed`, `content.status_changed`, `content.version_created`)에 남는다.

## 금지

- 진단명 확정, 약 이름·용량, 치료 결정 제시.
- 공식 출처 없는 수치.
- 검수 전 공개.
