# CareGap AI (케어갭 AI) — 경쟁·유사 서비스 조사

- 조사일: **2026-10-05**
- 조사 방법: WebSearch(검색엔진 결과 요약) 기반. 컨테이너 네트워크 정책상 `*.go.kr`, `data.go.kr`, `nid.or.kr`, `opendata.hira.or.kr` 등은 **직접 열람(WebFetch/curl)이 차단**되어, 각 서비스의 기능은 공식 페이지·보도자료·언론 기사의 **검색 결과 요약**으로 확인했다.
- 표기 원칙
  - **있음 / 없음**: 공개 자료에서 확인한 범위 내 판단
  - **미확인**: 공개 자료로 확인하지 못함(존재하지 않는다는 뜻이 아님)
  - 기능을 추정해 채우지 않았다. 앱 내부(로그인 후) 기능은 대부분 확인하지 못했다.

## 0. 비교 기준(질문 정의)

| 기준 | 의미 |
|---|---|
| A. 일정 시각화 | 어르신 1명의 7일×24시간 돌봄 일정을 한 화면(그리드/타임라인)으로 보여주는가 |
| B. 공백 자동 탐지 | 입력된 일정에서 "아무도 없는 시간"을 자동 계산·표시하는가 |
| C. 기능별 Care Gap 설명 | 식사·복약·이동·위생·병원동행·인지·낙상·야간·응급·사회적 접촉·가족 부담 등 **기능 단위**로 무엇이 비어 있는지 설명하는가 |
| D. 공공서비스 연결 | 비어 있는 기능에 맞는 공공/지역 서비스를 안내하는가 |

### 1-2. 지역사회 통합돌봄 (돌봄통합지원법)

- **시행 확인**: 2026년 3월 27일 전국 시·군·구 전면 시행(보건복지부 보도자료·정책브리핑으로 확인). 2026년 예산 914억 원(전년 71억 원)으로 확대
- 운영: 보건복지부 / 시·군·구(통합지원 전담), 국민건강보험공단
- 하는 일: 노쇠·장애·질병으로 일상생활 유지가 어려운 사람에게 시·군·구가 **돌봄 필요를 조사 → 개인별 지원계획 수립 → 의료·요양·돌봄 서비스 연계**. 언론 보도 기준 도입 단계 4개 분야 30개 서비스 연계, 2030년까지 60개 수준 확대 계획. 통합판정조사는 의료·간호·기능·돌봄·주거 5개 영역 58개 항목(언론 보도, 공식 원문 미열람 → 세부 수치는 재확인 필요)
- 신청: 읍면동 행정복지센터, 국민건강보험공단 지사(복지로·정부24 온라인 신청 여부는 2차 블로그 자료에만 있어 **미확인**)
- 실적: 시행 2주 만에 8,905명 신청(정책브리핑), 6월 26일 기준 4만6,215명 신청(언론 보도)
- 일정 시각화: 없음(국민용 도구로 공개된 것은 확인되지 않음. 내부 정보시스템 화면은 미확인)
- 공백 자동 탐지: 국민이 직접 쓰는 자동 도구는 없음. **담당 공무원의 방문 조사**로 필요를 파악하는 구조
- 기능별 Care Gap 설명: 행정 판정 영역(의료·간호·기능·돌봄·주거) 단위로 욕구를 파악하나, 가족이 결과를 즉시 보는 화면은 미확인
- 시사점: CareGap의 **가장 중요한 연결 대상**. CareGap 결과를 들고 읍면동에 상담·신청하도록 안내하는 "사전 정리 도구"로 포지셔닝 가능
- URL: https://www.mohw.go.kr/board.es?mid=a10503000000&bid=0027 (보도자료 목록), https://www.korea.kr/news/policyNewsView.do?newsId=148962660
- 확인일: 2026-10-05

## 5. 핵심 질문에 대한 답

> **"24시간 또는 7일 돌봄 일정을 시각화하고, 가족의 돌봄 공백을 자동으로 탐지하며, 기능별 Care Gap을 설명하는 서비스가 이미 있는가?"**

**답: 국내에서는 세 가지를 모두 갖춘 서비스를 찾지 못했다(2026-10-05 기준, 공개 자료 범위).**

- **국내 공공**: 통합돌봄·노인맞춤돌봄·돌봄SOS 모두 "돌봄 필요/공백"을 **공무원·사회복지사의 대면 조사**로 판단한다. 가족이 스스로 일정을 넣고 공백을 보는 국민용 도구는 확인되지 않았다. 복지로는 소득·가구 기반 **자격 매칭**이고, 장기요양 인정점수는 **필요도 평가**다.
- **국내 민간**: 케어닥·케어링·보살핌·한국시니어연구소는 모두 **인력 매칭/서비스 제공/기관 행정**이 본업이다. 케어링의 "돌봄 징후 10가지"가 가장 가까운 콘텐츠지만 정적인 관찰 체크리스트다. 효돌·응급안전안심서비스는 **센서 기반 이상 감지**로, 일정 공백 분석과는 다르다.
- **해외**: Lotsa Helping Hands, ianacare, Carely는 **공유 캘린더 + 빈 시프트/요청 표시**를 이미 제공한다. ianacare는 "돌봄 공백 탐지"를 표방한다(구체 방식 미확인). 따라서 **"일정 시각화 + 빈 시간 표시" 자체는 해외에 선례가 있다.** 다만 **기능 단위(식사·복약·야간 안전 등) Care Gap 규칙 해석 + 한국 공공서비스 연결**을 함께 하는 사례는 확인하지 못했다.
- 한계: 앱 내부(로그인 후) 기능, 지자체 자체 앱, 수행기관 내부 시스템은 확인하지 못했다. 비슷한 소규모 서비스가 있을 수 있다.

## 6. CareGap 차별점

1. **"시간 공백"과 "기능 공백"을 함께 본다**
   해외 캘린더 앱은 "누가 언제 있나"만 본다. CareGap은 같은 일정에서 "그 시간에 **식사·복약·이동·위생·야간 안전·응급 대응**이 실제로 누구에 의해 해결되는가"를 규칙으로 판정한다. 예: 요양보호사 3시간 방문이 있어도 저녁 복약·야간 화장실 이동은 비어 있을 수 있다.
2. **가족이 혼자 5~10분 안에 쓰는 사전 정리 도구**
   공공 통합돌봄은 신청 후 방문조사까지 시간이 걸리고 사람이 판단한다. CareGap은 신청 **전에** 가족이 상황을 정리해 읍면동·건보공단 상담에 가져갈 수 있게 한다(통합돌봄의 경쟁자가 아닌 **입구**).
3. **한국 공공·지역 서비스로 연결**
   공백 기능별로 통합돌봄, 장기요양, 노인맞춤돌봄, 응급안전안심서비스, 치매안심센터, 보건소, 교통약자 이동지원센터, 지자체 복지서비스를 매핑한다. 민간 매칭 앱처럼 특정 업체로 유도하지 않는다.
4. **가족 부담을 공백으로 다룬다**
   주 돌봄자 1인 집중, 연속 야간 돌봄 등을 "가족 부담" 기능 공백으로 표시한다. 기존 국내 서비스에서는 확인되지 않은 관점이다.
5. **시설 검색 서비스가 아니고, 진단하지 않는다**
   규칙 기반으로 "확인할 점"과 "알아볼 서비스"만 제시하며, 의료적 진단·등급 예측·기관 추천을 하지 않는다. 이는 법적·신뢰 리스크를 낮추는 동시에 케어닥·케어링 등 민간 매칭과 겹치지 않는 위치다.
6. **로그인·개인정보 수집 최소화(설계 목표)**
   일정·체크 입력을 브라우저 안에서만 계산하면 민감한 건강 정보를 서버에 저장하지 않아도 된다(설계 시 확정 필요).

### 주의할 점(정직한 포지셔닝)
- "세계 최초"나 "유일한 서비스"라고 표현하지 않는다. 해외에 일정 공유·공백 표시 선례가 있다.
- 공공 통합돌봄의 판정을 대신하거나 예측한다고 표현하지 않는다.
- 연결 서비스의 자격 요건(소득·연령·등급)은 지역·연도별로 바뀌므로 "해당 여부는 기관 확인 필요"로 표기한다.
