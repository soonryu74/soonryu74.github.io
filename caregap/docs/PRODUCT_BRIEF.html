CareGap AI (케어갭 AI) — 제품 개요

부모님의 돌봄에서 비어 있는 시간을 찾아드립니다. · Find the gaps in your parent’s care.

한 문장 정의

고령 부모의 현재 돌봄 일정(7일×24시간) 과 가족이 느끼는 걱정을 입력하면, 공개된 규칙으로 ① 언제 비어 있는지 ② 어떤 돌봄 기능이 빠져 있는지 ③ 무엇을 확인해야 하는지 ④ 어떤 공공·지역 서비스를 알아볼지를 정리해 주는 Care Gap Detection + Care Planning 도구. 요양기관 검색 서비스가 아니다.

대상 사용자

  • 1차: 80대 부모를 원거리·맞벌이로 돌보는 50~60대 자녀 (모바일, 큰 글씨 필요)
  • 2차: 방문요양센터·사회복지사·통합돌봄 창구 상담 전 사전 정리용(향후 B2G/B2B)

해결하는 문제

  • 주 3회 방문요양(9시간)을 받아도 나머지 159시간이 어떻게 비어 있는지 가족이 한눈에 보기 어렵다.
  • “돌봄을 받고 있다”는 사실과 식사·복약·야간 안전 같은 기능이 실제로 채워졌는가는 다른 문제다.
  • 공공 서비스는 많지만 가족은 어떤 공백에 어떤 제도가 맞는지 모른다.

MVP 기능 (구현 완료)

| 기능 | 내용 | |—|—| | 4단계 온보딩 | 기본정보(연령·성별·시군구·독거·등급 선택) → 걱정 9개 + 참고 정보(판단 미사용) → 이용 서비스 → 요일·시간 일정(여러 요일 동시 추가, 자정 넘김, 수정, 삭제) | | Care Map | 데스크톱: 요일×24시간 가로 타임라인(00–24, 3시간 눈금) / 모바일(≤720px): 요일 카드 타임라인. 빈 시간·야간 구간을 글자+무늬로 표시 | | Care Gap 엔진 | 규칙 파일 app/src/data/care_gap_rules.json — 11개 영역, 27개 규칙(ID·버전·근거·서비스 범주), 3단계 결과(확인 필요/입력으로 확인됨/현재 입력상 공백 발견 안 됨) | | 설명 가능성 | 모든 결과에 “왜 이 결과가 나왔나요?” — 입력 값 → 적용 규칙 → 결과 | | 서비스 연결 | 영역별 공공·지역 서비스 안내(공식 누리집 링크, 확인일 표기) + 시군구 장기요양기관 목록(VERIFIED PUBLIC DATA). 치매안심센터·보건소는 SOURCE NOT YET CONNECTED | | 가족 공유 | 주간 일정 + 확인 필요 영역 + 가족이 정한 할 일을 담은 공유 카드(미리보기·텍스트 복사·Web Share·PNG 저장). 연령대·지역 기본 제외, 메모·참고 정보 항상 제외 | | 예시로 체험하기 | 82세 독거 여성 사례 자동 입력 → 즉시 결과 | | 자연어 입력(선택) | “엄마가 자꾸 넘어지고…” → 후보 추출 → “다음 내용으로 이해했습니다” 확인 후 반영 |

하지 않는 것

진단, 낙상·치매 예측, 장기요양등급 판정, 의료서비스 추천, 기관 순위 추천, 개인 식별정보 수집.

기술

React 19 + TypeScript + Vite 7 (정적 빌드, 서버 없음) · 상태는 localStorage · 테스트: Vitest(엔진) + Playwright(390/768/1280px).
