# 공모전 전략 — CareGap AI

## 한 문장 답 (심사위원: “기존 통합돌봄·장기요양서비스와 뭐가 다른가?”)
> **“통합돌봄·장기요양은 ‘누가 어떤 서비스를 받을 자격이 있는가’를 공공이 판단하는 제도이고, CareGap은 그 이전에 가족이 ‘지금 받는 돌봄으로 일주일 168시간 중 어느 시간·어떤 기능이 비어 있는가’를 스스로 보고 그 공백에 맞는 제도로 찾아가게 하는 입구입니다.”**

## 1. 문제
- 2026년 3월 「돌봄통합지원법」 전국 시행으로 서비스는 늘었지만, 가족이 체감하는 질문은 여전히 “**지금 엄마가 혼자 있는 시간은 언제지? 그때 뭐가 빠져 있지?**”다.
- 주 3회 3시간 방문요양 = 주 9시간. 나머지 **159시간**의 공백은 아무도 그려주지 않는다.
- 공공 서비스 정보는 제도 단위(대상·자격)로 흩어져 있고, 가족은 공백 단위(밤·복약·병원 동행)로 생각한다. 이 **번역**이 없다.

## 2. 사용자
- 1차: 원거리·맞벌이로 80대 부모를 돌보는 50~60대 자녀(대표 시나리오: 서울 근무 딸, 82세 독거 어머니, 장기요양 3등급).
- 2차: 읍면동 통합돌봄 창구·방문요양센터·사회복지사(상담 전 사전 정리 자료).

## 3. 기존 서비스의 한계 (조사: [COMPETITOR_RESEARCH.md](COMPETITOR_RESEARCH.md))
| 구분 | 하는 일 | CareGap이 보는 빈칸 |
|---|---|---|
| 노인장기요양보험 | 등급 판정·급여 제공 | 급여 시간 밖의 공백은 가족 몫 |
| 지역사회 통합돌봄 | 신청 후 공무원·전문가가 필요도 조사·연계 | 신청 **전** 가족의 상황 정리 도구 없음 |
| 복지로·정부24 | 자격(소득·연령) 기반 서비스 검색 | “어떤 공백에 어떤 서비스”로 찾을 수 없음 |
| 응급안전안심·돌봄로봇 | 센서로 응급 감지 | 일정상 공백·기능 공백은 다루지 않음 |
| 케어닥·케어링 등 민간 | 요양보호사·기관 매칭 | 매칭 전 “무엇이 필요한지” 정리는 사용자 몫 |
| 해외 캘린더 앱(Lotsa, ianacare) | 가족 일정 공유·빈 시간 표시 | 기능별 공백·한국 공공서비스 연결 없음 |

국내에서 “7일×24시간 시각화 + 자동 공백 탐지 + 기능별 설명”을 함께 하는 서비스는 확인되지 않았다. 다만 일정 공유·빈 시간 표시 자체는 해외에 선례가 있으므로 “세계 최초”라고 주장하지 않는다.

## 4. CareGap 차별점
1. **시간 공백 × 기능 공백**: 168시간 지도 위에서 식사·복약·야간 안전 등 11개 기능을 따로 점검.
2. **설명 가능한 규칙 엔진**: 27개 규칙이 공개 파일로 존재, 결과마다 입력 → 규칙 → 결과를 보여줌. 블랙박스 AI 판정 없음.
3. **공백 → 한국 공공제도 매핑**: 야간 안전 → 응급안전안심서비스, 기억력 → 치매안심센터, 병원 이동 → 병원동행·교통약자 이동지원 등.
4. **개인정보 최소화**: 이름·주민번호 없이, 서버 저장 없이 동작.
5. **가족 공유 카드**: 형제·자매가 같은 그림을 보고 역할을 나눔.

## 5. 공공데이터 활용
- 사용 중: 국민건강보험공단 장기요양기관 평가결과(27,946곳) → 공백 영역에 맞는 급여종류의 시군구 기관 자동 필터.
- 연결 준비: 치매안심센터(국립중앙의료원), 전국보건기관표준데이터 — 파일 투입 시 자동 연결.
- 확장: 지자체복지서비스·중앙부처복지서비스 API로 “우리 시군구의 실제 돌봄 사업” 자동 매핑.
- 원칙: 미연결 데이터는 “출처 확인 중”으로 정직하게 표시(가짜·0건 표시 금지, 자동 테스트로 검증).

## 6. AI 활용 이유와 범위
- 판정은 규칙 엔진, AI는 **입력 장벽을 낮추는 데만** 사용: 50~60대 가족이 체크리스트 대신 “엄마가 요즘 자꾸 넘어지고 밤에 혼자 계셔서 걱정돼요”라고 말하면 후보를 구조화 → **사용자 확인 후 반영**.
- 이렇게 나눈 이유: 돌봄 판단은 설명 가능해야 하고(신뢰), 오류 시 책임 소재가 명확해야 하기 때문.
- 향후: 상담 메모 요약, 지자체 복지서비스 설명문 → 공백 영역 태깅(사람 검수 후 반영).

## 7. 사회적 가치
- 돌봄 공백(특히 독거 어르신의 야간·주말)의 **가시화** → 가족의 조기 대응.
- 공공 서비스 **이용률 제고**: 몰라서 못 쓰는 응급안전안심·노인맞춤돌봄·치매안심센터로 연결.
- 가족 돌봄 부담(한 사람 집중)을 공백으로 다뤄 돌봄 노동의 분담을 돕는다.

## 8. 확장성
- 규칙·서비스 매핑이 JSON이라 지자체별 사업을 데이터로 추가 가능.
- 장애인·중증질환 가족 돌봄으로 영역 확장.
- 다국어(외국인 요양보호사·해외 거주 자녀).

## 9. 사업화 가능성
- B2C 무료(신뢰 확보) → 가족 계정·실시간 공유·리마인더 프리미엄.
- B2B: 방문요양센터가 보호자에게 “우리 서비스 밖 공백” 리포트 제공(상담 품질 도구).
- 민간 매칭 플랫폼과 제휴 시에도 **추천·순위 노출과 판정 분리** 원칙 유지.

## 10. 향후 B2G 가능성
- 통합돌봄 창구의 **사전 상담지**: 가족이 미리 만든 Care Map·공백 목록을 창구 상담에 활용 → 상담 시간 단축.
- 시군구 단위 익명 집계(동의 기반)로 “야간 공백이 많은 지역” 같은 수요 지표 제공 — 개인정보 비식별·별도 동의 설계 필요.
- 지자체 누리집·통합돌봄 안내 페이지에 임베드 가능한 정적 위젯.
