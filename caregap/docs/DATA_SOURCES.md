# CareGap AI — 공공데이터 출처 조사

- 조사일: **2026-10-05**
- 조사 방법과 한계
  - 컨테이너에서 `www.data.go.kr`, `apis.data.go.kr`, `api.data.go.kr`, `opendata.hira.or.kr`, `nid.or.kr` 직접 접속(curl·WebFetch)이 **프록시 403으로 차단**되었다.
  - 따라서 아래 정보는 **WebSearch 결과(검색엔진이 data.go.kr 페이지 내용을 요약한 것)** 로 확인했다. 데이터셋 ID·이름은 검색 결과의 data.go.kr URL로 확인된 것만 적었다.
  - **엔드포인트 신뢰도 표기**
    - `[포털 확인]` : data.go.kr(또는 기관 공식 페이지) 검색 결과에 해당 요청주소가 나타남
    - `[2차 출처]` : GitHub 코드 등 비공식 출처에서만 확인됨 → 사용 전 data.go.kr 페이지에서 반드시 대조
    - `미확인(페이지에서 확인 필요)` : 확인하지 못함
  - 실제 연동 전 **브라우저로 각 data.go.kr 페이지의 "요청주소", "상세기능", "이용허락범위"를 다시 확인**할 것.
- 공통 사항(data.go.kr OpenAPI)
  - 인증: 공공데이터포털 회원 **활용신청 → 개인 인증키(serviceKey)** 필요. 파일데이터는 인증 없이 다운로드.
  - 트래픽: 대부분 개발계정 10,000건/일, 운영계정은 활용사례 등록 후 증량.
  - 「공공데이터의 제공 및 이용 활성화에 관한 법률」에 따라 제공 공공데이터는 원칙적으로 영리 목적 포함 자유 이용 가능. 단 "공공누리 제1유형(출처표시)" 등 **이용허락범위가 표시된 경우 그 조건을 따름**.

## 12. CareGap MVP 적용 계획

### 12-1. 지금 사용하는 것 (연결됨)
- **장기요양기관 평가 결과(15104801)** — 저장소 `dolbom/data/eval/chunk_*.json`, 27,946개 기관, 필드 `name/type/region/sigungu/grade/score/eval_year`(+영역별 점수).
- 용도: CareGap 결과 화면에서 "우리 시군구에 방문요양·주야간보호·단기보호 등 **급여종류별 기관이 몇 곳 있는지**"를 보여주는 **지역 자원 개수** 정도로만 쓴다.
- 한계: 주소·전화·좌표가 없어 "가까운 기관"을 안내할 수 없다. CareGap은 시설 검색 서비스가 아니므로 **기관 목록·순위 노출은 하지 않고**, 상세 검색은 노인장기요양보험 누리집(longtermcare.or.kr)으로 연결한다.

### 12-2. 키 없이 바로 넣을 수 있는 것 (다음 단계, 파일 다운로드 → 정적 JSON)

### 12-3. serviceKey가 필요한 것 → 빌드 시 GitHub Action으로만 호출
- 원칙: **serviceKey는 프런트엔드·저장소에 절대 넣지 않는다.** GitHub Secrets(`DATA_GO_KR_KEY`)에 저장하고, 예약 워크플로(예: 주 1회)에서 API를 호출해 **결과를 정적 JSON으로 커밋**한다. 브라우저는 정적 JSON만 읽는다.
- 대상(우선순위)
  1. 지자체복지서비스(15108347) + 중앙부처복지서비스(15090532): 노인·돌봄 관련 서비스만 필터 → 공백 기능별 "알아볼 서비스" 목록
  2. 장기요양기관 검색 서비스(15059029): 기관 주소·급여종류(엔드포인트 확인 후)
  3. 전국치매센터표준데이터 API(15021138), 전국보건기관표준데이터 API(15107750), 교통약자이동지원센터 API(15028207): 파일 대신 정기 갱신이 필요할 때
  4. 사회복지시설정보서비스(15001848): 노인복지관 등 시설종류 필터
- 공공누리 제1유형(HIRA 등) 데이터를 쓰면 화면에 **출처 표시 필수**.

- HIRA 병원정보서비스(15001698): CareGap은 병원 찾기가 목적이 아니며, 범위가 넓어 MVP에 불필요.
- 응급의료기관 정보 조회(15000563): 실시간 병상은 CareGap 용도와 맞지 않음. "응급 대응" 공백에는 119·응급안전안심서비스 안내로 충분.
- 장기요양기관 시설별 상세조회(15058856), 시설별 현황(15124763): 기관 상세는 시설 검색 서비스 영역.
- 노인복지 시설현황(15039034): 형태(목록/집계) 미확인.
- 통합돌봄 서비스 목록: 2026-10-05 기준 **data.go.kr 전용 데이터셋을 찾지 못함** → 보건복지부 안내 페이지·읍면동 안내 문구를 수기로 정리해 사용.
