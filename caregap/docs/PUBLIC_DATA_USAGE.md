# 공공데이터 활용 현황 (2026-10-05 기준)

> 원칙: 공공데이터라고 표시한 것은 실제 출처가 있다. 연결되지 않은 데이터는 0건·가짜 기관으로 채우지 않고 **“서비스 정보 출처 확인 중”** 으로 표시한다.
> 데이터셋별 상세(제공 필드·endpoint·이용조건)는 [DATA_SOURCES.md](DATA_SOURCES.md) 참고.

## 1. 실제로 사용 중인 공공데이터
| 데이터 | 제공기관 | 어디에 쓰나 | 처리 |
|---|---|---|---|
| 장기요양기관 평가결과 ([data.go.kr 15104801](https://www.data.go.kr/data/15104801/fileData.do)) | 국민건강보험공단 | 서비스 화면 “우리 동네 기관” — 시군구별 장기요양기관(기관명·급여종류·평가등급·평가연도), 공백 영역에 맞는 급여종류(방문요양·방문간호·방문목욕·주야간보호·단기보호·복지용구) 자동 필터 | `scripts/build_ltc.py`가 저장소 내 정리본(`dolbom/data/eval`, 27,946곳, 2021~2025 평가)에서 필드만 골라 `data/ltc/*.json`(시도별)·`data/regions.json` 생성. 값 변경 없음 |
| 지역(시도·시군구) 목록 | 위 데이터에서 파생 | 온보딩 1단계 지역 선택 | 세종특별자치시는 단층제라 “세종시 전체”로 표기 |

화면 표기: 기관 카드마다 **데이터 기준(평가연도)**, 블록마다 **출처 링크**와 “원자료에 주소·전화번호 없음” 고지. 목록은 가나다순, 추천·보증 아님.

## 2. 연결 준비됨(데이터 파일만 넣으면 자동 연결)
| 데이터 | 방법 | 화면 상태(현재) |
|---|---|---|
| 국립중앙의료원_치매안심센터 정보 (15138421, CSV, 인증 불필요) | `python3 caregap/scripts/import_institutions_csv.py dementia <CSV>` → `data/dementia.json` | 서비스 정보 출처 확인 중 + 중앙치매센터 링크 |
| 전국보건기관표준데이터 (15107750) | `... import_institutions_csv.py health_center <CSV>` → `data/health_center.json` | 서비스 정보 출처 확인 중 + 정부24 링크 |

어댑터(`app/src/adapters/publicData.ts`)는 파일이 있으면 출처·수집일과 함께 표시하고, 없으면 미연결로 표시한다.
작업 컨테이너에서는 data.go.kr 접속이 차단되어 파일을 직접 받지 못했다(공모전 제출 전 브라우저로 내려받아 실행 필요).

## 3. 안내 정보(API 아님, 수기 정리)
`app/src/data/services_catalog.json` — 노인장기요양보험, 응급안전안심서비스, 노인맞춤돌봄서비스, 지역사회 통합돌봄, 치매안심센터, 보건소 방문건강관리,
교통약자 이동지원, 지자체 병원동행, 식사 지원, 노인복지관, 가족돌봄휴가, 129, 119 (13종). 공식 누리집 링크와 **확인일**을 함께 표시하고,
대상·자격은 “공식 창구 확인”으로 안내한다. 화면 태그: “안내 정보(수기 정리)”.

## 4. DEMO DATA
“예시로 체험하기”의 82세 사례는 가상 사례. 화면 상단 배너와 데이터 출처 표에 **DEMO DATA**로 표시.

## 5. 인증키(serviceKey)가 필요한 API의 원칙
- 키는 프론트엔드·저장소에 넣지 않는다. GitHub Actions Secret `DATA_GO_KR_KEY` → 빌드 시 정적 JSON 생성 → 브라우저는 JSON만 읽는다.
- `.env.example`에 변수 이름만 둔다(`VITE_` 접두사 금지 — 붙이면 번들에 포함됨).
- 다음 연결 후보(우선순위): 지자체복지서비스(15108347)·중앙부처복지서비스(15090532) → 지역별 실제 돌봄 사업 목록, 장기요양기관 검색(15059029) → 주소·연락처.

## 6. 출처 표시
- 공공데이터포털 데이터는 이용허락범위에 따른 출처를 화면에 표시한다(기관 목록 하단 “출처: …”).
- 공공누리 제1유형 데이터를 추가할 때는 출처 표시가 필수.
