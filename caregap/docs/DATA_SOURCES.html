CareGap AI — 공공데이터 출처 조사

  • 조사일: 2026-10-05
  • 조사 방법과 한계
    • 컨테이너에서 www.data.go.kr, apis.data.go.kr, api.data.go.kr, opendata.hira.or.kr, nid.or.kr 직접 접속(curl·WebFetch)이 프록시 403으로 차단되었다.
    • 따라서 아래 정보는 WebSearch 결과(검색엔진이 data.go.kr 페이지 내용을 요약한 것) 로 확인했다. 데이터셋 ID·이름은 검색 결과의 data.go.kr URL로 확인된 것만 적었다.
    • 엔드포인트 신뢰도 표기
      • [포털 확인] : data.go.kr(또는 기관 공식 페이지) 검색 결과에 해당 요청주소가 나타남
      • [2차 출처] : GitHub 코드 등 비공식 출처에서만 확인됨 → 사용 전 data.go.kr 페이지에서 반드시 대조
      • 미확인(페이지에서 확인 필요) : 확인하지 못함
    • 실제 연동 전 브라우저로 각 data.go.kr 페이지의 “요청주소”, “상세기능”, “이용허락범위”를 다시 확인할 것.
  • 공통 사항(data.go.kr OpenAPI)
    • 인증: 공공데이터포털 회원 활용신청 → 개인 인증키(serviceKey) 필요. 파일데이터는 인증 없이 다운로드.
    • 트래픽: 대부분 개발계정 10,000건/일, 운영계정은 활용사례 등록 후 증량.
    • 「공공데이터의 제공 및 이용 활성화에 관한 법률」에 따라 제공 공공데이터는 원칙적으로 영리 목적 포함 자유 이용 가능. 단 “공공누리 제1유형(출처표시)” 등 이용허락범위가 표시된 경우 그 조건을 따름.

12. CareGap MVP 적용 계획

12-1. 지금 사용하는 것 (연결됨)

  • 장기요양기관 평가 결과(15104801) — 저장소 dolbom/data/eval/chunk_*.json, 27,946개 기관, 필드 name/type/region/sigungu/grade/score/eval_year(+영역별 점수).
  • 용도: CareGap 결과 화면에서 “우리 시군구에 방문요양·주야간보호·단기보호 등 급여종류별 기관이 몇 곳 있는지“를 보여주는 지역 자원 개수 정도로만 쓴다.
  • 한계: 주소·전화·좌표가 없어 “가까운 기관”을 안내할 수 없다. CareGap은 시설 검색 서비스가 아니므로 기관 목록·순위 노출은 하지 않고, 상세 검색은 노인장기요양보험 누리집(longtermcare.or.kr)으로 연결한다.
