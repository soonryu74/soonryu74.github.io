# 개인정보 처리 방식

## 받지 않는 정보
주민등록번호 · 이름 · 정확한 생년월일 · 건강보험번호 · 장기요양인정번호 · 상세 진료기록 · 질병명 · 연락처.
(대표 시나리오의 “고혈압·당뇨”도 질병명으로 받지 않고 “병원 방문이 잦다”로만 반영)

## 받는 정보와 저장 위치
| 정보 | 용도 | 저장 |
|---|---|---|
| 연령(숫자) · 성별(선택) | 표시·공유 카드(선택 시 연령대만) | 브라우저 localStorage (`caregap.v1`) |
| 시도·시군구 | 지역 기관 목록 | 〃 |
| 독거 여부 · 장기요양 등급(선택) | 혼자 계신 시간 계산 · 서비스 안내 | 〃 |
| 걱정 체크 9개 | 규칙 판단 | 〃 |
| 요일·시간 일정 · 메모 | Care Map·규칙 판단 | 〃 (메모는 공유 카드에 넣지 않음) |

- **서버 저장 없음, 서버 전송 없음.** 사이트는 정적 파일(GitHub Pages)이며 분석·로그 수집 코드가 없다.
- 브라우저가 서버에 요청하는 것은 정적 공공데이터 JSON(`data/*.json`)과 웹폰트(jsdelivr)뿐이며, 입력값을 담지 않는다.
- “데이터 출처·개인정보·한계” 화면의 **“이 기기에 저장된 입력 모두 지우기”** 로 즉시 삭제.

## 자연어 입력
- 기본: 브라우저 안 키워드 규칙. 문장이 밖으로 나가지 않는다.
- 운영자가 `VITE_AI_ENDPOINT`를 설정한 경우에만 문장이 그 서버로 전송되며, 화면에 그 사실을 표시한다. 현재 배포본은 **설정하지 않음**.

## 가족 공유
- 사용자가 직접 “복사/공유/이미지 저장”을 누를 때만 생성. 링크에 데이터를 담는 방식은 쓰지 않는다(건강 정보가 URL·서버 로그에 남지 않도록).
- 연령대·시군구는 기본 제외, 체크해야 포함. 일정 메모는 항상 제외.

## 향후 서버 기능을 만들 때
가족 간 실시간 공유·계정 기능은 건강 관련 민감정보 처리(개인정보 보호법 제23조)에 해당할 수 있어 별도 동의·암호화·보관기간 설계가 선행되어야 한다.
