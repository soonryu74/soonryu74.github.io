LM Studio 무료 전환 가이드

내 PC에서 공짜로 도는 AI로, 앞으로 사이트를 무료로 수정하기

갈매역삼성부동산 사이트 운영용 · soonryu74.github.io

0. 먼저 — 대부분은 AI가 필요 없어요

💡 중요 매물 추가/수정 = 구글시트, 실거래가 갱신 = 엑셀/자동 이라 AI가 필요 없습니다. LM Studio는 글자·색·전화번호 같은 “코드 수정”이 필요할 때만 쓰세요.

1. 준비물 (PC 사양)

  • RAM 16GB 이상 권장 (8GB면 아주 작은 모델만 가능)
  • 그래픽카드(GPU) 있으면 빠름 — 없어도 느리지만 작동
  • Windows · Mac · Linux 모두 가능

2. LM Studio 설치 & 모델 받기

  1. lmstudio.ai 접속 → 다운로드 → 설치
  2. 앱에서 모델 검색 → 다운로드
    추천: Qwen2.5-Coder-7B-Instruct(가볍고 코딩 잘함) / PC 좋으면 14B·32B

3. 로컬 서버 켜기 (API 주소 만들기)

  1. 왼쪽 개발자(Developer) 탭 → 받은 모델 Load
  2. Start Server 클릭
  3. 주소 확인 → http://localhost:1234/v1 (이게 API 주소)

4. 코딩 도구 연결 (aider 추천)

aider = 터미널에서 AI가 코드를 고쳐 주는 무료 도구.

pip install aider-chat

사이트 폴더에서 실행:

aider --openai-api-base http://localhost:1234/v1 --openai-api-key lm-studio --model qwen2.5-coder-7b-instruct

VS Code가 편하면 Cline 확장 설치 → 설정에서 “OpenAI Compatible” → 주소 http://localhost:1234/v1 입력.

5. 실제로 사이트 고치는 흐름

  1. 사이트 폴더(git 저장소)로 이동
  2. aider 실행 → 한국어로 지시: “홈페이지 전화번호를 031-575-4944로 바꿔줘”
  3. AI가 파일 고치고 자동 커밋 → git push 하면 사이트 반영

6. 솔직한 한계

⚠️ 알아두세요 로컬 7B 모델은 유료 AI(저)보다 많이 약합니다. 간단한 수정(문구·색·전화번호)은 잘하지만, 여러 파일이 얽힌 복잡한 작업은 실수할 수 있어요. 그래도 git 백업이 있어 언제든 되돌릴 수 있습니다.

7. 언제 뭘 쓰나 (요약)

작업도구비용
매물·실거래가 관리구글시트 / 엑셀무료 (AI 불필요)
문구·색·전화번호 등 간단 수정LM Studio + aider무료
새 페이지·복잡한 기능강한 유료 AI유료 (가끔)
참고: LM Studio·aider·Cline는 각 공식 사이트에서 무료 배포됩니다. 모델 성능은 PC 사양에 따라 달라집니다.
