# 그 세상, 그 시간, 그리고 우리 : 2007 ~ 2026

질병관리청 워크샵 상영용 영상 (4분 33초, 1920×1080, 30fps). Remotion으로 제작.

## 구조도

| 구간 | 시간 | 내용 | 음악 |
|---|---|---|---|
| 오프닝 | 0:00–0:18 | 뉴스 속보 스타일 연도 플래시 → 제목 | 뉴스 오프닝 |
| 1막 기반을 다지다 | 0:18–1:38 | 2007–2014 (2009 신종플루 강조) | 메인 비트 |
| 2막 멈춰 선 여름 | 1:38–1:59 | 2015 메르스 | 피아노 |
| 3막 다시 세우다 | 1:59–2:38 | 2016–2019 | 메인 비트 |
| 4막 질병관리청, 국민 곁으로 | 2:38–3:53 | 2020–2026 (2020 청 출범 강조) | 메인 비트 |
| 엔딩 | 3:53–4:33 | 20년 카운트 → 방패 메시지 → "당신이 있었습니다" | 클라이맥스 |

화면은 좌측 **그 세상**(대한민국 뉴스 3건), 우측 **그리고 우리**(질병관리본부·질병관리청 1건), 상단 연도 카운터, 하단 타임라인으로 구성.

## 수정 방법

- 연도별 문구: `src/data.ts`
- 내레이션·음악 재생성: `python3 scripts/gen_audio.py tts` / `music` (Gemini API)
- 미리보기: `npm run studio`
- 렌더링: `npm run render` → `out/kdca-workshop.mp4`
