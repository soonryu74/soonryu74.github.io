# 그 세상, 그 시간, 그리고 우리 : 2007 ~ 2026

질병관리청 워크샵 상영용 영상 (4분 41초, 1920×1080, 30fps). Remotion으로 제작.

## 구조도

| 구간 | 시간 | 내용 | 음악 |
|---|---|---|---|
| 오프닝 | 0:00–0:26 | 뉴스 속보 스타일 연도 플래시 → 제목 → 워크샵 컨셉 "감염병위기관리국 의논(意論)하다" | 뉴스 오프닝 |
| 1막 기반을 다지다 | 0:27–1:49 | 2007–2014 (2009 신종플루 강조) | 메인 비트 |
| 2막 멈춰 선 여름 | 1:49–2:08 | 2015 메르스 | 피아노 |
| 3막 다시 세우다 | 2:08–2:50 | 2016–2019 | 메인 비트 |
| 4막 질병관리청, 국민 곁으로 | 2:50–4:03 | 2020–2026 (2020 청 출범 강조) | 메인 비트 |
| 엔딩 | 4:03–4:43 | 20년 카운트 → 방패 메시지 → "당신이 있었습니다" | 클라이맥스 |

화면은 좌측 **그 세상**(대한민국 뉴스 3건), 우측 **그리고 우리**(질병관리본부·질병관리청 1건), 상단 연도 카운터, 하단 타임라인으로 구성.

## 수정 방법

- 연도별 문구: `src/data.ts`
- 내레이션·음악 재생성: `python3 scripts/gen_audio.py tts` / `music` (Gemini API)
- 미리보기: `npm run studio`
- 렌더링: `npm run render` → `out/kdca-workshop.mp4` (완성본: `kdca-workshop.mp4`)

## 상영 전 확인 필요

- 검증은 언론 보도 위주이며 공식 원문을 직접 연 것은 일부다. 내부 연혁 자료와 최종 대조 필요.
- 2025년 WHO 합동외부평가 수치(56개 중 52개): 언론 보도 기준.
- 2026년 인공지능 전담조직: 훈령상 한시 자율기구(2026.3.9 신설).
- "의논(意論)" 풀이 문구 "마음의 소리를, 둥글게 모여 말하다"는 제작 과정에서 붙인 해석.
- 영상·내레이션·음악은 AI 생성물이며 화면에 "AI로 제작되었습니다"를 상시 표기.
