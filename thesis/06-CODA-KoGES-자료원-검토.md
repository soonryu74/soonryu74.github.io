- 작성일: 2026-09-10

## 1. CODA가 뭔가

정식 명칭 **보건의료연구자원정보센터**(Clinical & Omics Data Archive). 질병관리청 국립보건연구원이 2016년 설립한 국가 보건의료 연구데이터 공유 플랫폼이다.

| 구분 | 규모 |
|---|---|
| 임상·역학 / 오믹스 | 733,549명 이상 |
| 의료영상 / 라이프로그 | 24,487명 이상 (**2026년 상반기 공개 예정**) |
| 총 연구대상자 | 860,911명 이상 |
| 분양 승인 | 298건 이상 |
| 분양·활용 연구자 | 785명 이상 |

### 하위 서비스

| 서비스 | 내용 | 링크 |
|---|---|---|
| 데이터 카탈로그 | 과제별 데이터 검색·분양 신청 | /lttot/selectCatalogTrgtTaskListAnonymous.do |
| **CODA Cohort Atlas** | 국내 코호트·레지스트리 55개, 520,708명 정보를 GECKO 국제표준 22개 카테고리·115개 세부항목으로 표준화한 데이터맵 | /usab/atlas/intro.do |
| **OPEN KoGES** | KoGES 21만명 자료의 통합검색 + 클라우드 분석환경(GUI·파이썬·터미널) | /usab/koges/intro.do |
| CODA ANALYSIS | 원격 분석환경 | /usab/codaAnalysis/intro.do |
| 한국인 임퓨테이션 서비스 | 유전체 | /usab/kis/intro.do |

**Cohort Atlas의 현재 한계**: 지금은 "어떤 종류의 정보를 보유하는지" 수준까지만 검색된다. 개별 조사 항목(변수) 단위 검색은 향후 확대 예정이다. 즉 "이 코호트에 취침시각 문항이 있나"는 아직 Atlas로 못 찾는다. 조사표·코드북을 직접 봐야 한다.

## 2. KoGES 개요

한국인유전체역학조사사업. 2001년 시작. 기저조사 참여자 약 245,000명. **2~4년마다 추적조사.**

| 코호트 | 대상 | 기저 | 규모(OPEN KoGES 기준) |
|---|---|---|---|
| 지역사회(안산·안성) | 40~69세 | 2001~2002 | 10,030명 |
| 농촌 | – | – | 28,337명 |
| 도시(HEXA 등) | – | 2004~2013 | 173,195명 |

- 변수 수: 코호트·차수별로 **약 1,000개**
- 조사 항목: 일반사항, 질병력, 식생활·생활습관, 신체계측, 임상검사
- 안산·안성은 2년마다 추적, **2003~2020년 격년 추적 실적 확인됨** (2023년에도 추적조사 실시)
- 2023년 지역사회 코호트 10년 추적자료 공개

## 3. 우리 주제에 결정적인 세 가지 확인

### 3-1. 🟢 식사 시각: 있다

KoGES는 FFQ(103항목 2001년 → 106항목 2004년)와 **24시간 회상법을 함께** 쓴다.

HEXA 코호트에서 2011~2013년 수집된 24시간 회상 자료는 식사 시각을 **시간 구간으로 코딩**한다:

> 아침 전 간식 05:00~07:00 / 아침 07:00~09:00 / … / 야식 21:00~23:00

실제 사용 논문: Lyu et al. 2024, *J Nutr Health Aging* — KoGES HEXA 9,474명(평균 54세), 평균 3.5년 추적, 826명 비만 발생.

| 노출 | HR (95% CI) |
|---|---|
| 야식 섭취 | 1.20 (1.02–1.41) |
| 야식 에너지 섭취량 증가 | 1.26 (1.06–1.49) |
| 수면 8시간 이상 (6시간 미만 대비) | 0.67 (0.53–0.85) |

→ **식사 시각 × 수면 × 비만 발생을 종단으로 본 국내 연구가 이미 있다.** 04번 문서의 아이디어와 인접하다. 다만 이 논문은 수면을 **시간(duration)만** 봤고, 규칙성이나 정합은 보지 않았다. 우리의 공백은 유지된다.

### 3-2. 🟡 수면 시각: 아마 있다 (확인 필요)

**핵심 단서**: 안산·안성 코호트가 **피츠버그 수면질 지수(PSQI)**를 조사했다. 2003-04-17 ~ 2005-02-23 사이 응답, 이후 2020년까지 격년 추적.

PSQI 1~4번 문항은 원래 이렇게 묻는다.
1. 지난 한 달, 보통 몇 시에 잠자리에 들었습니까?
2. 잠들기까지 몇 분 걸렸습니까?
3. 보통 몇 시에 일어났습니까?
4. 실제 수면시간은?

**PSQI 원문항 응답이 원시자료에 그대로 들어 있다면 취침시각·기상시각을 확보할 수 있다.** 수면중점(mid-sleep), 취침시각의 차수 간 변동을 산출할 수 있게 된다.

실제 사용 논문: KoGES 수면잠복기와 사망 (Lancet Healthy Longevity 2023) — PSQI 기반 수면잠복기 4군 분류. 다른 연구는 수면시간(<7 / 7~8 / >7시간)과 **규칙성(regular vs irregular)** 으로 분류하기도 했다.

**확인해야 할 것**
- PSQI 총점·구성요소 점수만 공개되는지, 아니면 문항별 원자료(시각)까지 공개되는지
- 어느 차수까지 PSQI를 조사했는지
- 주중/주말 구분 여부 → **PSQI는 "보통"을 묻지 주중·주말을 나누지 않는다. 따라서 사회적 시차(SJL)는 산출 불가.**

### 3-3. 🟡 라이프로그: 2026년 상반기 공개 예정

CODA가 라이프로그(생체신호, **활동량, 수면패턴**) 데이터베이스를 구축 중이고, 의료영상과 함께 24,487명분을 2026년 상반기 공개 예정이다.

→ 웨어러블 기반 **24시간 연속** 자료라면 KNHANES 가속도계로는 불가능했던 SRI·IS·IV 산출이 열린다. 05번 문서에서 폐기했던 설계안이 되살아날 수 있다.

**단, 아직 공개 전이고 표본이 2만 명대다.** 박사논문 일정에 맞물릴지 확인이 필요하다. 지금 시점에서 논문 계획의 전제로 삼기엔 위험하고, "향후 과제" 또는 "보조 분석"으로 두는 게 안전하다.

## 4. KNHANES vs KoGES 비교

| 기준 | KNHANES | KoGES |
|---|---|---|
| 설계 | 반복단면 | **전향적 코호트 (2~4년마다 추적)** |
| 역인과 대응 | 불가 | **가능** |
| 수면 시각(취침·기상) | 있음, 단 2016~2018·2021 4개 연도만 | PSQI 기반, 원자료 공개 여부 확인 필요 |
| 주중/주말 구분 | **있음 → 사회적 시차 산출 가능** | 없음(PSQI는 "보통") → SJL 불가 |
| 식사 시각 | 24시간 회상, 건별 시각 | 24시간 회상, 시간 구간 코딩 (HEXA 2011~2013) |
| 식사 시각 반복 측정 | 없음(단일일) | **코호트 차수별 반복 가능성** |
| 대사·검진 지표 | 매년, 전국 대표 | 있음, 지역 기반 |
| 표본 대표성 | **전국 대표** | 지역 기반(대표성 제한) |
| 연령 | 전 연령 | **40~69세 (중고령 집중)** ← 우리 주제에 유리 |
| 접근성 | 즉시 다운로드, 무료 | 심의 필요(월 1회), IRB 필수 |
| 가속도계 | 2014~2017, 허리, 취침 시 미착용 | 미확인 |

**핵심 트레이드오프**
- KNHANES: 사회적 시차를 잴 수 있지만 단면이다.
- KoGES: 종단이지만 사회적 시차를 못 잰다. 대신 **수면 시각 자체의 변화**와 **식사 시각**을 추적할 수 있다.

## 5. 이걸로 무엇이 달라지나 — 수정된 설계 3안

### 안 A. KNHANES 단독 (05번 문서 설계 유지)
- 강점: 즉시 착수 가능, 전국 대표성, 사회적 시차·정합 지표 산출 확정
- 약점: 단면, 4개 연도 한정

### 안 B. KoGES 단독 — 종단 전환
> "중고령층 수면 시각과 식사 시각의 장기 변화 궤적과 대사증후군 발생: KoGES 전향적 코호트"

- 노출: 취침·기상 시각(PSQI 원문항), 첫/마지막 식사 시각, 야식 여부
- 분석: 잠재계층성장분석(LCGA)으로 리듬 변화 궤적 유형화 → Cox 회귀로 대사증후군·당뇨·우울 발생 예측
- 강점: **역인과 정면 대응.** 심사에서 가장 강한 무기. 40~69세라 중고령 주제와 정확히 맞음
- 약점: PSQI 원자료 공개 여부에 전부 달려 있음. 분양 심의 시간 소요
- Lyu 2024가 이미 인접 영역을 했으므로 **차별화 지점을 "규칙성·궤적"으로 명확히** 해야 함

### 안 C. 두 자료 병렬 (권장)
> 1장 KNHANES: 단면 — 리듬 정합 지표의 분포와 대사·정신건강 연관성 (전국 대표)
> 2장 KoGES: 종단 — 수면·식사 시각 궤적과 질병 발생 (인과 방향)
> 3장 통합 논의: 두 자료의 일치·불일치와 정책 함의

- 박사논문 3장 구조로 딱 맞음
- "국내 두 대표 자료를 모두 활용"은 심사에서 강한 인상
- 위험 분산: KoGES 수면 원자료가 없더라도 1장은 살아남음

**현 시점 권장: 안 C.** 단 KoGES 확인 결과에 따라 안 A로 축소 가능하게 설계.

## 6. 분양 절차 (실무)

### 역학자료만 필요한 경우 → CODA
1. CODA 회원가입 → 데이터 카탈로그에서 대상 과제 검색
2. 연구계획서 + **IRB 심의결과서** 준비
3. 온라인 분양 신청
4. **월 1회 분양심의위원회** 심의 (연구계획 타당성·윤리성, 자원 활용 적절성)
5. 승인 후 다운로드 또는 보안 분석환경 접속
   - 대부분 공개자료는 승인 후 직접 다운로드
   - 응답률 낮거나 보안 필요한 자료는 **보안 환경에서만 사용**

문의: 043-249-3020, 3057

### 유전체·인체자원까지 필요한 경우 → 국립중앙인체자원은행
<https://biobank.nih.go.kr>, 1661-9070

### 일정 예상
IRB 준비 2~4주 + 분양 심의 월 1회(최대 4~6주) → **자료 손에 넣기까지 대략 2~3개월.** 지금 시작해야 논문 일정에 맞는다.
