# 프로젝트: 지역 건강프로파일 대시보드 (+ 후속 「랭킹」 플랫폼)

## 소유자
노모어매뉴얼 대표 (AI 교육 유튜버, 20년 영어 입시 교육 경력, AI 개발 경험 약간).
전문용어는 쉬운 비유로 설명하고, 터미널 명령은 윈도우/맥 각각 병기할 것.
반말이 아닌 존댓말, 핵심만 간결하게. 과장 금지.

## 미션
질병관리청 CIAT(지역사회건강지표 분석도구, R Shiny 대시보드)와 동일한 내용을
더 세련된 디자인의 반응형 웹 대시보드로 재구축하고, 이후 지역 건강프로파일과
강점 기반 랭킹 플랫폼(「랭킹」)으로 확장한다. 장기적으로 상업화(퇴사 후).

## 벤치마크: CIAT 구조 (분석 완료)
- 원본: https://kdca.shinyapps.io/ciat/ (질병청 수도권질병대응센터, 서울대 원성호 교수팀 연구용역)
- 메뉴: 지역사회건강조사(98개 지표) / e-지방지표(157개 지표) / 분석도구 / 안내
- 지표별 화면 6패널: 현황(게이지) · 추이 · 단계구분도(지도+연도 애니메이션) · 순위 · 연도별추이(수치/순위/증감량/증감률) · 격차(boxplot)
- 심층분석 3종: 연관지표 탐색(피어슨/스피어만/켄달 상관), 핫스팟(Getis-Ord + Mann-Kendall),
  황금다이아몬드(보건사업 우선순위: 시간축·공간축 대비 3×3 매트릭스)
- 데이터 흐름: 통계청 KOSIS openAPI → 정제 → 분석 → 시각화

## 기술 결정 (확정)
- R Shiny 사용 안 함. **React(Vite) + 정적 데이터** (2026-09-05 소유자 결정. 확장 시 Next.js 자연 전환).
  - 소스: app/ (컴포넌트: charts/TileMap/panels/Tooltip). 빌드는 단일 HTML 인라인
    (vite-plugin-singlefile) → index.html — 파일로 열어도 동작, 어디든 배포 가능.
  - 빌드: `cd app && npm install`(최초 1회) 후 `python scripts/build_dashboard.py`.
  - 지도: topojson-client + d3-geo (외부 타일/지도 서비스 의존 없음 → 오프라인·정적 배포 가능).
- 하이브리드 파이프라인: 통계 연산(상관, 핫스팟 등)은 Python으로 사전 계산 → JSON 산출 →
  프론트는 표시만. (통계 데이터는 연 1회 갱신이므로 실시간 연산 불필요)
- 호스팅: Vercel 또는 GitHub Pages (무료). 수집 자동화: GitHub Actions.
- 디자인: prototype/ 의 대시보드 스타일을 기준으로 유지 (라이트/다크, 모바일 우선 반응형).

## 데이터 소스
1. KOSIS openAPI — 지역사회건강조사 지표, e-지방지표. API 키는 .env의 KOSIS_API_KEY (커밋 금지).
   - 원칙: **전체 지표(98+157개)를 넣기 전에 데이터 검증 먼저** (결측, 연도범위 2008~최신, 시도/시군구 커버리지).
   - scripts/kosis_collect.py 가 시작점 (인벤토리 수집 → 검증 리포트).
2. 김동현 교수(한림대) DB — "지역사회 건강결과 및 건강 결정요인 DB 1.7v.xlsx" (51MB, 시트=연도 2010~2024).
   - 로컬 파일 경로는 소유자에게 물어볼 것 (다운로드 폴더 추정). 구조·유용성 검증부터.
3. 확장 예정(후순위): 암등록통계(KOSIS), 심평원 의료기관 API, 온열질환 감시(공공데이터포털),
   손상·심혈관(신청제, 마지막), 2025 지역사회건강조사 원시자료(2026.2 공개됨, chs.kdca.go.kr 신청제).

## 로드맵
- 1단계 (진행 중): KOSIS 파이프라인 + CIAT 기능 재현 + 세련된 디자인. 지표 검증 → 실데이터 연결.
- 2단계: 시군구 선택 → 건강조사+e-지방지표+암등록+인프라 통합 "지역 건강프로파일" 자동 생성.
- 3단계: 신청제 자료 연계 (온열질환, 심혈관, 손상, 돌봄 인프라).
- 4단계: 「랭킹」 — 강점 기반 랭킹 플랫폼. docs/랭킹_기획안_v1.md 참조.
  핵심 원칙: 꼴찌 비공개, 영역 세분화+인구규모 리그로 "모두가 어딘가 상위권",
  수준상/개선상 분리, 점수 대신 등급 배지, 약점 진단은 지자체 전용(유료).
