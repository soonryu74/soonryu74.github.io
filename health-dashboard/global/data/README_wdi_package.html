License screening

Only indicators whose WDISeries.csv License Type equals CC BY-4.0 were included in the first-pass product dataset. This is a metadata-level screening, not a legal opinion. Preserve attribution and source metadata, and review any third-party source-specific terms before commercial launch.

Important

Different indicators have different latest years. The UI should always display the observation year. Do not label the dataset as real-time.
