## 2. 검증 결과
- **값 정확성(지역사회건강조사)**: 2023년 마포구·송파구·강남구의 주관적 건강수준인지율·비만율(자가보고) 표준화율이 이 프로젝트의 KOSIS 수집값과 **소수 첫째 자리까지 완전 일치** → DB의 CHS 부분과 우리 파이프라인이 서로 검증됨.
- **커버리지**: 시군구 행 270(2008)→278(2024). 전 지표의 99.7%가 전국·시도·시군구 3수준 수록. 2021년 시트는 열이 1,117개로 다른 해(1,500~1,800)보다 적음(수록 누락 가능성 → 원저자 확인 필요). 2022~2024는 채움 열이 1,499~1,592개(미공표 지표 공란).
- **기대여명**: 2008·2011·2014·2017·2020 시트에 열이 있으나 **시도 행만 값이 있고 시군구는 공란**(통계청이 시군구 생명표를 공표하지 않기 때문 — 우리 건강수명 산출법 문서 §2.1과 일치).
- **건강수명**: 2018 시트에만 시군구 250개 값(62.2~75.3세, 세종 69.9·종로 72.3). 청구자료 YLD 기반 연구값으로 보이며(보건행정학회지 2024 연구와 지역 수 250 일치), 우리 근사 건강수명의 **외부 검증 기준**으로 사용 예정(순위 상관). 이 중 218개가 대시보드 시군구 코드와 직접 매핑되고 나머지 32개는 일반구(수원 장안구 등) 단위.
- **코드 체계**: 2008~2020은 통계청 행정구역 코드 2·5자리(11, 11010), 2021~은 5자리 0채움(00000, 11000). 대시보드(KOSIS 177 코드)와는 이름 기반 매핑 필요 — 이번 검증에서 시도+시군구명으로 매핑 가능 확인.
- **주의**: 헤더 표기가 연도마다 다름(예: "여자 현재흡연율_표준화" vs "_표준화율", 공백 포함). 지표명 정규화 사전이 필요.

## 3. 활용 판단
1. **바로 쓸 수 있는 것(2단계 지역 건강프로파일)**: 사망원인통계 시군구 사망률(표준화율 포함, 총·원인별·성별), 암발생률(24개 암종), 건강검진 결과, 감염병, 예방접종률, 의료이용·보건의료자원. 이 지표들은 KOSIS에서 우리가 아직 수집하지 않은 영역이라 DB를 1차 자료원으로 삼되, 게시 전 KOSIS 원표와 표본 대조(연 1회).
2. **중복(검증용)**: 지역사회건강조사 289개 지표 — 우리 파이프라인(41개 시군구 지표)이 이미 수집하므로 DB는 교차검증용.
3. **활용 조건**: 질병관리청 자료실에서 공개 배포되는 DB이므로 대시보드 게시 가능(2026-09-08 소유자 결정). 출처는 "지역사회건강조사 DB(질병관리청 자료실·한림대 김동현 교수 구축 v1.7)"와 자료실 URL로 표기. 원본 파일·추출물은 저장소 밖에만 보관.
