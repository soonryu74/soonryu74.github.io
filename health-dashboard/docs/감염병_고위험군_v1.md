## 2. 지역 자료로 옮긴 방법

| 집단 | 자료 | 산출 | 구분 |
|---|---|---|---|
| 65·75·85세 이상, 0~4세, 0~14세 | 주민등록연앙인구 5세별(통계청, 2024) | 직접 합산 | 실측 |
| 고혈압·당뇨 진단경험자 | 지역사회건강조사 진단경험률(30세 이상, 조율) × 30세 이상 인구 | 추정 | 추정 |
| 고혈압·당뇨·정신질환 진료실인원, 암 5종 진료실인원 | DB(건강보험) | 직접 | 실측 |
| 비만·현재흡연·우울증상 | 지역사회건강조사 조율 × 19세 이상 인구(15~19세의 1/5 포함 근사) | 추정 | 추정 |
| 임산부, 출생아, 유치원 원아 | DB(모자보건 등록, 출생통계, 교육통계) | 직접 | 실측 |
| 장기요양 시설 정원·기관 수, 재가 정원, 요양병원 수 | DB(국민건강보험공단·심평원) | 직접 | 실측 |
| 독거노인, 기초생활수급자, 기초연금 수급자 | DB | 직접(독거노인은 65세 이상 1인가구 수) | 실측 |
| 외국인 주민 | DB 인구 천명당 외국인 수 × 인구 | 추정 | 추정 |
| 인플루엔자 미접종 성인 | (100 − 접종률, 조율) × 19세 이상 인구 | 추정(성인 전체 기준, 65세 이상만의 값 아님) | 추정 |
| 결핵 신환자, 의사·간호사 수 | DB | 직접 | 실측 |

원칙: 집단끼리 겹치므로(65세 이상이면서 고혈압) 합계를 내지 않습니다. 순위는 인구 대비 비율 기준으로 비중이 큰 지역이 1위입니다. 시도 값이 DB에 없으면 시군구 합으로 보완하고 "시군구 합"으로 표시합니다.

## 3. 아직 못 넣은 것
- 정신의료기관·정신요양시설 입원자, 장애인복지시설 입소자: 시군구 공표 자료 없음(시설 수는 KOSIS 보건복지부 통계에서 추가 수집 가능).
- 면역억제제 복용자, 만성신장(투석)·만성폐질환 환자: 건강보험 시군구 진료인원 표(KOSIS 350)에서 추가 수집 가능.
- 등록장애인 수: DB에 2018년까지만 있어 제외(보건복지부 등록장애인 현황으로 갱신 필요).
- 노숙인, 의료·돌봄 종사자 수(의사·간호사만 있음).

## 4. 검증 메모
- 마포구(2024 인구 359,362명): 65세 이상 57,963명(16.1%), 고혈압 진단경험자 추정 66,673명 vs 진료실인원 실측 46,093명 — 추정치가 실측보다 큰 것은 진단경험(자기보고)이 연간 진료보다 넓은 개념이기 때문. 두 값을 나란히 보여 해석 여지를 남김.
