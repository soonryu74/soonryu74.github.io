외부 검토 참여 가이드 (v1, 2026-10-04)

「지역 건강프로파일 대시보드」(health-profile.kr)를 검토해 주셔서 감사합니다. 이 문서는 검토자께서 무엇을, 어떻게, 얼마나 확인하시면 되는지 한눈에 보시도록 정리한 안내입니다.

1. 먼저 알려 드릴 것

  • 무보수 자원 검토입니다. 사례비는 없습니다. 개인이 무료로 만들어 공개하는 도구입니다.
  • 「인증」이 아니라 「검토 의견」입니다. 화면에는 검토자께서 확인하신 범위와 검토한 버전(빌드 번호)만 표시합니다. 확인하지 않은 범위는 표시하지 않습니다.
  • 공개는 선택입니다. 이름·직위·소속·의견을 공개하는 데 동의하신 경우에만 게시하며, 게시 전에 실릴 문구를 다시 보내 드려 확인받습니다. 언제든 철회하실 수 있고, 철회하시면 이름과 인용을 즉시 내립니다.
  • 연락처와 서명 이미지는 공개하지 않습니다.
  • 발견하신 문제는 고친 뒤 정오표(docs/사용설명서_정오표_v1.md) 번호와 함께 기록에 남깁니다. 문제를 찾아 주시는 것이 가장 큰 도움입니다.

2. 소요 시간

범위 수 예상 시간
1개 약 1시간
2~3개(권장) 2~4시간

전부 보실 필요는 없습니다. 전문 분야 1~3개만 골라 주세요.

3. 검토 범위와 확인 방법

범위 확인하실 것 화면에서 하는 방법 참고 문서
데이터 정확성 수치가 원자료와 같은가 아무 지표·지역 10칸을 골라 수치 옆 [n]·ⓘ → KOSIS 원표와 대조 데이터_최신성_점검_v1.md, 김동현DB_검증_v1.md
지표 방향·정의 「높을수록 좋음/나쁨」 배정이 타당한가 지표 분석 → 추이 카드의 방향 근거 문구 지표_방향성_v1.md
순위 방법 종합 순위 산출(가중치·3년 평균·리그)이 합리적인가 지역 프로파일 → 「순위 산출 방식」 랭킹_방법론_v1.md
건강수명 산출 산출식·검산이 맞는가 지역 프로파일 → 건강수명 「산출 예시」 검산행 건강수명_산출법_v1.md
지역박탈지수 변수·가중·분위 구분이 타당한가 지표 분석 → 건강형평성 「산출 예시」 지역박탈지수_산출_v2.md
우선 검토 계산 격차·위치·추세·박탈 가중과 등급 기준이 합리적인가 지역 프로파일 맨 위 「우리 지역 우선 검토 항목」 → 「계산 방법」 HealthEquityRadar_설계_v1.md
표현·해석 인과 표현·과장·오해 소지가 있는가 홈·프로파일·지표 분석 문구 —
접근성 키보드·색 대비·휴대폰에서 쓸 만한가 휴대폰·키보드만으로 홈 → 프로파일 이동 —

참고 문서는 대시보드 「의견·문의」 탭 「방법론 문서」 목록이나 health-profile.kr/docs/문서이름 에서 바로 열립니다.

4. 의견서 보내는 방법

  1. 대시보드 「자료원」 탭 맨 위 「외부 검토·자문」 → 「의견서 서식 만들기」를 누릅니다.
  2. 이름·직위·소속을 넣고, 범위마다 「확인함 / 확인했으나 의견 있음 / 확인하지 않음」을 고릅니다.
  3. 의견(발견한 문제는 화면·지표 위치와 함께)과 이해관계를 적고, 공개 동의 여부를 체크합니다.
  4. 서식에는 검토한 빌드 번호와 날짜가 자동으로 들어갑니다. 아래 셋 중 편한 방법으로 보내 주세요.
    • 복사 → 메일·메신저에 붙여 넣기
    • ✉ 이메일로 보내기 → 메일 프로그램이 열림
    • 🖨 인쇄해서 서명 → 인쇄하거나 PDF로 저장해 서명(손서명 스캔 또는 전자서명 서비스 모두 가능)
