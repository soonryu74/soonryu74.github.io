# 한국건강증진개발원 「지역사회 통합건강증진사업 우수사례집」 검토 — 반영 여부 (v1, 2026-10-02)

소유자 지시: "연도별 통합건강증진사업 우수사례집 참고해서 반영 여부 검토해" (https://www.khepi.or.kr/kps/publish/view?menuId=MENU00890&page_no=B2017003&board_idx=11070)

## 1. 자료가 무엇인가

- 발행: 한국건강증진개발원(KHEPI) 지역정책팀(옛 지역기획팀·통합건강팀). 자료실 「지침/교육자료」에 올라온다.
- 선정 방식: 「지역사회 통합건강증진사업 평가매뉴얼」에 따라 시·도 평가단이 관내 시·군·구 사업을 평가해 선정(2016년 사례집 머리말: 16개 시·도 평가단, 47건). 2016년부터 경진대회 수상작 포함.
- 사례 한 건의 구성(2023년 사례집 기준): 담당 부서·담당자 → 건강영역(주영역·부영역)·사업대상·핵심 사업전략 → ① 추진배경(지역 통계 인용) ② 추진내용 ③ 추진성과(지표·산출) ④ 시사점·확산 계획. 길이 4~10쪽.
- 저작권: 공공누리 4유형(출처 표시 + 상업적 이용 금지 + 변경 금지). **원문을 옮겨 싣거나 요약해 2차 저작물을 만들 수 없다** → 우리가 쓸 수 있는 것은 목차 수준의 사실(지자체·사업명·쪽·분류)과 원문 링크다.

## 4. 반영 방식(이번에 구현)

1. `scripts/build_khepi_cases.py` → `data/khepi_cases.json`(47KB): 사례 247건(연도·사례집·시도·시군구·사업명·쪽·추정 영역, 2023년 사례는 대상·전략·주영역·부영역) + 사례집 10권(자료실 링크).
2. 예방·관리 탭 맨 아래 카드 「시군구 우수사례 — 통합건강증진사업 우수사례집」: 사례 연도 select · 「○○ 사례만」(현재 선택 시도) · 검색 · 영역 칩(기존 영역 선택과 연동) · 행마다 「원문 p.N ↗」(KHEPI 자료실 사례집 페이지 — 첨부 PDF는 폼 전송 방식이라 직접 링크 불가, 페이지에서 「내려받기」) · 사례집 10권 목록(접기).
3. 검색 색인에 「우수사례」 카드 추가.

지키는 선: 원문 내용(추진내용·성과 수치)은 옮기지 않는다(공공누리 변경 금지). 사업명·지자체·쪽·사례집 자체 분류만 쓴다.

## 5. 반영하지 않을 것과 이유

- **사례 본문 요약·성과 수치 전재** — 저작권(변경 금지) + AI 요약의 원문 불일치 위험. 지식베이스의 다른 항목처럼 「AI 요약」으로 넣지 않는다.
- **사례의 「성과」를 우리 지표 변화와 연결해 효과처럼 보이는 표시** — 사례집의 성과는 사업 산출(참여자 수 등)이 대부분이고, 지표 개선과의 인과는 입증되지 않는다(평가이론 문서의 산출-성과 분리 원칙).
- **우수사례 선정 여부를 순위·등급에 반영** — 선정은 시·도 평가단의 사업 평가이지 건강수준이 아니다.
- 2017·2015·2014·2013년분 목차 수작업 입력 — 글꼴 인코딩 문제로 자동 추출이 안 되고, 7~13년 전 사례의 활용 가치가 낮아 링크만 둔다.

## 6. 다음 단계(승인 시)

- 영역 연결 정확도: 2023년 사례집(11012)의 「건강영역별 우수사례」 목차(구강·비만·신체활동·음주·심뇌혈관·금연·방문·치매·영양 등)를 그대로 쓰면 키워드 추정 대신 공식 분류로 바꿀 수 있다(목차 4~7쪽 파싱).
- 프로파일 「권고 예방·관리 사업」 카드에 「같은 영역 우수사례 N건 →」 링크, 동류군 카드에 「동류군 중 우수사례 지역」 표시.
- KHEPI 자료실에 새 사례집이 오르면 `build_khepi_cases.py` 입력(목차 JSON)을 추가한다. 자동 수집은 사이트가 폼 전송·세션 의존이라 스크립트(scratchpad/khepi/fetch.mjs, Playwright 다운로드)로만 가능.
