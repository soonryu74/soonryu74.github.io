# 「랭킹」 기획안 v1 — 강점 기반 지역사회 건강 랭킹 플랫폼

작성일: 2026-08-17 · 상태: 초안 (대시보드 1단계 완료 후 착수)

---

## 1. 벤치마크: 멜버른은 어떻게 "살기 좋은 도시"가 됐나

멜버른을 세계 1위로 만든 것은 EIU(이코노미스트 인텔리전스 유닛)의 **글로벌 살기좋은 도시 지수(Global Liveability Index)**다. 멜버른은 2011~2017년 7년 연속 1위였고, 2025년 현재는 코펜하겐이 1위, 멜버른은 4위다.

### 채점 구조

전 세계 173개 도시를 5개 영역, 30여 개 지표로 평가해 100점 만점으로 환산한다.

| 영역 | 가중치 | 내용 |
|---|---|---|
| 안정성 | 25% | 범죄, 테러·분쟁 위험 |
| 문화·환경 | 25% | 기후, 부패 수준, 문화·스포츠·음식 접근성 |
| 의료 | 20% | 공공·민간 의료의 질과 접근성 |
| 인프라 | 20% | 도로, 대중교통, 주택, 에너지·수도·통신 |
| 교육 | 10% | 공공·민간 교육의 질과 접근성 |

각 지표는 전문가 패널과 현지 거주자 평가로 "허용 가능~견딜 수 없음" 등급을 매기고 정량 지표와 결합해 점수화한다.

### 성공 요인 4가지 (우리가 훔칠 것)

1. **순위가 벌이 아니라 상이다.** EIU는 "최악의 도시 발표"가 아니라 "최고의 도시 시상식"으로 소비된다. 언론도, 도시 정부도 상위권만 이야기한다. 빈 시는 아예 시 공식 홈페이지에 1위 사실을 걸어놓고 도시 마케팅에 쓴다. 멜버른도 7년 내내 그랬다. **평가받는 쪽이 결과를 자랑하고 싶어지는 구조** — 이것이 핵심이다.
2. **영역별 점수를 공개한다.** 종합 순위가 낮아도 "의료 100점 만점"처럼 영역별로 자랑거리가 생긴다. 실제로 여러 도시가 특정 영역 만점을 홍보에 쓴다.
3. **매년 갱신된다.** 연례 이벤트가 되어 매년 언론 보도가 반복되고, 순위 변동 자체가 뉴스가 된다.
4. **방법론이 공개되어 있고 일관적이다.** 신뢰의 원천. 순위가 바뀌면 "왜"를 추적할 수 있다.

## 2. 설계 원칙: 부정적이지 않은 순위

한국 지자체 대상 랭킹의 최대 리스크는 하위권 낙인이다. 해법은 순위를 없애는 게 아니라 **"모두가 어딘가에서는 상위권인 구조"**를 만드는 것이다.

### 원칙 5가지

1. **꼴찌를 발표하지 않는다.** 공개 화면에는 영역별 상위 지역만 노출. 전체 순위표는 검색한 지역 중심으로만 표시(내 지역 ±5).
2. **영역을 잘게 나눈다.** 영역이 10개면 10개의 1위가 나온다. 229개 시군구 × 10개 영역 + 인구규모 리그 분리(대도시/중소도시/군 지역)까지 하면 대부분의 지역이 최소 하나의 "자랑 배지"를 가진다.
3. **수준(level)과 개선(progress)을 분리해 두 번 시상한다.** 절대 수준이 낮아도 개선율 1위가 될 수 있다. "올해 가장 건강해진 도시" 상이 하위권 지자체의 참여 동기가 된다.
4. **점수 대신 등급 배지.** 90점 이상 = 플래티넘, 80 이상 = 골드 식의 등급제는 "3등과 150등"의 잔인한 비교를 없앤다. EIU도 언론에는 순위로 소비되지만 실제 산출물은 점수다.
5. **약점은 비공개 영역에서만.** 공개 화면은 강점 중심, 약점 진단과 개선 제안은 해당 지자체 전용(로그인/리포트) — 이 부분이 유료 상품이 된다.

### 프레임 문장

> "당신의 도시는 이미 무언가를 잘하고 있습니다. 우리는 그것을 찾아서 보여줍니다."

## 3. 지표 체계 초안 (한국형 건강 살기좋은 지수)

자료원: 지역사회건강조사(98개) + e-지방지표(157개) + 암등록·인프라 공공데이터. 전부 기존 파이프라인 재사용.

| 영역(안) | 예시 지표 | 자료원 |
|---|---|---|
| 건강 습관 | 금연(흡연율 역산), 절주, 걷기실천, 신체활동 | 지역사회건강조사 |
| 마음 건강 | 우울감경험률(역산), 스트레스 인지율(역산), 삶의 만족도 | 지역사회건강조사 |
| 예방과 관리 | 건강검진 수검률, 예방접종, 고혈압·당뇨 관리교육 이수 | 지역사회건강조사 |
| 의료 접근성 | 인구당 의사수, 응급의료기관 접근성, 미충족의료율(역산) | e-지방지표, 심평원 |
| 안전 | 안전벨트 착용률, 손상 관련 지표, 교통사고 | 지역사회건강조사, e-지방지표 |
| 생활 환경 | 녹지, 상수도 보급, 대기질, 체육시설 | e-지방지표 |
| 돌봄과 복지 | 노인여가시설, 보육시설, 사회복지예산 비중 | e-지방지표 |
| 공동체 | 사회적 연결망, 이웃 신뢰(사회통합 영역) | 지역사회건강조사, e-지방지표 |

산출 규칙(초안): 지표별 표준화(z-score→백분위) → "높을수록 좋음" 방향 통일(나쁜 지표는 역산) → 영역 평균 → 등급 부여. 인구 규모 리그 분리로 군 지역이 대도시와 직접 비교당하지 않게 함. 가중치와 표준화 방식은 김동현 교수 DB·연구 방법론 검토 후 확정.

## 4. 화면 구성 (공개 영역)

1. **홈**: "이번 달의 배지 도시들" — 영역별 골드 배지 지역 카드
2. **내 지역 프로파일**: 강점 TOP3 자동 추출 + 등급 배지 + 전국·시도 내 위치(±5 순위만) + 연도별 개선 그래프
3. **시상 페이지(연 1회)**: 영역별 1위, 개선상, 리그별 종합상 — 언론 배포용 보도자료 자동 생성
4. **지자체 전용(비공개·유료)**: 약점 진단, 우선순위 사업 추천, 사업 근거 문헌·예산 규모·활용 도구/앱 링크, 사업계획서 초안 자동 생성

## 5. 수익 연결

무료(순위·배지·프로파일) → 지자체 전용 리포트 구독 → 사업계획서 자동 생성(통합건강증진사업·지역보건의료계획) → 컨설팅/용역. 배지는 지자체가 보도자료에 쓰도록 이미지·문구까지 제공(빈 시 방식) — 지자체가 스스로 홍보하면 그게 곧 플랫폼 마케팅이 된다.
