# 근거원 검토: NICE · NHMRC (CPSTF 대안)

2026-09-22 · 검토 계기: CPSTF 224건의 판정일 중앙값이 2012년(평균 경과 14.0년)으로 확인됨

## 1. 방법

- NICE: 검색 페이지 장애(Error 0x8133)로 개별 지침 페이지 325개(PH1~60, NG1~265)를 직접 수집. 314건에서 제목·날짜 확보.
  NG 264건은 재수집해 페이지 내 모든 날짜(발표·최종갱신)와 주제 경로를 추출.
- 공중보건·지역 적용 가능 지침은 제목 키워드로 66건을 거른 뒤 손으로 20건 선정. 대체·폐지 배너 확인.
- NHMRC: `nhmrc.gov.au`·`clinicalguidelines.gov.au`·`health.gov.au` 모두 이 환경에서 연결 불가. 검색 결과에만 의존.

## 2. 연식 비교

| | CPSTF | NICE PH(구) | NICE NG(전체) | NICE NG 선정 20건 |
|---|---|---|---|---|
| 건수 | 224 | 56 | 258 | 20 |
| 중앙 연도 | 2012 | 2010 | 2019 | 발표 2019 · 갱신 2021 |
| 평균 경과 | 14.0년 | 15.7년 | 7.0년 | 발표 6.5 · 갱신 5.4년 |
| 5년 내 | 4.9% | 0% | 19.0% | — |
| 15년 이상 | 47.4% | 64.3% | 0% | 0% |

NG에 15년 넘은 지침이 없는 이유는 감시(surveillance) 절차 때문이다. 통상 2년, 최소 4년마다 갱신 필요성을 점검해
갱신·수정·폐지를 결정한다(NICE 「Developing NICE guidelines: the manual」 14장). 이번 수집에서도 NG92(금연 서비스)→NG209,
NG7(체중증가 예방)→NG246 로 대체된 것이 확인됐다. CPSTF는 판정 후 갱신 절차가 없어 1998년 판정이 「현행」으로 남아 있다.

주의: NICE 날짜는 페이지에 표기된 것을 그대로 썼다. 발표일과 최종갱신일을 나눠 기록했다.

## 3. 우리 41개 지표 커버리지

| | CPSTF | NICE NG | 합집합 |
|---|---|---|---|
| 연결 지표 | 34 | 34 | **37** |
| 직접 연결 | — | 23 | — |

- NICE만 있는 것: 연간 미충족의료율 · 주관적 건강인지율 · 연간 보건기관 이용률 (NG44 지역사회 참여·형평)
- CPSTF만 있는 것: 음주운전 경험률 · 안전벨트 착용률 2종 (교통사고 손상 — 중앙 2000년, 26년 경과)
- 둘 다 없는 것: 심폐소생술 2종 · 손 씻기 2종

## 4. NICE 약점

- **성인 음주 예방이 비어 있다.** 현행 NG는 청소년 대상 NG135뿐. 성인 음주 예방(PH24, 2010)은 구 시리즈라 낡았다.
- **권고 등급이 문자 등급이 아니다.** NICE는 A/B/C 대신 「offer(강)」「consider(약)」「do not offer」 문형으로 강도를 표현한다.
  CPSTF식 4등급 배지를 그대로 쓸 수 없고, 문형→등급 변환 규칙이 필요하다.
- 영국 지방정부(local authority)가 공중보건을 맡아 보건소 단위 적용성은 미국보다 낫지만, 여전히 외국 근거다.

## 5. NHMRC

후보에서 제외.
1. 승인 대상이 외부 개발 임상진료지침이라 「지역사회 중재 효과 등록부」가 아니다. 자체 인구집단 지침은
   식생활지침(2013)·음주지침(2020)·영유아수유지침(2012) 정도.
2. Australian Clinical Practice Guidelines Portal이 2022-03-17 폐쇄됐고 이용자를 G-I-N 라이브러리로 돌린다.
3. 직접 접속 불가로 목록·날짜를 검증하지 못했다(검색 결과 기반 판단).

## 6. 권고

- 주 근거원을 NICE NG로 전환. CPSTF는 제도·법률형 중재(주류세·금연구역·담배가격) 한정으로 보조 사용하되 판정연도 병기, 15년 초과 표시.
- 두 근거원을 합쳐도 심폐소생술·손 씻기 4개 지표는 국내 근거를 만들어야 한다.
- 데이터: `data/nice_guidance.json` (20건, 지표 매핑 포함).

## 7. 반영 (2026-09-22)

- 지표 분석 화면 하단 「이 지표의 현행 근거 지침」 카드(①②): NICE 현행 지침(직접/부분), 발표·최종갱신, 권고문 등급 배지,
  권고문 예시(원문·작성연도), CPSTF 보조(판정 중앙연도, 15년 초과 경고).
- 지역 프로파일 「무엇부터 손댈 것인가」 카드(④, ③ 흡수): 하위 25/30/40% 지표를 부담·격차·수단 3축으로 정렬하고
  지금 할 것 / 근거 얇음 / 근거 있음(CPSTF) / 근거 낡음 / 근거 없음 으로 묶음. 접이식 「근거가 비어 있는 곳」 요약 포함.
- ⑤ 자체평가 서식은 보류(대시보드 성격과 다름).
- 데이터 흐름: scripts/build_evidence.py → data/evidence.json (nice_guidance.json + nice_recs_samples.json + cpstf_findings.json).
