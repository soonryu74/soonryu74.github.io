근거원 검토: NICE · NHMRC (CPSTF 대안)

2026-09-22 · 검토 계기: CPSTF 224건의 판정일 중앙값이 2012년(평균 경과 14.0년)으로 확인됨

1. 방법

  • NICE: 검색 페이지 장애(Error 0x8133)로 개별 지침 페이지 325개(PH1~60, NG1~265)를 직접 수집. 314건에서 제목·날짜 확보. NG 264건은 재수집해 페이지 내 모든 날짜(발표·최종갱신)와 주제 경로를 추출.
  • 공중보건·지역 적용 가능 지침은 제목 키워드로 66건을 거른 뒤 손으로 20건 선정. 대체·폐지 배너 확인.
  • NHMRC: nhmrc.gov.au·clinicalguidelines.gov.au·health.gov.au 모두 이 환경에서 연결 불가. 검색 결과에만 의존.

NG에 15년 넘은 지침이 없는 이유는 감시(surveillance) 절차 때문이다. 통상 2년, 최소 4년마다 갱신 필요성을 점검해 갱신·수정·폐지를 결정한다(NICE 「Developing NICE guidelines: the manual」 14장). 이번 수집에서도 NG92(금연 서비스)→NG209, NG7(체중증가 예방)→NG246 로 대체된 것이 확인됐다. CPSTF는 판정 후 갱신 절차가 없어 1998년 판정이 「현행」으로 남아 있다.

주의: NICE 날짜는 페이지에 표기된 것을 그대로 썼다. 발표일과 최종갱신일을 나눠 기록했다.

4. NICE 약점

  • 성인 음주 예방이 비어 있다. 현행 NG는 청소년 대상 NG135뿐. 성인 음주 예방(PH24, 2010)은 구 시리즈라 낡았다.
  • 권고 등급이 문자 등급이 아니다. NICE는 A/B/C 대신 「offer(강)」「consider(약)」「do not offer」 문형으로 강도를 표현한다. CPSTF식 4등급 배지를 그대로 쓸 수 없고, 문형→등급 변환 규칙이 필요하다.
  • 영국 지방정부(local authority)가 공중보건을 맡아 보건소 단위 적용성은 미국보다 낫지만, 여전히 외국 근거다.

5. NHMRC

후보에서 제외.

  1. 승인 대상이 외부 개발 임상진료지침이라 「지역사회 중재 효과 등록부」가 아니다. 자체 인구집단 지침은 식생활지침(2013)·음주지침(2020)·영유아수유지침(2012) 정도.
  2. Australian Clinical Practice Guidelines Portal이 2022-03-17 폐쇄됐고 이용자를 G-I-N 라이브러리로 돌린다.
  3. 직접 접속 불가로 목록·날짜를 검증하지 못했다(검색 결과 기반 판단).

6. 권고

  • 주 근거원을 NICE NG로 전환. CPSTF는 제도·법률형 중재(주류세·금연구역·담배가격) 한정으로 보조 사용하되 판정연도 병기, 15년 초과 표시.
  • 두 근거원을 합쳐도 심폐소생술·손 씻기 4개 지표는 국내 근거를 만들어야 한다.
  • 데이터: data/nice_guidance.json (20건, 지표 매핑 포함).

7. 반영 (2026-09-22)

  • 지표 분석 화면 하단 「이 지표의 현행 근거 지침」 카드(①②): NICE 현행 지침(직접/부분), 발표·최종갱신, 권고문 등급 배지, 권고문 예시(원문·작성연도), CPSTF 보조(판정 중앙연도, 15년 초과 경고).
