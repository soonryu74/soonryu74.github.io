# 지역 건강 랭킹 가중치·방법론 보고서 v1

작성일: 2026-09-05 · 상태: 권고안 (소유자 검토 대기) · 근거: 공인 체계 조사 + 전문가 100인 패널(시뮬레이션) + 실데이터 실증 분석

> **중요 고지.** "전문가 100인 패널"은 실제 인물이 아니라, 6개 전문 분야의 전형적 관점을 가진 가상 전문가 100명을 AI가 시뮬레이션한 델파이 토론입니다. 각 패널은 웹에서 근거 문헌을 찾아 인용했지만, 최종 가중치의 정당성은 **실제 전문가 검토(예: 김동현 교수팀)로 확인**해야 합니다. 이 보고서는 그 검토에 올릴 "초안 + 근거 묶음"입니다.

---

## 1. 결론 요약

1. **가중치는 순위를 거의 바꾸지 않습니다.** 실데이터(232개 시군구, 2025년, 표준화율)에서 균등 가중 / 질병부담형 / 행태형 가중의 순위 상관은 0.98 이상, 상위 10위 집합은 8~9개가 겹칩니다. 가중치 논쟁은 "정당성과 수용성"의 문제이지 결과를 뒤집는 변수가 아닙니다.
2. **순위를 흔드는 것은 표본오차입니다.** 단년도 순위는 한 해 사이에 232곳 중 103곳이 30계단 이상 움직입니다(상관 0.73). **3년 이동평균**을 쓰면 42곳으로 줄고 상관은 0.94가 됩니다. 패널 100명 중 89명이 3년 평활에 찬성했습니다.
3. **리그 분리가 필요합니다.** 대도시 구 평균 57점, 시 49점, 군 45점. 전국 상위 30위 안에 군은 3곳뿐입니다. 표준화율을 써도 남는 구조적 격차이며, 패널 78%가 리그 분리(도시-군 2리그 48%, 인구규모 3리그 30%)에 찬성했습니다.
4. **정신건강은 독립된 차원입니다.** 다른 8개 영역과 상관이 거의 0(−0.20~+0.13)이고, 군 지역이 오히려 높습니다(군 59 vs 대도시 43). 단순 평균에 묻히지 않도록 별도 배지가 필요합니다.
5. **권고 가중치(100인 종합, 합 100):** 흡연 14 · 만성질환 관리 16 · 정신건강 13 · 음주 11 · 신체활동 11 · 식생활·비만 11 · 의료이용 11 · 예방·안전 9 · 구강건강 4.
6. **제외·이동 지표 4개:** 고혈압·당뇨 "진단 경험률"(검진을 잘할수록 높아지는 역설 → 결과층으로), 보건기관 이용률(방향 중립 → 참고), 건강생활실천율(흡연·음주·걷기의 합성지표 → 이중계산).
7. **표시는 순위가 아니라 등급**으로: 리그 내 상위 10% 플래티넘 · 25% 골드 · 50% 실버, 하위 비공개(랭킹 기획안 원칙, CHR 2024년 순위→그룹 전환과 일치).

### 3.4 모든 패널이 공통으로 지적한 것
- 고혈압·당뇨 **진단 경험률**을 "낮을수록 양호"로 두면 검진을 잘하는 지자체가 감점되는 역설 (6개 패널 전부).
- 시군구 표본 약 900명 → 치료율·합병증검사 수진율은 분모가 200~300명이라 단년도 비교 불가.
- 사망률·사회경제 지표 부재로 K-CHDI식 외적 타당도 검증(사망률 상관)이 현재 불가 → 후속 과제.
- 지표 수록 시작연도가 2008~2020으로 제각각 → 개선상은 공통 지표군으로 한정.

### 3.5 주요 소수의견 (기록)
- 정신건강 역학·정신건강의학: 자살 부담 대비 저평가, 최소 15~22 요구. 사망원인통계(자살률) 연계 시 결과층 핵심지표로 승격.
- 대도시 구 실무자: 주민 설명에는 조율이 직관적 → 조율 병기.
- 통계청계·가정의학: 리그 분리는 경계 지자체 순위를 인위적으로 바꿈 → 리그 없이 순위 신뢰구간만 표기.
- 형평성: 리그·꼴찌 비공개는 격차를 가림 → 연구자용으로 전국 단일 순위·격차 지표 제공.
- 기자: 3년 평균은 "올해 무엇이 달라졌나"를 지움 → 개선상은 단년 변화 병기.
- 데이터과학: 이동평균 대신 베이지안 축소추정(empirical Bayes)이 우수 → 후속 과제.

| 패널이 시뮬레이션임 | 실제 전문가 검토(김동현 교수팀·보건소장 협의회)로 가중치 확정. 본 보고서의 표를 설문지로 재사용 가능 |
| 사망률·사회경제 층 부재 → 현재 지수는 "건강행태·관리 성과 지수" | K-CHSI(51MB 엑셀)·사망원인통계 연계 → CHR형 결과층 추가 후 사망률 상관으로 가중치 재검증 |
| 순위 신뢰구간 미산출 | 지표 표준오차(데이터 보유)로 부트스트랩 순위 구간 → 겹치면 동일 등급 |
| 백분위 정규화의 정보 손실 | v2: z-score + 표준오차 기반 축소추정(empirical Bayes) |
| 2020~2022 코로나 행태 급변이 3년 평균에 혼입 | 해당 기간 민감도 분석 후 결정 |

**즉시 실행 가능한 것:** 대시보드 프로파일에 "가중치 프리셋(균등 / 100인 패널 / 사용자 조정)", 3년 평균 토글, 리그 선택, 등급 배지를 구현하는 것. 본 권고안은 코드 한 곳(가중치 표)만 바꾸면 실제 전문가 검토 결과로 교체됩니다.
