# 지표 방향성 확정표 v1 — 무엇이 "좋은 방향"인가

작성일: 2026-09-08 · 적용 파일: `data/directions.json`(scripts/build_directions.py) · 조사 원문: docs/지표_방향성_조사_미국.md · 국제.md · 국내.md

## 1. 왜 필요한가
지도 색(붉은색=나쁨, 파란색=좋음), 순위·백분위, 프로파일 강점·약점은 모두 "높을수록 좋은가"에 달려 있습니다. 지역사회건강조사 41개 지표는 질병관리청 상향·하향지표 관례를 따르지만, DB에서 가져온 115개 지표는 방향을 직접 정해야 했습니다. 그래서 미국·국제·국내 공인 체계가 같은 지표를 어떻게 다루는지 확인해 확정했습니다.

## 2. 조사한 체계와 그들의 규칙

| 체계 | 방향 처리 방식 | 우리 적용에 준 함의 |
|---|---|---|
| County Health Rankings 2025(미국) | 모든 지표를 z점수화, 기본은 "높을수록 나쁨"이고 예외 11개만 역코딩(운동기회 접근·1차의료 의사·치과의사·정신보건인력·독감접종·유방암검진·고교졸업·대학진학·사회단체·도서관·광대역). 인구·장애·가구구조는 Demographics(점수 제외) | 인구 구성은 맥락, 인력·검진·운동환경은 좋음 |
| CDC PLACES(미국) | 방향 필드 없음, 범주로 암시(건강결과·위험행태=나쁨, 예방=좋음), 순위 산정 금지 | 유병률·진단자 비율은 나쁨 |
| Healthy People 2030(미국) | 목표 동사(Increase/Reduce)가 방향. 인구·기후·출산·재정에는 목표 없음 | 정신질환 치료 이용은 증가 목표 → 진료인원 맥락 |
| America's Health Rankings 2025(미국) | ±1 곱으로 방향, 인구·유병률 지표는 비가중(순위 제외) | 유병률은 순위 제외 관행 존재 |
| WHO 건강도시(유럽)·Urban HEART | 지표 해석은 도시별, 벤치마크 대비 색 표시. 인구·자원 지표 없음 | 자원 지표 방향 부여 신중 |
| OECD Health at a Glance 2025 | 자원·이용 대시보드는 "better/worse로 분류할 수 없음"(병상 과잉 우려, 진료 횟수는 제도 영향) | 진료실인원·진료비·병상 = 맥락 |
| OECD Regional Well-Being | 실업·사망·대기오염·살인은 역코딩 명시 | 실업률·미세먼지 나쁨 |
| ECHI·Eurostat·UN SDG | 인구·출산은 인구장(맥락), 목표 문구로 방향(3.6.1 교통사망↓, 11.7.1 열린공간↑, 6.1.1 식수↑, 3.c.1 보건인력↑) | 환경·안전·인력 방향 |
| 국가지표체계·e-지방지표(국내) | 일부만 명시: 의사수↑, 재정자립도↑, 하수도↑, 교원1인당학생수↓. 인구·규모·의료비는 가치판단 없음 | 국내 명시 지표는 국내 체계 우선 |
| HP2030(국내) | 기준치→목표치로 방향. 진료실인원·진료비·인구·의사·병상은 성과지표 아님 | 의료이용 총량 맥락 |
| 지역안전지수·교통문화지수·소멸위험지수(국내) | 지수 정의가 방향(1등급 최안전, 100점 우수, 0.5 미만 위험) | 지수 정의 그대로 |
| 지역사회건강조사(질병관리청) | "(상향지표) 증가할수록 긍정, (하향지표) 감소할수록 긍정" 각주 | 기존 41개 지표 방향 유지 |


## 3. 결정 규칙

- R1 인구 구성·규모·기후 지표는 예외 없이 맥락 (CHR Demographics, AHR 비가중, ECHI 인구장, 국가지표체계 가치판단 없음)
- R2 의료이용 총량·진료비는 맥락 (OECD "better/worse로 분류 불가", HP2030 성과지표 아님, 격차의 대부분이 인구구조·건강수준)
- R3 질환별 진료인원은 유병률 대리로 나쁨 (PLACES·HP2030·ECHI·Urban HEART), 단 치료 확대가 목표인 정신질환은 맥락
- R4 보건의료 인력·시설(의사·간호사·의원·전문의·복지시설)은 좋음 (국가지표체계 "많을수록 의료복지 수준 높음", CHR 역코딩, SDG 3.c.1); 병상은 과잉 우려로 맥락(OECD·e-나라지표)
- R5 검진·예방접종·준수율 등 예방적 접점은 좋음, 판정 유병 비율은 나쁨(수검률 의존 주석)
- R6 지수는 지수의 정의를 따름 (지역안전등급 1등급 최상 → 숫자 낮을수록 좋음, 교통문화·교통안전지수 높을수록 좋음, 소멸위험지수 높을수록 안전)
- R7 국내 체계가 방향을 명시한 경우 국내 체계 우선 (재정자립도↑, 교원 1인당 학생수↓, 하수도 보급률↑)

| 지표 | 이전(가설) | 확정 | 이유 |
|---|---|---|---|
| 의료기관 진료실인원(천명당) | 나쁨 | 맥락 | OECD·HP2030 방향 없음, 격차의 대부분이 인구구조·건강수준 차이 |
| 1인당 진료비 | 나쁨 | 맥락 | 어떤 순위 체계도 사용하지 않음, 고령화율과 동행 |
| 정신질환 진료실인원 | 나쁨 | 맥락 | 미국·한국 HP2030이 치료 이용 증가를 목표로 함 |
| 병상 수(천명당) | 좋음 | 맥락 | OECD "과잉은 남용·비용", e-나라지표 "적정 수급" |
| 인구 천명당 사업체 수 | 좋음 | 맥락 | 건강 체계에 방향 사례 없음 |
| 교원 1인당 학생 수 | 맥락 | 나쁨 | e-나라지표가 "낮을수록 교육여건 좋음" 명시 |
| 빈집비율 | 나쁨 | 맥락 | 국내외 어디에도 방향 지표 없음 |
