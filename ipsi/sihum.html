고등학생이 만나는 모든 시험 — 누가 내고, 어디에 쓰이고, 어떻게 준비하나

시험은 "출제 기관"과 "활용처"를 알면 준비 방향이 정해집니다. 대입에 직접 쓰이는 시험(내신·수능·논술·면접·1차 시험)과 진단용 시험(학평·모평), 그리고 대입에 반영되지 않는 시험을 구분했습니다.

1. 내신 — 정기시험 + 수행평가

규칙(2026학년도 학업성적관리 시행지침)

  • '지필평가' 용어가 '정기시험'으로 변경. 교과별 정기시험 + 수행평가로 평가
  • 국어·수학·영어·사회(역사·도덕 포함)·과학 이론 중심 교과는 학기당 서·논술형 평가가 총 배점의 30% 이상(정기시험+수행평가 합산)
  • 수행평가만으로 평가 가능한 과목도 있음(학교 규정)
  • 성취도 A~E는 학교가 정한 성취 기준(A 90점 이상 원칙)
  • 5등급은 수강자 전체 석차 기준 → 소인수 과목일수록 1등급 인원이 적음(수강자 13명 이하 등급 미산출 규정 확인)

준비법 — 컨설턴트 버전

  1. 3주 전 시험 범위 확정 즉시 교과서·학습지·수업 필기 3종 병합 노트. 정기시험 출제자는 담당 교사 — 교사 강조 표현을 서술형 답안 문장으로 미리 써본다.
  2. 서술형 30% 대비: 단원별 "정의·이유·비교" 3문장 답안 템플릿. 채점 기준(키워드 채점)을 전년도 기출로 확인.
  3. 수행평가는 세특 투자: 보고서·발표 주제를 지망 전공과 연결. 교사가 세특에 적을 수 있도록 결과물에 탐구 과정·참고자료를 명시.
  4. 시험 후 24시간 내 오답 → 다음 정기시험 예상 문제 10개 작성.

과목별 무게 — 5등급제에서의 우선순위

대학 교과전형 반영 교과는 대개 국·수·영·사·과(+한국사). 성균관대는 공통과목 35% + 선택과목 35%로 정량화하니 고1 공통과목 성적이 대학 환산점수의 1/3입니다. 경희대 지역균형은 "진로선택 등급/성취도 중 유리한 것"을 자동 반영 — 고3 진로선택은 성취도 A(90점) 확보가 먼저입니다.

2. 전국연합학력평가(학평) — 교육청이 내는 "위치 확인 시험"

2026년 고1 일정·범위

  • 3.24(화) 서울시교육청 — 국·수·영·한국사·통합사회·통합과학. 범위 중학교 전 과정
  • 6월 부산시교육청 — 1학기 진도 누적
  • 9.2(수) 인천시교육청 — 시행 완료
  • 11월 경기도교육청 — 1년 누적
  • 국어는 2028 수능 체제 반영해 화법·언어(문법)·독서·작문·문학 전 영역 출제

고3(2028년)은 3·4·7·10월 교육청 + 6·9월 평가원 = 6회.

어떻게 써먹나

  1. 성적표의 백분위를 기록해 3년 추세선을 만든다(등급은 응시집단이 달라 흔들림).
  2. 3월 고1 학평 백분위는 중학 성취의 기준선 — 여기서 국어 문법·수학 함수 구멍을 발견하면 여름방학에 메운다.
  3. 학평은 대입에 전혀 반영되지 않는다. 점수 자체가 아니라 오답 유형 통계가 자산.
  4. 고2 11월 학평 = 수능 범위(대수·미적분Ⅰ 상당) 대부분 커버 → 사실상 첫 모의 수능.

3. 평가원 모의평가(고3 6월·9월) — 수능 출제기관의 예고편

  • 수능을 내는 평가원이 출제. 졸업생·검정고시생도 응시 → 처음으로 실제 경쟁집단이 보인다.
  • EBS 연계 방식·난이도 조정의 기준점. 9월 모평 이후 수능 난이도 예측 기사가 쏟아지는 이유.
  • 2010년생 기준: 2028년 6월 초, 9월 초(정확한 날짜는 2027년 3월 평가원 발표).
  • 준비법: 6월 모평까지 수능 전 범위 1회독 완료가 목표. 9월 모평 이후는 새 개념 금지, 실전·EBS 연계·시간 관리만.

4. 수능 — 2029학년도(2028.11.16)

체제·과목·문항은 바뀐 제도 › 수능에 정리했습니다. 여기서는 과목별 준비 원칙만.

국어

문법(화법과 언어)이 전원 필수가 된 것이 최대 변화. 예전엔 언매 선택자만 하던 음운·형태·통사를 모두 합니다. 고1 공통국어의 문법 단원을 수능 개념서처럼 다루세요. 독서(비문학)는 통합사회·통합과학 지문과 겹치는 소재가 늘 것 — 탐구 공부가 곧 독서 배경지식.

수학

대수·미적분Ⅰ·확률과 통계. 범위가 줄어 고2 말이면 수능 범위 완성이 가능하고 그래야 합니다. 킬러 대신 준킬러 다수 체제라 계산 정확도·시간 관리가 등급을 가릅니다. 미적분Ⅱ·기하는 수능엔 없지만 내신·권장과목·연세대식 수리논술 대비로 고3에 이수.

영어

절대평가 90점 = 1등급. 목표는 "안정 1등급"이지 만점 아님. 고1~2에 어휘·구문을 끝내고 고3은 EBS 연계·듣기만 유지. 사관학교·경찰대 지망이면 별도로 어휘 문항·듣기 없는 형식에 맞춘 훈련 필요.

통합사회·통합과학

고1 수업 = 수능 범위. 각 25문항 40분, 1.5·2·2.5점 배점. 통합과학은 물·화·생·지가 한 문항에 융합되고, 과학탐구실험과 연계된 자료 해석형이 예시문항의 특징. 고1 통합과학 노트를 3년간 보관하고 고2·3 일반선택(물리학·화학·생명과학·지구과학)으로 깊이를 더합니다. 통합사회는 지리·역사·경제·윤리·정치 융합 자료 해석.

한국사

절대평가 40점 이상 1등급, 필수. 고1 한국사1·2 내신을 성실히 하면 별도 대비는 고3 여름 2주면 충분. 단 미응시 시 전체 성적 무효.

기출의 조건

2010년생은 통합형 수능 실제 기출이 1회(2028학년도, 2027.11.18)뿐입니다. 평가원 2028 예시문항(2025.4), 2027~2028년 고1·2 학평, 2028년 6·9월 모평이 사실상의 기출 세트. 9등급 시절 기출은 국어 독서·문학, 수학 공통 범위만 선별해 활용.

6. 면접 — 5등급제가 키운 변별 장치

유형

  • 서류 기반 면접: 학생부 내용 확인(세특·활동 진위, 심화 질문). 대부분의 학종 2단계
  • 제시문 기반 면접: 서울대 일반전형(1단계 50 + 면접 50), 연세대 탐구인재형(면접 40), 고려대 학업우수(2028 면접 신설)
  • SNU 역량평가 면접(2028 신설): 서울대 지역균형 2단계, 수능최저 폐지 대신 다면 심층 평가
  • 적성·인성 면접(MMI): 의·치·한·약·간호, 서울대 정시 의대·수의대 20점
  • 교직 적·인성: 교대·사범대

반영 비율 상승 추세

  • 한양대 면접형 20→30%, 광운대·세종대 30→40%

  • 중앙대 CAU융합형(의학부) 면접 30% 신규, 성장형인재 면접 30%
  • 고려대 계열적합은 반대로 면접 폐지·서류 100%
