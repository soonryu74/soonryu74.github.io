목장 나눔터 · 알림 켜는 법

아이폰은 ‘홈 화면에 추가’를
먼저 해 주세요

아이폰은 사파리에서 홈 화면에 추가한 앱으로만 알림을 받을 수 있어요. 한 번만 하시면 됩니다.

아이폰 iOS 16.4 이상
1

사파리로 여세요

카톡에서 주소를 누른 뒤, 오른쪽 아래 메뉴(⋯) → [Safari로 열기]. 이런 안내가 보여요.

2

공유 단추 → [홈 화면에 추가]

사파리 아래쪽 공유 단추(□↑)를 누르고, [홈 화면에 추가] → [추가].

복사 ⧉
홈 화면에 추가 ＋
책갈피 추가 ▭
🔒 mokjang.app
그림 예시
3

홈 화면 아이콘으로 여세요

홈 화면에 생긴 ‘멜번방주교회’ 아이콘을 눌러 여세요.

그림 예시
4

[알림 받기] → [허용]

맨 위 [알림 받기]를 누르고, 물어보면 [허용].

✅ “알림을 켰습니다”가 보이면 성공이에요.
앞으로는 홈 화면의 ‘멜번방주교회’ 아이콘으로 들어오시면 됩니다.

잘 안 되시나요?

  • [알림 받기]가 안 보이면: 사파리가 아니라 홈 화면 아이콘으로 열었는지 확인해 주세요.
  • 알림이 안 오면: 아이폰 설정 → 알림 → 멜번방주교회에서 ‘알림 허용’을 켜 주세요.
  • 아이폰 소프트웨어가 오래되었으면 설정 → 일반 → 소프트웨어 업데이트를 먼저 해 주세요.
