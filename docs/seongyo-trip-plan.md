# 선교여행 고르기(가칭 "보냄") 개발 기획안 v0.1

> 작성 2026-10-25 · 사이트(예정): `/bonaem/` · 브랜치 `ccr-52b0b6e4-ewdh6i`
> 대상: 단기선교·비전트립·아웃리치를 준비하는 교회 선교부·팀장·참가자

**싸게 고르는 앱이 아니라, 안전하게·합법적으로 고르는 앱.**

## 1. 요약

- 한국 장기선교사는 2만 1,621명(171개국)으로 정체·고령화(평균 53.9세) 중이지만, **1년 미만 단기선교 활동은 7,292명(2024)으로 전년 5,065명 대비 44% 급증**했다. 참가자의 69.8%가 20대. 코로나 이전 전성기에는 연 10만 명 추산.
- 2026년 10월 네팔에서 **한국인 24명이 관광비자로 입국해 종교 훈련 프로그램에 참여했다가 체포·추방 절차**를 밟았다. 2025년 마다가스카르 선교사 2명 피살, 2026년 2월 러시아 선교사 체포. 외교부는 2025년 11월 선교단체 안전간담회에서 "중국 무비자는 종교활동에 적용되지 않는다"고 명시했다.
- 비기독교인이 꼽는 개신교 불신 1위가 "지나친 전도"(31.8%, 2025). 교회는 선교를 줄일 수도, 그대로 할 수도 없는 딜레마에 있고, 일부 교회는 청년 선교 프로그램을 중단했다.
- 시장에는 **단기선교팀의 "여행 상품 선택"을 돕는 서비스가 없다.** 국내는 성지순례 여행사(천지·익투스·소울트립)와 교회 내부 관리툴(온누리 아웃리치 플랫폼)만 있고, 해외(ServiceReef·ManagedMissions·GO)는 참가자 관리·모금 도구이며 항공·숙박·비자·안전은 다루지 않는다.
- 그래서 포지션은 **"선교지 → 합법 입국 경로 → 안전 등급 → 항공·보험·물품 비교 → 팀 견적"을 한 흐름으로 묶는 선택 도우미**다. 판매(여행업)는 하지 않고, 등록 여행사·보험사에 **견적 요청(RFQ)을 중개**한다.
- 수익은 ① 여행사·보험 견적 연결 수수료 ② 교회용 프로 플랜(팀 관리·문서 자동화) ③ 전자책·강의(바이브코딩 교회 앱 만들기) 순.

- 팀 규모: 권장 7~15명, 기간 2주 전후. 항공 단체요금 기준은 10명 이상(델타·에어캐나다·루프트한자·카타르 공통, 카타르는 종교단체 명시).

## 4. 핵심 기능 (MVP → 확장)

### 4-1. MVP (M1~M2, 정적 페이지 + Supabase, 서버 없음)

1. **선교지 고르기(`jido.html`)** — 지도·목록. 국가마다 4가지 신호등을 한 화면에:
   - 여행경보 단계(외교부 API 실시간)
   - **종교활동 비자 등급**(자체 DB): A 관광비자로 봉사·교류 가능 / B 사전 허가·초청장 필요 / C 종교활동 별도 비자 필수(중국·네팔 등) / D 외국인 종교활동 금지·여행금지
   - 감염병·필수 접종(황열·콜레라 등 국제공인접종 필요 여부)
   - 최근 사건(뉴스 큐레이션, 날짜·출처 명시)
2. **팀 견적 계산기(`gyeonjeok.html`)** — 인원·기간·출발 공항·활동 유형 입력 → 항공(단체 10인 기준 안내)·숙식·현지 이동·보험·예비비 범위를 **구간**으로 제시. 수치는 "어느 교회 사례, 어느 시점" 출처 표기. 단일 가격 단정 금지.
3. **견적 요청 보내기(RFQ)** — 같은 조건으로 등록 여행사 2~3곳·보험사에 한 번에 요청. 답변은 앱 안에서 비교. 여행업 등록 없이 가능한 구조(아래 7장).
4. **보험 고르기(`boheom.html`)** — 선교활동이 면책인지, 의료후송·유해송환 포함인지, 고위험 지역 담보 여부를 체크 항목으로. 상품 추천은 하지 않고 **물어볼 질문 목록**과 비교표 틀 제공.
5. **준비 체크리스트(`junbi.html`)** — KCMS 핸드북·남서울교회·미션파트너스 지침을 단계별(선정 → 6개월 전 → 1개월 전 → 출발 → 현장 → 귀국 후)로 재구성. 팀장용·참가자용 분리. 인쇄·PDF.
6. **비상 카드(`bisang.html`)** — 국가 선택 → 공관 전화·주소, 영사콜센터(+82-2-3210-0404), 현지 긴급번호, 의료기관 2곳 입력란, 팀 비상연락망. 오프라인 저장(PWA).

### 4-2. 2단계 (M3~M6)

- 팀 공간(Supabase 로그인): 참가자 명단·여권 만료일·접종 완료·보험 가입 여부 대시보드, 팀장만 전체 열람(목장 나눔터 RLS 재사용)
- 외교부 특별여행주의보 발령 시 해당 팀에 알림
- 실시간 항공 운임(Travelpayouts 또는 Trip.com 제휴) + 선교 운임 안내(Fly For Good 등, 한국 출발 가능 노선만)
- 현지 선교사 "요청 사항" 등록: 가르치러 가지 말고 요청받은 일을 하라는 원칙을 기능으로

### 4-3. 3단계 (M6+)

- 디아스포라 교회용 영어 UI, 출발지 멜번·시드니·LA
- 귀국 후 평가회 템플릿·일기 → 다음 해 팀에 전달
- 국내 이주민 사역 연결(해외 못 가는 교회의 대안, KRIM "이주민 선교 비중 증가" 흐름)

## 5. 종교활동 비자 등급 DB 설계 (핵심 자산)

```
countries(iso2, name_ko, name_en, alarm_level, alarm_updated_at,
          visa_free_days_kr, religious_activity_grade(A/B/C/D),
          grade_basis, grade_source_url, grade_reviewed_at, grade_reviewer,
          vaccines_required[], vaccines_recommended[],
          embassy_phone, embassy_addr, local_emergency)
incidents(country, date, summary, source_url, type)
checklists(phase, role, item, source)
quotes(team_id, vendor, type(air/ins/land), amount, currency, valid_until, file_url)
```

- 등급 판정 근거는 반드시 **1차 출처(해당국 이민법·대사관 공지·외교부 안내)** + 검토일 + 검토자. 근거 없으면 "미확인"으로 표시하고 회색 처리.
- 초기 30개국: 신규 파송 상위국 + 단기선교 다수 방문국(필리핀·태국·캄보디아·베트남·인도네시아·몽골·일본·네팔·인도·중앙아시아 4국·터키·이집트·케냐·탄자니아·우간다·에티오피아·과테말라·페루·멕시코·중국·러시아 등).
- 감수: 선교단체 법무·KCMS·현지 선교사 자문단. **"전문가 감수 전(베타)" 배지**를 모든 페이지에 표시(근거영양 사이트 방식).

| 지도 | Leaflet + OpenStreetMap | 무료 |
| 알림 | Supabase Edge Function 일 1회 경보 변화 감지 → 이메일 | 서버 없음 |
| AI | Claude API(선택): 체크리스트 개인화·국가 요약 초안. **등급 판정에는 사용하지 않음**(사람 감수) | 책임 경계 |

## 7. 법·규제 경계

- **여행업 등록**(관광진흥법 §4, 시행령 별표1 2025-08-26 개정): 종합 5천만 원, 국내외 3천만 원, 국내 1,500만 원(2026-06-30까지 750만 원). 여행업 정의는 "시설 이용 **알선**·계약 대리·여행 안내·편의 제공".
- MVP는 **정보 제공 + 견적 요청 전달**까지만 하고, 계약·결제·대리를 하지 않는다. 수수료를 받는 순간 "알선" 해석 위험 → 1단계는 무료, 수수료 모델 도입 전 한국관광공사·행정사 확인 필수.
- 통신판매업 신고: 유료 플랜 판매 시 필요.
- 개인정보: 여권번호·접종 기록은 민감정보. 저장 최소화, 팀 해산 후 90일 자동 삭제.
- 면책: 입국 가능 여부·안전은 최종적으로 당사국·외교부 판단. 앱은 "확인해야 할 것"을 보여줄 뿐 보증하지 않는다는 문구를 모든 등급 옆에 표기.

## 9. 콘텐츠 연계 (유튜브·전자책)
