# Seedance(드리미나) 사용 가이드 — 「입구」 제작용

**확인일** 2026-10-20 · 출처: Dreamina 공식 페이지(2.0 사용법, 2.5 사용법 2026-06-29 게재, 요금제 페이지). 수치는 제작 당일 UI에서 재확인.
**플랫폼** 웹 전용(dreamina.capcut.com). 윈도우·맥 동일. 로컬 설치 없음. 인터넷 필수.

---

## 1. 용어 먼저

| 용어 | 뜻 |
|---|---|
| Dreamina(드리미나) | 바이트댄스(틱톡 회사)의 AI 이미지·영상 웹 서비스. CapCut(캡컷) 계정으로 로그인 |
| Seedance(시댄스) | 드리미나 안의 영상 생성 모델. 2.0 / 2.5 / 2.0 Mini 세 가지 |
| 크레딧 | 생성할 때마다 차감되는 포인트. 해상도·길이·참조 개수에 따라 소모량 다름 |
| 레퍼런스(참조) | 인물·장소·스타일을 고정하기 위해 올리는 이미지·영상·오디오 |
| @태그 | 프롬프트 안에서 올린 참조를 지목하는 표기. 예: `@Image1` |
| 업스케일 | 해상도 올리기 · **보간**: 24fps → 30/60fps로 부드럽게 |

## 2. 모델 선택

| 모델 | 언제 |
|---|---|
| **2.0 Mini** | 구도·동작 테스트. 크레딧 적음. 채택 안 함 |
| **2.0** | 본 생성 기본. 참조 최대 12개(이미지 9·영상 3·오디오 3, 각 15초) |
| **2.5** | 캐릭터 일관성·멀티샷 강화. 'Omni reference' 모드. 참조 최대 50개, 1회 30초(확장 모드 5~180초 베타) |

**이 영화**: 레퍼런스 이미지 → 2.5 Omni reference로 본 생성. 2.5가 불안정하면 2.0 Multiframes로 후퇴.

## 3. 화면 구성 (AI Video 페이지)

1. 좌측 메뉴 **AI 비디오** 클릭
2. 상단 **모델** 드롭다운 → Seedance 2.5 (또는 2.0)
3. **모드** 선택
   - 2.0: `Single-frame`(첫·끝 프레임 지정) / `Multiframes`(참조 멀티모달)
   - 2.5: `Omni reference` 켜기
4. **+** 버튼 → 참조 업로드 (이미지·영상·오디오)
5. 프롬프트 입력창
6. **길이 · 종횡비 · 해상도** 선택 → 16:9, 1080p
7. **생성** → 결과 미리보기 → `재생성` / `업스케일` / `보간` / `사운드트랙 생성`
8. 우측 상단 **다운로드** (유료 플랜만 워터마크 없음)

크레딧 절약 순서: Mini로 구도 확인 → 720p 5초로 동작 확인 → 1080p 10초 본 생성.

## 5. 제작 워크플로우 (이 영화 기준)

### 0단계 — 폴더 준비 (윈도우·맥 공통)
```
입구_제작/
  01_레퍼런스/      R-DS25.png, R-HI.png, R-WALL.png …
  02_생성/S01/      1-1_v1.mp4, 1-1_v2.mp4 …
  03_채택/          1-1.mp4 …
  04_편집/
  로그.csv
```
윈도우: `C:\Users\이름\Documents\입구_제작\` · 맥: `/Users/이름/Documents/입구_제작/`
브라우저 다운로드 폴더를 `02_생성`으로 바꿔두면 정리가 빠름 (Chrome 설정 → 다운로드 → 위치).

### 1단계 — 레퍼런스 이미지 12장 (AI 이미지 메뉴)
13번 문서 §1 프롬프트로 생성. 각 3~5회 생성 후 1장 확정. 인물은 정면 1 + 측면 1.
확정본은 파일명 그대로 저장(R-DS25.png 등). **이후 절대 바꾸지 않는다.**

### 2단계 — 샷 생성 (AI 비디오, 2.5 Omni reference)
1. `+` → 해당 샷의 레퍼런스 올리기 (13번 문서의 REF 열 참조)
2. 프롬프트 입력창에 샷 프롬프트 붙여넣기. 레퍼런스는 `@Image1` 등으로 지목
3. 16:9 · 1080p · 길이(샷리스트 초 수, 5 또는 10 선택)
4. 생성 → 3~4회 변주 → 1개 채택 → `03_채택/`에 샷ID로 저장
5. 로그.csv에 기록 (§7)

**실제 입력 예 — 9-3 두 손 컷**
```
참조: @Image1 = R-HI (해인 손 포함 정면), @Image2 = R-DS25 (동수 손 포함 정면), @Image3 = R-LAKE

Pure black. A single headlamp switches on. In the new circle of light, resting on
a rubber boat edge: the young woman's hand from @Image1 lying on top of the older
man's thick weathered hand from @Image2. Neither hand moves. Setting as @Image3.
Fixed macro, nothing else visible.
Cinematic live-action realism, 16:9, 24fps, shallow depth of field, subtle film grain.
Palette: pure black shadows, warm orange headlamp light. Single light source only.
Everything outside the headlamp circle is pure black. No text, no logos, no subtitles.
```

### 3단계 — 보정
채택 컷만 `업스케일` + `보간(30fps)`. 전부 하면 크레딧 낭비.

### 4단계 — 편집 (드리미나 밖)
CapCut 데스크톱(무료, 윈도우·맥) 또는 DaVinci Resolve(무료).
- 컷 순서·길이 맞추기 → 암전 15초 삽입 → 타이틀·크레딧 → 영어 자막(SRT) → 사운드(숨·물방울·파도·용접)
- 내보내기: **MP4 · 1080p · 16:9 · 24fps**
- 공식 인트로 영상을 맨 앞에 붙이기 (주최 제공 다운로드)

### 5단계 — 제출
비공개/미등록 링크(유튜브 unlisted 또는 Vimeo) + 제출 폼 4단계 + AI 툴 사용 내역(로그.csv 기반).

## 6. 일관성 유지 규칙

1. 레퍼런스는 1단계에서 확정 후 **동일 파일**을 모든 샷에 첨부
2. 프롬프트 첫 문장에 **인물 고정 문구** 반복(13번 문서 §0)
3. 카메라 이동은 **샷당 하나**
4. 한 샷에 인물 2명까지. 군상은 얼굴 없이
5. 동굴은 "랜턴 원 밖 완전 검정" 문구를 매번. 배경 일관성 문제 자체를 없앰
6. 결과가 흔들리면 프롬프트를 **줄인다**. 늘리지 않는다

## 7. AI 툴 사용 기록 (제출 폼 필수)

`로그.csv` 열:
```
샷ID, 모델(2.0/2.5/Mini), 모드, 레퍼런스ID, 생성일, 길이(초), 해상도, 시도번호, 채택(Y/N), 비고
```
채택 컷의 길이 합계 ÷ 최종 러닝타임 = Seedance 비율. 70% 이상 증빙.

## 8. 자주 막히는 곳

| 상황 | 대응 |
|---|---|
| 생성이 느림 | 피크 시간 회피. 유료 플랜 우선 처리. 2.5 → 2.0으로 |
| 워터마크 | 무료 플랜은 제거 불가. 본 생성은 유료에서 |
| 얼굴이 바뀜 | 레퍼런스 재첨부, 고정 문구 반복, 얼굴 노출 줄이기(랜턴 그늘) |
| 랜턴 밖이 회색 | "pure black, zero ambient light" 추가. 편집에서 블랙 레벨 내리기 |
| 길이 옵션에 원하는 초가 없음 | 긴 쪽으로 생성 후 편집에서 자름 |
| 한국어 프롬프트 | 가능하나 영어가 안정적. 대사는 자막으로 처리하므로 영상엔 글자 넣지 않음 |
| 상업적 이용 | 약관 확인 필요. 공모전 출품은 상업 이용이 아니지만 주최측 라이선스 부여 조항 있으므로 드리미나 약관과 충돌 여부 확인 |

## 10. 2.0 vs 2.5 결정 기준

| | 2.0 | 2.5 |
|---|---|---|
| 참조 | 12개 | 50개 |
| 1회 길이 | 15초 참조 기준, 출력 길이 UI 확인 | 30초(확장 180초 베타) |
| 일관성 | 양호 | 강화(공식 주장) |
| 안정성 | 검증됨 | 신규. 실패 시 2.0 |
| 이 영화 | 후퇴 옵션 | 기본 |
