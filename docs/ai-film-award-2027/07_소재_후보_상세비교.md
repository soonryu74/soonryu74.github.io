## 1안 「물때」 — 서해 갯벌 할머니

**로그라인**
> 유네스코 갯벌에서 50년 조개를 캔 할머니가 무릎 때문에 갯일을 그만두는 날, 밀물 시간표를 앱으로만 아는 손자가 할머니의 호미를 들고 처음으로 갯벌에 들어간다. 물은 여섯 시간마다 돌아온다.

> On a UNESCO tidal flat, the day a grandmother's knees end fifty years of clam digging, her grandson — who knows the tide only from an app — takes her hoe and walks onto the mud for the first time. The water comes back every six hours.

| 항목 | 내용 |
|---|---|
| 두 존재 | 갯일 할머니 **옥분**(78) ↔ 손자 **민재**(30, 물류 스타트업 퇴사) |
| 장소 | 전북 고창 갯벌(2021 유네스코 자연유산). 끝없는 뻘, 널배, 노을, 철새 |
| 긴박 장치 | **밀물**. 갯벌은 하루 두 번 바다가 된다. 들어간 사람은 물때 안에 나와야 한다. 시계가 이야기 안에 내장 |
| 아크 | 은퇴 → 손자 도착(앱으로 물때 확인) → 앱이 못 보는 것: 뻘의 '길'(단단한 곳과 빠지는 곳) → 할머니 마지막 갯일, 동네 할머니들이 말없이 좋은 자리 비워줌 → 손자 첫 갯일, 뻘에 빠짐 → 할머니가 멀리서 널배 밀어 보냄 → 손자가 캔 조개를 할머니 바구니에 → 밀물이 들어오는 뻘 위, 할머니들이 하나씩 허리를 펴고 손자 쪽을 본다 |
| 울림길 장면 | ① 할머니들이 말없이 자리 비킴 ② 손자가 조개를 할머니 바구니에(게석 역전) ③ 밀물 앞에서 할머니들이 일제히 허리를 펴는 장면 = 도열 |
| 클라이맥스 | 물이 발목까지 차오른 뻘 위에서, 손자가 할머니가 늘 하던 대로 호미로 뻘을 세 번 두드린다(나간다는 신호). 멀리서 할머니들이 똑같이 세 번 두드린다 |
| 비주얼 톤 | 회갈색 뻘 + 주황 노을 + 은빛 밀물. 단일 팔레트 |
| AI 강점 | 지평선까지 뻘, 밀물이 차오르는 타임랩스, 널배 활주, 철새 떼. 실사로는 촬영 허가·물때 맞추기 극난 → AI 활용 점수 유리 |
| 실화 근거 | 한국의 갯벌 유네스코(2021), 갯일 종사자 고령화, 밀물 고립 사고 매년 발생 |
| 리스크 | 해외엔 '갯벌' 개념 설명 필요(자막 한 줄로 해결). 호미 세 번 신호는 창작이므로 크레딧 고지 |
| 기시감 | **낮음**. 갯벌 극영화는 국내외 거의 없음 |

## 2안 「득음」 — 판소리 명창과 고수

**로그라인**
> 목이 상해 더는 소리를 낼 수 없는 늙은 명창이, 북만 칠 줄 알던 젊은 고수에게 마지막 소리를 넘긴다. 소리는 악보에 없다.

> An aging pansori master whose voice is gone passes her final song to the young drummer who only ever kept her beat. The song was never written down.

| 항목 | 내용 |
|---|---|
| 두 존재 | 명창 **정님**(76) ↔ 고수 **한결**(27, 국악과 졸업, 북만 침) |
| 장소 | 지리산 자락 소리 수련터. 폭포, 한옥 마루, 밤 마당 |
| 아크 | 성대 손상 진단 → 공연 3주 전 → 제자는 악보로 배우려 함 → 명창: "소리는 북에 있다, 네가 60년 들었다" → 폭포 아래 수련 → 공연 날 고수가 북을 치다 소리를 낸다 → 객석의 늙은 소리꾼들이 하나씩 "얼씨구" 추임새 |
| 울림길 장면 | 공연장 객석의 원로 명창들이 말없이 일어나 추임새로 답함 = 도열 |
| 클라이맥스 | 무대 위 명창은 북 앞에 앉고, 고수가 소리를 한다. 역할 교환 |
| 비주얼 톤 | 먹색 한옥 + 흰 폭포 + 붉은 북 |
| AI 강점 | 폭포 수련, 소리의 시각화(물결·파동), 밤 마당 |
| 리스크 | 판소리 자체가 해외엔 생소. 소리 = 실제 명창 녹음 필요(라이선스). 립싱크 AI 생성 난도 높음 |
| 기시감 | 낮음(〈서편제〉는 1993년, 해외 심사위원 모름). 다만 '마지막 공연' 구조는 보편 |

## 3안 「안부」 — 섬 집배원과 홀로 사는 노인

**로그라인**
> 배로 열두 개 섬을 도는 집배원이 16년째 매주 편지를 전하던 할아버지 집 우편함이 처음으로 비어 있지 않은 날, 그는 편지를 두고 가지 않는다.

> A mail carrier who crosses twelve islands by boat has delivered to one old man every week for sixteen years. The first day the mailbox isn't empty, he doesn't leave the letter and go.

| 항목 | 내용 |
|---|---|
| 두 존재 | 집배원 **성호**(52) ↔ 홀로 사는 **박 노인**(84, 매주 서울 딸에게 답장을 씀) |
| 장소 | 전남 신안 다도해. 쾌속선, 선착장, 돌담집 |
| 아크 | 일상 루틴(배·섬·우편함) → 노인이 쓰러짐(집배원 발견, 실제 사례 기반) → 병원 → 노인이 못 쓴 답장을 집배원이 대신 쓸 수 없음 → 딸이 섬에 옴 → 노인이 회복 후 쓴 편지 한 장, 수신인: 집배원 |
| 울림길 장면 | 집배원이 섬을 돌 때 열두 섬 노인들이 선착장에 나와 서 있음(평소엔 없던 일). 말 없음 |
| 클라이맥스 | 집배원이 자기 앞으로 온 편지를 우편함에서 꺼낸다 |
| 비주얼 톤 | 남해 파랑 + 흰 배 + 빨간 우체통 |
| AI 강점 | 다도해 항공 뷰, 쾌속선 항해, 섬 풍경 |
| 실화 근거 | 신안 홍도 1인 집배원 16년, 우정사업본부 '안부살핌' 서비스, 집배원이 독거노인 구한 사례 다수(2023·2025) |
| 리스크 | 손편지 소재는 보편적이라 차별화 약함. 집배원-노인은 세대 관계지만 혈연 아님 → 감정 밀도 약할 수 있음 |
| 기시감 | 중간(이탈리아 〈일 포스티노〉 연상) |

## 4안 「북쪽 창」 — 실향민 할아버지와 손자

**로그라인**
> 북쪽 고향이 보이는 전망대에 50년째 매달 오르는 아흔한 살 할아버지가 더는 계단을 못 오르게 된 날, 손자가 할아버지 기억 속 고향 마을을 AI로 그려 전망대 창에 띄운다.

> A 91-year-old who has climbed to the lookout facing his North Korean hometown every month for fifty years can no longer manage the stairs. His grandson rebuilds the village from the old man's memory and projects it onto the lookout's window.

| 항목 | 내용 |
|---|---|
| 두 존재 | 실향민 **용철**(91, 황해도 출신) ↔ 손자 **준**(26, AI 영상 제작자) |
| 장소 | 오두산 통일전망대. 임진강 너머 북녘 |
| 아크 | 계단 못 오름 → 손자가 할아버지 기억을 받아 적음 → 생성된 마을이 "틀렸다"(우물 위치, 감나무) → 수정 반복 → 완성된 마을을 전망대 창에 투사 → 할아버지가 "맞다" → 다른 실향민 노인들이 창 앞에 모여 선다 |
| 울림길 장면 | 전망대의 실향민 노인들이 말없이 창 앞에 도열 |
| 클라이맥스 | 할아버지가 창에 손을 댄다 |
| 비주얼 톤 | 잿빛 강 + 북녘 산 + 기억 속 마을의 따뜻한 색 |
| AI 강점 | 1950년 황해도 마을 재현 = 영화 안에서 AI가 서사 장치. 주제 ③ 인간과 AI에도 해당 |
| 실화 근거 | 이산가족 생존자 33,147명(2026.7), 평균 82.7세, 80세 이상 66.9%. 상봉 2018년 이후 중단 |
| 리스크 | **HEAL(기억 속 진입)·Homeward(과거로 귀환)와 구조 유사**. 정치적 해석 여지(두바이 심사엔 무관하나 한국 투표에서 분열 가능). "AI가 기억을 복원한다"는 AI 공모전 단골 |
| 기시감 | **높음** |

## 5안 「깡깡」 — 영도 깡깡이 아지매와 손녀

**로그라인**
> 40년 동안 배의 녹을 망치로 두드려 떼어낸 부산 영도의 마지막 깡깡이 아지매가, 그 소리를 녹음해 보존하겠다는 사운드 디자이너 손녀에게 말한다. 소리는 배에 있는 게 아니라 손에 있다.

> For forty years she hammered rust off ship hulls in Busan's Yeongdo shipyards. When her granddaughter, a sound designer, comes to record the dying sound, the old woman tells her: the sound isn't in the ship. It's in the hand.

| 항목 | 내용 |
|---|---|
| 두 존재 | 깡깡이 아지매 **복순**(73) ↔ 손녀 **유나**(29, 사운드 디자이너) |
| 장소 | 부산 영도 대평동 수리조선소. 녹슨 선체, 비계, 바다 |
| 아크 | 조선소 폐업 통보 → 손녀가 녹음기 들고 옴 → 녹음된 소리는 "그 소리가 아님" → 할머니가 망치를 쥐어줌 → 손녀 첫 망치질, 손바닥 터짐 → 마지막 날, 남은 아지매들이 선체 양쪽에 서서 동시에 망치를 친다 |
| 울림길 장면 | **선체 양쪽 비계에 아지매들이 도열해 망치질** — 울림길과 가장 닮은 시각 구조. 소리가 의례가 됨 |
| 클라이맥스 | 손녀가 녹음기를 끄고 망치를 든다. 합주 |
| 비주얼 톤 | 녹 주황 + 선체 회색 + 바다 파랑 |
| AI 강점 | 거대 선체, 비계 위 군상, 망치질 불꽃·녹 가루. 실사 촬영 허가 극난 |
| 실화 근거 | 영도 대평동 수리조선업, 1970~80년대 수백 명 → 현재 절반 이하·외국인 노동자로 대체(2026.4 보도), 이복순(73) 40년 종사 |
| 리스크 | 해외엔 완전 생소 → 신선하지만 설명 필요. 여성 노동 서사로 읽히면 '인간관계'보다 '사회' 주제 |
| 기시감 | **매우 낮음** |

## 권고

**1순위 — 1안 갯벌 「물때」**: 「숨」의 모든 장점(바다·노인·몸의 지식·게석 역전·집단 신호)을 유지하면서 기시감만 제거. 밀물이 '숨'보다 더 큰 시계. v2 시나리오를 장면 단위로 치환 가능 → 작성 1일.

**2순위 — 5안 깡깡이 「깡깡」**: 울림길과 시각적으로 가장 닮음(선체 양쪽 도열 망치질). 가장 신선. 단, 해외 심사위원에게 "이게 무슨 일인가" 설명 비용이 들고, 주제가 '사회·노동'으로 기울 수 있음.

**탈락 — 4안 실향민**: 소재 힘은 최강이나 1회 결선작 두 편과 구조 중복, AI 공모전 단골 구조.
