# 용천동굴 심층 분석 — 시나리오·레퍼런스 고증용

**조사일** 2026-10-20 · 출처: 국가유산청 지정 고시, 제주 세계자연유산 공식 페이지, 국립제주박물관 2011 특별전 보도(제주의소리), 박재현 「제주 용천동굴 출토 토기 자료의 의미」(탐라문화 72, 2023), 대한지질학회 2009 초록(김련·우경식 외), 2010·2014 어류 보도, 위키백과(고시 각주)

---

## 1. 기본 사실 (수정 포함)

| 항목 | 내용 | 시나리오 수정 |
|---|---|---|
| 위치 | 제주시 구좌읍 **월정리**. 만장굴 입구 인근 도로변 | 김녕 → **월정리**로 변경 |
| 발견 | 2005년 전신주 공사 중 | 유지 |
| 지정 | 2006-02-07 천연기념물 466호(문화재청 고시 2006-12호). 같은 날 **공개제한** 고시(2006-13호) | "발견 직후"가 아니라 이듬해 |
| 출입 | 관리·학술 목적만, 국가유산청장 허가. 무단 출입 2년 이하 징역·2천만원 이하 벌금 | 영화의 '허가' 절차에 현실감 부여 |
| 길이 | 2,960m(2009 학회) / 3.4km(호수 포함, 관리단) / 2,470.8m+α(지정 고시) | 자막엔 "약 3km" |

## 2. 동굴 내부 — 구간별 비주얼 자산

### 2-1. 용암 지형 (검은 것)
| 지형 | 모습 | 영화 활용 |
|---|---|---|
| **용암두루마리 140m** | 식은 용암이 벽을 따라 두루마리처럼 말린 띠가 140m 이어짐. 용천동굴 대표 지형 | S5 입굴 직후 트래킹 샷 배경 |
| 용암선반 | 벽 중간 높이에 선반처럼 튀어나온 턱 | 장비 올려놓는 디테일 |
| 용암폭포 | 용암이 낙차를 흘러 굳은 계단 | 호수로 내려가는 구간 |
| 용암단구 | 바닥의 단 | |
| 용암종유·용암석순 | 용암 자체가 흘러내려 굳은 돌기 | 흰 탄산염과 대비 |

### 2-2. 탄산염 생성물 (흰 것) — 이 동굴이 세계적으로 드문 이유
**형성 원리**: 월정·김녕 해변의 조개껍데기 모래가 바람에 날려 동굴 위 지표에 쌓임 → 빗물에 녹음 → 현무암 절리와 **식물 뿌리**를 따라 스며내림 → 동굴 천장·벽에 방해석으로 침전. 용암동굴 위에 석회동굴 장식이 자람.

| 생성물 | 모습 | 영화 활용 |
|---|---|---|
| **종유관** (soda straw) | 빨대처럼 가늘고 긴 흰 관. 뿌리를 따라 자라 **나무뿌리처럼** 보임 | S5 "뿌리 종유석"의 정확한 정체 |
| 종유석·석순·석주 | 고드름·죽순·기둥 | 랜턴 원 안 실루엣 |
| **평정석순** | 윗면이 평평한 석순. 국내 희귀 | 디테일 컷 |
| 동굴산호 | 벽에 팝콘처럼 돋은 흰 알갱이 | 벽 클로즈업 질감 |
| 동굴진주 | 물웅덩이 속 둥근 방해석 알 | 물방울 떨어지는 곳 |
| 유석·휴석·커튼 | 벽을 타고 흐른 흰 막, 계단식 둑, 주름 | 벽 롱샷 |

→ 레퍼런스 핵심: **검은 현무암 위에 흰 방해석이 흘러내린 대비.** 석회동굴처럼 전체가 밝으면 틀림.

### 2-3. 호수
- 동굴 하류 끝. **국내 유일 용암동굴 호수.**
- 수치는 자료마다 다름: 발견 당시 길이 약 200m·폭 7~15m·깊이 6~15m / 관리단 800m·수심 8~13m·폭 최대 20m. 자막엔 수치 쓰지 않음.
- 민물과 바닷물이 **층을 이루며** 섞임. 바다 쪽으로 갈수록 염분 증가. 끝은 모래 둑, 바다와 연결.
- 영화의 "빛이 두 번" "아지랑이 층"은 이 사실에 근거.

### 2-4. 물고기
| 항목 | 사실 |
|---|---|
| 분류 | **주홍미끈망둑속**(Luciogobius) 미기록종. 신종 확정 아님 |
| 크기 | 3.4cm(2014 측정) ~ 4~7cm(2010 추정) |
| 색 | 멜라닌 적어 **옅은 분홍, 투명** |
| 눈 | "퇴화해 매우 작음" / "검은 점이 피부 속에 함몰" → **눈이 없는 게 아니라 피부 밑에 묻힘** |
| 형태 | 머리가 유난히 큼. 부레 퇴화 추정 |
| 유입 | 약 6,000년 전 해수면 상승 때 들어온 것으로 추정 |
| 발견 | 2010 관리본부 수중촬영, 2014 KBS 촬영 |

→ 시나리오 "눈이 있어야 할 자리가 매끈하다" → **"눈이 있던 자리에 검은 점 둘이 피부 밑에 묻혀 있다"**로 수정. 대사 "뭘 보고 사냐"는 유지 가능.

## 3. 사람의 흔적 — 1,200년 전

### 3-1. 발견된 것
| 유물 | 상세 |
|---|---|
| 토기 | 복원 22점 + 파편 다수. 동굴 **전 구간 61개 지점.** 전부 저장·운반용 **병·항아리.** 크기 규격화. 환원소성(밀폐 가마) → 탐라 기술 아님. 인화문(도장무늬) → **통일신라 육지 제작, 8세기 후반~9세기 전반** |
| 철기 | 철기 1, 철도자(작은 칼) 1, 철편 2. (2011 보도의 "칼과 창") |
| 조개 | 전복 + **홍합·꼬막** (제주에 서식하지 않음 → 육지에서 가져옴) |
| 동물뼈 | 사슴·뱀·염소·**멧돼지**. 먹다 남은 흔적 |
| 탄화물 | 연대 약 1,290~1,550년 전 |
| **벽 각자** | 동굴 벽에 **「火川」(화천)** 두 글자. "불기둥이 지나간 내"로 해석 시도 |
| 없는 것 | 당시 제주 토기(고내리식) 0점. 8세기 이후 유물 0점 |

### 3-2. 두 가지 해석
| | 제사 유적설 (초기 연구자) | 물품저장소설 (박재현 2023) |
|---|---|---|
| 근거 | 온전한 멧돼지 뼈, 철기, 전복 = 제물·제기 | 토기가 전부 운반용, 규격화. 제사터는 보통 높고 트인 곳(용담동·오키노시마). 동굴은 밀폐·저온 = **천연 냉장 창고** |
| 누가 | 탐라 지배층 | **신라 상인 집단**, 50년 미만 활동 |
| 무엇을 | 의식 | 쌀·술·소금·철 반입, 전복·귤·미역 반출의 중간 거점 |

**영화의 선택**: 어느 쪽도 단정하지 않는다. S7 회상은 "횃불 든 사람들이 항아리를 두고, 벽에 글자를 새기고, 나갔다"로. "그들도 보고, 두고, 나갔다"는 두 해석 모두에 맞는다. 크레딧에 "용도는 아직 밝혀지지 않았다" 한 줄.

### 3-3. 폐쇄
8세기 이후 유물이 없음 → 짧은 기간 사용 후 자연적 또는 인위적으로 입구가 막힘. 1702년 『탐라순력도』에도 김녕사굴만 기록. **1,200년 뒤 전신주 공사로 다시 열림.** 영화 제목 「입구」의 근거.
