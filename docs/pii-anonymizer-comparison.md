# 개인정보 자동 익명화 도구 비교 보고

> v0.1 · 2026-09-06 · 목적: 문서·표·사진에 든 이름·연락처·주소·얼굴을 AI에 넣기 전, 또는 외부로 보내기 전에 자동으로 지우거나 가명으로 바꾸는 도구를 검토한다.
> 조건: 오프라인 동작, 한국어 이름 처리, 현지어(동남아·중앙아시아) 처리, 컴퓨터 초보 사용 가능, 무료 우선.

## 0. 결론

**한 방에 되는 도구는 없다.** 특히 "한국어 이름"과 "현지어 이름"을 오프라인에서 자동으로 잡는 도구는 2026년 9월 현재 초보자용으로 존재하지 않는다. 현실적인 답은 세 겹이다.

| 겹 | 방법 | 잡는 것 | 신뢰도 |
|---|---|---|---|
| 1 | **내 사람 목록(사전) 치환** — 내가 아는 이름·기관·지명 목록을 만들어 두고 코드로 자동 교체 | 내가 아는 사람 전부 | 100% (목록에 있으면) |
| 2 | **패턴(정규식) 치환** — 전화·이메일·여권·계좌·주민번호·URL | 형식이 있는 것 | 95%+ |
| 3 | **AI 2차 검토** — 로컬 LLM 또는 NER 모델이 남은 이름·장소를 찾아 표시 | 목록에 없던 이름 | 60~90%, 언어별 편차 |

마지막은 사람 눈. 익명화는 "놓친 이름 하나"가 치명적이라 자동화만 믿으면 안 된다.

## 2. 왜 "자동"이 어려운가

- **한국어 이름**: 2~3음절 한글에 조사가 붙는다("순려가", "순려님께"). spaCy 한국어 모델은 KLUE 데이터로 훈련됐지만 알파 단계이고 조사 포함 문제가 보고돼 있다. 연구용 BERT 모델은 F1 0.94까지 나오지만 초보자용 앱은 없다.
- **현지어 이름**: 라오어·크메르어·미얀마어·우즈베크어는 GLiNER2-PII, spaCy 모두 미지원. 로컬 LLM이 유일한 자동 후보인데 저자원어 품질은 미검증.
- **이름이 아닌 식별자**: "마을 유일한 약국집 딸", "작년에 침례 받은 청년" 같은 서술은 어떤 도구도 못 잡는다. 사람이 읽어야 한다.
- **재식별**: 이름을 지워도 사진 배경·간판·날짜·행사명으로 특정된다. 도구는 텍스트만 본다.

## 3. 권장 운영 절차 (초보자용, 설치 최소)

### 3-1. 지금 당장 — 설치 없이

1. **내 사람 목록** 만들기: 엑셀 한 장. 실명 | 코드(P01, P02…) | 역할 | 기관 | 지명. 이 파일은 USB에만, 암호 걸기(엑셀 파일 → 정보 → 통합 문서 보호 → 암호).
2. 문서 작성 후 워드·엑셀 **찾기/바꾸기**로 목록의 실명을 코드로 일괄 교체. 조사가 붙은 형태("순려가")도 잡히도록 성 없이 이름만 검색.
3. **LibreOffice 자동 검게 칠하기**(도구 → Auto-Redact)에 정규식 등록: 전화 `0\d{1,2}-?\d{3,4}-?\d{4}`, 이메일 `[\w.]+@[\w.]+`, 여권 `[A-Z]\d{8}`, 계좌 `\d{2,6}-\d{2,6}-\d{2,6}`. 목록을 JSON으로 저장해 재사용.
4. **로컬 LLM 2차 검토**: 
   ```
   아래 글에서 사람 이름, 기관명, 마을·도시 이름, 날짜, 전화·이메일로 보이는 것을 전부 찾아
   표로 만들어 줘: 원문 | 종류 | 대체 제안. 확실하지 않아도 의심되면 포함해.
   ```
   두 번 돌려 결과 합집합을 본다.
5. 사진은 **Deface GUI**(PC) 또는 **Signal 블러**(폰)로 얼굴 처리 → **ExifCleaner**로 위치 정보 제거 → 간판·문패·문서가 보이는 사진은 쓰지 않는다.
6. 최종은 사람이 한 번 읽는다. 점검 질문: "이 글만 보고 마을 사람이 누군지 알 수 있나?"

### 3-2. 반자동 — 강사가 한 번 만들어 배포

파이썬 없이 쓰는 **한 파일 HTML 도구**(브라우저에서 열면 오프라인 동작): 텍스트 붙여넣기 → 내 사람 목록(CSV) 불러오기 → 정규식 + 목록 치환 → 결과 복사. 서버 없음, 설치 없음. 바이브코딩으로 반나절 분량. 로컬 LLM 2차 검토는 별도로.

### 3-3. 자동 — 기관 단위

Presidio + spaCy 한국어 + 정규식 + 사용자 사전을 묶은 데스크톱 앱(예: Tauri/Electron). 라오어 등은 사전 치환만. 개발 1~2주. 기관에 개발자가 없으면 Private AI 컨테이너 견적 검토(한국어 지원 여부 먼저 확인).

## 5. 정직한 한계

- 어떤 도구도 놓침 0을 보장하지 않는다. 자동화는 "사람이 놓친 것을 잡는 보조"이지 사람을 대체하지 않는다.
- 익명화된 문서라도 AI에 넣는 순간의 원칙은 같다: 온라인 AI에는 익명화 후에도 사역·수혜자 관련 서술을 넣지 않는다.
- 이름을 지운 결과물이 "누구인지 알 수 있는 이야기"라면 익명화는 실패다. 4차시 익명화 점검표를 함께 쓴다.
- GLiNER2-PII의 한국어 미지원, Azure 컨테이너의 한국어 "예정" 상태, Private AI의 한국어 명시 여부는 2026-09 기준이며 바뀔 수 있다.
