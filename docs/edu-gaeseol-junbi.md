# 통합돌봄사이버교육원 개설 준비

> 작성 2026-09-09 · 브랜치 `claude/lifelong-education-j41py9`
> 읽기 좋은 버전: https://claude.ai/code/artifact/8d438cba-fc09-45f7-be8c-bfc78017640f
> 근거는 평생교육법 제33조와 시행령, 교육지원청 신고 안내. 관할 교육지원청 확인이 필요한 항목은 따로 표시했습니다.

## 결론 먼저

병목은 하나입니다. **평생교육사 1명**입니다.

신고 서류에 평생교육사 자격증 원본과 재직증명서를 내야 합니다. 이것이 없으면 다른 서류를 다 갖춰도 신고가 되지 않습니다. 나머지는 준비하면 2주에서 3주 안에 끝납니다.

지금 상태에서 개설까지 걸리는 시간은 평생교육사를 어떻게 확보하느냐로 결정됩니다. 직접 취득하면 1년 안팎, 채용하면 한 달 안팎입니다.

## 전체 순서

| 순서 | 할 일 | 선행 조건 | 걸리는 시간 |
|---|---|---|---|
| 1 | 사업자등록 | 없음 | 당일 |
| 2 | 사무소 확보 | 없음 | 계약 기간에 따름 |
| 3 | 평생교육사 확보 | 없음 | **1년 또는 1개월** |
| 4 | 운영규칙 확정 | 1 | 이미 초안 있음 |
| 5 | 원격평생교육시설 설치 신고 | 1·2·3·4 | 교육청 심사 기간 |
| 6 | 평생교육이용권 사용기관 등록 | 5 | 신고번호 발급 후 |
| 7 | 첫 과정 개강 | 5 | 신고 수리 후 |

3번이 가장 오래 걸립니다. 나머지와 병행할 수 있으니 오늘 시작하는 것이 좋습니다.

## 신고 대상에 해당하는가

원격평생교육시설 신고는 아래를 모두 충족할 때 의무입니다.

- 학습비를 받을 것
- 10명 이상을 대상으로 할 것
- 교육과정이 30시간 이상일 것
- 인터넷 강의, 화상 강의 등 정보통신기술을 활용할 것

실무과정 30시간과 셀프돌봄 AI 과정 30시간이 여기에 해당합니다. 신고 대상이 맞습니다.

## 제출 서류

관할 교육지원청 안내를 기준으로 정리한 목록입니다.

| 서류 | 지금 상태 | 준비 방법 |
|---|---|---|
| 설치 신고서 | 없음 | 교육지원청 서식 |
| 운영규칙 | **초안 있음** | 정보공개 페이지의 요약을 전문으로 확장 |
| 위치도 | 없음 | 사무소 확정 후 |
| 시설배치도 | 없음 | 사무소 확정 후 |
| 건축물대장 현황도 | 없음 | 정부24 발급 |
| **평생교육사 자격증 원본** | **없음** | 아래 참조 |
| **평생교육사 재직증명서** | **없음** | 아래 참조 |
| 설치자 신분증 | 있음 | 개인 사업자인 경우 |
| 재산목록 및 입증서류 | 없음 | 장비 목록과 구입 증빙 |
| 임대차 계약서 사본 | 없음 | 사무소가 임차인 경우 |
| 서버 임대계약서 | 없음 | 클라우드 계약서로 갈음 여부 확인 필요 |
| 콘텐츠 계약서 | 해당 없음 | 자체 제작이므로 제작 사실 소명 |
| 홈페이지 캡처 출력물 | **있음** | 이미 개설된 사이트 |

사이트를 먼저 만들어 둔 것이 여기서 값을 합니다. 신고 서류에 홈페이지 캡처가 들어갑니다.

## 평생교육사 확보

### 길 A. 직접 취득

학점은행제로 평생교육 관련 과목 30학점, 10과목을 이수합니다.

- 필수 5과목. 이 중 하나가 **평생교육실습 160시간**입니다.
- 선택 5과목.
- 실습을 제외한 필수 4과목을 먼저 마쳐야 실습을 신청할 수 있습니다.
- 출석 80퍼센트 이상, 평균 80점 이상.
- 자격증 신청은 연 4회. 1월, 4월, 7월, 10월.

학사 이상이면 과목 이수만 하면 됩니다. 보건학 박사과정을 수료하셨으니 학력 요건은 이미 충족입니다.

현실적으로 두 학기, 8개월에서 12개월이 걸립니다. 실습 160시간이 가장 큰 부담입니다.

### 길 B. 채용

평생교육사 자격증을 가진 사람을 직원으로 둡니다. 재직증명서를 발급할 수 있어야 합니다.

- 시간: 채용에 걸리는 기간만큼. 한 달 안팎.
- 비용: 인건비가 계속 나갑니다.
- 확인 필요: 상근이어야 하는지, 시간제나 겸직이 가능한지는 관할 교육지원청 판단입니다.

### 권고

**A와 B를 동시에 갑니다.**

오늘 학점은행제 등록을 하시고, 동시에 채용을 알아보십시오. 채용이 먼저 되면 그해 안에 개설하고, 안 되면 1년 뒤 본인 자격으로 개설합니다. A를 시작해두면 나중에 인건비를 줄일 수 있고, 강의 설계에도 도움이 됩니다.

A만 하면 1년을 기다려야 하고, B만 하면 사람이 나갈 때마다 신고가 흔들립니다.

## 지금 당장 할 수 있는 것

신고와 무관하게 오늘 시작할 수 있는 일입니다.

1. **학점은행제 등록.** 다음 학기 개강 일정을 확인하고 필수 4과목부터 신청합니다.
2. **사업자등록.** 홈택스에서 당일 처리됩니다. 업종은 교육서비스업.
3. **운영규칙 전문 작성.** 정보공개 페이지에 요약이 이미 있습니다. 이것을 신고용 전문으로 확장합니다.
4. **교재 3모듈 집필.** 신고와 무관하고, 개강일이 정해지면 그때부터는 시간이 없습니다.
5. **사무소 검토.** 원격 시설이라도 주된 사무소가 필요합니다. 자택 사용 가능 여부를 관할 교육지원청에 확인하십시오.

## 기다려야 하는 것

- 수강 신청 접수와 학습비 수납. 신고 수리 전에 받으면 미신고 운영입니다.
- 평생교육이용권 사용기관 등록. 신고번호가 나온 뒤에 됩니다.
- 개강일 공지. 심사 기간을 알 수 없으니 날짜를 먼저 약속하지 않습니다.

## 확인해야 할 것

- [ ] 관할 교육지원청이 어디인지 (사무소 소재지 기준)
- [ ] 자택을 주된 사무소로 신고할 수 있는지
- [ ] 평생교육사 상근 여부와 겸직 허용 범위
- [ ] 클라우드 서버가 서버 임대계약서를 갈음하는지
- [ ] 자체 제작 콘텐츠의 소명 방법
- [ ] 처리 기간과 수수료
- [ ] 설치자 결격사유 조항
- [ ] 손해배상 보험이나 공제 가입 의무 여부

이 여덟 가지는 관할 교육지원청 평생교육 담당자에게 전화 한 통이면 대부분 해결됩니다. 방문 전에 목록을 들고 가십시오.
