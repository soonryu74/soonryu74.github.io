# 1인 출판사 세무사 상담 질문지

> 작성 2026-10-10 · 기획안 `docs/1in-chulpansa-plan.md` 3장의 [확인] 항목을 상담 한 번에 끝내기 위한 목록.
> 상담 전 준비물: 출판사신고확인증(또는 접수증), 유튜브 채널 수익 현황, 예정 상품 목록(전자책 10권·온라인 강의·코칭).

## 상담에서 받아 올 답 (빈칸을 채운다)

| # | 질문 | 답 | 근거(법령·예규) |
|---|---|---|---|
| 1 | ISBN을 받은 전자책(EPUB·PDF)을 **자사 페이지에서 직접 판매**하면 부가가치세 면세인가 | | |
| 2 | 같은 책을 **크몽 같은 재능마켓**에서 팔 때도 면세인가, 아니면 용역으로 과세인가 | | |
| 3 | ISBN 없이 PDF만 파는 경우는 과세로 보는 것이 맞는가 | | |
| 4 | 전자책(면세) + 온라인 강의(과세) + 코칭(과세)을 **한 사업자로 겸영**할 때 등록 업종·업태를 어떻게 적는가 | | |
| 5 | 겸영 시 **간이과세** 적용이 되는가. 되면 유리한가, 강의 매출 예상(연 ___ 원) 기준으로 | | |
| 6 | 면세 매출과 과세 매출의 **장부·세금계산서·계산서** 구분 방법 | | |
| 7 | 유튜브 광고 수익(구글 애드센스)과 출판·강의 매출을 **같은 사업자**에 묶는 것이 맞는가 | | |
| 8 | 직판 결제 수단(계좌이체·간편결제 링크) 별로 **현금영수증 의무 발행** 기준 | | |
| 9 | 국립중앙도서관 **납본 보상금**은 어떤 소득으로 처리하는가 | | |
| 10 | 아마존 KDP 해외 로열티(달러)의 **신고 방법**과 W-8BEN 제출 시 한미 조세조약 원천징수율 | | |
| 11 | 전자책 제작비(표지 외주·도구 구독료·Canva·Claude)의 **경비 처리** 범위 | | |
| 12 | 집에서 운영할 때 **임차료·통신비 안분** 기준 | | |
| 13 | 통신판매업 신고 **면제 요건**(직전 연도 거래 횟수·간이과세자)에 내가 해당하는가 | | |
| 14 | 월 매출이 커질 때 **일반과세 전환 시점**과 그때 바뀌는 것 | | |

## 상담 뒤 할 일

1. 답을 위 표에 기록하고 기획안 3장의 [확인] 표시를 지운다.
2. 사업자등록 업종·업태를 답 4번대로 홈택스에 입력한다.
3. 13번 답이 "신고 대상"이면 구청에 통신판매업 신고를 한다(판매 페이지에 신고번호 표기).
