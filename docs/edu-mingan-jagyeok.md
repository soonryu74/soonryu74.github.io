# 돌봄 실무 민간자격 등록 준비

> 작성 2026-09-24 · 대상 통합돌봄사이버교육원 · 브랜치 `claude/lifelong-education-j41py9`
> 읽기 좋은 버전: https://claude.ai/artifact/W8EPJGn3HuL4iF7vWV3TH6
> 대표 결정(2026-09-24): 민간 교육과정으로 운영하고, 수료자에게 민간자격을 발급한다. 이전 문서의 "민간자격 보류" 판단은 이 결정으로 대체됩니다.

## 결론 먼저

**등록이 끝나기 전에는 사이트에 자격증을 한 줄도 쓰지 않습니다.** 자격기본법 제39조는 등록 없이 민간자격을 신설·운영하면 3년 이하 징역 또는 3천만원 이하 벌금, 제41조는 표시 의무 위반에 3천만원 이하 벌금입니다. 지금 사이트에 "민간자격증을 주지 않습니다"라고 적힌 문장은 등록 결정 통보가 올 때까지 그대로 둡니다.

지금 할 일은 세 가지입니다.

1. 자격 명칭을 정하고 민간자격정보서비스에서 중복·유사 여부를 확인한다.
2. 관리·운영 규정과 검정 설계를 쓴다. 검정은 재설계한 기본과정의 산출물(사례 파일 한 벌)을 그대로 실기로 쓴다.
3. 사업자등록 뒤 다음 달 1~20일에 등록을 신청한다. 심사는 3~4개월이다.

평생교육시설 신고와는 법이 다르고 절차가 독립적입니다. 병행할 수 있습니다.

## 두 개의 법, 두 개의 서류

| | 교육과정 | 자격 검정 |
|---|---|---|
| 근거 법 | 평생교육법 | 자격기본법 |
| 하는 일 | 가르치고 수료증을 준다 | 시험 보고 자격증을 준다 |
| 신고·등록처 | 관할 교육지원청 (원격평생교육시설 설치 신고) | 한국직업능력연구원 민간자격정보서비스 → 주무부처 검토 |
| 병목 | 평생교육사 1명 | 명칭 심사와 금지 분야 심사 |
| 상태 | 준비 중 | 이 문서로 시작 |

같은 사업자가 둘 다 할 수 있습니다. 다만 **수료증과 자격증은 끝까지 다른 물건**이어야 합니다. 수료증은 과정을 들었다는 증명, 자격증은 검정에 통과했다는 증명입니다. 교육 안 듣고 검정만 볼 수 있어야 자격증 장사라는 말을 안 듣습니다.

## 등록 절차 (사실)

| 항목 | 내용 |
|---|---|
| 등록 관리기관 | 한국직업능력연구원 민간자격정보서비스 (pqi.or.kr) |
| 신청 기간 | 매월 1일~20일 |
| 검토 | 관리기관이 주무부처에 검토 의뢰 → 주무부처가 등록 가능 여부 결정 |
| 소요 | 통상 3~4개월 (정부24 안내 약 3개월) |
| 주무부처 | 자격 분야로 정해짐. 돌봄이면 보건복지부. 2026년 1월 정부조직 개편으로 부처명이 바뀐 경우 바뀐 부처로 접수 |
| 등록 유효기간 | 등록일부터 5년. 만료 6개월 전~3개월 전에 갱신 신청 |
| 핵심 서류 | 민간자격 등록신청서(시행규칙 별지 제1호), 관리·운영 규정, 관리기관 증빙(사업자등록증 등), 시설·인력·재정 현황 |

**사업자등록이 선행 조건입니다.** 관리기관 정보에 들어갑니다. 개설 준비 문서의 1번과 같습니다.

## 등록이 막히는 두 지점

### 금지 분야 (자격기본법 제17조)

"국민의 생명·건강·안전 및 국방에 직결되는 분야"는 신설 불가입니다. 돌봄이 여기 걸리는지는 심사관 판단입니다. 걸리지 않게 만드는 방법은 하나입니다. **규정과 검정 과목에서 임상을 완전히 배제하고, 그 사실을 명문화하는 것.**

이미 사이트 전체가 "제도·행정·서식·연계·디지털 활용만 다룬다"로 되어 있습니다(`e17a873`). 규정도 같은 문장으로 씁니다.

### 명칭

국가자격과 같거나 비슷한 명칭은 안 됩니다. 사회복지사, 요양보호사, 간호조무사 같은 어휘, 그리고 "~사" 어미가 국가자격처럼 읽히는 경우가 문제입니다. 공적 제도의 이름을 자격명으로 쓰면 국가 인증으로 오인된다는 심사 지적도 예상해야 합니다.

| 후보 | 위험 | 판단 |
|---|---|---|
| 통합돌봄사 | 공적 제도명 + "사" 어미. 국가자격 오인 소지 가장 큼 | 피함 |
| 통합돌봄 케어플래너 | "통합돌봄"이 정부 사업 브랜드. 혼동 심사 가능 | 2순위 |
| **지역돌봄 케어플래너** | "지역 돌봄"은 법률 제명의 일반 어구, 사업 브랜드가 아님. "플래너"는 국가자격 어미와 겹치지 않음 | **추천** |
| 돌봄 지원계획 코디네이터 | 무난하나 길고 특색 없음 | 3순위 |

**확인 필요**: 민간자격정보서비스(pqi.or.kr) 검색에서 "케어플래너", "돌봄", "지역돌봄"으로 기등록 자격을 확인해야 합니다. 이 세션에서는 검색 페이지가 검색어를 받지 않아 확인하지 못했습니다. 대표님이 직접 한 번 검색하시면 됩니다.

## 자격 설계

재설계한 교육과정과 맞물리게 짭니다. 검정이 과정의 산출물을 그대로 쓰기 때문에 따로 시험 준비를 시킬 필요가 없습니다.

### 등급

**2급 하나로 시작합니다.** 1급은 실무 경력과 상황별 전개(치매·뇌혈관질환·낙상·임종기) 이수를 요건으로 나중에 변경등록으로 추가합니다. 처음부터 두 등급을 등록하면 규정이 두 배로 복잡해지고 1급 검정을 당장 시행할 수도 없습니다.

### 검정 방법

| 구분 | 내용 | 배점·기준 |
|---|---|---|
| 필기 | 온라인. 제도 구조·대상자·절차·서식·서비스 분류·연계·비밀유지. 40문항 | 100점 만점, 60점 이상 |
| 실기 | **사례 파일 한 벌 제출.** 가상 사례 하나를 인테이크 기록 → 사정표 → 욕구·목표 → 개인별지원계획서 → 회의 발언 대본 → 연계표 → 모니터링 서식까지 완성 | 루브릭 채점 100점, 60점 이상 |
| 합격 | 필기·실기 모두 60점 이상 | |

실기는 기본과정 8회차 "처음부터 끝까지 혼자"와 같은 형식입니다. 과정을 들은 사람은 이미 한 번 해본 일이고, 안 들은 사람도 서식만 있으면 할 수 있습니다.

루브릭은 정직하게 만듭니다. "사정표에서 빠뜨린 항목", "욕구와 목표가 연결되는가", "계획서의 서비스마다 이유가 있는가", "함께 넣을 수 없는 조합을 넣었는가", "발언에 금지 표현이 있는가", "모니터링 기준이 측정 가능한가". 원문 대조가 가능한 항목만 채점합니다.

### 응시 자격

둘 중 하나.
- 본 교육원 통합돌봄 기본과정 또는 실무과정 수료자
- 돌봄·복지·보건 기관 실무 경력 1년 이상 (재직증명서)

두 번째 줄이 있어야 "교육 안 사면 시험 못 본다"가 아닙니다.

### 유효기간

**유효기간을 두지 않습니다.** 갱신비를 받지 않습니다. 제도가 바뀌면 자격 취득자에게 개정 내용을 무료로 보냅니다. 정보공개 페이지의 "끼워 팔지 않는다" 원칙과 같은 선입니다.

대안으로 3년 유효 + 보수교육 6시간이 있지만, 지금 브랜드에서는 갱신 장사로 읽힐 위험이 더 큽니다. 나중에 제도 변화가 잦아 정말 필요해지면 변경등록으로 넣습니다.

### 수수료

| 항목 | 원칙 |
|---|---|
| 검정료 | 채점 인건비 실비. 필기·실기 합쳐 3만원 안팎 |
| 자격증 발급 | 실비. 전자 발급이면 무료 |
| 재발급 | 무료 (수료증과 동일 원칙) |
| 교육비와의 관계 | **완전 분리.** 교육비에 검정료를 포함하지 않고, 검정료에 교육을 끼우지 않는다 |

## 관리·운영 규정 초안 골격

등록 신청서에 붙일 규정입니다. 항목별로 무엇을 쓸지 정했습니다. 전문은 대표님이 명칭을 확정하시면 씁니다.

| 장 | 내용 |
|---|---|
| 1. 총칙 | 자격 명칭·등급, 목적, 관리운영기관(상호·사업자번호·소재지·대표), **자격의 성격**: 국가공인 아님, 취업·승진 보장 없음, 법정 자격·보수교육 대체 아님, **의료행위·임상 판단을 검정하지 않음** |
| 2. 검정 | 과목, 방법(필기·실기), 문항 수·배점·합격 기준, 시행 횟수(연 4회), 온라인 시행과 부정행위 방지 |
| 3. 응시 | 응시 자격, 원서 접수, 검정료, 환불 기준(평생교육법 시행령 반환 기준을 준용해 명시) |
| 4. 자격증 | 발급, 기재 사항(등록번호·자격명·등급·발급일·관리기관), 재발급, 유효기간 없음 |
| 5. 자격 취득자 관리 | 명부, 제도 개정 시 안내, 취소 사유(부정 취득) |
| 6. 검정위원 | 자격(제도·서식 원문 대조 가능한 실무 경력자), 위촉, 채점 기준 공개 |
| 7. 정보 공시·표시 | 광고 시 등록번호·자격종류·관리기관·"국가공인 아님" 표시, 사이트 공시 |
| 8. 개인정보 | 수집 항목, 보유 기간, 파기 |
| 9. 변경·폐지 | 변경등록, 등록 갱신(5년), 폐지 시 취득자 통지 |

## 순서와 시간

| 순서 | 할 일 | 걸리는 시간 | 선행 |
|---|---|---|---|
| 1 | 명칭 확정 + pqi 중복 검색 | 하루 | 없음 |
| 2 | 사업자등록 | 당일 | 없음 |
| 3 | 규정 전문 + 필기 문항 40개 + 실기 루브릭 작성 | 2~3주 | 1 |
| 4 | 등록 신청 (1~20일) | 하루 | 2, 3 |
| 5 | 주무부처 심사 | 3~4개월 | 4 |
| 6 | 등록 결정 통보 → 사이트 반영 → 첫 검정 공고 | 1주 | 5 |

3번은 제가 초안을 씁니다. 원문 대조가 필요한 문항은 대표님이 확인하십니다.

## 등록 뒤 사이트에 바꿀 것

지금은 손대지 않습니다. 통보가 오면 한 번에 바꿉니다.

- 자주 묻는 질문 "민간자격증을 주나요" 답변을 교체. **왜 만들었는지**를 먼저 씁니다. 기관과 지자체가 담당자에게 "근거 있는 자격"을 요구하기 때문이라는 실무 이유. 국가공인이 아니라는 문장은 그대로.
- 과정 안내와 각 과정 페이지에 자격 정보 표시: 자격명, 등록번호, 관리기관, "국가공인 민간자격 아님", 취득 조건(수료와 별개로 검정 통과).
- 정보공개 페이지에 규정 전문 게시, "하지 않는 일"에 "자격 취득이 취업을 보장하지 않습니다" 유지.
- 수강 안내에 검정료와 교육비가 별개임을 명시.

## 남는 위험

- **금지 분야 심사**에서 돌봄이 건강·안전 직결로 읽히면 반려됩니다. 규정의 임상 배제 조항이 방어선입니다. 반려되면 명칭·과목을 조정해 재신청합니다.
- **브랜드 충돌.** 지금 사이트가 "민간자격증은 주지 않습니다"를 강한 문장으로 쓰고 있습니다. 등록 뒤 바꿀 때 이유를 정직하게 설명하지 않으면 톤이 깨집니다. FAQ 답변 초안을 미리 써두는 편이 낫습니다.
- **AI 민간자격은 여전히 보류입니다.** 이 결정은 돌봄 실무 자격에 한합니다. 550개 포화와 정부 정리 착수라는 사정은 그대로입니다.
