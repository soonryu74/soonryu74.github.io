### 검토자 3. 건강보험 수가·보건경제 전문가

- **종합 평가**
  - 재원 실현가능성 **2/5**: 경로 네 가지(⑧ 요구사항 2 표)를 나열했지만 확보된 경로는 하나도 없습니다. 개인 보상 재원(조례·기금)은 파일럿 기간 중에 마련하도록 되어 있어(⑨ 로드맵 1단계) 파일럿 초기에는 개인 보상 없이 운영하게 됩니다.
  - 유인 설계 타당성 **2/5**: 건당·개인 보상으로 전환하자는 주장을 보고서 자체 근거가 뒷받침하지 않습니다. 심뇌혈관 4분 36초는 팀 정액으로 달성한 성과입니다. 대기(가용성)에 대한 보상이 없고, 허위 수락·환자 선별을 막는 장치는 "상황실 감시" 한 줄뿐입니다.
  - 재정 지속가능성 **3/5**: 개인 보상 규모(연 1.4억~2.5억 원)는 작고 "건당 지급 → 기본재원 편입"이라는 출구(⑧ 원칙 셋째)도 제시했습니다. 다만 비용 추계가 없는 기관 수가 확대 항목이 실제 재정 위험입니다.

- **동의하는 핵심 설계**
  1. **⑧ 요구사항 2 "수락 행위의 정의"**: 수락을 ①원격 자문 ②전원 수용 ③출동·순환당직의 세 유형으로 나누고, ①(자문 행위)을 수가 연결의 주 경로로 둔 판단은 옳습니다. 국내 수가는 클릭이 아니라 '행위'를 대상으로 정의되기 때문입니다.
  2. **④ 분석·⑧ 보상 원칙 첫째·P3**: 지급 주체를 공공으로 한정하고 민간 플랫폼의 직접 지급을 배제한 것은 알선·리베이트 해석 위험을 피하는 유일한 길입니다.
  3. **P2·⑧ 워크플로**: 구조화 이벤트로 시간·자격·동의를 자동 기록해 청구 근거를 만드는 설계입니다. FAST Act의 과소·오청구 교훈을 정확히 반영했습니다.

- **반드시 수정할 사항** (우선순위 순)

  1. **재원 경로별 소요 기간과 파일럿 개시 시점이 맞지 않음**
     - 문제: 파일럿은 2027.5에 시작하는데 조례 제정·기금 보조사업 편성·시행계획 반영은 파일럿 기간 중의 과제로 잡혀 있습니다(⑨). 개인 보상이라는 핵심 개입 없이 파일럿이 시작될 수 있습니다.
     - 근거(의견): 통상적인 소요 기간은 다음과 같습니다.
       - 건강보험 수가 신설: 행위 정의 → 상대가치 산정 → 건정심 의결 → 고시까지 18~36개월
       - 기존 시범사업 지침 개정(원격협의진찰료 지정 시스템 추가, 전자적 의뢰 인정): 6~12개월
       - 신규 건강보험 시범사업: 12~18개월
       - 응급의료기금: 전년도 기금운용계획에 반영되어야 하므로 2027년 신규 편성은 사실상 어렵고 2028년부터 가능
       - 시도 조례: 입법·의회 의결에 6~12개월, 여기에 해당 연도 지방예산 편성이 따로 필요
     - 수정안: 경로별 법적 근거, 지급 대상(기관/개인), 소요 기간, 파일럿 1년차 사용 가능 여부를 표로 다시 정리하십시오. 1년차 개인 보상은 (a) 심뇌혈관 인적 네트워크 시범사업 연장·확대분에 얹거나 (b) 기존 응급의료 보조사업 안에서 사업비를 변경해 충당하고, 조례·기금은 2년차 재원으로 명시할 것을 권합니다(의견).

  2. **기관 청구 체계에서 개인에게 실제로 돈이 전달되는 경로가 없음**
     - 문제: 기관 수가는 소속 기관이 받고, ⑧ '역할'에는 "기관이 개인 보상 수령·배분"이라고만 되어 있습니다. 병원이 이 돈을 흡수하면 개인 유인은 0이 됩니다.
     - 근거: 심뇌혈관 지원금도 "인건비 사용 가능" 수준에 그칩니다(③).
     - 수정안: 두 경로를 분리해 설계하십시오.
       - 기관 경유: 지침에 개인 배분 최소 비율과 증빙 제출을 의무화하고, 미이행 시 다음 연도 지원금을 감액합니다.
       - 지자체 직접 지급: 조례에 지급 대상(민간 의사 포함), 소득 구분(원천징수), 소속 기관 겸직 승인 요건을 명시합니다.
       - 두 경로 공통: 근무시간 중 당직 의사는 이미 급여를 받고 있으므로 개인 보상에서 제외하거나 감액합니다. 비번 시간이나 타 기관 소속 의사의 자문에만 개인 보상을 준다는 원칙을 넣으십시오(의견).

  3. **건당·개인 보상 일변도 → 혼합형으로 전환**
     - 문제: 응급 협진의 병목은 개별 수락 건이 아니라 '응답 가능한 의사가 대기하고 있는 상태'입니다(⑩ 리스크 1순위가 인력 풀 부족). 건당 보상은 대기에 대해 아무것도 지급하지 않습니다.
     - 근거: ③은 1인당 연 약 19만 원으로 "개인 유인이 약하다"고 추론했지만, 26.3억 원은 사후 성과분(0~40%)뿐입니다. 사전 100% 지급분을 빼고 계산했으므로 1인당 금액이 과소 계산되었습니다. 사후분이 최대 40%라고 가정하면 사전분은 최소 약 65억 원입니다(산술 추론). 이 추론을 근거로 팀 정액을 폐기하는 것은 성급합니다.
     - 수정안: 세 층으로 구성할 것을 권합니다(의견).
       - (a) 온콜 명부 등록 시간에 비례하는 가용성 정액
       - (b) 소액 건당 보상
       - (c) 네트워크 단위 성과 사후 가산(0~40%)
       - 심뇌혈관 팀 구조는 유지하고 진료과만 확대합니다.

  4. **유인 왜곡 방지 장치를 구체화**
     - 문제: ⑧ '역할'의 "과다·형식적 수락 감시"와 ⑩의 "시간 기반 지표" 외에는 장치가 없습니다.
     - 수정안: 아래 다섯 가지를 지급 규칙으로 명문화하십시오.
       - 지급 시점: 버튼 클릭이 아니라 '수락 + 자문 기록 완결 + 요청자 확인'으로 정의합니다(양측 확인).
       - 전원 수용(②)의 확인: 수용 기관의 해당 환자 응급실 청구·NEDIS 내원 기록과 사후 대사가 맞을 때만 지급하고, 수락 후 미진료·수용 철회 건은 환수합니다.
       - 중복 수락 처리: 동시 수락 시 최초 1인만 인정하고, "추가정보 요청"만으로는 응답 KPI나 보상을 인정하지 않습니다.
       - 환자 선별 방지: 중증도(KTAS 등)에 따라 가중치를 두고, 거절 사유 분포를 의사별로 모니터링합니다.
       - 담합 방지: 같은 기관 내 요청·수락을 제외하고, 특정 요청자-수락자 쌍이 반복되면 감사합니다. 의사별 일·월 상한을 두고 무작위 표본 심사를 시행합니다.

  5. **해외·국내 벤치마크 오적용 정정**
     - NHS A&G £20은 **의뢰 측 GP 진료소**에 지급되는 수가입니다(노트 04). 응답 전문의 보상 근거로 쓸 수 없습니다.
     - Ontario $200/h는 비동기·선택진료, 자가 신고 시간에 비례하는 방식입니다. 야간의 동기식 응급 대기와는 기회비용 구조가 다릅니다.
     - Medicare 99451은 보고서 스스로 "유인 약함"이라고 평가한 금액이어서 "정합" 기준으로 삼으면 자기모순입니다.
     - 회송료는 회송(하향)을 수행한 기관에 지급되는 수가이므로 ②전원 수용(상향)의 보상 경로로 둘 수 없습니다.
     - 이름은 '상한'인데 실제로는 하한 수준인 기준: DMAT 40만 원/8시간은 시간당 5만 원입니다. 건당 3만~5만 원(10~15분 가정)은 시간당 12만~30만 원에 해당해 DMAT를 '상한'으로 쓴 설정과 충돌합니다(산술).
     - 수정안: 환율로 단순 환산하지 말고, 국내 상대가치(원격협의진찰료 3,280~40,770원, 진찰료, 응급 당직 보상)를 기준으로 단가를 다시 도출하십시오.

  6. **비용 추정과 재정 영향**
     - 문제 1(건수 근거): 연 응급 3,000건·읍면 5,000건은 근거가 없습니다. 참고로 상황실 경유 실패 475건이 실패율 9%라면 2025년 1~7월 전국 상황실 경유 건수는 약 5,300건으로 역산됩니다(산술).
     - 문제 2(비용 미추계): 기관 수가 확대 항목의 비용 추계가 없습니다. 원격협의진찰료의 취약지 요건 완화, 배정지원금의 "상황실 배정과 동등 인정"이 해당합니다.
     - 문제 3(중복 산정): 한 사례에서 원격협의진찰료, 배정지원금, 응급가산, 개인 활동비, 심뇌혈관 지원금이 함께 지급될 수 있는데 중복 산정 규칙이 없습니다.
     - 문제 4(알림 건수 불일치): 알림 월 100만 건 가정은 파일럿 연 8,000건 규모와 맞지 않습니다.
     - 수정안: 아래 다섯 가지를 보완하십시오.
       - 건수에 대해 기본·고·저 시나리오를 둡니다.
       - 공급자 유인 수요(건당 지급 후 건수 증가)를 반영합니다.
       - 확산 단계별 재정영향분석(BIA)을 하고, 재원 분담 주체(건보·기금·지방비)를 명시합니다.
       - 회피된 이송·재이송으로 인한 절감을 추정해 비용효과 분석 틀을 만듭니다.
       - 개발비 하한뿐 아니라 총소유비용(인프라·인증·유지관리)을 산정합니다.

  7. **성과 평가 설계**
     - 문제: KPI 사전 등록(⑨)만 있고 대조군이 없습니다. 2026~2027년에는 이송체계 혁신 시범사업 전국 확대, 개정 응급의료법의 상황실 지정권, 건정심 응급가산 200%, 심뇌혈관 본사업 전환이 동시에 진행되므로 효과를 플랫폼에 귀속시킬 수 없습니다.
     - 수정안: 아래 다섯 가지를 평가 설계에 넣으십시오.
       - 설계: 시군·병원 단위 단계적 쐐기형(stepped-wedge) 배치, 또는 매칭 비교 도와의 이중차분(DiD)
       - 1차 지표: 60분 초과 이송 비율, 재이송 건수, 내원 후 24시간 내 최종치료율
       - 균형 지표: 이송 회피 후 72시간 내 재방문·사망, 전원 후 24시간 내 퇴원(불필요 전원), 2차 전원율
       - 데이터: 플랫폼 사례 ID를 심평원 청구(특정내역 코드 부여)·NEDIS·119 구급활동일지와 연계합니다.
       - 표본: 사망률은 검정력이 부족할 것이므로 과정·중간 지표 중심으로 사전 분석계획을 세웁니다(의견).

- **누락된 사항**
  - 법정 의무와 보상의 관계: 응급의료의 거부금지 의무(조문 확인 필요)와 개정법의 상황실 지정권이 있는데 '자발적 수락'에 보상하면 법정 의무 이행에 추가로 지급하는 셈이 됩니다. 정책 정합성 논리가 없습니다.
  - 의뢰 측 보상: 의뢰 측(보건지소·현장 응급의) 보상과 노력이 다뤄지지 않았습니다. 노트 06에서도 의뢰·회송 보상 비대칭을 지적했고, 영국은 의뢰자와 응답자 보상을 분리했습니다.
  - 환자 본인부담: 신설 협진 수가의 본인부담률(회송료 0% 선례)과 환자 비용 고지가 정해지지 않았습니다.
  - 기관 수입 효과: 이송 회피로 수용 기관 수입이 줄고 의뢰 기관 수입은 유지되는 데 따른 기관 단위 유인 정렬이 다뤄지지 않았습니다.
  - 자문 의사의 법적 책임: 원격 자문 의사의 배상책임 부담을 보상 단가에 반영해야 합니다(의견).
  - 출구 전략: 파일럿 종료 후 재원 승계 주체와 일몰·편입 조건이 없습니다.

- **파일럿 착수 전 선결 조건**
  - [ ] 1년차 개인 보상 재원 확정(사업명, 금액, 집행 근거 문서)
  - [ ] 개인 지급 경로 확정: 기관 배분 의무 비율 또는 조례 직접 지급, 세무·겸직 처리 유권해석
  - [ ] 근무 중 당직의와 비번·외부 의사의 보상 구분 원칙
  - [ ] 지급 트리거·환수·상한·중증도 가중·담합 배제 규칙을 담은 지급 지침
  - [ ] 기관 수가 항목별 중복 산정 금지 규칙과 심평원 협의 결과
  - [ ] 재정영향분석(시나리오 3종)과 재원 분담 합의
  - [ ] 의료법 제27조 제3항(유인·알선) 및 응급의료 거부금지 의무와의 관계에 대한 법률 검토 회신
  - [ ] 대조군 설계, 사전 분석계획, 청구·NEDIS·119 연계 데이터 사용 승인
  - [ ] 균형(안전) 지표의 중단 기준 설정
