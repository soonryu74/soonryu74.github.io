Paperling 유튜브 콘텐츠 기획 v0.1

작성 서순려 · 2026-10-25 · 기획안: docs/ai-note-app-plan.md

원칙: 제작 과정 자체가 콘텐츠다. 낚시 없이 실제 화면으로 보여준다. 매 편 끝에 랜딩(/paperling/) 사전등록과 바이브코딩 강의 연결. 제목 금지어(기본기·총정리·사용법·기초·완벽 정리) 사용 안 함.

시리즈: “손글씨 다이어리, 사진 한 장으로 노션에 넣는 앱을 직접 만들어 봤어요”

편 제목(안) 썸네일 문구(정직 톤) 핵심 시연 강의 연결 길이
1 손글씨 메모 찍으면 노션에 자동 저장, 이거면 끝 (직접 만들었어요) “종이 다이어리 그대로 → 노션” 실제 다이어리 사진 → 정리 결과 → 노션 페이지 생성까지 1분 멀티모달 AI 호출 1회로 OCR+정리 8~10분
2 몰랐죠? 사진 속 “10/28 3시 치과”가 구글 캘린더에 알아서 들어갑니다 “날짜만 쓰면 일정 등록” 일정 추출 → “넣을까요?” 확인 → 캘린더 반영 구글 캘린더 OAuth 연동 8분
3 무료 손글씨 폰트 109종, 내 글씨랑 제일 비슷한 걸 고르는 숨겨진 방법 “나눔손글씨, 상업 이용 무료” 폰트 선택 화면, 테마 미리보기 디자인 토큰·테마 시스템 7분
4 MBTI로 다이어리 디자인 고르기? 과장 없이 해본 결과 “재미로, 진단 아님” 취향 퀴즈 60초 → 추천 3세트 온보딩 설계·설문 로직 8분
5 노션·원노트·에버노트·옵시디언 한 번에 보내는 꿀조합 “앱 안에 가두지 않습니다” 연동 체크박스 한 줄, 서랍별 보낼 곳 커넥터 규격 통일(파일 1개 추가) 9분
6 바이브코딩으로 6주 만에 만든 앱, 비용·막힌 곳 전부 공개 “숫자 그대로” AI 처리 비용, 오인식률, 수정한 프롬프트 수업 커리큘럼 안내 12분

편마다 고정 구성

  1. 0~15초: 결과 먼저. 사진 찍고 노션에 들어가는 장면.
  2. “왜 만들었나” 30초: 다이어리 유저의 불편(못 찾는다, 일정 다시 입력한다).
  3. 시연 4~6분: 실제 내 손글씨. 오인식도 숨기지 않고 고치는 장면 포함.
  4. 만드는 법 핵심 1가지 2분: 코드 전체가 아니라 “이 부분이 핵심” 한 조각.
  5. 마무리 30초: 사전등록 링크, 강의 안내. 과장 문구 없이.

숏츠 (각 편에서 3개씩)

  • “종이에 쓰고 → 찍고 → 노션” 15초 무편집 컷
  • 오인식 고치는 장면 “AI도 틀려요, 그래서 확인 단계가 있어요”
  • 테마 바꾸는 장면 4연속

썸네일 규칙

  • 실제 화면 캡처 + 손글씨 사진. 합성·과장 금지.
  • 문구는 7자 이내 1줄. 느낌표 1개 이하.
  • 얼굴 표정은 놀람 과장 대신 “보여드릴게요” 톤.

지표

  • 편당 사전등록 유입(링크에 ?src=yt1 형식 파라미터, 랜딩 폼의 source 컬럼에 저장됨)
  • 강의 페이지 클릭률
  • 댓글 중 “나도 만들어보고 싶다” 비율

전자책 소재 표시

  • 2편의 일정 추출 흐름과 4편의 “MBTI를 정직하게 쓰는 법”은 전자책에!
