### 사례 A (1~7회차 관통)

박○○ 어르신, 78세, 여성. 뇌경색으로 협약병원에 3주 입원 후 퇴원 예정. 오른쪽 팔다리 힘이 약해져 혼자 걷기 불안. 아파트 3층(엘리베이터 없음). 남편 사별, 혼자 거주. 딸이 차로 40분 거리, 주 1회 방문. 고혈압·당뇨 약 복용 중. "집에 가고 싶다, 딸한테 짐 되기 싫다"가 본인 말. 장기요양 등급 없음. 경제: 기초연금 + 딸 지원.
※ 가상 사례. 실제 인물과 무관. 회차마다 정보가 한 겹씩 더 드러난다.

### 사례 B (8회차 혼자 완주용)

김○○ 어르신, 83세, 남성. 낙상으로 고관절 골절 수술 후 재활병원 거쳐 퇴원. 아내(80세)와 둘이 거주, 아내도 무릎이 안 좋음. 아들은 타 지역. 단독주택, 화장실이 마당 건너. 장기요양 3등급. "다시 넘어질까 무섭다"가 본인 말.

## 1회차 · 의뢰가 왔다 (접수·상담)

**목적** 협약병원에서 퇴원 예정 어르신의 의뢰가 왔을 때, 첫 통화와 첫 방문에서 무엇을 묻고 무엇을 적는지 안다. 8회차 전체가 어디를 도는지 지도를 갖는다.

**습득목표**
1. 통합돌봄 절차 8단계를 순서대로 말할 수 있다.
2. 의뢰가 들어오는 경로 네 가지(본인 신청·발굴·협약병원 퇴원 통보·기관 의뢰)를 구별한다.
3. 첫 통화에서 주호소·긴급성·동석자·방문 장소를 확인한다.
4. 인테이크 기록 한 장을 빈칸 없이 채운다.
5. "계약"이 아니라 "신청·동의·권리 안내"임을 설명한다.

**내용 · 60분**
- 도입 5분 — S1 절차 대조표. 의뢰→사정→욕구→계획→회의→연계→점검→종합. 8회차가 이 순서 그대로임을 보여준다. 일본 케어매니지먼트 프로세스와 같은 골격, 단계 이름만 한국 절차.
- 10분 — 의뢰가 들어오는 네 경로. 협약병원 퇴원 통보(통보 의무·동의 절차), 읍면동 발굴, 본인·가족 신청(별지 제1호), 노인맞춤돌봄·응급안전안심 등 기관 의뢰. 사례 A는 협약병원 통보.
- 15분 — 첫 통화 6가지. ① 누가 의뢰했고 본인은 아는가 ② 주호소 — 본인 말 그대로 ③ 긴급성 — 오늘 안에 움직여야 하나(퇴원일, 혼자 있는 시간, 식사) ④ 상담 수단 — 전화·방문·내방 중 무엇이 맞나 ⑤ 첫 방문 장소·동석자(딸 동석?) ⑥ 미리 확인할 것(퇴원 예정일, 약, 집 구조).
- 10분 — 신청·동의·권리 안내. 개인정보 수집·이용·제3자 제공 동의(문서로), 서비스 제공기관 선택권, 거부권, 이의신청 창구. 일본의 "계약" 단원을 한국에서는 이것으로 대체한다는 설명 1분.
- 15분 — 인테이크 기록 작성(사례 A). 의뢰 경로 / 주호소(본인 말) / 긴급성 판단과 근거 / 동석자·장소 / 미리 확인한 것 / 다음 행동.
- 마무리 5분 — 2회차 예고: 첫 방문에서 무엇을 묻나.

**진행** 녹화 강의. 첫 통화 장면은 음성 재연(대표 1인 2역). 서식은 화면에 띄워 함께 채운다.

**산출물** 인테이크 기록 1장(사례 A).

**부록 서식**
- S1 절차 대조표: [한국 절차 단계 | 우리 회차 | 그 단계에서 남는 서식 | (참고) 일본 단계명]
- S13-① 인테이크 기록: 의뢰 경로 / 의뢰자·연락처 / 본인 인지 여부 / 주호소(본인 말) / 긴급성(상·중·하 + 근거) / 상담 수단 / 첫 방문 일시·장소·동석자 / 사전 확인 항목 / 동의 확인(수집·제공) / 다음 행동 / 작성자·일자

**일본 근거** 과목 6(프로세스 전체상), 과목 7(인테이크·주호소·긴급성·상담 수단·사전 준비). 계약 부분 불채택.

## 2회차 · 이 사람의 지금을 적는다 (포괄적 사정)

**목적** 사전조사 8항목을 같은 사례에 실제로 채운다. 몸·마음·환경을 나누어 묻는 틀을 갖는다.

**습득목표**
1. 사전조사 8항목을 사정 영역(기본정보·건강·ADL/IADL·인지·가족·주거·경제·의향)에 대응시킨다.
2. 몸·마음·환경(ICF)을 나누어 묻고 적는다.
3. 통원처·복약 목록·단골 약국을 사정 때 확인한다.
4. 의료 정보는 "판단"이 아니라 "사정에 잇는 것"임을 안다.
5. 강점(본인이 할 수 있는 것, 가진 관계)을 반드시 적는다.

**내용 · 60분**
- 도입 5분 — 사정은 한 번이 아니다. 인테이크에서 시작해 점검 때까지 이어진다(단계적 진전).
- 10분 — S2 매핑표. 사전조사 8항목이 어느 영역에 해당하는지. 빠지기 쉬운 영역: 경제, 의향, 강점.
- 10분 — 몸·마음·환경 틀. 같은 "걷기 불안"도 몸(힘), 마음(무서움), 환경(3층 계단) 중 어디가 막는지 갈라 적는다. 촉진 요인·저해 요인 한 줄씩.
- 10분 — 의료 정보 다루기. 퇴원 요약·처방전을 받아 "무슨 병, 어느 병원, 무슨 약, 언제 외래"를 적는다. 해석하지 않는다. 모르는 단어는 협약병원 담당자·방문간호에 묻는다. 통원처·복약 목록·단골 약국 칸.
- 20분 — 사정표 작성(사례 A, 첫 방문 장면 재연). 딸이 대신 말할 때 "본인 말"과 "가족 말"을 구분해 적는 법.
- 마무리 5분 — 3회차 예고.

**진행** 첫 방문 장면 음성 재연. 사정표는 항목별로 멈추며 함께 채움.

**산출물** 채워진 사정표 1장.

**부록 서식**
- S2 사정 영역 매핑표: [사전조사 항목 | 사정 영역 | 반드시 물을 것 | 흔히 빠지는 것]
- S13-② 사정표: 기본정보 / 건강(진단명·통원처·복약·단골약국·최근 입원) / 몸(ADL) / 생활(IADL) / 인지·정서 / 가족·관계 / 주거·환경 / 경제 / 본인 의향(본인 말) / 가족 의향 / 강점 / 촉진·저해 요인 / 확인 필요(누구에게)

**일본 근거** 과목 8(사정 항목·정보수집·ICF·강점·다직종 정보), 과목 2(ICF), 과목 25(통원처·복약 확인). 과제분석 표준항목 23은 영역 구조만 채택.

## 3회차 · 욕구를 문장으로 (욕구 파악)

**목적** 사정표에서 "이 사람이 원하는 삶"과 "막고 있는 것"을 세 줄로 뽑고, 목표를 측정 가능하게 쓴다.

**습득목표**
1. 현상 → 요인 → 앞으로의 전망 → 과제 순서로 니즈를 정리한다.
2. 과제를 이용자를 주어로 쓴다("어르신이 ~할 수 있다").
3. 우선순위를 본인과 합의한다.
4. 목표를 측정 가능하게 쓴다(무엇을·언제까지·어느 정도).
5. 강점을 목표에 연결한다.

**내용 · 60분**
- 도입 5분 — 사정표는 정보, 계획서는 서비스. 그 사이를 잇는 것이 니즈 정리. 한국 서식에는 이 칸이 없어서 사람마다 다르게 쓴다 → 우리는 S3로 한다.
- 15분 — S3 니즈 정리표 채우기(사례 A). 현상: 혼자 계단 못 내려감 / 요인: 오른쪽 힘 약함 + 3층 + 무서움 / 전망: 나가지 못하면 근력 더 떨어짐, 딸 부담 증가 / 과제: "어르신이 주 2회 밖에 나갈 수 있다".
- 10분 — 이용자 주어 문장. "방문요양 주 3회 필요" ✗ → "어르신이 낮에 혼자 식사를 차릴 수 있다" ○. 서비스는 계획서에서.
- 10분 — 우선순위 합의. 본인이 1순위로 꼽는 것과 실무자가 보는 위험이 다를 때 — 둘 다 적고, 본인 것을 먼저. 긴급한 위험은 설명하고 합의.
- 15분 — 측정 가능한 목표 3개 쓰기. 장기(3개월)·단기(1개월) 두 층.
- 마무리 5분 — 4회차 예고.

**진행** 녹화 강의 + 화면 작성. "틀린 예 → 고친 예" 대비 5쌍.

**산출물** 니즈 정리표 1장(욕구·목표 세 줄).

**부록 서식**
- S3 니즈 정리표: [영역 | 현상(사정표에서) | 요인(몸·마음·환경) | 이대로면(전망) | 과제(이용자 주어) | 본인 우선순위 | 실무자 우선순위 | 강점 활용 | 목표(장기/단기·측정)]

**일본 근거** 과목 8(니즈 도출 사고과정·우선순위·유지개선악화 예측·이용자 주체 표기), 과제정리총괄표의 사고 틀. 예후 판단은 "다직종 의견 반영"으로 한정.

## 4회차 · 계획서를 채운다 (케어플랜 작성)

**목적** 별지 제2호 개인별지원계획서를 같은 사례로 채운다. 서비스마다 고른 이유를 적는다.

**습득목표**
1. 계획서 각 란의 기재 목적을 말한다.
2. 종합 원조 방침을 한 줄로 쓴다.
3. 장기·단기 목표와 기간을 적는다.
4. 서비스마다 "왜 이것인가"를 사정 근거와 연결해 적는다.
5. 설명하고 동의를 받는다 — 동의와 합의는 다르다.

**내용 · 60분**
- 도입 5분 — 계획서는 시군구가 확정하지만 초안은 우리가 쓴다. 초안의 질이 회의의 질.
- 10분 — S4 란별 기재 목적. 본인 의향 란(본인 말 그대로), 종합 방침(팀이 공유할 한 문장), 목표, 서비스·제공기관·빈도·기간, 긴급 연락.
- 10분 — 종합 원조 방침. "집에서 계속 살면서 주 2회 밖에 나가고, 딸의 부담은 주 1회 방문 수준을 넘지 않게" — 팀 전체가 같은 방향을 보게 하는 문장. 해결 못 하는 과제도 적는다.
- 15분 — 서비스 고르기와 "왜". 서비스 분류표에서 고르되 각 줄에 근거(사정표 어느 항목). 공식 자원 + 비공식 자원(딸, 이웃, 경로당) + 본인 내적 자원. 기간 설정(단기 목표에 맞춤). 종결 목표 한 줄.
- 10분 — 설명과 동의. 이해도에 맞춘 설명(쉬운 말, 한 번에 하나). 동의(서명)와 합의(같은 그림)의 차이. 강압·유도 금지. 본인이 거부하면 — 이유를 적고, 대안을 적고, 다시 온다.
- 10분 — 계획서 초안 작성(사례 A).

**진행** 녹화 강의 + 화면 작성. 별지 제2호 실제 서식 사용.

**산출물** 개인별지원계획서 초안 1부.

**부록 서식**
- S4 계획서 란별 기재 목적표: [란 이름 | 이 란의 목적 | 잘 쓴 예 | 흔한 실수] + 장기·단기 목표 예시 6개 + 종결 목표 예시 3개
- S13-③ 계획서 초안(별지 제2호 양식 + 각 서비스 옆 "근거" 칸 추가)

**일본 근거** 과목 9(서식 각 란 목적·종합 원조 방침·장단기 목표·기간·개별서비스계획 연동·공식/비공식 자원), 과목 5(설명·동의와 합의·강압 금지·비동의 대응). 개호예방 서식 불채택.

## 5회차 · 회의에서 내 몫 3분 (다직종 협력)

**목적** 통합지원회의의 구성과 흐름을 알고, 우리 기관 몫을 3분 발언으로 쓴다.

**습득목표**
1. 회의 개최 사유 다섯 가지를 안다(신규·재판정·퇴원 통보·상황 급변·지원 곤란).
2. 회의 전·중·후에 할 일을 체크리스트로 안다.
3. 우리 계획서 초안과 각 기관 급여제공계획이 맞는지 한 문장으로 확인한다.
4. 3분 발언을 사정 근거 → 제안 → 부탁 순서로 쓴다.
5. 금지 표현을 피한다.

**내용 · 60분**
- 도입 5분 — 회의는 시군구가 주재한다. 우리는 참여자. 참여자의 일은 "준비해 오고, 짧게 말하고, 받아 적고, 돌아가서 한다".
- 10분 — S5 회의 체크. 사유별 준비물. 전: 정보 제공 동의 확인, 계획서 초안, 물을 것 목록. 중: 3분 발언, 다른 기관 몫 받아 적기, 정합 확인. 후: 남은 과제, 자료 회수·폐기, 우리 기록.
- 10분 — 정합 확인 한 문장. "우리 방문요양 주 3회 오전이 계획서 단기목표 ○과 맞습니까?" 계획서-급여제공계획이 어긋나면 회의에서 잡는다.
- 15분 — 3분 발언 구조. ① 우리가 본 것(사정 근거 2개) ② 우리가 제안하는 것(서비스·빈도·이유) ③ 다른 기관에 부탁하는 것 ④ 확인하고 싶은 것. 금지 표현: "당연히", "원래", "그건 저희 일 아닌데", 진단하는 말.
- 15분 — 발언 대본 작성(사례 A) + 온라인 회의일 때 다른 점(카메라·자료 공유·기록).
- 마무리 5분 — 6회차 예고.

**진행** 녹화 강의 + 모의 회의 음성(3인 역할). 대본은 화면에서 함께 작성.

**산출물** 발언 대본 1장.

**부록 서식**
- S5 통합지원회의 체크: [개최 사유 | 우리가 준비할 것] + [전 / 중 / 후 체크 12항목] + [정합 확인 문장 틀] + [금지 표현 10개]
- S13-④ 회의 메모: 참석 기관 / 결정 사항 / 우리 몫 / 다른 기관 몫 / 남은 과제 / 다음 회의 / 자료 처리

**일본 근거** 과목 10(회의 의의·개최 사유·전중후·정합성·자료 회수·온라인), 과목 5(다직종 합의·장면별 설명). "주재" 관점은 "참여" 관점으로 재구성.

## 6회차 · 누구에게 무엇을 의뢰하나 (자원연계)

**목적** 계획서의 서비스마다 실제 의뢰처·서식·함께 넣을 수 없는 조합을 정리한다. 내 지역 자원 지도를 만든다.

**습득목표**
1. 계획서의 서비스 하나하나에 의뢰처·서식·담당자를 적는다.
2. 공식·비공식·본인 내적 자원 세 갈래를 구별한다.
3. 함께 넣을 수 없는 조합(유사중복)을 확인한다.
4. 우리 시군구의 통합돌봄지원센터·협약병원·재가기관 세 곳 이상을 찾아 자원 지도에 적는다.

**내용 · 60분**
- 도입 5분 — 계획서는 종이, 연계는 전화와 서식. 의뢰가 안 가면 계획은 없는 것.
- 15분 — 연계표 만들기(사례 A). 서비스 | 의뢰처 | 서식 | 담당자·연락처 | 언제까지 | 확인 방법. 방문간호는 방문간호지시서가 먼저, 장기요양은 등급 신청이 먼저 — 순서가 있는 것들.
- 10분 — 세 갈래 자원. 공식(장기요양·재택의료센터·방문진료·보건소·치매안심센터·노인맞춤돌봄·긴급돌봄·응급안전안심), 비공식(딸·이웃·경로당·종교·자원봉사), 본인 내적 자원(할 수 있는 것, 하고 싶은 것). 계획서에 비공식 자원이 없으면 다시 본다.
- 10분 — 유사중복. 노인맞춤돌봄 ↔ 장기요양 등급자, 긴급돌봄 ↔ 장기요양 급여, 응급안전안심 조건. "안 되는 조합" 표.
- 15분 — S12 자원 지도 과제 안내. 우리 시군구에서: 통합돌봄지원센터(전담조직), 협약병원, 재가기관 3곳 이상, 방문진료·재택의료센터 유무, 치매안심센터, 노인맞춤돌봄 수행기관. 공식 정보(누리집·복지로)만, 후기 금지.
- 마무리 5분 — 7회차 예고.

**진행** 녹화 강의 + 화면 작성. 자원 지도는 수강생 각자 지역으로 — 제출만.

**산출물** 연계표 1장 + 자원 지도 1장(과제).

**부록 서식**
- S13-⑤ 연계표: [서비스 | 의뢰처 | 서식 | 담당자·연락처 | 선행 절차 | 기한 | 확인 방법 | 결과]
- S12 자원 지도 양식: [구분(공식·비공식) | 기관·자원명 | 무엇을 하나 | 대상 조건 | 연락처 | 의뢰 서식 | 확인일] — 한국 직종·기관 목록 예시 첨부
- 유사중복 표: [조합 | 되나 | 조건]

**일본 근거** 과목 13(사회자원 종류·조사), 과목 9(공식/비공식/내적 자원), 과목 12(연락처·경로 명확화). 일본 기관 목록은 전부 한국판으로.

## 7회차 · 한 달 뒤 무엇을 보나 (모니터링·평가)

**목적** 모니터링 방문에서 확인할 것, 바뀌었을 때 계획을 고치는 기준, 기록 방식을 안다.

**습득목표**
1. 모니터링 확인 5항목을 순서대로 본다.
2. 방문·전화·온라인·회의 네 수법을 상황에 맞게 고른다.
3. 재사정이 필요한 변화를 알아본다.
4. 악화 신호를 보면 누구에게 언제 알리는지 안다.
5. 종결 장면 다섯 가지와 종결 시 평가를 안다.

**내용 · 60분**
- 도입 5분 — 계획서를 만들고 한 달. 계획대로 됐는지가 아니라 사람이 어떤지.
- 10분 — S6 확인 5항목. ① 계획대로 제공되고 있나 ② 내용이 지금도 적절한가 ③ 목표에 다가가고 있나 ④ 종합 방침에 맞나 ⑤ 계획을 고쳐야 하나. 본인·가족 쪽에서 보는 모니터링(생활 전체, 가족관계 변화).
- 5분 — 수법 4종. 방문이 기본, 전화·온라인은 보조, 회의는 여러 기관이 얽혔을 때.
- 10분 — 재사정 기준. 입원·낙상·가족 변화·서비스 거부·본인 의향 변화. 바뀌면 2~4회차로 돌아간다.
- 10분 — S9 악화 신호 보고표(요약판). "이것을 보면 → 누구에게 → 언제". 판단하지 않고 보고한다. 야간·주말 연락처.
- 10분 — 종결. 장면: 지원 불필요·입원/입소·타 지역 전출·본인 거부·사망. 종결 시 평가: 바라던 생활에 비추어 무엇이 됐고 무엇이 안 됐나. 재신청 조건.
- 10분 — 모니터링 기록 작성(사례 A, 한 달 뒤 장면). "판단이 드러나는 기록" — 본 것 / 판단 / 다음 행동.

**진행** 녹화 강의 + 한 달 뒤 방문 장면 음성 재연 + 화면 작성.

**산출물** 모니터링 기록 1장.

**부록 서식**
- S6 모니터링 확인표: [5항목 | 확인 방법 | 본 것 | 판단 | 다음 행동] + [재사정 기준 목록] + [종결 장면·종결 시 평가 칸]
- S9 악화 신호 보고표(요약): [보이는 것 | 누구에게 | 언제(즉시/당일/다음 방문) | 기록]
- S13-⑥ 모니터링 기록: 일시·수법 / 5항목 확인 / 변화 / 재사정 필요 여부 / 보고 사항 / 다음 행동

**일본 근거** 과목 11(확인 항목·수법·재사정·기록·종결 장면·종결 시 평가), 과목 25(관찰→보고). 평가표는 S6로 대체. 월 1회 방문 의무는 한국에 없음 — 권고로.

## 8회차 · 처음부터 끝까지 혼자 (종합연습)

**목적** 새 사례 B를 1~7회차 서식으로 혼자 완주한다. 서로 검토한다.

**습득목표**
1. 사례 B로 인테이크 → 사정 → 니즈 → 계획 → 발언 → 연계 → 모니터링 서식 7종을 혼자 채운다.
2. 비식별화 원칙을 지킨다.
3. 동료 사례 두 건에 서면 의견을 쓴다.
4. 수강 전 목표와 비교해 자기 과제를 적는다.

**내용 · 60분**
- 도입 5분 — 사례 B 소개. 사례 A와 다른 점(부부, 골절, 등급 있음, 단독주택).
- 5분 — S13 비식별화 체크리스트. 실제 사례를 쓰고 싶으면: 이름·주소·생년월일·기관명 삭제, 나이는 연령대, 소속 기관 동의. 어기면 본인 책임.
- 40분 — 혼자 작성(녹화는 여기서 멈춤 / 실시간 수업이면 작성 시간). 서식 7종. 막히면 1~7회차 해당 부분으로.
- 10분 — 상호 검토 안내. 동료 사례 2건에 "잘 된 것 1, 빠진 것 1, 나라면 1" 세 줄. 실시간 수업이면 소그룹, 아니면 게시판. 자기점검: 수강 전 목표 / 지금 할 수 있는 것 / 아직 못 하는 것 / 다음에 배울 것.

**진행** 실시간 수업 권장(60분). 녹화 수강자는 작성 후 게시판 제출 + 튜터 서면 피드백.

**산출물** 사례 파일 한 벌(서식 7종) + 동료 의견 2건 + 자기점검표.

**부록 서식**
- S13 사례 파일 서식 5종(①인테이크 ②사정표 ③계획서 초안 ④회의 메모 ⑤모니터링 기록) + S3 니즈 정리표 + 연계표 = 7종 한 벌
- S13 비식별화 체크리스트: 10항목 + 서약란
- 자기점검표(S14 축약판): 수강 전 목표 / 할 수 있게 된 것 / 못 하는 것 / 다음 학습

**일본 근거** 과목 28(종합연습·서식 기입·되돌아보기), 과목 16·17(실습 → 사례 파일 대체, 비식별화·비밀유지), 과목 18(상호 검토·언어화), 과목 29(수강 전 목표 대비 자기평가).
