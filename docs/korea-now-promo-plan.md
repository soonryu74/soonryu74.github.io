## 결론

1인 사업자가 외국인 관광객에게 **직접** 닿는 홍보는 대부분 실패합니다. 영어 커뮤니티, 중국어
샤오홍슈, 일본어 X를 한 사람이 동시에 지속할 수 없기 때문입니다.

대신 **남이 만들어 놓은 유통망에 올라타는 길**이 세 개 있고 전부 0원입니다.

1. 관광지 55곳을 각각 검색되게 만들기
2. 관광데이터 활용 공모전 출품 — **이 앱은 이미 자격을 갖췄습니다**
3. VISITKOREA 얼라이언스 신청 — 8개 국어 번역·감수 무상

## 2. 우선순위

### 1군 · 지금 바로 (0원 · 복리 · 대표님이 잘하는 형태)

**1. 관광지 55곳 검색 노출** — 구글은 JS를 실행해 색인하지만 공식 문서에 지연이 명시돼 있고,
`#` 뒤쪽은 별개 페이지로 세지 않습니다. 수요 근거로 영문 위키백과 조회수를 집계했습니다
(제주 월 3.2만, 경복궁 월 1.7만, 남산타워 4,200, 북촌 3,400). 공수 1~2일.

**2. 관광데이터 활용 공모전** — 필수 조건이 관광공사 OpenAPI 활용인데 이미 쓰고 있어 추가 개발
불필요. 대상 1,000만 원(문체부 장관상), 시상 22팀, 국내 거주자 개인도 가능. 수상 시 정부
보도자료 노출이 상금보다 큽니다. **접수 일정은 출처 간 상충 → 공식 공고 확인 필요.**

**3. VISITKOREA 얼라이언스** — 매년 2월 15개사 내외 선발. VK 연 방문 3,300만 명, SNS 팔로워
370만, **회원사 서비스 8개 국어 번역·감수 무상**. 자격은 "민간 플랫폼, 이종산업 등 다양한 분야".
접수는 투어라즈(touraz.kr). 비용 0원.

### 2군 · 정비 뒤 (0원이지만 사람 손)

**4. 구글 플레이 등재** — 등록비 $25 1회. TWA는 본인 도메인이면 정책 위반 아님(구글 공식 경로).
병목은 **2023-11-13 이후 개인 계정의 테스터 12명 × 14일 연속** 요건. 중간 이탈 시 리셋.
다만 구독자 1만 명이 있으니 12명 모으는 건 영상 하나. 단체 계정 면제 여부는 미확인.

**5. r/koreatravel** — 구독자 22.7만. **위키가 이미 "쓸 만한 사이트와 앱" 목록을 운영**(카카오맵·
네이버지도·1330 앱 등재) → 도구 공유가 규범에 맞음. 광고 글이 아니라 질문 답변으로 접근.

### 3군 · 여력이 생기면

**6. 관광벤처사업 초기부문** — 업력 3년 이내, 직전 회차 4,000만~8,000만 원. 홍보비 직접 지원.

**7. 게스트하우스 QR** — 정상 영업 외국인관광도시민박업 6,134곳(서울 3,869곳)의 주소·좌표가
localdata.go.kr에 무료 공개. 명단을 코드로 뽑아 홍대·명동·종로만 추려 발송하면 1인 규모.

**8. 국가별 플랫폼 한 개만** — 관광공사가 "국가별 해외여행 활용 SNS" 공공데이터를 공개
(data.go.kr/data/15149395). 그걸 받아 한 나라 한 채널만 선택.

### 하지 말 것

- **애플 앱스토어** — 심사 규정 4.2.2가 웹사이트 래핑을 명시적으로 거부. $99/년 + Mac 필요
- **r/Living_in_Korea** — 규칙 원문에 "Avoid self-serving posts", "Bans: spammers, solicitors,
  and self-interested shills", "댓글 홍보 엄격 금지" 명시
- **유료 광고** — 전환율을 모르는 상태에서는 그냥 소멸. 측정부터
- **Product Hunt** — 개발자·창업자 대상이라 타깃 불일치. 백링크 값어치 정도

## 4. 대표님 유튜브는 홍보 채널이 아니다

구독자 1만 명은 한국어를 쓰는 30~60대이고 앱 사용자는 한국에 오는 외국인입니다. 겹치지 않습니다.
대신 채널은 두 가지를 하고, 둘 다 사용자 확보보다 돈이 됩니다.

- **테스터 12명** — 플레이 등재를 막는 유일한 병목을 하루면 해결. 그 과정이 영상 한 편
- **강의 상품** — 공공 API 붙이고, 공모전 내고, 스토어 올리는 전 과정이 바이브코딩 강의의 마지막 장

## 5. 첫 90일

| 순서 | 할 일 | 공수 |
|---:|---|---|
| 1 | 측정 붙이기 + robots.txt + 사이트맵을 이 앱 것으로 | 2일 |
| 2 | 관광지 55곳 검색 노출 | 1~2일 |
| 3 | 투어라즈 회원가입 + 공모전·얼라이언스 공고 확인 | 즉시 |
| 4 | 구독자로 테스터 12명 모아 플레이 등재 | $25 + 14일 |
| 5 | r/koreatravel 질문 답변 (주 2~3회) | 꾸준함 |
| 6 | 서울 게스트하우스 명단 뽑아 QR 발송 | 인쇄·우편비 |

1·2번은 홍보가 아니라 정비입니다. 3번부터가 진짜 홍보인데 그중 둘은 **신청서를 쓰는 일**입니다.

## 6. 확인이 더 필요한 것

- 관광데이터 공모전 **접수 일정** (출처 간 상충)
- 구글 플레이 **단체 계정 면제 여부**와 D-U-N-S 요건
- 외래관광객조사 **여행정보 획득 경로** 비율 (보고서 원문 열람 필요)
- 영문 키워드 **절대 검색량** (공개 자료 없음 → 위키백과 조회수로 대체)
- 페이스북 한국여행 그룹의 정확한 규모·규칙 (로그인 필요)
