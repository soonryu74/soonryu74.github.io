# 1단계 — 내 책 10부 찍기

> 작성 2026-10-11 · 한뼘(HANDSPAN) 기획안 §16 '다음 행동' 1단계 · 도구: `handspan/tools/a6-print/`

출판·유통·사업을 몰라도 됩니다. 이 단계에서 필요한 건 원고 하나와 2만 원입니다.
끝나면 손에 A6(105×148mm) 책 10권이 있고, 그걸로 한뼘의 첫 상품 사진과 첫 판매 경험이 생깁니다.

## 0. 비용·시간

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 인쇄 10권(64쪽 흑백 무선) | 14,500 + 부가세 1,450 + 배송 3,500 = **19,450원** | 레드프린팅 실측 2026-10-10 (`docs/handspan-unit-cost.md` §1.1) |
| 20쪽이면 | 약 4,000~6,000원대 | 장수 비례, 주문 화면 공급가 확인 |
| 출고 | 결제 후 2영업일 | 레드프린팅 안내 |
| 내 시간 | 원고 고르기 1시간, 조판 30분, 주문 20분 | 추정 |

## 1. 책 고르기

세 가지만 맞으면 됩니다.
- **이미 쓴 글**이어야 합니다. 새로 쓰지 않습니다.
- **한 주제**여야 합니다. 글 10~20편이 한 제목 아래 묶여야 합니다.
- 분량은 **1만~1만 3천 자**면 64쪽, 3천 자면 20쪽(최소)입니다. A6 한 쪽에 약 200자가 들어갑니다.

첫 책으로는 이 저장소의 읽는 이북 『콘텐츠 자동화의 정석』(`ebook-automation.html`)을 추천합니다. 이미 장·절 구조가 있고, 샘플로 변환해 두었습니다(`handspan/tools/a6-print/sample/`). 2,700자라 20쪽 책이 됩니다. 64쪽을 채우려면 4개 장에 절을 2~3개씩 더하면 됩니다.

## 2. 원고 만들기 — 마크다운 한 파일

메모장·구글 문서·클로드 어디서든 됩니다. 규칙은 넷뿐입니다.

```
---
title: 콘텐츠 자동화의 정석
subtitle: 유튜브·블로그를 코드로 짓는 콘텐츠 공장
author: 노모어매뉴얼 서순려
---

# 플랫폼의 본질            ← 장 (오른쪽 페이지에서 새로 시작)
*알고리즘을 이기려 하지 말고, 성질을 안다*   ← 장 부제

## 쇼트폼은 멋이다          ← 절
본문 문단. 빈 줄로 문단을 나눕니다.

> 메모나 인용은 이렇게
```

클로드에게 글을 붙여 넣고 이렇게 부탁하면 됩니다.
"이 글들을 위 형식의 마크다운 원고로 묶어 주세요. 글은 한 글자도 고치지 말고, 장·절 제목만 붙여 주세요."

## 3. 인쇄 PDF 만들기 — 두 길 중 하나

### 길 A. 터미널 없이 (구글 문서)

레드프린팅 규격은 "재단 크기보다 가로·세로 10mm 큰 낱장 PDF"입니다. 구글 문서로 바로 맞출 수 있습니다.

| 순서 | 할 일 | 값 |
| --- | --- | --- |
| 1 | 파일 → 페이지 설정 → 페이지 크기 **사용자 지정** | 가로 **11.5cm**, 세로 **15.8cm** |
| 2 | 여백 | 위 1.8 / 아래 2.0 / 왼쪽 1.7 / 오른쪽 1.7cm |
| 3 | 글꼴·크기·줄간격 | Noto Serif KR 또는 나눔명조, 10.5pt, 줄간격 1.7 |
| 4 | 삽입 → 페이지 번호 → 아래 가운데 | — |
| 5 | 장 제목 앞에 **페이지 나누기** | 윈도우 `Ctrl+Enter` / 맥 `⌘+Enter` |
| 6 | 파일 → 다운로드 → **PDF** | 쪽수가 4의 배수인지, 20쪽 이상인지 확인 |

표지는 캔바(Canva)에서 **사용자 지정 크기 22.2×15.8cm**(20쪽, 책등 2mm 기준)로 만듭니다. 64쪽이면 책등 3.5mm → 22.4cm. 왼쪽 절반이 뒷표지, 가운데 띠가 책등, 오른쪽이 앞표지입니다. 가장자리 5mm는 잘려 나가니 글자를 넣지 않습니다. PDF(인쇄)로 내려받습니다.

### 길 B. 도구로 한 번에 (내지 + 표지 + 주문값)

`handspan/tools/a6-print/` 폴더를 내려받아 원고 옆에 둡니다. 처음 한 번만 설치합니다.

| | 윈도우 (PowerShell) | 맥 (터미널) |
| --- | --- | --- |
| 노드(Node.js) 설치 | `winget install OpenJS.NodeJS.LTS` | `brew install node` |
| 팬독(pandoc) 설치 (표·목록용, 선택) | `winget install JohnMacFarlane.Pandoc` | `brew install pandoc` |
| 폴더로 이동 | `cd $HOME\Downloads\a6-print` | `cd ~/Downloads/a6-print` |
| 라이브러리 설치 | `npm install` | `npm install` |
| 브라우저 설치(PDF 그리기용) | `npx playwright install chromium` | `npx playwright install chromium` |
| **책 만들기** | `node make-minibook.mjs 원고.md` | `node make-minibook.mjs 원고.md` |

`원고-print` 폴더에 `내지.pdf`, `표지.pdf`, `주문입력값.txt`가 생깁니다. 표지 색을 바꾸려면 `--color "#8a3b2a"`, 본문 글자를 키우려면 `--font 11`을 뒤에 붙입니다.

## 4. 검수 — 올리기 전 3가지

| 확인 | 어떻게 | 기준 |
| --- | --- | --- |
| 쪽수 | PDF 열어 마지막 쪽 번호 | 4의 배수, 20쪽 이상 |
| 크기 | 윈도우 Adobe Reader `Ctrl+D` / 맥 미리보기 `⌘+I` | 내지 115×158mm, 표지 가로 = 222mm + (책등−2mm) |
| 잘림 | 가장자리 5mm 안에 글자가 없는지 | 본문은 재단선에서 11mm 이상 안쪽 |

## 5. 레드프린팅 주문 입력값

메뉴: 책자 → **[토너] 무선 책자 (흑백)** (상품코드 PRBKOPB). '독립출판/개인 책자' 메뉴는 같은 책이 권당 1만 원대이니 고르지 않습니다.

| 항목 | 입력 |
| --- | --- |
| 규격 | 무선책자(A6세로형) 105×148 |
| 표지 | 아트지 250g, 컬러 단면, **무광코팅 단면**(코팅 필수) |
| 내지 | 백색모조 100g, 양면, 흑백 |
| 내지 장수 | 쪽수 ÷ 2 (64쪽 → 32장) |
| 제본 | 무선, 좌철(세로형) |
| 수량 | 10 |
| 파일 | 표지.pdf 1페이지, 내지.pdf 낱장 |
| 확인 | 화면의 '세네카'(책등) 값이 표지 책등과 같은지. 다르면 `--spine 값`으로 표지만 다시 생성 |

## 6. 받고 나서 — 한뼘의 첫 상품으로

1. **자와 함께 사진**을 찍습니다. 한뼘 상품 사진 규칙(자 동봉)이 여기서 시작됩니다.
2. 손에 올린 사진, 펼친 사진, A5 책 옆에 둔 비교 사진 — 유튜브 1편 B롤입니다.
3. 3권은 지인에게 **9,000원에 팝니다.** 입금·포장·준등기(1,800원) 발송까지 직접 해 봅니다. 이것이 유통의 전부입니다.
4. 1권은 보관, 나머지는 두 번째 작가 후보(수강생·구독자)에게 견본으로 보냅니다.
5. 영수증·운송장을 모아 둡니다. 2단계(사업자·통신판매업 신고) 때 그대로 비용 처리됩니다.

여기까지 하면 "출판을 모른다"는 말은 더 이상 맞지 않습니다. 원고 → 조판 → 인쇄 → 포장 → 발송 → 입금을 한 번 다 해 본 사람이 됩니다. 이 부분은 전자책에: "책 한 권은 2만 원과 하루면 됩니다."
