# 한뼘(HANDSPAN) — 작은 책만 파는 곳 기획안 v0.2

> 작성 서순려 · 2026-10-10 · 브랜치 `ccr-6f7d4cfd-9shv27`
> 근거 자료: `docs/minibook-market-review.md` (한국·일본·세계 시장 검토, 출처 링크 포함)

**한 뼘 안에 들어오는 책만 팝니다.**

세상에 미니북 전용 마켓은 없다. 작가들은 서점 46곳에 메일을 보내 9곳에 입고하고 1권을 정산받는다.
우리는 작은 책 하나를 위해 생긴 자리에, 고정비 없이, 정산을 숨기지 않고, 고르는 재미를 판다.

## 1. 요약

- **시장 규모 통계는 어디에도 없다.** 대신 수요 신호는 셋 다 켜졌다. 한국은 2025년 민음사 7.4×10.5cm 시집 3,000부가 하루에 매진되고 주머니시가 2024년 23,000부를 팔았다. 일본 文学フリマ東京은 2026년 5월 3,509출점·18,689명으로 사상 최다. 글로벌 핸드메이드 Etsy는 2025년 거래액 104.6억 달러인데 미니북 전용 플랫폼은 없다.
- **작가가 떠나는 이유는 수수료율이 아니다.** 고정비(인디펍 종당 10만 원, 아이디어스 월 5만 원), 정산 보류(Etsy 75%를 45일), 입고 승인율 20~33%, 돈 내야 보이는 노출, 공동작업 분배 불가. 이 다섯을 뒤집은 것이 우리 약속이다.
- **이름은 한뼘(HANDSPAN).** "한 뼘(장변 190mm) 안에 들어오면 입점, 넘으면 못 들어온다"는 규칙이 곧 브랜드다. handspan.kr·handspanbooks.com·hanppyeom.kr 비어 있음(2026-10-10 확인).
- **ISBN은 '넣을까'가 아니라 '누가 발행인이 될까'다.** 기본은 ISBN 없는 핸드메이드 트랙(자유가격·납본 없음), 선택은 플랫폼 ISBN 트랙(서점·도서관 진출, 할인 15% 상한·납본 대행). 해외 작가 책은 거의 전부 ISBN 없이 들어온다.
- **배송비가 매출의 15~55%를 먹는다.** 그래서 설계의 중심은 가격이 아니라 묶음이다. 여러 작가 합포장, 3권 무료배송, 두께 3cm 봉투 규격. 해외는 미국이 아니라 일본·대만·홍콩부터(K-Packet 100g 4,160~4,550원, 국내 등기소포 4,000원과 같다).
- **수수료만으로는 못 산다.** 9,000원짜리 책 한 권에 플랫폼이 남기는 돈은 700원대다. 수익은 네 갈래: 수수료, 큐레이션 상품(선서 묶음·블라인드 福袋), 미니북 제작 클래스(우리 본업), 인쇄 파트너 제휴.
- **우리 강점은 작가를 만들어낼 수 있다는 것.** 구독자 1만 명의 유튜브, 전자책·이북 제작 스킬, 직접 만드는 개발력. 다른 플랫폼은 작가를 '모집'하지만 우리는 '양성'한다.

## 6. ISBN 결정

**질문을 바꾼다.** "ISBN을 넣을까"가 아니라 "누가 발행인이 되어 납본·정가제·면세 책임을 질까."

| 사실 | 출처 |
| --- | --- |
| 한국 ISBN은 무료지만 발행자번호에 구청 출판사 신고확인증이 필수. 개인 작가는 출판사 신고 없이는 못 받는다 | 국립중앙도서관 서지정보유통지원시스템 |
| 4쪽 이상 소책자도 부여 가능. 단 "일반 유통이 아닌 자가출판", 노트·다이어리(정보성 텍스트 30% 미만)는 제외 | 같은 곳 |
| 붙이는 순간 납본 2부(30일 내), 도서정가제(15% 상한, 12개월 후 재정가), 정가 표시 의무 | 도서관법 21조, 출판문화산업진흥법 22조 |
| 일본 ISBN 1점 11,000엔+세, 미국 $125, 영국 £93. 1,000엔 豆本 수십 권에는 비현실적 | 日本図書コード管理センター, Bowker, Nielsen |
| 외국 발행 간행물은 국내 판매 주목적이 아니면 정가제 제외 → 해외 작가 책은 자유가격 | 출판문화산업진흥법 시행령 |
| 2026년 정가제 3년 재검토 진행 중, 결론 미확정(2026.10) | 출판진흥원 공개토론회 2026.05 |

**결정**
1. 기본은 ISBN 없는 트랙 B. 판매는 합법이고 통신판매·청약철회 규율은 같다.
2. 트랙 A는 플랫폼이 발행인. 한뼘 명의로 출판사 신고 → 면세·과세 겸영 사업자 → 발행자번호 → 작가별 ISBN·부가기호 → 납본 대행. 작가는 신청서 하나만 쓴다.
3. 가격 엔진의 할인 상한은 설정값(현행 15%)으로 둔다. 2026년 하반기 정가제 결론이 나면 숫자만 바꾼다.
4. 정산서는 면세/과세 라인을 분리한다. 책+키링 세트는 처음부터 두 상품으로 등록하게 한다.
5. 확인 필요: ISBN 없는 수제본의 면세 유권해석, 비출판사 개인 발행물의 정가제 적용 여부. 국세청·문체부 질의 후 트랙 B 문구 확정.

| 구간 | 선택 | 비용(2026) |

**설계 규칙**
- 작가 직배송이 기본(1단계). 창고는 2단계에서, 처리비는 **주문당**으로(BOOTH가 개당 정률로 바꾸자 반발).
- **합포장**: 여러 작가 책을 한 봉투에. 이것이 배송비 비율 15~55%를 낮추는 유일한 레버다. 작가 직배 단계에서는 "같은 작가 3권 무료배송", 창고 단계에서 "누구 책이든 3권 무료배송".
- 봉투 규격 통일: 두께 3cm 이내 안전봉투(약 267원) + 보드 심지 1장(파손 6%→1.5%).
- 해외는 **아시아 먼저**. 일본은 1만 엔 이하 면세(2028년 폐지 전망). 미국·EU는 묶음·현지 POD 병행.

## 10. 세상의 모든 미니북 작가가 오게 하려면

### 해외 작가가 겪는 벽
- 한국 작가가 Etsy에 가려면 Payoneer만 가능, 환전 2.5%. 한국 법인은 Stripe 계정을 열 수 없다.
- 외국 작가가 한국에 팔려면 한국어 UI·원화 정산·세무가 막는다.
- MBS 디렉토리는 거래 기능 없는 정적 목록이고, Bo Press 같은 프레스 사이트는 사라졌다.

### 세 가지 판매 모델 (작가가 고른다)

| 모델 | 흐름 | 적합 |
| --- | --- | --- |
| 디지털 | PDF·읽는 이북 업로드, 배송 없음 | 모든 해외 작가의 첫 상품 |
| 한국 허브 위탁 | 작가가 10~20부를 한국 창고로 보냄 → 한국·아시아 판매 | 일본·대만·미국 豆本 작가 |
| 작가 직배 | 작가 국가에서 직접 발송, 플랫폼은 주문·결제·정산만 | 같은 권역 구매자 |

### 지급
해외 작가 지급은 PayPal Payouts 또는 Wise로, 월 1회 USD·JPY. **확인 필요**: 한국 운영사의 PayPal Payouts·Wise Business 이용 조건과 수수료, Stripe Connect KR 연결계정의 해외 지급 가능 여부.

### 언어·규격
- UI 한국어·영어·일본어. 상품 설명은 작가 언어 + 자동 번역 병기.
- 치수는 mm, 가격은 작가 통화 표시 + 원화 환산.
- 콩(S) 배지는 MBS 3인치·豆本協会 76mm와 같은 숫자라 해외 작가가 바로 이해한다.

### 커뮤니티 캘린더 (온보딩 시점)
언리미티드 에디션(서울, 가을) · 서울퍼블리셔스테이블 · 文学フリマ東京(5월·12월) · TOKYO ART BOOK FAIR(가을) · MBS Conclave(2026.8 베를린) · CODEX(격년 2월) · NY Art Book Fair(9월). 행사 직후 "남은 재고 온라인으로" 캠페인.

### 작가가 머무는 이유
수수료가 아니라 **발견**이다. 文学フリマ 참가자는 발견 경험에 입장료 1,000엔을 낸다. 이번 주 한 권·선서·福袋·뉴스레터가 작가에게는 무료 노출이고 구매자에게는 고르는 재미다.

## 11. 우리 강점을 더 잘하게

다른 플랫폼은 작가를 모집한다. 우리는 작가를 만들 수 있다.

| 강점 | 어떻게 키우나 |
| --- | --- |
| **유튜브 1만 구독자(50대 이상 + 30~40대 직장인)** | "내 첫 미니북" 시리즈: 글 20편 → 미니북 한 권 → 한뼘 입점 → 첫 판매까지 영상으로. 50대 구독자의 수익화 욕구와 30~40대의 1인 창업 니즈가 둘 다 '작가 되기'로 이어진다. 입점 작가 수가 콘텐츠 성과 지표가 된다 |
| **전자책·읽는 이북 제작 스킬(`ebook-maker`)** | 디지털 미니북 트랙: 작가가 글만 넣으면 넘기는 이북·인쇄용 PDF·A6 판형이 한 번에 나온다. 해외 작가도 배송 없이 바로 판다. 전자책 10권 계획도 한뼘 디지털 트랙의 첫 상품이 된다 |
| **직접 만드는 개발력** | 정적 사이트 + Supabase 스택(목장 나눔터·반값 운영 경험). 외주 없이 2~3개월 MVP. 수수료 0.7%p 차이보다 "작가 요청을 다음 주에 반영"이 작가를 붙든다 |
| **교육 본업** | 플랫폼 수익의 큰 축을 클래스로. "미니북 제작 입문(무료)" → "소량 인쇄·판매 실전(유료)" → 바이브코딩으로 내 작가 페이지 꾸미기. 강의가 작가를 만들고 작가가 플랫폼을 채운다 |
| **신뢰·정직 톤** | 수수료·정산일·보류 사유를 전부 공개. 낚시 없는 썸네일 철학을 플랫폼 UI에 그대로. "믿을 수 있는 사람이 운영하는 작은 책 가게" |

이 부분은 전자책에: "플랫폼은 수수료로 안 산다. 플랫폼 위의 사람을 가르치는 것으로 산다."

## 12. 기술 구조

정적 사이트(GitHub Pages) + Supabase(계정·RLS·Edge Functions) + PG 지급대행. 목장 나눔터와 같은 뼈대에 결제·정산이 붙는다.

| 페이지 | 역할 |
| --- | --- |
| `handspan/index.html` | 이번 주 한 권, 콩·손·뼘 진열, 福袋·선서 |
| `handspan/shop.html` | mm 필터, 장르·제작·국가 필터, 작가 국적 깃발 |
| `handspan/book.html` | 치수 자 사진, 에디션 번호, 제본, 커버·책갈피 옵션, 한 권 더 보내기 |
| `handspan/artist.html` | 작가 페이지, 제작 과정, 행사 일정 |
| `handspan/studio/` | 작가 대시보드: 상품 등록(mm 검증), 재고, 주문, 다음 지급일, 분배 설정, ISBN 신청(트랙 A) |
| `handspan/box.html` | 선서 신청(테마 입력), 福袋 |
| `handspan/admin/` | 큐레이션 편성, 정산 실행, 납본 체크리스트 |

| 구성 | 선택 | 비고 |
| --- | --- | --- |
| 결제 | 토스페이먼츠 지급대행(서브몰) 또는 포트원 파트너정산 | 플랫폼이 대금을 직접 쥐면 전자금융거래법 PG 등록(자본금 10억/소규모 3억) 필요 → 지급대행으로 회피 |
| 해외 카드 | PG 해외카드 MID(3.8~4.5%+VAT) 또는 PayPal | 아이디어스 글로벌은 고정 5% |
| 해외 작가 지급 | PayPal Payouts / Wise | 확인 필요 |
| 배송 | 우체국 API(준등기·K-Packet), 편의점 택배 연동 | 1단계는 작가가 운송장 입력 |
| 디지털 | Supabase Storage 서명 URL, 다운로드 횟수 제한 | ebook-maker 산출물 그대로 |
| 번역 | 상품 설명 자동 번역 병기 | 작가 원문 우선 |

MVP 범위(3개월): 트랙 B만, 국내 결제만, 작가 직배송, 이번 주 한 권·福袋, 정산 자동화. 트랙 A·해외 결제·창고는 2단계.
