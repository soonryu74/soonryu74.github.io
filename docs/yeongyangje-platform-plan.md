# 근거영양 플랫폼 기획안 v0.2

> 작성 2026-09-05 · 갱신 2026-09-07 · 사이트: `/yeongyangje/` · 브랜치 `claude/vitamin-supplement-research-tq2ltd`

**팔기 위해 근거를 고르지 않고, 근거에 맞춰 판다.**

## 1. 요약

- 한국 건강기능식품 시장은 약 6조 원(2024년 6조 440억, −1.6%; 2025년 5조 9,626억, +0.2%)에서 정체. 구매 경험률은 83.6%로 5년 최고. 홍삼(0.95조)이 1위지만 비타민 합계(1.05조)에 역전됨. 온라인 구매 71%.
- 시장이 정체된 이유는 "무엇을 왜 먹어야 하는지" 근거를 제시하는 플레이어가 없기 때문. 광고와 후기가 전부.
- 대규모 연구의 결론은 명확하다. 건강한 성인에게 영양제는 수명·심혈관 예방 효과가 없고(NIH 39만 명 20년, PHS II, COSMOS), **결핍 교정**만 확실하며(비타민 D·B12·철·엽산), 일부는 **유해**하다(베타카로틴·비타민 E 400 IU·고용량 오메가-3).
- 그래서 포지션은 "근거로 걸러 주는 플랫폼". 추천 엔진은 판매와 분리되고, 판매는 근거 A·B 성분만, 판매 제품은 자체 연구(n-of-1 → 실용 RCT)로 검증한다.
- 수익은 ① 큐레이션 판매(마진) ② n-of-1 개인 효과 검증 패키지(프리미엄) ③ B2B 데이터·콘텐츠(약국·검진센터·보험) 순으로 확장.

### 근거 등급
A(대규모 RCT 다수 일관) · B(RCT/메타, 조건부) · C(관찰·소규모·혼재) · D(효과 없음 확인) · X(유해). 등급은 "성분 × 대상 × 용량 × 결과"에 붙는다.

### 건강 수준 4단계 (추천 엔진과 R&D 공용)
- L1 건강: 결핍 위험 없음 → 식사 우선, 선택만
- L2 결핍 위험군: 실내 근무·채식·임신·65세+·위장질환·메트포르민·검사 결핍 → 결핍 교정(근거 A/B)
- L3 만성질환: 고혈압·당뇨·이상지질·골다공증·황반변성·자가면역 → 질환별 근거 성분
- L4 주의·금기: 항응고제·신장질환·항암치료·흡연 → "피하세요" 우선, 의사 확인

| 2 | M6~9 | n-of-1 개인 효과 검증 패키지(제품+위약 키트+주간 설문+리포트) | 프리미엄 |
| 3 | M9~12 | 실용 RCT 1건 사전등록(CRIS)·IRB. 결과 공개 | 신뢰 자산 |
| 4 | M12+ | B2B: 검진센터·약국용 추천 엔진 API, 건강 수준별 데이터 리포트, 전자책·강의 | 라이선스·콘텐츠 |

### 판매 원칙 (jepum.html에 사전 공개)
1. 근거 A·B 성분만 판매, C 이하는 정보만
2. 로트별 시험성적서 공개, 없으면 판매 중단
3. 추천 엔진과 판매 분리, 비권장 항목 판매 금지
4. 이해상충 문구 명시
5. 판매 제품은 자체 연구로 검증, 부정 결과도 공개, 효과 없으면 중단
6. 식약처 표시·광고 규정 준수

## 5. R&D 설계 요약 (상세: rnd.html)

- 0단계 데이터 인프라(M1~3) → 1단계 실사용 관찰(M3~6, 300명, IRB 신속심의) → 2단계 n-of-1(50명)·실용 RCT(200명, CRIS 사전등록) → 3단계 외부 검증(대학병원, 식약처 인체적용시험)
- 지표: 25(OH)D, 페리틴, B12, 오메가-3 지수, 혈압, HbA1c, 지질, 골밀도, MoCA-K, 주간 PRO(피로·수면·통증·기분)
- DB: participants / health_profiles / regimens / outcomes_pro / labs / studies / study_arms / products (판매·연구 공용 participant_id, 개인식별정보 분리)
- 규제: 생명윤리법·공용 IRB, CRIS, 개인정보보호법(민감정보), 건강기능식품법·표시광고법, 의료법 27조, 식약처 인체적용시험 가이드, GMP
- 예산: 관찰 600만 원 · n-of-1 500만 원(매출 상쇄) · 실용 RCT 2,500~4,000만 원

## 6. 유튜브 콘텐츠 연계 (노모어매뉴얼)

성공 공식 "누구나 아는 툴 + 아무도 모르는 활용법"을 영양제에 적용하면 "누구나 먹는 영양제 + 아무도 안 읽은 연구 원문".

- "하버드 20년 연구, 종합비타민 결론은 이겁니다" — NIH 39만 명 + COSMOS
- "비타민 D, 한국인 절반이 결핍인데 먹으면 안 되는 사람" — KNHANES + VITAL
- "오메가-3 먹다가 심방세동" — STRENGTH·35개 RCT
- "흡연자가 절대 먹으면 안 되는 영양제 성분표" — ATBC·CARET
- "영양제 고르는 5단계 체크리스트(시험성적서 요청하는 법)"
- 바이브코딩 각도: "이 추천 엔진, 클로드로 하루 만에 만들었습니다"(rules.js 시연) → 강의 연결
