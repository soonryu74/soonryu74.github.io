# 목장 나눔터 — 멜번방주교회 & ALF

목자가 매주 자기 목장 이야기와 목원별 기도제목을 적어 목사에게 전하는 비공개 웹사이트입니다.
**목자는 자기 목장만**, **목사는 모든 목장**을 봅니다.

- 주소: `https://soonryu74.github.io/gajeong/`
- 검색 노출 차단(`noindex`), 로그인해야만 내용이 보입니다.

## 처음 한 번 — 목사님 계정 만들기

깔거나 내려받을 것은 없습니다. 브라우저에서 주소만 열면 됩니다.

1. `https://soonryu74.github.io/gajeong/` 에 들어갑니다.
2. 맨 아래 **이 교회에서 처음 시작하시나요?** 를 누릅니다.
3. 등록 코드와 이름·아이디·비밀번호를 넣습니다.
4. 목사 화면으로 바로 들어갑니다. 이 절차는 교회마다 **한 번뿐**입니다.

> 등록 코드는 이 저장소가 공개돼 있으므로 **여기에 적지 않습니다.** 따로 전달받은 코드를 쓰세요.
> 코드를 잃어버렸다면 Supabase 대시보드에서 `church_setup` 표의 `setup_code` 를 새로 정하고
> `used` 를 `false` 로 되돌리면 됩니다.

### 먼저 시험해 보고 넘겨 드리기

등록 코드는 한 번뿐이지만 **목사 계정은 여러 개 만들 수 있습니다.**
먼저 본인 계정으로 등록해 목자 계정까지 만들어 두루 눌러 보신 뒤,
**목장·목자 관리 → 목사 계정** 에서 실제 목사님 계정을 하나 더 만들어 아이디와 비밀번호를 넘겨 드리면 됩니다.
목사 계정끼리는 보는 것이 똑같습니다.
시험 삼아 만든 목장은 같은 화면의 **목장 지우기** 로 일기까지 한꺼번에 치울 수 있습니다.
마지막 남은 목사 계정과 자기 계정은 실수로 지워지지 않게 막아 두었습니다.

## 목자 계정 만들기 (목사)

목사 화면 → **목장·목자 관리** → *목자 계정 만들기*.
이름·목장 이름·아이디·첫 비밀번호를 넣으면 **계정과 목장이 함께** 만들어집니다.
아이디와 첫 비밀번호를 목자에게 알려 주면 됩니다. 목자는 들어간 뒤 스스로 바꿀 수 있습니다.
비밀번호를 잊은 목자는 같은 화면에서 **비밀번호 새로**를 눌러 다시 정해 주면 됩니다.

## 화면

| 화면 | 파일 | 하는 일 |
| --- | --- | --- |
| 로그인 · 최초 설치 | `gajeong/index.html` | 아이디/비밀번호, 역할에 따라 자동 이동 |
| 목자 | `gajeong/mokjang.html` | 주간 일기 쓰기, 목원 명단, 지난 일기, 내 계정 |
| 목사 | `gajeong/moksa.html` | 주간 현황, 기도제목 모아보기(인쇄), 목장·목자 관리 |

목자 화면에는 **지난주 기도제목 불러오기**가 있어 매주 처음부터 다시 치지 않아도 됩니다.
목사 화면의 **기도제목 모아보기**는 한 주 전체를 한 장으로 모아 주일 중보기도 자료로 인쇄·PDF 저장할 수 있습니다.

## 시간대

교회가 멜번에 있으므로 '이번 주'는 **멜번 현지 시각**으로 계산합니다(`Australia/Melbourne`).
서머타임이 해마다 바뀌므로 시차를 숫자로 박지 않고 표준 시간대 이름을 씁니다.
목사가 한국에 계시든 멜번에 계시든 목자와 같은 '이번 주'를 봅니다.

## 구조

정적 페이지(GitHub Pages) + Supabase(계정·데이터). 별도 서버가 없습니다.

- 로고: `gajeong/assets/` — 교회 공식 로고에서 따온 심볼과 파비콘, 색(파랑 #0054A8, 연두 #84C03C, 주황 #F07818)
- 데이터베이스: `supabase/migrations/0002_church.sql` — `church_` 로 시작하는 표 7개
- 계정 관리 함수: `supabase/functions/church-admin/index.ts` (목사만 호출 가능)
- 프로젝트: Supabase `korea-now`(`dxhmprqfgigljgbstqrg`)
  — 무료 요금제가 활성 프로젝트 2개까지라 기존 프로젝트에 표 이름을 구분해 함께 두었습니다.
  나중에 전용 프로젝트로 옮기려면 위 두 파일만 새 프로젝트에 적용하고
  `gajeong/common.js` 의 `SB_URL`·`SB_KEY` 두 줄을 바꾸면 됩니다.

### 누가 무엇을 볼 수 있나

접근 통제는 브라우저가 아니라 **데이터베이스 RLS(행 수준 보안)** 로 겁니다.
주소를 직접 치거나 개발자 도구를 열어도 남의 목장은 한 줄도 나오지 않습니다.

| 대상 | 목자 | 목사 |
| --- | --- | --- |
| 자기 목장·목원·일기·기도제목 | 읽기·쓰기 | 읽기·쓰기 |
| 다른 목장 | **안 보임** | 모두 보임 |
| 계정 목록 | 자기 것만 | 모두 |
| 계정 만들기·비밀번호 재설정 | 불가 | 가능 |

목자가 스스로 목사 권한을 갖는 것은 데이터베이스 트리거가 막습니다. 설치 코드는 아무도 읽을 수 없습니다.

### 확인한 것

브라우저 자동 검사 16가지 통과 — 로그인·역할별 이동, 목원 등록, 일기 작성·제출·새로고침 유지,
목원 추가 중 작성 내용 유지, 목사 열람·코멘트, 모아보기, 관리 화면, 목자의 목사 화면 접근 차단, 로그아웃.
데이터베이스 쪽으로도 다른 목장 열람 시도, 설치 코드 읽기 시도, 권한 상승 시도가 모두 막히는 것을 확인했습니다.
