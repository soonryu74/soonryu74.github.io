### 과제 1. 검역소 소독업체 지도

| 항목 | 내용 |
|---|---|
| 과제명 | 검역소 소독업체 지도 |
| 결과물 형태 | 웹(단일 HTML 파일, 오프라인 동작, 모바일 대응) |
| 사용 모델명/교체 가능 여부 | 실행 시 LLM 미사용. 데이터 가공·좌표 변환은 Python, 지도 표시는 브라우저 내장 SVG. 특정 모델 종속 없음 |
| 공공 GitLab 링크 | (등록 후 기재) |

**개요 및 주요 기능**
- 문제: 검역소장이 항공기·선박 소독을 명령하거나 선박위생관리증명서를 발급할 때 소독업무대행자(검역법 시행규칙 제12조)를 찾아야 하지만, 전국 소독업체 약 1만 곳 중 요건을 갖춘 업체 명단이 공개돼 있지 않아 담당자가 전화로 수소문한다.
- 해결: 검역소·지소 26곳과 내 위치를 기준으로 반경 1~100 km 안의 소독업체를 거리순으로 보여주고, 업체마다 공적 확인 수준을 3단계로 색 구분한다. 1단계 농림축산검역본부 훈증 방제업체 신고(35곳), 2단계 행정안전부 소독업 신고(2026-08-31 기준 10,466곳), 3단계 미확인.
- 기능: 검역소 선택 → 반경·업체 유형(훈증·항공기·선박·일반) 필터 → 전화·FAX·주소 즉시 확인. 업체명·주소 검색. GPS 또는 지도 지정으로 내 위치 설정.
- 데이터: 행안부 지방행정인허가(소독업), 검역본부 방제업체 목록, 검역소 제공 전화·주소록, 통계청 행정구역 경계. 모두 공개·기관 제공 자료, 개인정보 없음. 중부원점 TM 좌표를 WGS84로 변환해 좌표 정확도 확보.
- 기대효과: 소독 명령·증명서 발급 시 업체 탐색 시간 단축, 무자격 업체 호출 방지. 13개 검역소·13개 지소가 동일 파일로 바로 사용 가능. 데이터 갱신 스크립트로 연 1회 재생성.
- 확산: 보건소(소독업 신고 관할), 공항·항만공사, 농림축산검역본부 등 소독 수행업체를 찾는 기관에 그대로 이식 가능.

### 과제 2. 지역 건강프로파일 대시보드

| 항목 | 내용 |
|---|---|
| 과제명 | 지역 건강프로파일 대시보드 |
| 결과물 형태 | 웹(React 빌드 결과를 단일 HTML로 합침, 서버 불필요) |
| 사용 모델명/교체 가능 여부 | 실행 시 LLM 미사용. 통계 연산(상관·핫스팟 등)은 Python 사전 계산, 화면은 React·d3. 특정 모델 종속 없음 |
| 공공 GitLab 링크 | (등록 후 기재) |

**개요 및 주요 기능**
- 문제: 질병관리청 CIAT(지역사회건강지표 분석도구)는 R Shiny 기반이라 모바일에서 쓰기 어렵고, 지표가 지역사회건강조사와 e-지방지표에 흩어져 있어 한 시군구의 건강 상태를 한 화면으로 보기 어렵다.
- 해결: KOSIS openAPI로 지역사회건강조사 41개·시군구 130개 지표(2008~2025, 시도 17·시군구 229)를 수집·검증해 시군구별 건강프로파일을 자동 생성한다.
- 기능: 지표별 현황·추이·단계구분도(지도)·순위·격차 6패널, 연관지표 탐색(상관), 핫스팟, 보건사업 우선순위 매트릭스, 건강수명 보조 지표. 라이트/다크, 모바일 우선 반응형.
- 데이터: 통계청 KOSIS 공개 API, 질병관리청 지역사회건강조사 공표 자료. 개인정보 없음. 숫자 검증 리포트(`docs/DATA_VALIDATION.md`)를 빌드마다 자동 생성.
- 기대효과: 보건소·시군구 보건정책 담당자가 자기 지역의 강점·약점 지표를 설치 없이 확인. 연 1회 스크립트 실행으로 갱신.
- 확산: 질병관리청 권역질병대응센터, 시도 공공보건의료지원단, 보건소 통합건강증진사업 계획 수립에 공통 활용 가능.

| 항목 | 내용 |
|---|---|
| 과제명 | 국정감사 자료 DB (보건복지위원회 트랙) |
| 결과물 형태 | 웹(정적 HTML + JSON) · GitHub Actions 자동 수집 |
| 사용 모델명/교체 가능 여부 | 실행 시 LLM 미사용. 회의록 질의·답변 짝짓기와 주제 분류는 키워드 규칙 기반(확실/추정/미분류 표시). LLM 요약을 붙일 경우 모델 교체 가능한 구조 |
| 공공 GitLab 링크 | (등록 후 기재) |

**개요 및 주요 기능**
- 문제: 국감 준비 때 담당자가 과거 결과보고서·회의록·시정요구를 매년 다시 찾아 읽고, 예상 질의를 수작업으로 정리한다. 자료가 국회·기관 사이트에 흩어져 있고 검색이 안 된다.
- 해결: 국회 열린국회정보 공개 API에서 결과보고서·시정 및 처리요구·회의록을 자동 수집(평시 주 1회, 국감 시즌 매일)해 복지부·질병청·식약처 등 기관별로 정리하고 검색한다.
- 기능: 기관별 6년치(2020~2025) 지적사항·Q&A 검색, 감사일별 자동 요약 카드(최다 언급 주제·질의 횟수 상위 위원), 주제 비중·추세, 의원별 가이드북(27명 약력 일괄 인쇄), 예상 질의와 근거, 답변 대비 워크북.
- 데이터: 국회 공식 API·PDF만 사용. 모든 원문 링크는 국회 시스템. 개인정보는 공개된 위원 약력에 한정.
- 기대효과: 국감 대비 자료 탐색 시간 단축, 반복 지적사항 조기 파악. 비공식 참고자료임을 화면에 명시.
- 확산: 상임위원회·기관명만 바꾸면 타 부처·공공기관 국감 트랙으로 재사용. 자동 수집 워크플로를 그대로 복제.

| 알려진 제약 사항 | 행안부 데이터 외 업체 좌표는 OpenStreetMap 지오코딩 근사값(≈ 표시). 소독업무대행자(유해화학물질관리자·가스소독 장비) 보유 여부는 공개 자료가 없어 미표시 → 출동 전 전화 확인 필요. 소독업 신고 업체 점은 시·군 수준으로 확대해야 표시. 글꼴 Noto Sans KR(OFL), 경계 데이터 통계청 공개 자료, 재배포 제한 라이브러리 없음 |

**개발 경위 요약**: 2026년 8~10월. 검역소 소독업무대행자 명단이 비공개이고 "쓸 수 있는 업체는 31곳"이라는 업계 통설의 근거도 없어, 법령(감염병예방법·검역법·농약관리법)과 국제기준(WHO·ICAO·IMO)을 먼저 조사해 "자격은 신고·등록부 두 층뿐"임을 확인했다(연구노트 7편 동봉). 그 결론에 따라 공개 명단 대조로 자격 수준을 추정하는 지도를 바이브코딩(Claude Code)으로 만들었고, 검역소 제공 주소록을 반영해 전화·FAX를 갱신했다.

| 모의데이터 안내 | 불필요. `data/dataset.json`(KOSIS 공표 통계) 내장. 검증 요약 `data/validation_summary.json` |
| 기능 사용 순서 | ① 시군구 선택(예: 인천 중구) → 건강프로파일 6패널 확인 ② 지표 선택(예: 현재흡연율) → 단계구분도 연도 애니메이션·순위·격차 ③ 심층분석 → 연관지표 탐색(상관)·핫스팟·우선순위 매트릭스 |
| 알려진 제약 사항 | 지역사회건강조사(조사 단위 258곳)와 시군구 지표(229곳)는 단위가 달라 합산하지 않음(화면에 명시). 전문가 감수 전 베타. 오픈소스: React·Vite·d3·topojson(MIT), 재배포 제한 없음. KOSIS 연속 호출 제한으로 전체 재수집에 수십 분 소요 |

**개발 경위 요약**: 질병관리청 CIAT(R Shiny)를 벤치마크해 메뉴·패널 구조를 분석한 뒤, 2026년 9월 React+정적 데이터로 재구축하기로 결정. KOSIS 전 표 커버리지 검증을 먼저 끝내고 실데이터를 연결했다. 숫자 검증·국제 심사 자료(10월)까지 자동화했다.
