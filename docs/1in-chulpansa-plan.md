# 노모어매뉴얼 1인 출판사 기획안 v0.1

> 작성 2026-10-10 · 브랜치 `ccr-89356287-s4jtzy`
> 근거: 출판문화산업진흥법, 도서관법 제21조, 국립중앙도서관 서지정보유통지원시스템(nl.go.kr/seoji) 안내, 크몽 판매 수수료 정책(2024-08-20 기준). 플랫폼 정산율처럼 공식 페이지에서 수치를 확인하지 못한 항목은 **[확인]** 으로 표시했습니다.

## 결론 먼저

세 가지만 정하면 나머지는 절차입니다.

1. **전자책 먼저, 종이책은 주문형(POD)으로 나중에.** 재고·인쇄비 없이 시작하고, 반응이 확인된 책만 종이로 냅니다.
2. **출판사 신고 → 사업자등록 → 발행자번호(ISBN)** 순서로 2주 안에 끝냅니다. ISBN이 붙은 전자책은 부가가치세 면세 대상이 될 수 있어 사업 구조가 단순해집니다.
3. **판매는 두 갈래.** 직판(유튜브 → 자사 페이지)으로 수익을 남기고, 서점 유통(유페이퍼·부크크 → 교보·리디·알라딘·예스24·밀리)으로 신뢰와 검색 노출을 얻습니다.

전자책은 그 자체가 주 수익원이 아닙니다. **유튜브 → 전자책(신뢰) → 바이브코딩 강의(주 수익) → 코칭** 흐름에서 전자책은 "돈 내고 사본 첫 상품"입니다. 그래서 가격은 낮게, 권수는 많게, 매 권 끝에 강의로 가는 문을 둡니다.

| 순서 | 할 일 | 어디서 | 서류 | 기간 |
|---|---|---|---|---|

| 2 | 출판사 신고 | 주소지 시·군·구청 문화체육과 | 신고서, 신분증, (임대 시) 임대차계약서 | 3~5일 |

주의할 점.

- **집에서 하는 1인 출판사**는 근로자 없이 주거시설에서 운영하면 신고서에 사업체 소재지를 적지 않아도 됩니다. 아파트라도 신고에 문제없는지는 구청에 전화 한 통으로 확인합니다.
- 발행자번호 신청 자격은 **출판사신고확인증을 받은 곳**입니다. 개인 자격으로는 ISBN을 받을 수 없어 신고가 선행 조건입니다. 법인은 필요 없습니다.
- ISBN을 받은 온라인 자료(전자책)는 도서관법상 **납본 의무 대상**입니다. 납본 시 보상 청구를 선택하면 정가 기준 보상금을 받습니다.
- 자사 페이지에서 직접 팔면 전자상거래법상 **통신판매업 신고** 대상입니다. 직전 연도 거래 횟수가 적거나 간이과세자면 면제될 수 있으니 세무사 상담 질문지 13번에서 확인합니다. 판매 페이지 하단에 신고번호를 표기해야 합니다.
- 2026년 4월 도서관법 개정안(대안)이 발의되어 납본·보상 기준이 바뀔 수 있습니다. 첫 납본 전에 nl.go.kr/seoji 공지를 한 번 더 봅니다.

## 3. 세금 구조

| 판매 형태 | 부가가치세 | 메모 |
|---|---|---|
| ISBN 부여 전자책(EPUB·PDF)을 서점·자사 페이지에서 판매 | 면세 가능 | 부가가치세법 시행령의 전자출판물 기준(문체부 고시) 충족 시 |
| ISBN 없는 PDF를 크몽 등에서 판매 | 과세 | "자료 제공 용역"으로 봄 |
| 온라인 강의·코칭 | 과세 | 출판과 별개 매출 |

- 출판업(면세)과 강의(과세)를 한 사업자로 하면 **겸영 사업자**가 됩니다. 사업자등록 때 두 업종을 함께 넣고, 면세·과세 매출을 장부에서 나눕니다.
- 크몽에서도 ISBN을 붙인 책을 팔면 면세 적용 여부가 달라질 수 있습니다. **[확인]** 세무사 또는 국세청 126에 "ISBN 전자책을 재능마켓에서 판매할 때 면세 여부"를 묻고 답을 이 문서에 기록합니다.
- 간이과세 가능 여부도 같은 자리에서 확인합니다. 강의 매출 규모가 커지면 일반과세가 유리할 수 있습니다.

## 4. 판매 채널

| 트랙 | 채널 | 작가 몫 | 역할 |
|---|---|---|---|
| A 직판 | 유튜브 설명란 → 자사 페이지(결제 링크) | 결제 수수료만 (약 3~4%) | 수익의 중심. 구매자 이메일 확보 |
| B 재능마켓 | 크몽 | 서비스 이용료 1구간 16.4% + 결제망 3.3% + 부가세 (2024-08-20 정책 기준) | 검색 유입, 후기 축적 |
| C 서점 유통 | 유페이퍼 또는 부크크 → 교보·리디·알라딘·예스24·밀리의서재 | **[확인]** 정가의 50~70% 수준으로 알려짐, 공식 정산표 확인 | 신뢰, 서점 검색 노출, ISBN·납본 대행 |
| D 글로벌 | 아마존 KDP | 2.99~9.99달러 구간 70%, 그 외 35%, MB당 전송비 차감 | 영어판 실험용. 1년차 후순위 |

크몽 수수료는 구간 누진이라 소액 전자책(1만~3만 원)은 사실상 1구간 요율이 전부 적용됩니다. 수수료만 보면 직판이 압도적이지만, 크몽의 역할은 수익이 아니라 **검색으로 들어오는 신규 독자**입니다.

유페이퍼와 부크크 중 하나만 씁니다. 같은 책을 두 곳에서 서점에 내보내면 중복 등록으로 반려됩니다. 유페이퍼는 전자책 유통 폭이 넓고, 부크크는 종이책 POD까지 한 곳에서 됩니다. **첫 3권은 유페이퍼로 전자책만, 반응이 좋은 책을 부크크 POD로 종이책**을 내는 순서를 권합니다. 부크크로 낼 때는 전자책도 부크크로 옮기거나 ISBN을 따로 받습니다.

## 5. 제작 파이프라인

이미 있는 자산을 그대로 씁니다. 저장소의 `.claude/skills/ebook-maker` 스킬이 "읽는 이북" HTML을 만들고, 브라우저 인쇄로 A4 PDF가 나옵니다.

| 단계 | 도구 | 산출물 | 시간 |
|---|---|---|---|
| 1 재료 | 유튜브 대본·댓글 질문·시연 캡처 | 원고 메모 | 영상 제작 시 함께 |
| 2 구조 | Claude Cowork로 목차·쪽 콘티 | 콘티(쪽당 메시지 1개) | 반나절 |
| 3 집필 | 콘티 → 쪽별 본문 다시쓰기 | 마크다운 원고 | 2~3일 |
| 4 조판 | ebook-maker 스킬 | 읽는 이북 HTML + PDF | 반나절 |
| 5 EPUB | Pandoc 또는 Calibre | EPUB(서점 유통용) | 1시간 |
| 6 표지 | Canva | 표지 JPG(권장 1,600×2,560) | 1시간 |
| 7 등록 | ISBN → 유페이퍼 → 납본 | 판매 개시 | 2~5일 |

EPUB 변환 명령. 마크다운 원고가 `book.md`, 표지가 `cover.jpg`일 때.

```
# Mac (Homebrew)
brew install pandoc
pandoc book.md -o book.epub --metadata title="책 제목" --metadata author="서순려" --epub-cover-image=cover.jpg

# Windows (PowerShell)
winget install JohnMacFarlane.Pandoc
pandoc book.md -o book.epub --metadata title="책 제목" --metadata author="서순려" --epub-cover-image=cover.jpg
```

Mac과 Windows 모두 설치 명령만 다르고 변환 명령은 같습니다. Calibre를 쓰면 `ebook-convert book.epub book.pdf` 로 PDF 재생성도 됩니다.

주의. 영상 속 타사 화면 캡처는 책에 넣을 때 **직접 만든 화면**으로 바꿉니다. 남의 유료 강의 내용은 내 말로 다시 쓴 요약만 씁니다.

## 7. 가격과 매출 모델

| 항목 | 값 |
|---|---|
| 전자책 정가 | 9,900원 ~ 19,900원 (실전편 상단) |
| 직판 비중 목표 | 60% |
| 1권당 첫 달 판매 목표 | 100부 (구독자 1만 명의 1%) |
| 10권 누적, 12개월차 월 매출 | 300~500만 원 |
| 전자책 → 강의 전환율 목표 | 5% |

월 1억 목표에서 전자책의 몫은 5% 안팎입니다. 나머지는 바이브코딩 강의가 맡습니다. 그래서 이 사업의 성과 지표는 전자책 매출이 아니라 **전자책 구매자 중 강의로 넘어온 비율**입니다. 매 권 마지막 쪽에 강의 안내와 구매자 전용 쿠폰을 넣고, 직판 구매자의 이메일로 강의 오픈을 알립니다.

## 11. 리스크

| 리스크 | 대응 |
|---|---|
| 도구 업데이트로 책 내용이 금방 낡음 | 전자책은 파일 교체가 가능. 판 갱신 시 구매자에게 재배포. 서점판은 ISBN 유지하고 내용만 갱신 |
| 유튜브 영상과 책 내용 중복으로 구매 동기 약함 | 책에만 있는 것 1개 이상: 템플릿 파일, 프롬프트 모음, 체크리스트 |
| 타사 화면·상표 캡처 저작권 | 직접 만든 화면, 도구 이름은 텍스트로만 |
| 납본·세무 기준 변경 | 분기마다 nl.go.kr/seoji 공지와 세무사 확인 |
| 크몽 수수료 부담 | 크몽은 유입용. 가격을 직판과 같게 두고 직판에 보너스 자료를 붙임 |
