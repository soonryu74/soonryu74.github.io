# 오프라인 AI 입문 6차시 — 해외 장기 체류 실무자용

> v0.1 · 2026-09-06 · 대상: 해외에서 수년째 교육·보건·개발 협력·소규모 사업을 하는 실무자. 현지어 학습, 후원 기관 소식지·보고서·정산이 일상인 분. 컴퓨터 초보 가능.
> 6차시 × 90분. 심화 과정(영어 교실·보건 안내문·소상공인 자동화 12차시)의 앞 단계.

**이 과정의 약속.** 인터넷 없이 됩니다. 돈 안 듭니다. 내 기기 밖으로 정보가 나가지 않습니다. 첫 시간에 눈앞에서 인터넷을 끊고 보여 드립니다.

## 1차시. 오프라인 AI 키트

**목표** 인터넷을 끊어도 대화가 되는 AI를 노트북과 폰에 갖춘다. 설치는 한국에서, 현지에서는 켜기만.

**용어 한 줄** LLM(엘엘엠)은 "글 잘 쓰는 신입 직원". 똑똑하지만 아는 척을 하니 확인은 사람이 한다. 프롬프트(prompt)는 "부탁하는 말".

**노트북**

| 단계 | Windows | Mac |
|---|---|---|
| 설치 | lmstudio.ai → Windows용 다운로드 → 실행 | lmstudio.ai → Mac(Apple Silicon)용 → 응용 프로그램으로 드래그 |
| 모델 | 돋보기 → `gemma-4-e4b` 또는 `qwen3.5-4b` → Q4 다운로드(2.5~3GB). 16GB RAM이면 `qwen3.5-9b` | 동일 |
| 자동 업데이트 끄기 | 설정 → App → 자동 업데이트 확인 해제 | 동일 |
| 오프라인 확인 | 비행기 모드 켜기 → 채팅에 "안녕" → 답 오면 성공 | Wi-Fi 끄기 → 동일 |
| 모델 백업 | `%USERPROFILE%\.lmstudio\models` 폴더를 USB에 복사 | `~/.lmstudio/models` |

**폰(안드로이드)** Google AI Edge Gallery 설치 → Gemma 4 E2B 다운로드 → 비행기 모드 테스트. 대안 PocketPal AI. 구글 번역 앱 → 오프라인 번역 → 한국어·영어·현지어 팩 다운로드.

**실습** 비행기 모드에서 "나는 ○○에서 일하는 교사야. 오늘 할 일 3개를 정리해 줘"를 한국어로. 답이 오면 같은 부탁을 영어로.

**막히는 곳** 모델이 안 뜨면 RAM 부족 → 2B 모델. 답이 느리면 정상(초당 8~15단어). 영어로만 답하면 첫 줄에 "한국어로 답해 줘".

**과제** 모델 2개(4B·2B)와 설치 파일을 USB에. 현지에서는 다운로드가 어렵거나 흔적이 남는다.

## 2차시. 현지어 파트너

**목표** 매일 10분, 인터넷 없이 현지어를 말하고 고쳐 받는 루틴을 만든다.

**저자원 언어 주의** 영어·중국어·아랍어·베트남어·태국어는 소형 모델도 쓸 만하다. 라오어·크메르어·미얀마어·소수민족어는 품질이 검증되지 않았다. 이 경우 AI는 "영어를 거쳐" 쓰고, 현지 친구가 최종 판정한다.

**설정 프롬프트(한 번 붙여넣기)**
```
You are my language partner for <현지어>. I am a Korean adult, level: beginner.
Rules: (1) reply in <현지어> with romanization in parentheses and a short English gloss,
(2) one or two short sentences per reply, (3) if I make a mistake, reply naturally first,
then add one line "Better: ..." (4) keep the topic everyday life: market, neighbors, office, clinic.
Start by asking what I did today.
```

**문장 교정** `Correct my <현지어> sentence. Show: original | corrected | why (one phrase). Then give one more natural way to say it.`

**내 단어장** 하루 대화가 끝나면: `List every new word I used or you introduced today as a table: word | romanization | Korean meaning | example sentence.` → 엑셀에 붙여넣어 누적. 주 1회 `Make a 10-question quiz from this word list` 로 복습.

**발음** 구글 번역 오프라인 팩의 스피커로 듣고 따라 말한다. 폰 마이크 인식은 언어 팩마다 지원이 달라 사전 확인.

**문화 표현** `What should I NOT say to an older neighbor in <현지어> culture? Give 5 examples with the polite alternative.` 결과는 참고만, 현지 친구에게 확인.

**실습** 10분 역할극(시장에서 장보기) → 교정 3문장 → 단어장 첫 20단어 저장.

**과제** 7일 연속 10분. 단어장 100단어 도달.

## 3차시. 현지어 문서·행정

**목표** 현지어 서류를 읽고, 양식을 채우고, 번역이 틀리지 않았는지 스스로 검사한다.

**절차: 역번역 검수**
1. 현지어 원문 → 영어 번역(로컬 AI 또는 구글 번역 오프라인).
2. 영어 → 한국어로 이해.
3. 내가 쓸 답변을 한국어 → 영어 → 현지어로.
4. 그 현지어를 다시 영어로 번역시켜 원래 뜻과 비교. 달라진 줄에 표시.
5. 표시된 줄만 현지 친구에게 확인. 검수 없이 제출하지 않는다.

**프롬프트** `Translate to <현지어>, formal register, for a government office form. Keep numbers and names exactly as given. After the translation, back-translate it to English on a separate line so I can check.`

**개인정보 마스킹** 서류에 있는 이름·여권번호·주소·전화는 AI에 넣기 전에 `[NAME]`, `[PASSPORT]`, `[ADDR]`로 바꾼다. 로컬 AI라도 습관은 같게. 번역 후 원래 값을 손으로 되돌린다.

**자주 쓰는 양식 5종** 비자 연장 신청 사유서, 거주 신고, 은행 계좌, 임대 계약 요약, 학교 입학 서류. 각각 "빈칸 서식 + 예시 문장"을 만들어 USB `양식` 폴더에.

**실습** 가상 임대 계약서(현지어 1쪽)를 절차 1~4로 처리하고 "의심 줄" 표 작성.

**과제** 내가 실제로 받은 서류 1건을 마스킹 후 처리.

## 4차시. 소식지·보고서 자동화

**목표** 월간 소식지와 후원 기관 보고서를 반나절에서 30분으로 줄인다. 그리고 소식지 때문에 누군가 곤란해지지 않게 한다.

**입력은 메모, 출력은 초안** 한 달 동안 메모장에 날짜별 한 줄씩(활동, 만난 사람 역할, 느낀 점, 필요). 이름은 쓰지 않는다. 월말에:
```
아래 한 달 메모로 후원자용 소식지 초안을 써 줘. 구조: 인사 2문장 → 이번 달 이야기 1개(300자) →
소식 3개(각 2문장) → 감사와 요청(3줄) → 다음 달 계획. 따뜻하지만 과장 없이. 이름·지명·단체명은
메모에 있는 그대로 두고 새로 만들지 마. 메모: <<<붙여넣기>>>
```

**보고서** 기관 양식이 있으면 항목명을 그대로 주고 `이 항목 순서대로, 각 항목 3문장 이내로 채워 줘. 숫자는 내가 표시한 것만 사용.` 숫자는 5차시 정산표에서 가져온다.

**익명화 규칙(발송 전 점검표)**
- 현지인은 가명 또는 이름 없이 역할만("이웃 아주머니", "학생 한 명").
- 지명은 국가·도시 대신 지역 수준("동남아 한 마을").
- 사진은 넣지 않거나 얼굴·간판·문패가 없는 것만. 촬영 동의와 공개 동의는 다르다.
- 단체명·기관명·협력 기관명은 쓰지 않는다.
- 현지 정부·제도 비판은 쓰지 않는다.
- 웹·SNS에 올리지 않는다. 이메일은 BCC.

**파일 위생** 문서 → 파일 → 정보 → 문제 확인 → 문서 검사 → 모두 제거(Windows). Mac은 도구 → 문서 검사. PDF로 저장. 사진은 속성에서 위치 정보 제거.

**실습** 가상 메모 20줄 → 소식지 초안 → 익명화 점검표 → PDF. 30분 안에.

**과제** 이번 달 실제 소식지를 이 흐름으로. 발송 전 점검표 6항목 체크.

## 5차시. 경비 정산·가계부

**목표** 영수증 더미를 월 보고표로 만들고, 환율 계산과 항목별 합계는 AI가 짠 함수에 맡긴다.

**시트 구조** 날짜 | 항목(식비/교통/교육/의료/임대/기타) | 현지 통화 금액 | 환율 | 원화 환산(=금액*환율) | 영수증 번호 | 메모. 이름은 넣지 않는다.

**함수 부탁**
```
엑셀 함수 써 줘. C열 현지 통화 금액, D열 환율, E열 원화 환산.
(1) E열 수식 (2) 이번 달 항목별 합계 표 (3) 월 총액과 예산 대비 남은 금액
(4) 예산의 90%를 넘으면 셀이 빨개지는 조건부 서식 방법. 한국어 엑셀 기준.
```
오류가 나면 오류 메시지를 그대로 AI에 보여 준다.

| 단축키 | Windows | Mac |
|---|---|---|
| 합계 | Alt + = | ⌘ + Shift + T |
| 표 만들기 | Ctrl + T | ⌘ + T |
| 필터 | Ctrl + Shift + L | ⌘ + Shift + F |

**영수증 입력** 폰 카메라 텍스트 인식(아이폰 Live Text, 안드로이드 구글 렌즈)은 인터넷 없이도 숫자는 읽는다. 읽은 값은 사람이 확인.

**월 보고표** 4차시 보고서에 붙일 "항목별 합계 + 총액 + 전월 대비" 표를 피벗 테이블로. `피벗 테이블로 항목별 월 합계 만드는 단계를 한국어 엑셀 메뉴 기준으로 알려 줘.`

**실습** 가상 영수증 30건 입력 → 함수 4개 → 피벗 표 → 보고서에 붙이기.

**과제** 이번 달 실제 정산 완료. 영수증 원본은 사진으로 보관하되 파일명에 사람 이름 금지.

## 6차시. 개인정보·기기 안전

**목표** 무엇을 AI에 넣으면 안 되는지, 기기를 어떻게 지키는지, 앱을 어디서 받는지 정한다. 해외 NGO·언론인이 쓰는 표준 수준.

**넣으면 안 되는 것(온라인 AI 기준. 로컬 AI도 습관은 같게)**
- 실명, 전화번호, 주소, 여권·ID 번호, 얼굴 사진
- 함께 일하는 현지인·수혜자·협력 기관의 이름과 위치
- 모임 시간·장소, 이동 계획
- 현지 정부·제도에 대한 평가

**온라인 AI를 쓸 때(도시에서, 일반 정보만)**

| 서비스 | 설정 |
|---|---|
| ChatGPT | 설정 → Data Controls → "Improve the model" 끄기, 민감하면 Temporary Chat |
| Claude | 설정 → Privacy → "Help improve Claude" 끄기 |
| Gemini | Keep Activity 끄기 또는 Temporary Chat. 사람 검토된 대화는 3년 남는다 |
| 현지 국산 AI 앱 | 온라인 사용 안 함. 데이터가 현지 서버에 남는다 |

**기기 규칙 10개**
1. 잠금은 6자리 숫자 대신 12자 이상 문장형 비밀번호.
2. iPhone은 설정 → 개인정보 보호 → 잠금 모드(Lockdown Mode) 켜기. 안드로이드 16은 설정 → 보안 → 고급 보호(Advanced Protection) 켜기.
3. OS·앱 업데이트를 미루지 않는다. 단, 로컬 AI 앱의 업데이트는 한국에서.
4. 앱은 공식 스토어에서만. 채팅방·링크로 온 설치 파일(APK)은 열지 않는다. "번역 앱", "사전 앱"으로 위장한 감시 앱 사례가 있다.
5. 주 계정에 2단계 인증. 문자(SMS) 인증 대신 인증 앱 또는 보안 키. Google은 "고급 보호 프로그램" 가입.
6. 로그인 링크는 메일에서 누르지 않고 주소를 직접 친다. "계정 보안 경고" 메일은 사칭부터 의심.
7. 노트북 전체 암호화 확인(Windows BitLocker, Mac FileVault).
8. 매일 한 번 재부팅. 장기 미사용 시 자동 재부팅(iOS 18.1+, Android 16) 확인.
9. 국경·검문 전: 클라우드·메일·메신저 로그아웃, 생체 인식 끄기, 전원 완전히 끄기. 기기에 설명할 수 없는 파일을 두지 않는다. "숨김 폴더"는 보호가 아니다.
10. 자녀 기기도 같은 규칙. 게임 채팅·링크가 가장 흔한 입구.

**사고가 났을 때** 기기가 이상하거나 "정부 지원 공격" 경고를 받으면 초기화하지 말고 Access Now 디지털 보안 헬프라인(help@accessnow.org, 24시간, 무료)에 먼저 연락한다.

**실습** 내 폰·노트북에서 규칙 1·2·5·7을 지금 적용. 온라인 AI 계정 설정 변경.

**과제** 가족 기기 전부 점검. 자주 쓰는 사이트 3곳의 2단계 인증을 SMS에서 인증 앱으로.

## 부록. 자녀 학습 도우미(선택 1차시)

홈스쿨 가정용. 로컬 AI에 `You are a patient tutor for a 10-year-old. Subject: fractions. Explain with one example, then give 3 practice questions, then wait for answers and check them.` 과목·학년만 바꾼다. 영어 독해는 2차시 파트너 프롬프트를 아이 수준으로. 채점표는 5차시 엑셀 구조 재사용. 아이 이름·학교명은 넣지 않는다.

## 강사 운영 메모

- 1차시에 인터넷을 끊고 시연. 이후 질문의 절반이 사라진다.
- 50대 이상에게 "쉬워요" 금지. "저도 처음엔 헷갈렸어요".
- 한 사람에게 한 가지 결과물. 6차시를 다 못 해도 단어장과 소식지 하나가 돌아가면 성공.
- 자료는 화면 공유, 배포는 USB 또는 만료 링크. 수강생 명단은 강사만 보관, 종료 후 파기. 세션 녹화 없음.
