# 오프라인 AI 실무 과정 — 영어 교실 · 보건 안내문 · 소상공인 자동화

> v0.1 · 2026-09-06 · 대상: 인터넷이 느리거나 끊기는 지역에서 교육·보건·소규모 사업을 하는 현장 실무자 (컴퓨터 초보 가능, 50대 이상 환영)
> 12차시 · 차시당 90분 · 준비물: 노트북(8GB RAM 이상) 또는 안드로이드폰(6GB RAM 이상), USB 메모리 1개

**이 과정의 약속.** 인터넷 없이 됩니다. 돈 안 듭니다. 개인정보를 밖으로 내보내지 않습니다. 배운 날 바로 씁니다.

**왜 오프라인인가.** 현장은 인터넷이 느리고, 데이터 요금이 비싸고, 학생·환자·손님 정보는 밖으로 나가면 안 됩니다. 이 과정의 AI는 전부 내 기기 안에서만 돕니다. 한국에서 미리 설치해 가면 현지에서는 켜기만 하면 됩니다.

---

## 과정 지도

| 과목 | 차시 | 결과물 |
|---|---|---|
| 0 공통 준비 | 1~2 | 오프라인 AI 키트가 깔린 내 노트북·폰, 개인정보 없는 파일 만드는 습관 |
| 1 오프라인 AI 영어 교실 | 3~6 | 레벨별 수업 자료 세트, 회화 연습 방법, 작문 교정 루틴 |
| 2 보건·위생 안내문 | 7~9 | 쉬운 말 안내문 6종, 현지어 번역 검수 절차, 문답집 |
| 3 소상공인·마을 사업 자동화 | 10~12 | 오프라인 장부, 서식 세트, 원가·가격 계산표 |

각 차시 구조: 도입 10분 → 시연 20분 → 실습 45분 → 정리·과제 15분.

## 0과목. 공통 준비

### 1차시. 오프라인 AI 키트 설치

**목표** 인터넷을 끊어도 대화가 되는 AI를 내 노트북과 폰에 갖춘다.

**용어 한 줄** LLM(엘엘엠)은 "글 잘 쓰는 신입 직원"입니다. 똑똑하지만 가끔 아는 척을 하니 확인은 사람이 합니다. 프롬프트(prompt)는 "부탁하는 말"입니다.

**노트북 (한국에서 미리)**

| 단계 | Windows | Mac |
|---|---|---|
| 설치 | lmstudio.ai에서 Windows용 다운로드 → 실행 | lmstudio.ai에서 Mac(Apple Silicon)용 다운로드 → 응용 프로그램 폴더로 드래그 |
| 모델 받기 | 앱 왼쪽 돋보기 → `gemma-4-e4b` 또는 `qwen3.5-4b` 검색 → Q4 버전 다운로드(약 2.5~3GB) | 동일 |
| 자동 업데이트 끄기 | 설정 → App → "자동 업데이트 확인" 해제 | 동일 |
| 오프라인 확인 | 작업 표시줄 → 비행기 모드 켜기 → 채팅 탭에서 "안녕" 입력 → 답이 오면 성공 | 메뉴 막대 Wi-Fi 끄기 → 동일 |
| 더 확실히 막기(선택) | PowerShell(관리자): `netsh advfirewall firewall add rule name="LMStudio-out" dir=out program="%LOCALAPPDATA%\Programs\LM Studio\LM Studio.exe" action=block` | 시스템 설정 → 네트워크 → 방화벽 → 옵션 → LM Studio "들어오는 연결 차단". 나가는 연결은 Wi-Fi 끄기로 대신 |
| 모델 파일 위치 | `%USERPROFILE%\.lmstudio\models` | `~/.lmstudio/models` |

RAM 8GB면 4B 모델, 16GB면 9B까지. 답이 초당 8~15단어면 정상입니다.

**폰 (안드로이드)**
1. Google AI Edge Gallery(구글 공식) 설치 → Gemma 4 E2B 또는 E4B 다운로드. 플레이스토어가 없으면 GitHub 배포 APK를 한국에서 받아 둔다.
2. 대안: PocketPal AI(오픈소스) → 모델 목록에서 `Qwen3.5-2B` 또는 `Gemma-4-E2B` 다운로드.
3. 비행기 모드 → 대화 테스트.
4. 구글 번역 앱 → 오프라인 번역 → 영어·현지어 팩 다운로드(언어별 30~90MB).

**실습** 비행기 모드에서 "내 이름은 ○○이고 영어 선생님이야. 자기소개 3문장 써 줘"를 한국어·영어로 각각 시켜 본다.

**막히는 곳** 모델이 안 뜨면 RAM 부족 → 더 작은 모델(2B). 답이 영어로만 오면 "한국어로 답해 줘"를 첫 줄에.

**과제** 모델 2개(4B, 2B)를 USB에 백업. 현지에서는 다운로드가 어렵습니다.

### 2차시. 개인정보 없는 파일 만들기

**목표** 학생·환자·손님 이름이 든 파일을 AI에 넣지 않고도 일하는 습관을 만든다. 남에게 주는 파일에서 내 정보를 지운다.

**원칙 3개**
1. AI에 넣기 전에 이름·전화·주소를 "학생A", "010-XXXX"로 바꾼다. 로컬 AI라도 습관은 같게.
2. 남에게 주는 문서·사진은 작성자·위치 정보를 지운다.
3. 원본은 한 곳(USB), 작업본은 따로.

**메타데이터 제거**

| 대상 | Windows | Mac |
|---|---|---|
| 워드·파워포인트·엑셀 | 파일 → 정보 → 문제 확인 → 문서 검사 → 모두 제거 | 도구 → 문서 검사 (또는 검토 → 문서 보호 → 저장 시 개인 정보 제거) |
| 사진 | 파일 우클릭 → 속성 → 자세히 → "속성 및 개인 정보 제거" | 사진 앱 → 파일 → 내보내기 → "위치 정보 포함" 해제 |
| PDF | 새 워드 문서에 내용만 붙여넣기 → 문서 검사 → PDF로 저장 | 동일 |
| 화면 캡처 | 계정명·시간·알림이 보이는 상단은 잘라낸다 | 동일 |

**실습** 가상 학생 명단(엑셀 12명)을 받아 이름을 학생A~L로 바꾼 사본을 만들고, 원본 엑셀의 작성자 정보를 지운다.

**과제** 내 노트북의 로그인 비밀번호를 6자리 숫자에서 12자 이상 문장형으로 바꾼다. 예: `아침에커피두잔2026!`

## 1과목. 오프라인 AI 영어 교실

### 3차시. 레벨별 수업 자료 한 번에 만들기

**목표** 초급·중급 학생용 대화문·어휘 카드·빈칸 문제를 10분 안에 뽑는다.

**프롬프트 뼈대(영어로 시키면 영어 자료 품질이 좋습니다)**
```
You are an English teacher for adult beginners in Southeast Asia.
Topic: at the market (buying vegetables)
Make: (1) a 8-line dialogue A/B, (2) 10 vocabulary words with simple meanings,
(3) 5 fill-in-the-blank questions from the dialogue, (4) answer key.
Level: CEFR A1. Use short sentences. No idioms.
```
한국어 뜻이 필요하면 마지막 줄에 `Add Korean meaning for each word.`

**변주** 주제만 바꾼다: 병원 접수, 오토바이 수리점, 게스트하우스 체크인, 학교 첫날, 전화 받기. 레벨은 A1 → A2 → B1.

**실습** 주제 3개 × 레벨 2개 = 6세트를 만들어 워드로 정리. 각 세트 제목 형식: `주제_레벨_날짜`.

**품질 확인** AI가 만든 문장을 소리 내 읽어 본다. 어색하면 "Make it more natural for spoken English"로 재요청. 문화적으로 안 맞는 예시(눈, 지하철)는 현지 것으로 바꿔 달라고 한다.

**과제** 내 학생 수준에 맞는 주제 5개 목록 작성.

### 4차시. 회화 연습 파트너 만들기

**목표** 학생이 AI와 역할극으로 말하기 연습을 하게 한다. 강사가 없는 시간에도 연습이 되게.

**설정 프롬프트(한 번 붙여넣고 대화 시작)**
```
Role-play. You are a shopkeeper. I am a customer learning English (A1).
Rules: reply in 1-2 short sentences; if I make a grammar mistake, first reply
naturally, then add one line "Better: ..." with the corrected sentence.
Start by greeting me.
```

**발음·듣기** 폰 구글 번역 오프라인 팩의 스피커 아이콘으로 문장을 들려준다. 학생이 따라 말하고, 마이크 입력으로 인식되는지 본다(오프라인 음성 인식은 언어 팩에 따라 지원이 다름 → 사전 확인).

**실습** 2인 1조. 한 명은 학생 역할로 AI와 5분 역할극, 한 명은 "Better:" 줄만 모아 오답 노트 작성.

**막히는 곳** AI가 길게 말하면 규칙 줄에 `Maximum 15 words per reply` 추가. 학생이 뭘 말할지 모르면 `Give me 3 things I could say next` 요청.

**과제** 역할 5개(가게·병원·학교·교통·전화) 설정 프롬프트를 메모장에 저장해 학생에게 나눠 준다.

### 5차시. 작문 교정과 오류 패턴 찾기

**목표** 학생 작문 20편을 하루 안에 교정하고, 반 전체의 공통 오류를 뽑는다.

**교정 프롬프트**
```
Correct this A2 student's writing. Output a table with 3 columns:
original sentence | corrected sentence | one-word error type (article/tense/word order/spelling).
Do not rewrite the whole text. Keep the student's meaning.
Text: <<<여기에 붙여넣기>>>
```

**공통 오류 집계** 학생 20명 결과표를 한 파일에 모아 넣고:
```
Here are error tables from 20 students. List the 5 most common error types
with counts and one example each. Then suggest one 10-minute activity per error type.
```

**실습** 가상 작문 5편(이름 없음)으로 교정표 → 집계 → 다음 수업 활동 1개 설계.

**개인정보** 학생 이름은 파일에 넣지 않는다. 학생1, 학생2로.

**과제** 실제 수업 작문을 익명 처리해 교정 루틴 1회 실행.

### 6차시. 시험지·평가표·학부모 안내 자동화

**목표** 단원 시험지, 채점 기준표, 성적 안내문을 서식화한다.

**시험지** `Make a 20-question test for Unit: <주제>, A1, mixed: 8 vocabulary, 8 grammar, 4 short answer. Then give the answer key separately.`

**평가표(루브릭)** `Make a 4-level speaking rubric (fluency, accuracy, vocabulary, interaction), 1-4 points each, one sentence per level.`

**안내문** 성적표 문구는 학생 이름 없이 서식만 만든 뒤 워드 "편지 병합(메일 머지)"으로 이름을 붙인다. AI에는 이름이 가지 않는다.

| 편지 병합 | Windows Word | Mac Word |
|---|---|---|
| 위치 | 편지 → 편지 병합 시작 → 편지 → 받는 사람 선택(엑셀) | 우편물 → 편지 병합 관리자 → 문서 유형 → 받는 사람 목록(엑셀) |

**실습** 단원 1개 시험지 + 답안 + 루브릭 + 안내문 서식 완성.

**과제** 1과목 산출물을 폴더 하나로 정리: 자료 6세트, 역할극 5개, 교정 루틴, 시험 세트.

## 2과목. 보건·위생 안내문

**전제** 의학 정보는 AI가 틀릴 수 있습니다. 내용의 출처는 WHO·현지 보건부·한국 질병관리청 공개 자료로 하고, AI는 "쉬운 말로 바꾸기·구조 잡기·번역 초안"만 맡깁니다. 최종 검토는 보건 전문가 또는 현지 보건소.

### 7차시. 쉬운 말 안내문 6종

**목표** 손씻기, 물 끓여 마시기, 뎅기열 모기 예방, 설사 시 수분 보충(ORS), 상처 소독, 임산부 영양 — 6개 주제를 초등 3학년 수준 문장으로.

**프롬프트**
```
아래 공식 자료 내용을 초등학교 3학년이 읽을 수 있는 한국어로 다시 써 줘.
규칙: 한 문장 12단어 이내, 전문용어는 쉬운 말로 바꾸고 괄호에 원래 용어,
"하세요/하지 마세요" 형식, 항목은 5개 이하, 마지막에 "이럴 땐 보건소로" 한 줄.
자료: <<<WHO/보건부 원문 붙여넣기>>>
```

**검토 체크** 원문에 없는 내용이 들어갔는가 → 있으면 삭제. 숫자(끓이는 시간, 용량)는 원문과 대조.

**실습** 6개 주제 중 3개 완성. 각 안내문 아래 "출처: ○○, ○○년" 표기.

**과제** 나머지 3개 완성.

### 8차시. 현지어 번역 초안과 검수 절차

**목표** 안내문을 현지어로 옮기되, 잘못 번역된 채 배포되는 일을 막는 절차를 익힌다.

**절차**
1. 한국어 안내문 → 로컬 AI로 영어 번역 (`Translate to simple English, keep the structure`).
2. 영어 → 현지어: 구글 번역 오프라인 팩 + 로컬 AI 두 가지로 각각 번역.
3. **역번역**: 현지어 결과를 다시 영어로 번역시켜 원문과 비교. 뜻이 달라진 줄에 표시.
4. 현지어 화자에게 표시된 줄 중심으로 검수 요청. 검수 없이는 인쇄하지 않는다.
5. 검수자 이름은 문서에 넣지 않는다.

**로컬 AI 번역 품질** 라오어·크메르어 등은 소형 모델의 품질이 검증되지 않았습니다. 초안 용도로만 쓰고, 두 번역이 다르면 현지 화자 판정을 따릅니다.

**실습** 손씻기 안내문 1개를 절차 1~3까지 진행하고 "의심 줄" 표를 만든다.

**과제** 현지 화자 검수 1회 진행 후 수정본 저장.

### 9차시. 문답집과 텍스트 포스터

**목표** 마을 보건 봉사자가 받는 질문 20개에 대한 답을 준비하고, 그림 없이도 읽히는 포스터를 만든다.

**문답집** `아래 안내문 6개를 바탕으로 마을 주민이 물어볼 만한 질문 20개와 짧은 답(2문장)을 만들어 줘. 답에 없는 내용은 "보건소에 물어보세요"로.`

**텍스트 포스터** 워드 A4 세로, 제목 36pt, 본문 20pt, 항목 5개, 흑백 인쇄 기준. AI 생성 이미지는 쓰지 않는다(품질·추적 표식 문제). 필요한 그림은 손그림 또는 공공 픽토그램.

**실습** 문답집 20개 + 포스터 2장.

**과제** 포스터를 흑백으로 인쇄해 가독성 확인. 3m 거리에서 제목이 읽혀야 함.

## 3과목. 소상공인·마을 사업 자동화

### 10차시. 오프라인 장부 — 수입·지출·재고

**목표** 엑셀(또는 무료 LibreOffice Calc) 하나로 장부를 만들고, 함수는 AI에게 시킨다.

**시트 구조** 날짜 | 구분(수입/지출) | 항목 | 금액 | 메모. 재고 시트: 품목 | 입고 | 출고 | 현재고.

**함수 부탁하기**
```
엑셀 함수를 만들어 줘. A열 날짜, B열 구분(수입/지출), D열 금액.
(1) 이번 달 수입 합계 (2) 이번 달 지출 합계 (3) 항목별 지출 합계 표
(4) 현재고가 5 이하인 품목만 표시하는 조건부 서식 방법. 한국어 엑셀 기준.
```
답을 붙여넣고 안 되면 오류 메시지를 그대로 AI에 보여 준다.

| 단축키 | Windows | Mac |
|---|---|---|
| 합계 자동 | Alt + = | ⌘ + Shift + T |
| 표로 만들기 | Ctrl + T | ⌘ + T |
| 필터 | Ctrl + Shift + L | ⌘ + Shift + F |

**실습** 가상 카페 한 달 거래 40건을 입력하고 월 요약표 완성.

**과제** 실제 장부 1주일분 입력. 손님 이름은 넣지 않는다(항목만).

### 11차시. 서식 세트 — 가격표·안내문·영수증·문자

**목표** 매일 손으로 쓰던 것을 서식 하나로 끝낸다.

- **가격표** `카페 메뉴 12개 가격표를 A4 한 장, 3열, 큰 글씨로 만들 워드 표 구조를 제안해 줘.`
- **영업 안내문** `영업시간 변경 안내문을 정중하고 짧게 3가지 톤(격식·친근·최소)으로.`
- **영수증** 엑셀 서식: 번호 | 품목 | 수량 | 단가 | 금액(=수량*단가) | 합계.
- **손님 문자 3종** 예약 확인, 주문 준비 완료, 재방문 감사. `각 60자 이내, 이모지 없이, 이름 자리는 {이름}으로 비워 둬.`

**실습** 4종 서식 완성 후 USB에 `서식` 폴더로 저장.

**과제** 이번 주 실제 문자 3건을 서식으로 보내 보고 반응 메모.

### 12차시. 원가·가격 계산과 한 장 사업계획

**목표** "이 메뉴 팔면 남나?"를 숫자로 답한다.

**원가표** 메뉴 | 재료비 | 인건비 배분 | 기타 | 원가 합계 | 판매가 | 마진율(=(판매가-원가)/판매가).
`위 표 구조로 엑셀 함수 써 줘. 마진율 30% 미만인 행은 빨갛게 표시하는 조건부 서식도.`

**손익분기** `월 고정비 ○○, 메뉴 평균 마진 ○○일 때 하루 몇 개 팔아야 본전인지 계산식과 답을 보여 줘.`

**한 장 사업계획** 제목 | 누구에게 | 무엇을 | 얼마에 | 월 고정비 | 하루 목표 판매 | 첫 달 할 일 5개. AI에는 구조와 질문만 시키고 숫자는 내가 넣는다.

**실습** 가상 카페 메뉴 12개 원가표 + 손익분기 + 사업계획 한 장.

**수료 산출물 점검** 0과목 키트 + 1과목 폴더 + 2과목 안내문 6·문답 20·포스터 2 + 3과목 장부·서식 4·원가표·사업계획. 전부 USB 한 개에.
