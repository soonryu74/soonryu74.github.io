## 2. 제품 설계: 심사위원에게 보여줄 90초 시연
1. **문제(10초)**: 같은 인구 규모라도 체육시설 접근 기회는 다르다. 대상은 지자체 체육정책 담당자와 시설 운영자.
2. **지역 선택(15초)**: 지도에서 비교 가능한 지역을 선택, 데이터 기준연도와 시설 범위 표시.
3. **격차 진단(20초)**: 시설 공급량, 접근거리, 고령자 비중 등 검증된 지표 비교.
4. **예산 시뮬레이션(20초)**: 예산·시설유형 선택 → 우선 후보지역 순위 변화와 계산 근거.
5. **의사결정(15초)**: 추천 위치가 아니라 우선 검토 지역 및 사업유형 3건, 데이터 불확실성 표시.
6. **마무리(10초)**: 도입 대상, 향후 시설 운영 데이터와 연계 계획(실제 도입 실적 아님).

## 3. 데이터 검증 및 제한
- 후보 출처: 공공데이터포털(data.go.kr), 문화체육관광부/국민체육진흥공단 공공체육시설 현황, KOSIS 인구, 지자체 개방데이터, 국토정보플랫폼 경계. **실제 존재하는 데이터셋의 URL·라이선스·컬럼을 개발 시 직접 검증**.
- 스포츠시설 종류(공공/민간), 폐업/중복, 좌표계, 지역코드·연도 불일치, 인구 분모 오류 확인.
- '운동참여율'은 별도 설문 근거가 없으면 추정하지 말 것.
- 장애인 접근성은 단순 시설거리만으로 평가할 수 없음. 무장애 시설 정보가 없다면 접근성 주장 제한.
- GIS 경로 기반 이동시간 데이터가 없다면 거리 기반 대리지표라고 명시.
