## 2. Part 1 — 강사: 강의 자료를 보안을 염두에 두고 만드는 법

### 2-1. 자료를 세 층으로 분리한다

| 층 | 내용 | 형태 | 국경에서 발견되면 |
|---|---|---|---|
| A 범용 AI 스킬 | 엑셀 자동화, 문서 정리, 언어 학습, 로컬 LLM 설치, 메타데이터 제거, 계정 보안 | 파일 배포 가능. 종교 용어 0, 사례는 카페·물류·교육 | "일반 직장인 AI 강의" |
| B 사역 적용 | A를 성경 공부·현지어 말씀 자료·관계 사역에 어떻게 쓰는가 | **파일 없음. 말로만.** 슬라이드에 남기지 않음 | 없음 |
| C 보안 수칙 | 이 문서의 3장 | 세션 중 화면 공유만. 배포 시 만료 링크 + "현지 반입 금지" 명시 | "디지털 보안 교육"(인권단체 공개 자료 수준) |

원칙: **파일은 국경을 넘고 압수당한다고 가정하고 만든다.** A층은 노모어매뉴얼 공개 콘텐츠와 같은 품질·같은 내용이어야 하고, 그래야 수강생이 "AI 업무 강의 들었다"고 사실대로 말할 수 있다. B층을 파일로 만드는 순간 A층까지 오염된다.

### 2-2. 콘텐츠 규칙

1. 실명·지명·단체명·교회명 금지. 사례는 국가·연도·인물을 바꾸거나 합성한다. 실제 사건은 공개 보도 범위만.
2. 예제 데이터에 성경 구절·찬양 가사·기도문을 넣지 않는다. 엑셀 예제는 매출표, 문서 예제는 회의록.
3. 스크린샷은 계정명·이메일·시간대·알림·브라우저 프로필 아이콘·탭을 가린다. 강의용 별도 OS 계정을 만들어 찍는다.
4. 대체어 표(God→아버지, Bible→책/말씀, 선교사→worker, 전도→활동)는 선교단체 관행이지만, First Alliance 지침은 **"암호화·코드로 쓰지 말라, 오히려 주목을 끈다"**고 경고한다. 대체어는 뉴스레터용이지 강의 자료 위장용이 아니다. 강의 자료는 대체어가 필요 없을 만큼 범용이어야 한다.
5. AI가 만든 문구·이미지는 추적 표식이 남는다. Office는 "AI 지원 기능 데이터" 메타데이터, Gemini·ChatGPT 이미지는 SynthID(스크린샷·재압축에도 생존). 자료용 이미지는 로컬 생성이나 직접 제작.

### 2-3. 파일 위생 — 배포 전 반드시

| 항목 | Windows | Mac |
|---|---|---|
| Office 문서 개인정보 | 파일 → 정보 → 문제 확인 → 문서 검사 → 모두 제거 | 도구 → 문서 검사, 또는 검토 → 문서 보호 → "저장 시 개인 정보 제거" |
| 사진 EXIF (GUI) | 속성 → 자세히 → "속성 및 개인 정보 제거" | 사진 앱 → 내보내기 → "위치 정보 포함" 해제 (미리보기는 불완전) |

| PDF | `exiftool -all:all= 입력.pdf -o 중간.pdf` → `qpdf --linearize 중간.pdf 최종.pdf` | 동일 (`brew install exiftool qpdf`) |
| docx 잔여 항목 | mat2 네이티브 지원 제한. 새 문서에 내용만 붙여넣기 | `pipx install mat2` → `mat2 문서.docx` |

| 인쇄물 | 컬러 레이저는 추적점(MIC)을 찍는다고 가정. 흑백 프린터 또는 화면 공유 | 동일 |

exiftool은 원본을 `_original`로 남기므로 함께 삭제한다.

### 2-4. 배포

- 최선은 배포하지 않는 것. 세션 중 화면 공유로만.
- 배포해야 하면: 개별 초대 + 뷰어 권한 + 다운로드·복사 금지 + 만료(7~30일). "링크가 있는 모든 사용자" 금지. 링크가 게시판·SNS·다른 문서에 한 번 올라가면 검색엔진이 색인한다(2026.8 사례).
- 협력자를 이메일로 초대하면 그 이메일이 공유 목록·버전 기록·댓글에 남는다. 최종본은 "사본 만들기"가 아니라 **새 문서에 값만 붙여넣기**로 이력을 끊는다.
- 가장 민감한 자료(C층)는 클라우드 없이 암호화 파일(7z AES-256 또는 VeraCrypt)로, 비밀번호는 다른 채널로.
- 수강생 안내문에 명시: "개인 기기·클라우드에 저장하지 말 것, 현지에 반입하지 말 것, 참석 사실을 SNS·이력서·후원 편지에 쓰지 말 것."

### 2-5. 세션 운영 (온라인·오프라인 공통)

1. 녹화·녹음·자동 자막·AI 회의록 전부 끈다. Zoom AI Companion은 2026.1부터 켜면 전원 동의가 강제된다. Google Meet "Gemini로 메모"는 주최자 Drive에 **무기한** 저장되고 캘린더 초대자에게 공유될 수 있다. Otter 등 외부 노트봇은 집단소송 중이며 대기실에서 차단.
2. 참가자 표시 이름을 호스트가 입장 전 일괄 변경. 실명·소속·국가를 이름·자기소개에 쓰지 않는다. 카메라는 선택, 배경 흐림 기본.
3. 1회용 링크 + 비밀번호 + 대기실. 링크를 단체방·SNS에 올리지 않는다.
4. 참가자끼리 소속·사역지를 묻지 않는다는 규칙을 시작 시 낭독(Chatham House Rule 변형). Concilium 원칙: 모르면 누설할 수 없다.
5. 질문은 식별 정보를 받지 않는 익명 폼. 채팅 기록은 종료 시 삭제.
6. 강사 기기: 단일 창 공유, 알림 끄기, 바탕화면 정리, 강의 전용 OS 계정.
7. 통역·조교도 같은 규칙에 사전 동의.
8. 플랫폼은 참가자 거주국에서 합법인지 먼저 확인. 금지된 플랫폼 사용 흔적 자체가 위험.
9. 세션 후 강사는 개별 연락하지 않는다. 참가자가 먼저 연락하는 구조로, 창구 하나만.
10. 오프라인 세션: 회의실에 폰 반입 금지 관행(Open Doors 서방 직원도 민감 회의에 폰을 밖에 둔다). 출석부·명찰 없음.

### 2-6. 강사 본인이 단일 실패점이다

강사 계정 하나가 뚫리면 수강생 전원이 노출된다. 다른 어떤 조치보다 먼저.

- 주 계정을 Google Advanced Protection(2026 현재 패스키 1개로 가입 가능)에 등록. 하드웨어 키 2개(1개는 별도 보관). SMS 2단계 인증·복구 전화번호 제거.
- 강의 전용 계정·전용 브라우저 프로필. 노모어매뉴얼 유튜브·사업 계정과 분리.
- 수강생 명단은 이메일·메신저·구글 폼에 남기지 않는다. 오프라인 암호화 파일 한 곳, 종료 후 파기. 등록 폼은 수업 후 응답 삭제. 발송은 BCC만.
- 강의 홍보: **공개 채널에 "선교사 대상"이라고 쓰지 않는다.** 강사 = 선교사 훈련자라는 공개 연결이 수강생 특정의 출발점이다(IMB: 비자 데이터 + AI 검색으로 신학 학위·과거 비자를 연결).
- 사칭 피싱: "○○선교회입니다, 자료 공유드립니다" 링크는 전화로 확인 후 연다. Google Drive 링크 → 비밀번호 걸린 압축 파일은 2025 Citizen Lab이 기록한 공격 패턴.
- 강의 준비에 클라우드 AI를 써도 되는 범위: A층(범용)은 무방. B·C층 초안, 수강생 관련 내용, 사역지 정보는 로컬 LLM에서만.

## 3. Part 2 — 선교사: 배운 것을 현지에서 안전하게 활용하는 법

### 3-1. 대원칙 다섯

1. **폰에 없으면 줄 것도 없다.** 현지인 연락처·사진·대화·종교 파일을 외국인 기기에 두지 않는다. 필요한 것은 기억하거나 가명으로 종이에.
2. **은닉보다 평범함.** 볼트 앱·숨김 앨범·이름 바꾼 파일은 포렌식에 그대로 드러나고, 발각 시 은폐 자체가 가중 사유가 된다. 완전히 빈 기기도 의심을 산다. "평범한 여행자 수준의 사진·앱"이 자연스럽다.
3. **온라인은 집회다.** 게시·재게시·채팅방 개설·온라인 예배 참석이 기소 근거다. 텍스트는 자동 감시된다.
4. **삭제는 복구된다.** 사라지는 메시지는 "애초에 남기지 않는" 도구이지 사후 삭제 도구가 아니다.
5. **현지인이 기준.** 외국인은 추방으로 끝나지만 현지인은 징역이다. 단기팀·방문자를 핵심 현지인에게 소개하지 않는다.

### 3-3. 계정·통신

- **계정**: Advanced Protection + 패스키/하드웨어 키. SMS 2FA 제거. 현지에서 만든 계정(실명 SIM·안면인식 연동)은 익명이 아니다.
- **메신저**: 조직 소통은 Signal(사용자명으로 번호 노출 없이, 사라지는 메시지 1주 이하 기본, 설정 → 개인정보 → 고급 → 검열 우회). 러시아·이란·베네수엘라는 차단 중이므로 **그 나라에서 Signal 사용 흔적이 합법인지 먼저 확인**. Telegram 일반 채팅은 종단간 암호화가 아니고 2025년 1분기에만 22,777명 정보를 당국에 제공했다. WhatsApp은 내용은 암호화되나 누가·언제·누구와가 Meta에 남는다. 인터넷 차단 대비 Briar(블루투스·Wi-Fi P2P) 또는 SimpleX(식별자 없음)를 미리 설치·테스트.
- **VPN**: 법적 지위 표(1-1) 확인. 러시아·이란·투르크메니스탄에서는 VPN 자체가 처벌 대상. 우회 계정(실명·결제·전화번호 연결)은 IP 기록 한 번으로 정지되고 위치를 드러낸다.
- **코드워드**: 보조 수단. 과도한 암호는 주목을 끈다. 평범한 언어로 평범한 삶을 쓴다.

### 3-4. AI 활용의 안전한 형태

**핵심: 사역과 관련된 것은 오프라인 로컬 AI에서만, 클라우드 AI에는 사람·장소·교회를 특정할 수 있는 정보를 절대 넣지 않는다.**

| 구분 | 도구 | 비고 |
|---|---|---|
| PC | LM Studio(GUI, 텔레메트리 없음 공식), Ollama(`-cloud` 모델 금지, 로컬 전용 모드), Jan(오픈소스, 대화가 로컬 JSON) | 모두 llama.cpp 기반, GGUF 호환 |
| 폰 | PocketPal AI(오픈소스, 전부 기기 내), Google AI Edge Gallery(Gemma 4 E2B/E4B, 인터넷 불필요, GitHub APK) | 4GB RAM 폰은 1~2B, 6~8GB는 2~4B |
| 모델 | Gemma 4 E4B/12B(140개 언어), Qwen 3.5 4B/9B(201개 언어 표기) | 한국어·중국어·아랍어는 기본 지원. **페르시아어·우즈베크어 등 저자원 언어 품질은 미확인 → 모어 화자 검수 필수** |
| 사양 | 8GB 노트북: 3~4B(Q4 약 2.5~3GB). 16GB: 7~9B | CPU만으로 7B는 초당 8~15토큰 |

도입 절차:
1. **안전한 지역(한국)에서** 앱과 모델을 미리 받는다. 현지에서 Hugging Face·GitHub 접속 자체가 흔적이다.
2. 비행기 모드 또는 방화벽으로 실행 파일의 아웃바운드를 막고 대화가 되는지 테스트한다. "오프라인"은 "받은 뒤 끊어도 동작한다"이지 "절대 안 나간다"가 아니다. LM Studio는 업데이트 확인 시 IP·기기 정보를 보낸다고 명시하므로 자동 업데이트를 끈다.
3. **대화 파일도 증거다.** Jan·LM Studio·Ollama 모두 로컬에 대화를 저장한다. 전체 디스크 암호화 + 대화 자동 삭제 습관. 폰 앱도 마찬가지.
4. 로컬 AI로 안전하게 할 수 있는 일: 현지어 학습 파트너, 문서·회의록 정리, 번역 비교, 개인 성경 공부 노트 초안(오프라인, 기기에 남기지 않음), 텐트메이킹 본업(업무 자동화)의 실제 성과.
5. 클라우드 AI를 써야 할 때: 학습 옵트아웃 + 임시 채팅 + 조직/Enterprise 계정, 그리고 A층 내용만. 무료·개인 계정에 사역 내용 금지.
6. **현지 국산 AI(DeepSeek·Qwen 앱·Doubao 등)는 온라인으로 쓰지 않는다.** DeepSeek 정책(2026.2)은 모든 대화를 중국 내 서버에 저장한다고 명시하고 정부 접근이 법적으로 가능하다. 오픈 가중치 모델을 오프라인으로 돌리는 것은 별개로 안전하다.
7. 번역·전사(Whisper)는 없는 말을 지어낸다(전사의 약 1%에 허구 문장, 그중 38%가 유해 내용). 성경 번역·검토는 SIL Scripture Forge·AQuA 같은 전문 도구와 모어 화자·번역 컨설턴트 검수 없이 쓰지 않는다. 범용 LLM은 용어 일관성 확인·역번역 비교까지만.
8. AI 생성 이미지·문서는 추적 표식(SynthID·C2PA·Office AI 메타데이터)이 남는다. 현지 배포물은 로컬 생성·직접 제작.

### 3-5. 말씀을 전하는 방식의 보안 비교

말씀 내용은 이 문서 범위가 아니다. 매체별 "발견되면 누가 어떤 처벌을 받는가"만 정리한다.

| 방식 | 장점 | 발견 시 위험 | 판정 |
|---|---|---|---|
| 구술(Orality, 이야기) | 발견될 물건이 없다. SIL·Seed Company가 인쇄 배포 불가 지역 표준으로 권장 | 녹음하는 순간 오디오와 같아짐 | 가장 안전 |
| 전용 오디오 기기(MegaVoice 등) | 계정·인터넷 불필요, 폰과 분리 → 연락망 노출 없음 | 기기 자체가 변명 불가 증거. 중국은 판매 시 최대 6년형 | 개인 위험 큼, 조직 위험 작음 |
| USB·microSD | 은닉 쉬움 | 소지·판매 자체 처벌(북한·중국) | 개인 위험 큼 |
| 오프라인 성경 앱(SIL Scripture App Builder 등) | 파일 암호화, 블루투스 전달 | 설치 자체가 폰에 남는 증거. 해시 대조 자동 탐지 | 폰이라서 위험 |
| 일반 성경 앱(YouVersion) | 흔함 | 폰 검사 시 즉시 노출. 카자흐스탄에서 설치 도운 행위가 기소됨 | 폰이라서 위험 |
| 폰 속 파일·채팅 | 편리 | **폰은 연락처·채팅·위치까지 함께 넘어간다. 파일 하나가 조직 전체의 열쇠** | 가장 위험 |

원칙: 개인 위험은 오디오 기기·SD가 크고, **조직 위험은 폰이 압도적**이다. 성경·찬양·설교 파일은 폰이 아닌 분리 매체에, 폰에는 현지에서 합법이고 설명 가능한 것만.

텐트메이킹과 결합: AI로 얻은 실제 업무 성과(엑셀 자동화, 언어 능력)가 체류 명분의 실체가 된다. 적자 사업은 위장으로 의심받고 흑자 사업은 이웃이 된다(BAM 경험자 공통 증언).

### 3-6. 흔적 관리 — SNS·뉴스레터·검색

- first name 또는 가명, 국가명 대신 지역명, 단체명·교회명·현지 파트너명 없음, 전자 매체 사진 없음(인쇄물만 제한적), BCC 발송, 웹 게시 금지, 실시간 스트리밍에 노출되면 중단.
- 현지 신자의 사진·간증·이름은 본인이 위험을 이해하고 자유롭게 동의한 경우에만, 그것도 가명·얼굴 처리로. **촬영 동의는 공개 동의가 아니다**(Bond·MSF 기준).
- 출국 전과 분기마다 자기 이름·이메일·사진을 검색해 선교 관련 노출을 정리. IMB(2026): "무해해 보이던 사진·목소리로도 AI가 신원을 특정한다."
- **온라인 신학 과정 수강·해외 훈련 참석·온라인 예배 참석 기록은 이란에서 혐의가 됐다.** 이 강의 참석 사실도 같다.
- 현지 지인용 SNS 계정은 후원자용과 분리. 친구 목록 비공개. 위치 태그 해제.

### 3-7. 구금·압수 상황

1. 거짓말하지 않는다(범죄). 묻지 않은 것을 먼저 말하지 않는다.
2. 비밀번호는 말하지 말고 "직접 입력하겠다"고 요청. 요원 이름·시간·장비 기록, 압수 영수증 요구.
3. 원격 삭제(Find My, Find Hub)는 압수 즉시 패러데이 백에 들어가면 작동하지 않는다. **계획이 아니라 마지막 수단.** 사전 최소화만이 실효 조치.
4. 되돌려받은 기기는 초기화하지 말고 Access Now 디지털 보안 헬프라인(24시간, help@accessnow.org)이나 Amnesty Security Lab에 포렌식 상담 후 처리. 초기화하면 증거가 사라진다.
5. 연락 순서(가족 → 단체 보안 담당 → 변호사 → 대사관)와 번호를 **기기 밖에** 두고 팀 전원이 같은 절차를 안다. IMB는 24시간 보안센터·10분 간격 위치 신호를 운영한다.
6. 심문 중 이름을 말하지 않으려면 애초에 몰라야 한다(3-1 원칙 5).

### 3-8. 현지인 보호 — 처벌 격차

| 국가 | 외국인 | 현지인 |
|---|---|---|
| 카자흐스탄 | 벌금 + 추방(2025.3부터 자동) | 벌금, 반복 시 형사 |
| 중국 | 벌금·추방·기소 가능 | 시온교회 18명 최대 3년형, 티베트 해외 연락 최대 20년 |
| 이란 | 2025 사례 미확인 | 개종자 8~15년형 |
| 인도 | 비자 제한 | 목회자 5년형, 주법 최대 종신 |
| 튀르키예·네팔·사우디 | 보안코드·추방(증거 없이) | 목회 공백, 배교 시 사형 가능(사우디) |

외국인의 활동 흔적(연락처·채팅·송금·사진)이 현지인 기소의 증거가 된다. 중국 시온교회 기소 논리에 "해외 종교 침투"가 포함됐다.

## 4. 체크리스트

### 강사 (자료 제작·세션 운영) 15

1. 자료를 A(범용)/B(구두)/C(보안) 3층으로 나눴는가. B층 파일이 존재하지 않는가.
2. A층에 종교 용어·성경 텍스트·사역 사례가 0인가.
3. 실명·지명·단체명이 없고 사례가 합성인가.
4. 스크린샷의 계정명·시간·알림·탭을 가렸는가.
5. Office 문서 검사 → PDF 평탄화 → exiftool/qpdf를 거쳤는가. `_original` 파일을 지웠는가.
6. AI 생성 이미지를 쓰지 않았는가(SynthID).
7. 배포는 개별 초대·뷰어·만료인가. "링크 아는 사람" 공유가 없는가.
8. 녹화·자동 자막·AI 회의록·노트봇을 껐는가.
9. 참가자 표시 이름을 바꿨고 서로 소속을 묻지 않는 규칙을 낭독했는가.
10. 명단이 오프라인 암호화 파일 한 곳에만 있고 종료 후 파기 계획이 있는가.
11. 강사 계정이 Advanced Protection + 하드웨어 키이고 SMS 2FA가 없는가.
12. 강의 전용 계정·브라우저 프로필·OS 계정을 쓰는가.
13. 공개 채널에 "선교사 대상"이라고 쓰지 않았는가.
14. 수강생에게 "저장 금지·반입 금지·참석 사실 비공개"를 서면 안내했는가.
15. 사역 관련 초안을 클라우드 AI에 넣지 않았는가.

### 선교사 (현지 실천) 20

1. 여행용 기기 분리, 출발 전 백업 → 초기화 → 최소 적재.
2. Lockdown Mode / Android Advanced Protection 상시.
3. 긴 영숫자 암호, 국경 전 생체 끄기 + 완전 전원 끄기.
4. 72시간 자동 재부팅 확인, 매일 재부팅.
5. FileVault/BitLocker 확인, 복구 키 계정 보호.
6. 공식 스토어 외 설치 금지. 채팅방 APK 금지.
7. 국경 전 클라우드·메일·메신저 로그아웃, "최근 삭제" 비우기.
8. 볼트 앱·숨김 앨범에 기대지 않는다. 둘 수 없는 것은 두지 않는다.
9. 현지인 연락처·사진·대화를 외국인 기기에 두지 않는다.
10. 성경·찬양·설교 파일은 폰이 아닌 분리 매체에.
11. Signal 사용자명 + 사라지는 메시지. 해당국 합법 여부 확인. Telegram 조직 채널 금지.
12. Briar/SimpleX 사전 설치·테스트.
13. VPN·우회 계정의 법적 지위와 IP 기록 위험을 안다.
14. 로컬 AI(앱+모델)를 한국에서 받아 네트워크 차단 테스트 후 반입. 자동 업데이트 끄기.
15. 로컬 AI 대화 파일 자동 삭제 + 디스크 암호화.
16. 클라우드 AI에 사람·장소·교회 특정 정보 금지. 현지 국산 AI 온라인 사용 금지.
17. 번역·전사는 모어 화자 검수 후에만.
18. 뉴스레터·SNS: first name·지역명·사진 없음·BCC·웹 게시 금지. 분기마다 자기 이름 검색.
19. 단기팀·방문자를 핵심 현지인에게 소개하지 않는다.
20. 구금 시 연락 순서를 기기 밖에 두고, 되돌려받은 기기는 초기화 전 헬프라인 상담.

## 5. 정직한 한계

- **기술로 못 막는 것**: 인적 정보원, 심문 중 진술, 제3자 촬영, 동료의 실수. 2026 Concilium 사례는 암호화가 아니라 사람이 무너진 경우다. 보안의 절반은 "누가 무엇을 아는가"를 줄이는 조직 설계다.
- **완벽한 도구는 없다**: Cellebrite는 2026년 "최신 iPhone 접근"을 주장하고(검증 자료 없음), SynthID 우회 연구와 제거 도구가 존재하며, 삭제 30일 원칙에는 예외가 있다. 모든 조치는 확률을 낮출 뿐이다.
- **법은 매년 강화된다**: 2025년 한 해에 중국 2건, 러시아 2건, 인도 2개 주, 카자흐스탄이 개정됐다. 이 문서는 2026.9 기준이며 **분기마다 각 사 정책·현지 법령을 다시 확인**해야 한다. Perplexity는 2026.7 정책 본문에서 약정을 조용히 뺐다.
- **미확인 항목**(원문 참조): 신장 강제 설치 앱의 2025~26 지속 여부, 이란 공항 체계적 검사 실태, 중국 2025 외국인 선교사 개별 추방 사례, 페르시아어·우즈베크어 소형 모델 품질, Anthropic 안전 플래그 예외의 공식 입장, 오디오 기기·블루투스 전달이 직접 적발된 공개 사건, 선교단체의 세션 녹화 금지 명문 규정.
- **이 문서의 위치**: 공개 저장소에 두지 말 것(맨 위 경고).
