## 4. P0 처리 내역

### ✅ P0-01 예시 데이터와 인증 표시 — 완료
- `seed` 배열(가상 인물 3명) **표시 경로에서 완전 제거**. DB 행은 건드리지 않음.
- 조회 실패 시 `loadFailed` 상태 → **오류 안내 + 다시 시도 + 고용24 대안** 표시. 데모 인물 노출 없음.
- `verified` **'인증' 배지 렌더링 제거** — 자격 서류 확인 절차가 실제로 운영되지 않으므로 근거 없는 배지를 붙이지 않음.
- `프리미엄` → **`프리미엄 · 광고`** 로 변경하고 "자격 확인과 무관" 툴팁 추가 → 광고와 확인 배지 분리.
- 모든 카드에 **"본인이 직접 입력한 정보"** 고지 추가.

### 🔶 P0-02 의료서비스와 일상돌봄 분리 — 부분 완료
- 완료: `gujik.html` 강점 선택지에서 **흡인·석션 / 콧줄·위루 제거**, `체위변경·이동 보조`로 대체.
- 완료: 의료행위는 **방문간호·가정간호·방문진료 등 면허 제공기관**을 통해야 한다는 안내 추가.
- **미착수**: `gajok.html` 설문에서 의료·간호 선택 시 개인 구직 목록으로 보내지 않는지 미검증. (§4 P0-02 핵심 항목)

### ❌ P0-03 추천 조건과 제도 안내 — 미착수
`gajok.html` 추천 로직(연령·노인성 질병·지속성 구분, '잘 모르겠어요', 본인부담률 수치 검증) 손대지 않음.

### ✅ P0-04 기관 평가자료와 건수 — 완료
- 건수 표기를 **"평가자료 27,946건"** 으로 정정하고, 기관 수는 **추정치**임을 명시.
- **기관기호가 없어** 동명 기관 병합·분리 위험이 있다는 한계를 화면에 공개.
- **주소·전화가 원자료에 없음**을 명시하고, 연락처는 노인장기요양보험에서 조회하도록 안내. (없는 정보를 있는 것처럼 표시하지 않음)
- 평가연도를 **2021~2025**로 정정.
- **`public.institutions_latest` 뷰 신설** — `(name, type, region, sigungu)` 기준 최신 `eval_year` 1건만 노출. 페이지네이션 **이전에 서버에서** 최신 선택이 끝남. `security_invoker=true`라 기반 테이블 RLS를 그대로 따름.
- 조회 실패 시 **재시도 + 공식 대안** 표시.

### 🔶 P0-05 사전등록·프로필·개인정보 — 부분 완료
- 완료: 곁애 버튼 `사전등록 신청서 만들기` → **`사전등록 접수`**.
- 완료: **서버 성공 확인 후에만** '접수 완료' 표시 (기존에도 그러했음, 상태 표기 강화).
- 완료: `submitting`/`submitted` 플래그로 **이중 클릭·중복 접수 차단**, 성공 후 버튼 `접수 완료`로 잠금.
- 완료: **개인정보 localStorage 백업 제거** — `gyeotae_waitlist`(곁애), `mosim_profiles_local`(모심) 모두 저장 중단 + **기존 키만** `removeItem`. `localStorage.clear()` 미사용(글자크기·고대비 설정 보존).
- 완료: 모심 프로필 저장 실패 시 **로컬에 몰래 쌓지 않고** 실패를 실패로 알림.
