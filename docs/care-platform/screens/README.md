# 화면 캡처 (2026-10-04)

작업 브랜치 `claude/korean-caregiving-portal-0n9kje` 의 파일을 헤드리스 Chromium 으로 렌더링한 것이다.
**운영 배포본이 아니다.** `gh-pages` 에 올라간 라이브 사이트는 아직 이전 버전이다.

실제 개인정보는 들어 있지 않다. `caregivers` 테이블에는 현재 등록 프로필이 없고,
`waitlist` 는 익명 조회가 차단되어 있어 화면에 표시되지 않는다.

## 재현 방법

```
npm i playwright-core
node tests/shot.js
```

브라우저: `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`, 로케일 `ko-KR`.
`05`·`06`·`17` 은 `file://` 로 열어 외부 요청이 실패한 상태다. 따라서 **오류·빈 상태 화면**이 찍혀 있다.
`16`·`18` 은 실제 데이터(16: 운영 공공데이터, 18: 격리 환경 fixture)를 Node 로 중계해 찍었다.
`18` 의 공고는 **격리 환경의 합성 데이터**이며 운영 DB에는 존재하지 않는다.
