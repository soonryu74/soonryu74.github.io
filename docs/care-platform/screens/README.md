# 화면 캡처 (2026-10-04)

작업 브랜치 `claude/korean-caregiving-portal-0n9kje` 의 파일을 헤드리스 Chromium 으로 렌더링한 것이다.
**운영 배포본이 아니다.** `gh-pages` 에 올라간 라이브 사이트는 아직 이전 버전이다.

실제 개인정보는 들어 있지 않다. `caregivers` 테이블에는 현재 등록 프로필이 없고,
`waitlist` 는 익명 조회가 차단되어 있어 화면에 표시되지 않는다.

| 파일 | 화면 | 확인 포인트 |
|---|---|---|
| `01-가족추천-데스크톱.png` | 가족 설문 → 추천 결과 (고령·지속·중증·의료필요·퇴원) | 의료 필요를 **개인 구직 목록이 아닌 제공기관·공식 안내**로 보냄 |
| `02-가족추천-잘모르겠어요.png` | 모든 문항을 '잘 모르겠어요' 로 선택 | 빈 결과가 나오지 않고 공식 상담으로 연결 |
| `03-지역창구-확인된지역.png` | 지역 찾기 — 경기 부천시 | **직접 확인한 창구 + 출처 링크 + 확인일** 표시 |
| `04-지역창구-미확인지역.png` | 지역 찾기 — 전남 목포시 | 확인하지 못한 지역은 **번호를 지어내지 않고** 공식 조회 경로 안내 |
| `05-기관평가.png` | 기관 평가 검색 | '평가자료 27,946건', 평가연도 2021~2025, 기관 수 미제공 |
| `06-구직디렉토리.png` | 돌봄종사자 구직 | 연락처 공개 선택 체크박스, 조회 실패 시 오류·재시도·공식 대안 |
| `07-모심홈.png` | 모심 홈 | 가짜 후기 제거 후 '하는 일 / 하지 않는 일' 로 교체 |
| `08-곁애랜딩.png` | 곁애 랜딩 | **준비 중** 명시, 온라인 접수 비활성 상태 |
| `09`~`12` | 모바일 390px | 도움 버튼 이름 유지, 한 열 배치 |
| `13`,`14` | CSS 뷰포트 195px (390px 기기에서 **200% 확대**) | 가로 스크롤 없음 |

## 재현 방법

```
npm i playwright-core
node shot.js   # 실행 스크립트는 작업 중 임시 디렉터리에 두었다
```

브라우저: `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`, 로케일 `ko-KR`.
`05`·`06` 은 `file://` 로 열어 Supabase 요청이 실패한 상태이므로 **오류 상태 화면**이 함께 찍혀 있다.
