Paperling(페이퍼링) 사업기획안 v0.4

작성 서순려 · 2026-10-25 (v0.2 결정 반영) · 브랜치 claude/ai-note-app-planning-l3fx39 읽기 좋은 버전(기획안): https://claude.ai/artifact/6NR8wRLZencw4M2UTFNc8R

종이에 쓰고, 사진 한 장 찍으면, 예쁘게 정리돼서 내 노션·캘린더에 들어간다.

다이어리 좋아하는 사람은 종이를 버리지 않는다. 그래서 종이를 대체하지 않고, 종이 뒤에 붙는 디지털 서랍을 만든다. 서비스명은 Paperling(페이퍼링): paper + -ling, 종이를 아끼는 사람의 작은 종이 친구. “서랍”은 앱 안 분류 기능의 이름으로 남긴다. 손글씨를 찍어 올리면 AI가 읽고, 다듬고, 서랍(일기·할 일·일정·아이디어)에 자동 분류해 넣는다. 서랍의 생김새(디자인·폰트)는 내 취향대로 고른다.

0. 네 가지 약속 (모든 화면·기능의 합격 기준)

약속 뜻 측정 어기면
예쁘다 열 때마다 기분이 좋아야 한다. 종이 다이어리만큼 테마·폰트 변경률, 공유 카드 생성률, 첫인상 설문 “예쁘다” 80% 이상 디자이너 리뷰 없이 화면 출시 금지
편리하다 사진 올리고 3번 이내 탭으로 끝 업로드→저장 완료 20초 이내, 탭 수 3 이하 탭이 4개 넘으면 화면 다시 설계
쉽다 50대도 설명 없이 쓴다 첫 사용 성공률 90% (도움말 없이), 큰 글씨 모드 설명 문구가 필요하면 화면이 틀린 것
연동된다 쓰던 앱을 버리게 하지 않는다 연동 설정 1분 이내, 2곳 이상 연동 사용자 30% 앱 안에 가두는 기능은 넣지 않는다

네 가지가 충돌하면 순서는 쉽다 → 편리하다 → 예쁘다 → 연동된다. 예쁨을 위해 어렵게 만들지 않고, 연동을 위해 복잡하게 만들지 않는다.

1. 요약

  • 문제: 종이 다이어리 유저는 “쓰는 즐거움”은 있는데 “다시 찾아보기·일정 반영·공유”가 안 된다. 디지털 노트 유저는 반대로 예쁘게 쓰는 즐거움이 없다. 둘 사이가 비어 있다.
  • 해법: 사진 → AI 정리(텍스트화·구조화·날짜/할 일 추출) → 내 노션 자동 저장 → 구글 캘린더에 일정 반영. 사용자 조작은 “찍기 → 확인 → 저장” 3단계로 고정.
  • 차별점 1 고르는 재미: 일반 디자인 라인 + 아티스트 디자인 라인, 한글 손글씨 폰트 선택. MBTI·갤럽 강점 결과로 처음 3세트를 추천하고 언제든 바꿀 수 있게.
  • 차별점 2 연동이 단순: 경쟁 앱은 앱 안에 가두려 한다(굿노트·삼성노트). 우리는 사용자가 이미 쓰는 노션·캘린더로 보내주는 “통로”다. 가둘 필요가 없어 신뢰를 얻는다.
  • 수익: 구독(프로) + 아티스트 디자인 팩 판매(수익 배분) + 연말 손글씨 북 인쇄. 대표님 채널에서는 바이브코딩 제작 과정 자체가 콘텐츠이자 강의 사례가 된다.
  • 첫 검증: 랜딩 + 대기자 모집 2주, MVP(사진→노션) 6주. 디자인·취향 기능은 그 다음.

2. 누구를 위한 것인가

구분 1차 타깃 2차 타깃
누구 종이 다이어리·만년필·스티커를 좋아하는 30~40대 직장인 여성 50대 이상, 손글씨 메모 습관이 있는데 디지털 정리를 포기한 층
지금 하는 행동 다이어리 꾸미기(다꾸), 인스타에 다이어리 사진 업로드, 노션도 “써보려다 멈춤” 메모지·수첩에 쓰고 사진으로 찍어 카톡 ‘나에게 보내기’
불편 쓴 걸 못 찾는다, 일정은 다시 폰에 입력한다, 노션은 예쁘게 세팅하기 어렵다 글씨 입력 자체가 느리고 앱이 복잡하다
우리가 주는 것 종이 그대로 쓰고 사진만 찍으면 정리·연동 끝, 예쁜 디자인 선택 “찍기 → 확인 → 저장” 3단계, 큰 글씨 모드

다이어리 시장은 “기록 도구”가 아니라 취향·정체성 소비 시장이다. 그래서 기능보다 “고르는 재미”가 핵심 지표가 된다. 이 부분은 전자책에!

3. 경쟁·참고 서비스 분석

서비스 핵심 강점 약점(우리 기회) 가격대(2026.10 기준 추정, 확인 필요)
굿노트 6 (아이패드) 필기감 최상, 손글씨 검색·텍스트 변환, 디지털 속지 생태계 아이패드+펜슬 필수, 앱 안에 갇힘, 종이 유저는 대상 아님 연 구독 또는 일회 구매
노타빌리티 녹음+필기 동기화, 수업·회의 특화 디자인·감성 요소 약함, 구독 전환 반발 연 구독
애플 메모 무료, 사진 속 글자 인식(라이브 텍스트) 정리·구조화 없음, 디자인 선택 없음, 외부 연동 약함 무료
삼성 노트 무료, S펜, 필기→텍스트 변환, 윈도우 동기화 삼성 기기 종속, 디자인 획일, 노션·구글 연동 없음 무료
프랭클린 플래너 가치→목표→주간계획 철학, 충성 고객, 속지 사업 모델 디지털 전환이 어색, 사진·AI 없음, 젊은 층 유입 약함 종이 리필 연 3~6만 원대
로켓북 사진 찍으면 클라우드로 전송(우리와 가장 가까운 개념) 전용 노트 필요, 디자인·정리 없음, 한글 손글씨 인식 약함 노트 3~5만 원대 + 앱 무료
노션 사용자가 이미 데이터를 모으는 곳 예쁘게 세팅이 어렵고 사진 메모를 못 읽음 무료/플러스
데이원(Day One) 일기 앱 중 최고 감성, 사진·위치 자동 기록 손글씨 입력 없음, 한국 사용자 적음 연 구독
모트모트·아날로그키퍼 등 국내 플래너 브랜드 디자인·커뮤니티·굿즈 팬덤 앱이 없거나 단순 타이머 수준 종이 1~3만 원대

읽히는 패턴

  1. 아이패드·삼성 계열은 “기기 안에서 다 하기”다. 종이 유저는 처음부터 제외된다.
  2. 로켓북이 “종이→클라우드”를 증명했지만 못생겼고 정리를 안 해준다.
  3. 굿노트 속지 시장과 국내 플래너 브랜드 팬덤이 보여주듯, 디자인은 돈을 낸다.
  4. 프랭클린 플래너의 “철학 있는 양식”은 50대의 신뢰 자산이다. 우리 테마 중 하나로 흡수한다.

→ 종이 뒤에 붙는 예쁜 AI 서랍은 비어 있는 자리다.

4. 제품 정의

4-1. 핵심 흐름 (3단계 고정)

  1. 찍기: 손글씨 메모·다이어리 페이지를 사진으로 찍거나 갤러리에서 올린다. 여러 장 묶음 가능.
  2. 확인: AI가 읽어낸 텍스트와 정리 결과를 보여준다. 오타·오인식은 탭 한 번으로 수정. 원본 사진은 항상 옆에 붙어 있다(신뢰).
  3. 저장: 서랍에 자동 분류되고, 노션·캘린더로 동시에 들어간다.

4-2. 서랍(자동 분류) 5종 + 1

서랍 들어가는 것 자동 처리
일기 하루 기록, 감정 날짜·감정 태그, 월별 모아보기
할 일 체크박스·”~하기” 문장 노션 할 일 DB로, 완료 체크 양방향
일정 “10/28 3시 치과” 같은 날짜+시간 구글 캘린더 이벤트 생성(확인 후)
아이디어 영감, 인용, 떠오른 생각 태그, 비슷한 메모 연결
추억 오래된 손 다이어리·육아 일기·편지 사진 화질 복원, 날짜 추정, 시간순 타임라인(4-5 참조)
미분류 판단 못한 것 사용자가 끌어다 넣으면 학습

“서랍”은 Paperling 안의 분류 단위 이름이다. 사진 한 장이 알아서 서랍에 들어간다.

4-3. AI가 하는 “예쁘게 정리”의 정의

  • 손글씨 → 텍스트(한글·영문·숫자·간단한 그림 설명)
  • 제목 뽑기, 문단 나누기, 목록은 목록으로
  • 날짜·시간·사람 이름·장소 추출 → 일정·관계 연결
  • 말투 선택: “그대로” / “다듬어서” / “요약해서” (기본은 그대로. 내 글을 바꾸지 않는다는 신뢰)
  • 손글씨 폰트로 다시 렌더링해 “내가 쓴 느낌” 유지하는 옵션

4-4. 연동 (복잡하지 않게, 넓게)

원칙: 사용자가 이미 쓰는 곳으로 보낸다. 연결은 최초 1회, 이후 사진 올리면 끝. 연동을 안 해도 앱 안 서랍장만으로 완결되게 하고, 연동은 선택이다.

층 대상 방식 시점
1층 직접 연동 노션, 구글 캘린더 공식 API·OAuth. 노션은 “Paperling” 페이지와 서랍별 DB 자동 생성, 캘린더는 일정 서랍 항목을 “넣을까요?” 확인 후 생성 MVP
1층 직접 연동 원노트(마이크로소프트 그래프), 에버노트, 구글 드라이브/독스 공식 API. 서랍별 노트북·폴더 자동 생성 2단계
2층 범용 통로 옵시디언, 로그시크, 베어 등 마크다운 기반 노트 마크다운 파일 내보내기(드라이브·드롭박스 폴더 동기화), ICS 캘린더 피드 2단계
2층 범용 통로 아이폰·삼성·아웃룩 캘린더 구글 캘린더 동기화 또는 ICS 구독으로 자연히 따라옴 MVP(부수 효과)
3층 공식 API 없음 애플 메모, 삼성 노트, 굿노트, 카카오톡 나에게 보내기 공유 시트(모바일)·복사 붙이기·이메일 전달. “보내기” 버튼 하나로 통일 2단계

연동 설정 화면은 체크박스 한 줄짜리다: “노션에 저장 ☑ / 구글 캘린더에 일정 넣기 ☑ / 원노트 ☐ …”. 각 서랍마다 보낼 곳을 다르게 둘 수 있다(예: 일기는 노션만, 할 일은 노션+원노트).

4-5. 추억 복원 모드: 오래된 다이어리도 괜찮아요

아이들 유치원 다닐 때 쓴 육아 다이어리, 신혼 때 가계부, 돌아가신 부모님 편지. 서랍 깊숙이 있는 종이 기록을 꺼내 사진으로 찍으면 사진은 사진대로 살리고, 글은 글대로 정리한다.

단계 하는 일 원칙
1. 복원 업스케일(2~4배), 빛바램·누렇게 변한 색 보정, 기울기·그림자 제거, 접힌 자국 완화 원본은 절대 덮어쓰지 않는다. 복원본과 원본을 나란히 보관
2. 읽기 그 시절 손글씨·흐려진 글자 인식. 아이 그림·스티커는 “그림”으로 남기고 설명만 붙임 못 읽은 부분은 못 읽었다고 표시. 지어내지 않는다
3. 날짜 찾기 적힌 날짜가 없으면 문맥(유치원 행사, 계절, 아이 나이)으로 추정하고 “추정”이라 표시 사용자가 한 번 고치면 앞뒤 페이지에 같이 반영
4. 엮기 시간순 타임라인, 사람별(첫째·둘째) 보기, 그 시절 한 줄 요약 추억 서랍은 노션으로도 보내지만 기본은 앱 안 비공개
5. 남기기 “그 시절 책” 인쇄: 복원 사진 왼쪽, 정리 글 오른쪽 대면 배치 6장 수익 모델의 손글씨 북과 같은 인쇄 파이프라인
  • 묶음 처리: 한 번에 50장까지 올리면 백그라운드로 처리하고 끝나면 알림. 오래된 기록은 한꺼번에 나오기 때문.
  • 업스케일은 처리 비용이 커서 프로 기능. 무료는 월 5장 체험.
  • 기술: 오픈소스 초해상도 모델(Real-ESRGAN 계열) 또는 상용 API 비교 후 선택. 종이 사진 전용 보정(황변 제거)은 자체 후처리.
  • 감정 설계: 처리 중 문구는 “옛 글씨를 조심스럽게 읽고 있어요”. 광고 톤 금지. 이 부분은 전자책에!
  • 로드맵: 2단계(취향·연동 확장)에 “추억 복원 베타” 포함. 사전등록 폼에 관심도 질문 추가해 수요 먼저 확인.

5. 디자인 시스템: 고르는 재미

5-1. 두 라인

라인 성격 예시 테마 가격
일반(베이식) 깔끔·실용, 매일 봐도 안 질림 화이트 노트 / 모던 그리드 / 클래식 플래너(프랭클린형) / 다크 저널 무료 3종 + 프로 전체
아티스트 일러스트레이터·캘리그라퍼 협업, 시즌 한정 드롭 수채화 정원 / 빈티지 우표 / 민화 / 필름 카메라 / 레트로 사무실 팩 개별 구매, 작가 수익 배분

아티스트 라인은 굿노트 속지 크리에이터·인스타 다꾸 작가를 섭외한다. 이미 팬덤이 있는 작가가 자기 팔로워를 데려오는 구조라 마케팅비가 거의 안 든다.

5-2. 폰트

  • 한글 손글씨: 나눔손글씨 109종(무료·상업 이용 가능)에서 선별 12종. 사용자가 “내 글씨와 가장 비슷한 것”을 고르게 안내
  • 본문용: 프리텐다드, 리디바탕, 마루부리, 노토세리프
  • 테마마다 기본 폰트 조합이 있고, 폰트만 바꿀 수도 있다
  • 라틴 숫자·날짜는 가독성 우선 폰트로 고정(일정 오독 방지)

5-3. 취향 추천: MBTI·갤럽 강점

전제를 정직하게 둔다. MBTI는 과학적 성격검사가 아니라 자기표현 언어다. 그래서 “진단”이 아니라 “고르는 재미의 출발점”으로만 쓴다. 강제하지 않고, 추천 3세트 중 고르거나 전체에서 고를 수 있다. 갤럽 강점(CliftonStrengths)은 결과를 아는 사용자가 적으니 “알면 입력, 모르면 건너뛰기”.

MBTI 4축 → 디자인·정리 방식 매핑(가설, 베타에서 검증)

축 한쪽 추천 반대쪽 추천
E/I E 공유 카드 생성 기본 켜짐, 밝은 톤 I 비공개 일기 모드, 차분한 톤
S/N S 표·체크리스트·날짜 중심 레이아웃 N 여백 많은 카드, 아이디어 서랍 우선
T/F T 모노톤·그리드, 요약 모드 기본 F 따뜻한 색, 손글씨 폰트, “그대로” 모드 기본
J/P J 주간·월간 플래너 뷰, 진행률 P 자유 노트 뷰, 태그 탐색

온보딩 60초 “취향 퀴즈”: MBTI 아는 사람은 4글자 입력, 모르면 6문항(그림 고르기). 결과로 테마 3세트 + 폰트 1종 + 기본 모드를 보여주고 바로 체험. 바꾸고 싶으면 언제든 설정에서. 퀴즈 결과 카드는 그 자체로 인스타 공유 콘텐츠가 된다(정직한 톤, 과장 금지).

7. 기술 구성 (바이브코딩으로 가능한가: 가능)

  • 프론트: 웹앱(PWA) 우선(확정). 앱스토어 수수료·심사 없이 시작, 홈화면 추가로 앱처럼 사용. 모바일 “공유 시트”로 사진 받기는 PWA 공유 타깃으로 처리. 반응 좋으면 네이티브 래핑
  • AI: 멀티모달 모델 1회 호출로 OCR+구조화를 한 번에 처리. 입력은 사진, 출력은 JSON(제목·본문·날짜·할 일·태그·서랍). 한글 손글씨 인식은 모델 비교 후 결정(클로드·제미나이 후보)
  • 백엔드: 수파베이스(인증·DB·스토리지). 연동은 “커넥터” 1개 규격으로 통일(노션·구글·마이크로소프트·에버노트 OAuth가 같은 틀), 새 노트 앱 추가가 파일 1개 추가로 끝나게
  • 렌더링: 테마는 CSS 토큰 + 폰트 조합 파일 1개. 아티스트 팩은 이 파일과 이미지 묶음이라 작가가 코딩 없이 제출 가능
  • 비용 가정: 사진 1장당 AI 처리 수십 원 수준. 월 20장 무료는 감당 가능 범위
  • 개인정보: 원본 사진은 사용자 선택으로 “처리 후 삭제” 가능. 국내 리전 저장. 사진에 타인 정보가 있을 수 있으니 공유 카드 생성 시 가림 처리 안내
