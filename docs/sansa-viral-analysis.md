# 산사(sansatemple.com) 유행 분석 보고

작성 2026-11-05. "확인" = 사이트 코드·공개 자료에서 직접 확인. "추정" = 정황 근거.

## 1. 산사가 무엇인가 (확인)
- 한 줄 정의(사이트 메타): **"말없이 같이 앉아 있는 온라인 절"**. 제목 "산사, 잠깐 쉬어가요".
- 3인칭 3D 공간. 동자승 아바타 뒤에서 둘러보고, 바닥을 눌러 이동. 청연당(법당)·연등 산책길·연꽃 연못·열린 마당.
- 할 수 있는 일: 염주 108알 돌리기(바퀴 수 표시), 절하기, 향 올리기, 목탁 두드리기, 방석에 앉아 쉬기, 새벽·저녁 **공동 예불 시간**(같은 시각에 모두 함께 듣기), 바람·새·염불 소리 고르기.
- 채팅 없음. 다른 방문자는 보이지만 말은 못 함. 커피 한 잔을 "두 손으로" 건네는 것이 유일한 상호작용.

## 3. 코드에 박혀 있는 성장 장치 (확인)
1. **인스타 link_in_bio 유입** — 공유 URL에 `utm_source=ig&utm_medium=social&utm_content=link_in_bio`. 인스타 프로필 링크가 주 입구.
2. **공유 카드** — "친구에게 보내기": QR이 들어간 이미지 카드 저장 + 링크 복사("카카오톡이나 메시지에 붙여넣어"). 카드 자체가 릴스·스토리 소재가 됨.
3. **함께 있음의 가시화** — "N명 함께 있는 중", 서버 목록·만석. 희소성과 '나 말고도 쉬러 온 사람이 많다'는 안도감을 동시에 줌.
4. **정해진 시각의 공동 행위** — 새벽·저녁 공동 예불. 재방문 이유를 만들고 "그 시간에 가 봐" 식 입소문 유발.
5. **선물 루프** — 무소유 커피: 내가 내린 커피를 모르는 방문자에게 건네고, 받은 사람은 또 건넴. 말 없는 소셜 루프.
6. **브랜드 협업** — CAFE25 for dreamers 팝업·'공양이' 고양이·설강화 회화. 협업사의 채널로 2차 노출.
7. **낮은 수익화** — 공양미(후원) 창만 있고 광고·가입 없음. "돈 안 받는 공간"이라는 인상이 공유 저항을 낮춤.
8. **모바일 우선** — PWA 메타, 세이프에어리어, 두 손가락 확대, 백그라운드 재생 안내. 릴스에서 바로 눌러 들어가는 경로가 매끄러움.

## 4. 왜 통했나 (해석)
- **익숙한 장소 + 몰랐던 형식**: '절'은 누구나 아는 공간인데 '말없이 같이 있는 웹사이트'는 처음 보는 형식. 설명이 한 줄로 끝나 공유가 쉬움.
- **종교가 아니라 쉼**: 메시지가 "기도하세요"가 아니라 "잠깐 쉬어가요". 종교 무관 2030이 거부감 없이 들어옴.
- **보이지만 말 걸지 않는 사람들**: 혼자는 외롭고, 채팅은 피곤한 세대에게 정확히 맞는 거리감.
- **짧은 반복 행위**: 염주·절·목탁은 1분 안에 '한 것 같은' 느낌을 주는 피젯. 영상으로 찍기도 쉬움.
- **릴스 친화 화면**: 세로 화면에서 동자승·연등·불상이 그대로 썸네일이 됨.
