# 뽀글할미 프로크리에이트 제작 가이드

> 2026-10-13 확정. 캐릭터 레퍼런스: `research_notes/카카오 이모티콘 승인 기획/뽀글할미_레퍼런스/` (챗GPT 생성, **레퍼런스 전용**, 카카오 제출 금지). 원화 32장은 아이패드 + 애플펜슬 + 프로크리에이트(Procreate, 프로크리에이트)로 직접 그린다.

## 1. 원칙 (카카오 운영 원칙 2026 대응)

- 레퍼런스는 프로크리에이트 **참고(Reference) 창**에 띄워 옆에 두고 본다. 캔버스에 불러와 위에 덧그리는 트레이싱은 하지 않는다. 트레이싱도 제한 범주다.
- 글자는 그림에 넣지 않는다. 32장 완성 후 별도 레이어·폰트로 얹는다.
- 생성 이미지 파일은 제안서·상품화 어디에도 첨부하지 않는다.

## 2. 캔버스 설정

| 항목 | 값 | 이유 |
|---|---|---|
| 크기 | 1080 × 1080 px | 제출 규격 360×360의 3배. 축소하면 선이 깔끔해짐 |
| DPI | 72 | 화면용, 인쇄 아님 |
| 색상 | sRGB | 카톡 표시 기준 |
| 배경 | 투명(배경 레이어 체크 해제) | PNG 투명 배경 |
| 안전 영역 | 가장자리 60px 비움 | 축소 후 20px 여백 |

파일명은 `01.png`~`32.png`. 캔버스 하나를 복제해 32개 만들고 제목에 번호와 문구를 적는다(예: `07_우리강아지`).

## 3. 레이어 구성 (모든 컷 동일)

1. 러프 (연필, 불투명도 30%, 완성 후 삭제)
2. 선 (Monoline 또는 Studio Pen, 굵기 캔버스 기준 **9~10px**, 전 컷 동일)
3. 색 (선 레이어 아래, 클리핑 마스크 안 씀, 단색만)
4. 볼터치 (살구 단색 원 2개, 그라데이션 없음)

선 굵기와 머리 덩어리 개수(6개)를 32컷 전부 고정한다. 심사에서 "비율·완성도 불일치"로 걸리는 지점이다.

## 4. 색 팔레트 (레퍼런스 360px 이미지에서 추출)

| 용도 | HEX |
|---|---|
| 머리 | #A898B0 |
| 피부 | #F8C8A8 |
| 볼 | #F8A090 |
| 조끼 | #E87070 |
| 조끼 꽃 | #F8E0C0 |
| 바지 | #684858 |
| 선 | #000000 |

프로크리에이트 팔레트에 이 7색을 등록하고 이 외 색은 소품(지폐·사과·택배 상자)에만 쓴다.

## 5. 제작 순서 (32컷, 2주)

| 일차 | 컷 | 내용 |
|---|---|---|
| 1 | 기준 컷 1장 | "밥 먹었니?" 정면. 이 한 장을 360px로 축소해 카톡 대화창에 띄워 보고 선 굵기·눈 크기 확정 |
| 2 | 표정 시트 | 확정 기준 컷을 복제해 눈·입만 바꿔 표정 8종(웃음, 놀람, 서운, 윙크, 졸림, 끄덕, 눈물, 하트눈) |
| 3~5 | 1~12번 | 끼니·안부 6, 사랑·칭찬 6 |
| 6~8 | 13~22번 | 용돈·먹을 것 4, 걱정·당부 6 |
| 9~11 | 23~32번 | 응답 6, 만남 2, 축하 2 |
| 12 | 검수 | 32장을 4×8 격자로 한 화면에 놓고 실루엣·선 굵기·색 불일치 교정 |
| 13 | 글자 | 32장에 같은 손글씨체로 문구 얹기(크기·위치 고정) |
| 14 | 내보내기·규격 검사 | PNG 투명, 360×360 축소, 150KB 이하 확인 후 제안 |

표정 시트(2일차)를 먼저 만들면 이후 컷은 몸·소품만 그리면 되어 속도가 2배 이상 난다.

## 6. 내보내기와 규격 검사

프로크리에이트: 동작 → 공유 → PNG(배경 투명). 32장을 아이클라우드 또는 에어드롭으로 Mac/Windows에 옮긴 뒤 아래로 일괄 축소·검사한다.

| | Mac (터미널, zsh) | Windows (PowerShell) |
|---|---|---|
| 이미지매직 설치 | `brew install imagemagick` | `winget install ImageMagick.ImageMagick` |
| 360px 축소 | `magick mogrify -resize 360x360 -path out *.png` | `magick mogrify -resize 360x360 -path out *.png` |
| 용량 확인 | `ls -l out \| awk '$5>153600'` | `Get-ChildItem out \| Where-Object Length -gt 153600` |

용량 초과 시 `-colors 128`을 붙여 재실행한다. 보고서 7절의 파이썬 스크립트를 쓰면 축소·검사·번호 매기기가 한 번에 된다(초안, 1주차에 로컬 테스트).

## 7. 카톡 대화창 테스트

제안 전 반드시 실제 대화창 크기로 본다. 360px 이미지를 카톡 "나와의 채팅"에 보내 1.5m 거리에서 표정이 읽히는지 확인한다. 안 읽히면 눈·입을 키운다. 심사자는 이 크기로 본다.

## 8. 유튜브 기록

1일차 기준 컷 제작 과정을 화면 녹화(아이패드 제어센터 → 화면 기록)해 둔다. "AI 레퍼런스 → 직접 그리기 → 카톡 테스트"가 2편 소재다.
