0. 지금 뭐가 문제냐면요

💡 쉽게 말하면 지금 사이트 주소는 soonryu74.github.io 라서 손님이 보면 "이게 부동산 사이트 맞나?" 싶어요. galmae-budongsan.com 처럼 바꾸면 명함·현수막·카톡에 넣기 딱 좋습니다.
사이트는 그대로, 주소(간판)만 바꾸는 것이라 내용은 하나도 안 사라집니다.

1. 준비물

  • 신용/체크카드 1장 (1년에 약 1.5~2만원 결제)
  • 휴대폰 또는 컴퓨터, 10분

2. 어떤 이름으로 살까 (예시)

아래 중 사용 가능한 것으로 고르면 됩니다. 짧고 기억하기 쉬운 게 좋아요.

galmaebds.comgalmae-budongsan.comgalmae.kr guri-galmae.com갈매동부동산.kr갈매역삼성.kr
👍 추천 .com 또는 .kr 이 제일 무난합니다. "갈매"가 들어가면 동네 손님이 기억하기 좋아요. 한글 도메인(갈매동부동산.kr)도 가능합니다.

3. 사는 방법 (가비아 기준 · 한국 사이트라 쉬움)

  1. gabia.com 접속 → 회원가입/로그인
  2. 첫 화면 도메인 검색창에 원하는 이름 입력 (예: galmaebds) → 검색
  3. "등록 가능" 이라고 뜬 것을 장바구니 담기 (빨간불이면 다른 이름으로)
  4. 결제 단계에서 등록 기간 선택(1년 이상), 카드 결제
  5. 자동 연장(자동 갱신) 켜기 — 안 그러면 1년 뒤 주소가 날아갈 수 있어요
  6. 후이즈(WHOIS) 개인정보 보호 옵션이 있으면 켜기 (내 전화·주소 공개 방지, 보통 무료)
⚠️ 딱 하나만 조심 결제 후 "호스팅도 같이 사시겠어요?" 같은 추가 상품 권유가 나오면 안 사도 됩니다. 우리는 도메인만 필요해요. (사이트는 이미 공짜로 돌아가고 있어요.)

4. 다 샀으면 이것만 알려주세요

② 어디서 샀는지 (예: 가비아)

🔧 (운영자·대표님 전용) 연결 설정

유진 님은 안 보셔도 됩니다. GitHub Pages 커스텀 도메인 연결 절차입니다.

A. 등록처(가비아 등) DNS 설정

루트 도메인(galmaebds.com)이면 A레코드 4개 + (선택)AAAA, www는 CNAME:

타입호스트값
A@185.199.108.153
A@185.199.109.153
A@185.199.110.153
A@185.199.111.153
CNAMEwwwsoonryu74.github.io

IPv6까지 넣으려면 AAAA: 2606:50c0:8000::153 / 8001::153 / 8002::153 / 8003::153

B. 저장소(GitHub) 설정

  1. 담당자(Claude)가 저장소에 CNAME 파일 추가 + 배포 워크플로에 cname 반영 (도메인 확정 후 자동 처리)
  2. GitHub 저장소 → Settings → Pages → Custom domain에 도메인 입력 → Save
  3. DNS 전파(최대 몇 시간) 후 Enforce HTTPS 체크 → 자물쇠(보안) 적용
📌 메모 이 사이트는 gh-pages 브랜치로 배포되므로 CNAME 파일이 빌드 산출물(gh-pages)에 포함돼야 합니다. peaceiris 액션의 cname: 입력값으로 넣거나 소스 루트에 CNAME 파일을 두면 됩니다. 도메인 이름을 알려주시면 담당자가 즉시 반영합니다.
참고: GitHub Pages 커스텀 도메인·HTTPS는 무료입니다. 도메인 등록비(연 1.5~2만원 수준)만 발생합니다. 가격·상품명은 등록처에 따라 다를 수 있습니다.
