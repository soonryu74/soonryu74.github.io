  • 합성 골격: 서기 ≈180°, 깊은 스쿼트 ≈90°(±2°), 외반 시 KASR < 0.80·안쪽 변위 ≥ 15%, 기울기 14° 재현(±1.5°), 비대칭 > 15°
  • 샘플 6종이 의도한 플래그를 내는지: 좋은 스쿼트(5회, ≥90점, 외반 없음) / 외반(5회 모두 valgus, ≤70점, 둔근 루틴) / 얕고 빠름(shallow+fast, 가동성 루틴) / 런지 비대칭(asym+lean, 한다리·코어 루틴) / 부드러운 착지(3회, ≥85점) / 딱딱+모임(stiff+valgus, 착지 루틴)
  • 영양: 70 kg 보통 활동 → 탄수화물 350~490 g, 단백질 84~140 g, 수분 350~490 mL, 1회 단백질 21~28 g; 65세 이상 주석; 땀 손실 2 kg/90분/500 mL → 2.5 L, 1.67 L/h, 2.9%, 보충 2.5~3 L; 보충제 체중 비례; 도핑 키워드 중복 매칭 방지(‘슈도에페드린’ ≠ ‘에페드린’), 상태별 정렬
