# a6-print — 마크다운 원고 → 미니북 인쇄 PDF

레드프린팅 **[토너] 무선 책자** 업로드 규격에 맞춰 두 파일을 만듭니다.

| 파일 | 내용 | 크기 |
| --- | --- | --- |
| `내지.pdf` | 낱장 페이지(표제지·차례·본문·판권), 쪽수는 4의 배수·최소 20쪽 | 재단 105×148 + 사방 5mm 여분 = 115×158mm |
| `표지.pdf` | 뒷표지 + 책등 + 앞표지 펼침 1장 | (105+책등+105) × 148 + 사방 5mm 여분 |
| `주문입력값.txt` | 주문 화면에 넣을 옵션과 예상 금액 | — |

## 쓰는 법

```
npm install                       # playwright 설치
npx playwright install chromium   # PDF를 그릴 브라우저 설치(처음 한 번)
node make-minibook.mjs 원고.md    # 원고와 같은 이름의 -print 폴더에 결과
```

옵션: `--out 폴더` `--trim 105x148` `--bleed 5` `--spine 4`(책등 mm, 기본 자동 계산) `--color "#2f4a3f"`(표지색) `--font 10.5`(본문 pt) `--multiple 4`(쪽수 배수)

pandoc이 있으면 표·목록·강조까지 변환하고, 없으면 제목·문단·인용만 변환합니다.

## 원고 형식

```
---
title: 책 제목
subtitle: 부제(표지 뒷면 소개글로도 쓰임)
author: 지은이
---

# 1장 제목
*장 부제*

## 절 제목
본문 문단. 빈 줄로 문단을 나눕니다.

> 메모·인용
```

`#`는 장(오른쪽 페이지에서 새로 시작), `##`는 절입니다. 샘플: `sample/콘텐츠-자동화의-정석.md`.

## 확인한 것(2026-10-11)
- 내지 115×158mm, 표지 222×158mm(20쪽·책등 2mm)로 생성됨을 pdfinfo로 확인.
- 책등은 백색모조 100g 0.10mm/장 + 표지 0.3mm로 계산. 주문 화면의 '세네카' 값과 다르면 `--spine`으로 다시 생성.
- 글꼴은 Noto Serif KR·Pretendard를 웹에서 불러옵니다. 인터넷이 없으면 시스템 글꼴로 대체됩니다.
