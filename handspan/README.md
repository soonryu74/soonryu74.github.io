# 한뼘(HANDSPAN) — MVP 화면 시안

> 한 뼘 안에 들어오는 책만 팝니다 / Books that fit in a hand.
> 기획안: `docs/minibook-platform-plan.md` (5·7·8·9·12절이 이 화면의 근거)

빌드 없는 정적 HTML/CSS/JS입니다. 데이터는 `data/*.json`, 장바구니와 신청서는 브라우저 `localStorage`에만 저장됩니다. **결제·계정·배송 API는 없습니다.**

## 로컬에서 열기

```
cd <저장소 루트>
python3 -m http.server 8000
# http://localhost:8000/handspan/
```

`file://`로 열면 `fetch`가 JSON을 읽지 못하므로 꼭 서버로 여세요.

## 데이터

- `data/books.json` — 24권. 콩 7·손 10·뼘 7, 장르 11종 전부, 제작 4종, 트랙 A 3권(ISBN 있음), 해외 작가 책 8권(JPY·USD·EUR + `krw_equiv`).
- `data/artists.json` — 12명(한국 7, 일본 2, 대만 1, 미국 1, 독일 1). 가공 인물입니다.
- `data/weekly.json` — 이번 주 한 권(인터뷰 3문답, 제작 과정 캡션 3개).

표지 이미지는 없습니다. `cover_color`로 CSS 표지를 그리고, 크기는 `width_mm × height_mm`를 `--mm`(화면 폭에 따라 1~1.35px/mm)로 환산합니다. 그래서 25×35mm 펜던트 시집은 화면에서도 손톱만 하고, 150×190mm 책은 그 일곱 배로 보입니다.

## 기획안과 맞춘 숫자

190mm(장변 상한), 76/148/190(콩·손·뼘), 12%/15%(트랙 B/A), 15%(정가제 할인 상한, 10%+5%), 3권(같은 작가 무료배송), 1,800/1,800/1,900/4,000(준등기·CU·GS25·등기소포), 4,550/4,330/4,160/8,090(일본·대만·홍콩·미국 K-Packet), 7일·월 2회(1일·16일), 첫째 금요일 0%, 29,000원~(선서), 122,018권(ブックサンタ). 전부 `app.js` 상수와 `supabase/schema.sql`의 `platform_settings`에 있습니다.

## 만들지 않은 것

- [ ] 계정·로그인(Supabase Auth). 스튜디오는 미리보기만.
- [ ] 결제(PG 지급대행: 토스페이먼츠 서브몰 / 포트원 파트너정산). 장바구니의 '결제로'는 안내문만.
- [ ] 배송 API(우체국 준등기·K-Packet, 편의점 택배). 요금표는 2026년 값을 손으로 적음.
- [ ] 번역(영어·일본어 UI, 상품 설명 자동 번역 병기). 꼬리말의 언어 단추는 스텁.
- [ ] 관리자 화면 `admin/`(큐레이션 편성, 정산 실행, 납본 체크리스트).
- [ ] 이미지 업로드와 실물 사진(자 동봉). 지금은 CSS 표지뿐.
- [ ] 디지털 책 내려받기(Storage 서명 URL).
- [ ] 환율 재계산. `krw_equiv`는 고정값.
- [ ] 사업자 정보·통신판매업 신고번호. 꼬리말에 미기재 상태를 적어 둠.
- [ ] 국세청·문체부 확인 사항(ISBN 없는 수제본 면세, 비출판사 발행물 정가제). 문구는 기획안 6절 기준.
