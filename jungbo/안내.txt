[중보기도 나눔터 — 공유용 안내문]
아래 글을 그대로 복사해서 카카오톡 단톡방에 올리시면 됩니다.

① 인도자(모임 만드는 분)께
━━━━━━━━━━━━━━━━━━━━
1. https://mokjang.app/jungbo/ 를 엽니다.
2. [새 모임 만들기]에 모임 이름과 내 이름을 넣고 [모임 만들기]
3. 바로 뜨는 창에서 [카카오톡으로 초대장 보내기] → 우리 단톡방 선택
   (같은 창의 '내 열쇠 코드'는 사진으로 찍어 두세요. 휴대폰을 바꿀 때 씁니다)
4. [모임] 탭에서 [알림 켜기]
5. 식구들이 다 들어오면 [모임] 탭 → '초대 주소로 새 식구 받기'를 끄세요.

② 식구들께 (인도자가 단톡방에 올리는 글)
━━━━━━━━━━━━━━━━━━━━
🙏 [모임 이름] 중보기도 나눔터에 초대합니다
아래 주소를 누르고 이름만 넣으면 바로 들어와요. (앱 설치·회원가입 없음)
(여기에 인도자 화면의 초대 주소를 붙여 넣으세요)

들어온 뒤 꼭 해 주실 것:
· [모임] 탭 → [알림 켜기]  → 긴급기도가 올라오면 휴대폰이 바로 울려요.
· 아이폰은 사파리 공유 단추 → [홈 화면에 추가] → 홈 화면 아이콘으로 열고 알림을 켜 주세요.
· 카카오톡 안에서 열렸으면 [크롬·사파리로 열기]를 먼저 눌러 주세요. (카카오톡 안에서는 알림이 안 와요)

━━━━━━━━━━━━━━━━━━━━
③ 긴급기도가 필요할 때
━━━━━━━━━━━━━━━━━━━━
1. [기도제목 올리기] → [🚨 긴급] 선택 → 누구를 위해 / 내용 → [올리기]
2. 알림 켠 식구들 휴대폰에 '🚨 긴급기도가 올라왔습니다' 알림이 바로 갑니다.
3. 이어서 뜨는 창에서 [카카오톡으로 보내기] → 단톡방 선택 → 알림 안 켠 분들도 봅니다.
4. 식구들은 글을 눌러 [기도했어요]·이모지·댓글로 마음을 전합니다.
5. 응답받으면 글에서 [응답받았어요]를 눌러 주세요. 모두에게 감사 소식이 갑니다.

④ 자주 묻는 것
━━━━━━━━━━━━━━━━━━━━
· 카카오톡 단톡방에 자동으로 글이 올라가나요?
  → 카카오톡은 외부 앱이 단톡방에 자동으로 글을 쓰는 것을 허용하지 않습니다.
    그래서 올린 분이 [카카오톡으로 보내기]를 한 번 눌러 단톡방을 고릅니다. (2초면 됩니다)
    휴대폰 알림(알림 켜기)은 사람 손 없이 바로 갑니다.
· 휴대폰을 바꿨어요 → 첫 화면 [열쇠 코드로 들어가기]에 열쇠 코드를 넣습니다. ([모임] 탭 → 내 정보에서 볼 수 있어요)
· 열쇠 코드를 잃어버렸어요 → 초대 주소로 새 이름으로 다시 들어온 뒤, 인도자가 예전 이름을 [빼기] 하면 됩니다.
