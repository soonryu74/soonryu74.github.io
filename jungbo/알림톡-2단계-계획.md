# 알림톡 2단계 계획 — 긴급기도를 카카오톡으로 "자동" 보내기

지금(1단계)은 **웹 푸시(자동) + 카카오 공유 창(한 번 누름)** 입니다.
알림톡을 붙이면 올린 사람이 아무것도 안 눌러도 식구들 **카카오톡**에 바로 갑니다. 단, 아래 조건과 비용이 있습니다.

## 1. 전제 조건
| 항목 | 내용 |
|---|---|
| 카카오톡 채널 | 모임(또는 교회) 이름으로 **비즈니스 채널** 개설 + 비즈니스 인증 (사업자등록증 또는 고유번호증 필요. 교회는 고유번호증으로 가능) |
| 발송 대행사 | 알림톡은 카카오가 직접 API를 열지 않고 대행사를 통해 보냅니다. 솔라피(Solapi)·알리고·NHN Cloud 등. 가입 후 채널 연결 |
| 템플릿 심사 | "긴급기도 요청이 올라왔습니다" 문구를 **정보성 템플릿**으로 등록 → 카카오 심사 1~3일. 광고성 문구는 반려 |
| 받는 사람 전화번호 | 알림톡은 **전화번호**로 보냅니다. 식구가 앱에서 번호를 입력하고 "카카오톡 알림 받기"에 동의해야 함 |
| 발송 시간 | 정보성이라도 **20:50~08:00 야간 발송 제한** (긴급기도의 한계. 야간엔 웹 푸시만 감) |

## 2. 비용 (2026년 10월 대행사 공개 요금 기준, VAT 별도)
- 알림톡 1건 약 **8~13원**
- 예: 식구 30명 모임, 긴급기도 월 10건 → 300건 ≈ **3,000~4,000원/월**
- 선불 충전식. 교회 재정이나 인도자가 부담

## 3. 템플릿 예시 (심사용)
```
[#{모임이름}] 긴급기도 요청
#{대상} 을(를) 위한 긴급기도가 올라왔습니다.
#{내용요약}
함께 기도해 주세요.
```
버튼: **기도방 열기** (웹링크 → `https://mokjang.app/jungbo/?g=#{모임코드}#p=#{글번호}`)

- 변수(#{…})는 심사 시 "서비스 이용자에게 보내는 정보"임을 설명
- 템플릿 하나 더: `[#{모임이름}] 기도 응답 소식` (응답받았어요 알림)

## 4. 구현 (코드 변경 범위)
1. **DB**: `pray_member`에 `phone text`, `alimtalk boolean` 추가. 전화번호는 암호화(pgcrypto) 저장
2. **화면**: [모임] 탭 → "카카오톡 알림톡 받기" 칸 — 전화번호 입력 + 동의 체크 (선택 사항, 안 넣어도 앱은 그대로 씀)
3. **서버 함수 `pray-notify`** `posted`에서:
   - 웹 푸시 보낸 뒤
   - 긴급이면 `alimtalk = true` 식구들의 번호로 대행사 API 호출 (솔라피 기준 `POST /messages/v4/send-many/detail`)
   - 비밀값: 대행사 API 키·채널 ID·템플릿 ID → Edge Function 비밀값(`supabase secrets set`)
   - 야간이면 건너뛰고 응답에 `skipped: 'night'` 표시 → 화면에서 "지금은 카카오톡 발송 제한 시간이라 앱 알림만 갔어요. 단톡방에 직접 알려 주세요" 안내
4. **인도자 설정**: 모임별로 알림톡 켜기/끄기, 이번 달 발송 건수 표시
5. **검사**: 대행사 테스트 모드(실제 발송 없이 응답만)로 Playwright 검사 1개 추가

예상 작업량: 코드 반나절 + 채널 인증·템플릿 심사 대기 3~7일

## 5. 판단 기준 — 언제 2단계로 가나
- 식구 중 **휴대폰 알림을 못 켜는 분**(아이폰 홈 화면 추가가 어렵거나, 카카오톡 안에서만 여는 분)이 1/3 이상이면 알림톡 도입 가치 있음
- 모임 20명 이하이고 인도자가 [카카오톡으로 보내기] 한 번 누르는 게 부담 없으면 1단계로 충분

## 6. 대안 (알림톡 없이 자동화에 가까운 것)
- **오픈채팅 방장봇**: 카카오 공식 기능이지만 외부 연동 불가 — 해당 없음
- **카카오톡 채널 "친구톡"**: 2025년 12월 종료 → "브랜드 메시지"로 대체(건당 50원 이상, 광고성) — 기도 알림에는 부적합
- **문자(SMS)**: 알림톡보다 비싸고(건당 약 20원) 카톡 창이 아님. 알림톡 실패 시 대체 발송용으로만
