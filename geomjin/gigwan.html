1. 검진기관 생애주기 — 법령 의무 지도

지정

검진기관 지정 신청

건강검진기본법 §14 · 시행규칙 §4~§5 · 별표1~5. 의료법상 의료기관·보건소가 유형별(일반·암·영유아·구강) 인력·시설·장비 기준 충족 → 공단 제출(7일 내 검토) → 시·군·구청장 3일 내 지정. 변경 시 15일 내 신고.

운영

검진 실시·질 관리

건강검진실시기준·암검진실시기준 준수, 검진 의사 교육과정 이수(고시 §3·별표8, 폐암은 국립암센터 과정), 검진전담인력 주 2일 16시간 이상, 장비 정도관리, 문진표·결과통보서 서식.

평가

검진기관 평가 (3년 주기)

건강검진기본법 §15 · 시행규칙 §7~§12. 9개 검진유형별 평가(공단 위탁). 결과 공개, 미흡 기관 교육·수시평가, 최하등급 연속 시 업무정지·지정취소(시행령 §10).

청구

검진비용 청구·심사

건강검진기본법 §21·§24 → 건강검진실시기준 §13 · 암검진실시기준 §12. 검진 완료일부터 30일 내 청구, 공단은 접수 15일 내 지급. 토·공휴일 상담료 30% 가산. 부당청구 환수(별표7)·업무정지.

통보

결과 통보·자료 제출

고시 §10(검진일부터 15일 내 통보) · 기본법 §18(자료 활용)·§22(자료 협조, 2026.2 개정)·§23(비밀누설 금지). 공단 전산 제출, 의료법 §22 준용 보관.

조문 번호는 건강검진기본법 페이지에서 원문과 대조하세요.

3. 검진기관 평가

근거
건강검진기본법 §15, 시행규칙
주기
3년마다 (시행규칙 §8). 1주기 2012~2014 → 2주기 2015~2017 → 3주기 2018~2020 → 4주기 2021~2023(결과 2024.4) → 5주기 2024~2026(평가 진행 중). 직전 최하등급 기관은 수시 평가
대상
검진유형별 연간 건수 기준 충족 기관(4주기: 연 50건 이상, 13,203개소 — 병원급 1,398·의원급 11,805). 직전 최우수·연속 우수기관 면제. 5주기는 종별 구분 없이 약 2만 5천 기관
영역
9개 유형: 일반·영유아·구강 + 위·대장·간·유방·자궁경부·폐암. 4주기 8개 분야 437문항(안내, 검진의사 업무, 시설·장비, 검체관리, 판정 정확도, 청구 성실성·자료보관, 결과통보, 교육이수). 서면(웹 평가표) + 방문조사
등급

공개

4. 비용 청구 · 수가

  • 청구 경로: 공단 전자청구. 검진 완료일부터 30일 이내 청구, 공단은 접수일부터 15일 이내 지급(건강검진실시기준 §13, 암검진실시기준 §12).
  • 수가 구조: 건강보험 행위 상대가치점수 × 환산지수(분류번호) 방식 + 일부 정액. 상담료·행정비용 가-1(AA154)×52.1%, 생활습관평가 1종 6,000원, 노인신체기능 2,400원, 치면세균막 3,000원, CAPE-15 6,000원, 장애인 안전·편의관리비 83,830원, 영유아 구강 7,920원. 토·공휴일 상담료·행정비용 30% 가산. 2026 수가표 →
  • 본인부담: 일반·구강·영유아 0%. 암검진 10%(공단 90%) — 보험료 하위 50%·의료급여수급권자·대장암·자궁경부암 0%. 확진검사(고혈압·당뇨 HbA1c·이상지질혈증·C형간염 RNA 등) 본인부담 없음.
  • 환수·제재: 미실시 항목 청구, 대리 검진, 항목 누락 → 환수(고시 별표7·암 별표4), 업무정지·지정취소(기본법 §16, 시행령 §10: 부정청구·평가 거부·최하등급 연속 등).

⚠ 암종별 원 단위 단가와 2026 환산지수 적용값은 고시 별표 원문 확인 후 반영.

5. 결과 통보 · 자료 관리

  • 수검자에게 검진일부터 15일 이내 우편·이메일·모바일 통보(건강검진실시기준 §10, 암검진실시기준 §9). 영유아·구강·생활습관평가는 직접 교부 원칙. 공단 전산 전송.
  • 검진자료 활용은 건강검진기본법 §18(정책·통계·연구), §22(자료 협조 — 2026.2.12 시행 개정: 최소범위·목적 외 사용 금지), §23(비밀누설 금지). 결과활용 동의서(고시 별지12).
  • 질환 의심자 확진검사 안내(다음 해 3.31까지), 폐암 검진 시 금연 상담 기록, 내시경 소독대장 3년 보관.

6. 제재 · 벌칙 (건강검진기본법 §16 · §28, 시행령 §10)

위반조치
거짓·부정 방법으로 지정, 지정기준 미달지정취소 또는 6개월 이내 업무정지 (§16). 취소 후 2년 재지정 불가
비용 부정청구, 국가검진임을 알리지 않은 유인, 정당한 사유 없는 검진 거부, 평가 거부, 평가 최하등급 연속, 자료제출 거부시행령 §10·별표 1~3차 처분기준(업무정지·지정취소), 비용 환수
검진 업무상 비밀 누설 (§23)3년 이하 징역 또는 3천만 원 이하 벌금 (§28)
위탁업무 종사자 수뢰 등공무원 의제(§27의2) → 형법 §129~§132

조문 원문은 건강검진기본법 제3장·제5장 참고. 이 법에는 과태료 조항이 없고, 벌칙은 비밀누설(§28) 하나입니다.

7. 의료기관용 도입 패키지 (판매 모델)

Basic · 고시 추적

매년 고시 개정 요약 + 변경 항목 diff, 대상자 판정 규칙 업데이트, 법령 체계도·조문 요약(본 사이트 콘텐츠) 기관 내부 사용 라이선스.

Standard · 수검자 안내

Basic + 기관 로고 삽입형 수검자 안내문(연령별·암검진별), 검진 전 준비사항, 결과 해석 안내, 2차검진 안내 서식, 홈페이지 임베드용 "내 검진 찾기" 위젯.

Pro · 평가 대비

Standard + 검진기관 평가 체크리스트, 직원 법령 교육 슬라이드·퀴즈, 해외 가이드라인 비교 자료(건강증진센터 상담용), 맞춤 데이터 제공(API/JSON).

기관에 주는 가치

  • 고시가 매년 바뀌어도 대상자 안내 오류(잘못된 연령·주기 안내 → 부당청구 위험) 감소.
  • 수검자 문의 응대 시간 절감: 안내문·위젯이 1차 응답.
  • 평가 준비 표준화: 조문 기준 체크리스트.
  • 건강증진센터·종합검진 상담 시 "국가검진 vs 종합검진 vs 해외 권고" 근거 설명 자료.
