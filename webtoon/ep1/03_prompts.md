# 프롬프트 (챗GPT 이미지 생성용)

## 사용법
- 인물이 나오는 컷(2~14)은 `characters/soonssaem.png`를 반드시 첨부하고 아래 프롬프트를 붙여넣는다
- 결과에 글자·말풍선이 섞이면 재생성. 얼굴이 다르면 '첨부 이미지와 같은 얼굴로' 한 줄 추가해 재생성
- 저장명: `cuts/cut01.png` ~ `cuts/cut14.png`

## 공통 스타일 블록
```
세피아 톤 연필 소묘 스타일 웹툰 컷. 아이보리색 종이 질감 배경,
섬세한 펜 해칭, 차분하고 서정적인 분위기, 한국 웹툰,
그림 안에 글자·말풍선·텍스트·화면 속 문자 절대 없음.
```

## 캐릭터 고정 블록
```
순샘: 50세 한국 여성, 턱선 길이 단정한 단발머리(옆가르마), 얇은 뿔테 안경,
눈가에 옅은 주름, 따뜻하지만 조금 지친 눈매, 보통 체형,
연한 색 라운드 니트 카디건 안에 흰 셔츠, 손목에 작은 시계.
첨부한 기준 이미지와 같은 인물, 같은 얼굴, 같은 화풍을 유지.
```
