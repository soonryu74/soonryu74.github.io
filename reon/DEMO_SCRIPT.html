시간 화면 말할 것 클릭
0~10초 홈 “퇴직·경력단절·돌봄을 겪은 분들은 ‘무슨 일을 할 수 있는지’부터 모릅니다. 기존 검색은 직업명을 아는 사람에게만 유리합니다. 다시ON AI는 내가 해온 일에서 시작합니다.” 90초 데모 시작
10~25초 경력 입력(자동 입력) → 분석 중 “48세, 사무직 경력 뒤 아이와 부모님을 돌보느라 공백이 있는 분입니다. 이력서가 아니라 말하듯 적은 3문장과 ‘주간근무 희망’뿐입니다. 주민번호·주소는 묻지 않습니다.” (자동 진행)
25~40초 AI 경력 번역 “경험을 역량 8개로 번역했습니다. 각 역량 밑에 어느 문장에서 나왔는지 근거가 있습니다. 틀리면 ×로 지우고 빠진 건 추가합니다. AI는 제안만 하고 결정은 본인이 합니다.” (역량 하나 × 삭제 시연 가능) → 다음 단계
40~55초 전환직무 TOP3 “1위 노인맞춤돌봄 생활지원사 76%. 점수 아래 ‘왜 잘 맞나요?’ — 돌봄 경험·소통·전화응대가 핵심 능력과 연결된다고 문장으로 설명합니다. ‘점수는 어떻게 계산했나요?’를 열면 가중치와 미반영 요소(전망·접근성) 까지 숨기지 않습니다.” 다음 단계
55~70초 역량 Gap → 훈련 “이 직업으로 가려면? 이미 갖춘 것 4개, 보완할 것, 필요한 자격을 필수●/권장○ 으로 구분합니다. 다음 화면에서 그 역량을 채우는 훈련을 고용24 훈련과정 API 구조로 보여줍니다. 지금은 DEMO 표기, 키 연결 시 실제 과정으로 바뀝니다.” 다음 단계 ×2
70~80초 채용 “지금 지원할 수 있는 일자리. 형식 예시는 DEMO 로 명확히 표시하고, 실제 공고는 고용24 공식 검색으로 연결합니다. 가짜 공고를 진짜처럼 보이게 하지 않습니다.” 다음 단계
80~90초 전환 리포트 “핵심역량·TOP3·이유·Gap·훈련·채용 검색어·다음 행동 3가지가 한 장에 담기고 PDF 로 저장됩니다. 하단 ‘근거 보기’에서 입력→추출→비교→출처가 전부 공개됩니다. 직업 이름을 몰라도 됩니다. 다시ON AI가 경력을 다음 일자리의 언어로 번역합니다.” 인쇄/PDF 또는 근거 보기

예비 질문 대응

  • “AI 가 실제로 돌아가나?” → 지금 화면은 규칙 기반 DEMO 분석기(배지 표시). js/config.js 의 AI_ENDPOINT 에 서버 주소를 넣으면 같은 화면이 원격 AI 결과로 바뀌며 배지가 “AI 분석(원격)”으로 변경됨. 실패 시 자동으로 규칙 분석기로 복귀.
  • “공공데이터는?” → 고용24 채용·훈련 OPEN-API 구조에 맞춘 어댑터와 수집 스크립트 준비. 키 발급 후 캐시 JSON 이 생기면 화면이 자동 전환. 미연결 요소는 화면에 “미반영”으로 표시(DATA_SOURCES.md).
  • “개인정보는?” → 서버 저장 없음, sessionStorage 만 사용, 탭 닫으면 삭제, “내 기록 지우기” 버튼.
