## 예비 질문 대응
- "AI 가 실제로 돌아가나?" → 지금 화면은 규칙 기반 DEMO 분석기(배지 표시). `js/config.js` 의 `AI_ENDPOINT` 에 서버 주소를 넣으면 같은 화면이 원격 AI 결과로 바뀌며 배지가 "AI 분석(원격)"으로 변경됨. 실패 시 자동으로 규칙 분석기로 복귀.
- "공공데이터는?" → 고용24 채용·훈련 OPEN-API 구조에 맞춘 어댑터와 수집 스크립트 준비. 키 발급 후 캐시 JSON 이 생기면 화면이 자동 전환. 미연결 요소는 화면에 "미반영"으로 표시(DATA_SOURCES.md).
- "개인정보는?" → 서버 저장 없음, sessionStorage 만 사용, 탭 닫으면 삭제, "내 기록 지우기" 버튼.
