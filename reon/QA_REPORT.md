- 실행일: 2026-10-06 (근거 보강 후 재실행)
- 도구: Playwright 1.56.1 + Chromium(헤드리스), 뷰포트 1280×860 / 390×844(모바일)

## 발견·수정한 결함
1. `b2b_sales` 처럼 숫자가 든 직무 id가 라우트 정규식에 걸리지 않아 Gap 화면으로 이동하지 못함 → 정규식 수정.
2. Evidence·TOP3 점수표가 390px 에서 164px 가로 넘침 → 표를 가로 스크롤 컨테이너로 감쌈.
3. "보고" 키워드가 "해보고 싶다"에 오탐 → 키워드를 "보고서/보고했"으로 교체.
4. Gap 3열 카드가 `.card + .card` 여백 규칙으로 높이가 어긋남 → 그리드 안 카드 여백 제거.
