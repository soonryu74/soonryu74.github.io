고용24 OPEN-API 키 발급·연결 절차

  1. https://www.work24.go.kr 회원가입 → 고객센터 → OPEN-API → 서비스 소개 및 신청에서 채용정보·훈련과정·직업정보 신청(기업회원 전용이라는 기록이 있어 개인 가입 가능 여부 확인).
  2. 승인 후 인증키를 GitHub 저장소 Settings → Secrets → WORK24_API_KEY 로 등록(소스에 넣지 않음).
  3. .github/workflows/reon-work24.yml 을 수동 실행(Actions → Run workflow). 승인 명세서의 응답 항목명과 reon/scripts/fetch_work24.py 의 FIELD_MAP 을 대조해 수정.
  4. reon/data/cache/openings.json, training.json 에 items 가 생기면 화면이 자동으로 “고용24 수집 데이터(수집일)”로 전환.

이용 조건 메모

  • 고용24 OPEN-API: 회원가입 후 서비스 신청 → 담당자 심사 → 인증키 발급. 기업회원 전용(사업자등록번호 요구)이라는 2차 출처 기록이 있어 개인 참가자는 발급 가능 여부를 먼저 확인해야 한다. 일일 호출 한도(2차 출처: 1,000회)도 승인 안내로 확인.
  • 공공데이터포털(data.go.kr) OpenAPI: 활용신청 → serviceKey. 개발계정 10,000건/일.
  • 출처 표기: 화면 Evidence 와 리포트에 “고용24 OPEN-API(한국고용정보원)” 표기 예정. 공공누리 유형은 데이터셋별 확인.

저장소에 넣지 않은 것(원칙)

  • 존재가 확인되지 않은 API 주소·파라미터를 “연결된 것처럼” 쓰지 않았다. 캐시가 없으면 화면은 DEMO 로 표시된다.
  • 가짜 채용공고·가짜 훈련과정을 실제처럼 보이게 하지 않았다(DEMO 배지, 원문 링크 없음 명시).
  • 직업전망·임금·지역별 채용 밀도 수치를 만들어 넣지 않았다(미반영 표시).
