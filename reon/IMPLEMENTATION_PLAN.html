3. 점수 설계(Career Transition Score)

  • 전이역량 유사도 40%: 사용자 역량 태그 ∩ 직무 핵심역량(가중 합) / 직무 핵심역량 가중 합
  • 희망조건 적합도 20%: 근무형태·근무시간 선호와 직무 일반 근무 패턴 일치(직무 사전에 정의)
  • 진입장벽 15%: 필수 자격 없음=만점, 필수 자격 있으나 미보유=감점(교육 의향 있으면 완화)
  • 직업전망·노동시장 15%: 현재 데모에서는 반영하지 않음(고용24 직업정보 상세 연결 예정) → 화면 표시, 가중치는 나머지로 재정규화
  • 지역·근무형태 접근성 10%: 희망지역 입력 시 직무의 “전국 분포” 속성으로만 판단, 실제 채용 밀도 데이터 없음 → “데이터 연결 예정” 표시
