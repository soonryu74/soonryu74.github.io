90초 시연 대본 — 클릭 순서와 예상 화면

사전 준비: 브라우저 1440px, 주소 https://soonryu74.github.io/sportsgap/ (병합 전에는 로컬 http://127.0.0.1:4180/sportsgap/). 캐시 비우고 새로고침. 네트워크가 불안하면 지도 타일이 안 떠도 폴리곤·표는 나온다고 미리 말한다.

초 행동 예상 화면 말
0–10 첫 화면 보여주기 상단 배지(시설 2024-12-31 · 인구 2026년09월 · 정류장 2025-10-31), 지도에 31개 시군 색칠, 왼쪽에 조건 패널 “문제는 간단합니다. 같은 인구인데 체육시설에 닿는 기회가 다릅니다. 화면 위 배지가 데이터 기준일입니다.”
10–25 지도에서 광주시 클릭 → 부천시 클릭 두 지역이 주황 테두리, 오른쪽 ‘나란히 비교’에 카드 2장: 인구·1만 명당 시설·추정거리·정류장 밀도·중앙값 “광주시는 1만 명당 시설 1.0개, 추정거리 1.6km. 부천시는 0.7개지만 0.5km. 숫자 옆에 도 중앙값이 같이 보입니다.”
25–45 순위표로 스크롤, 1~3위 가리키기 → 왼쪽 ‘대상 집단’을 아동(0~14세) 로 변경 표 헤더가 ‘0~14세 %’로 바뀌고 순위 재정렬, 시설 범위가 ‘아동친화형’으로 자동 변경 “기본 가중치로는 광주·가평·파주가 상위입니다. 대상을 아동으로 바꾸면 시설 범위와 순위가 같이 바뀝니다. 가중치도 슬라이더로 바로 조정됩니다.”
45–65 ‘예산 시나리오’에서 예산 300, 단가 50 확인 → 시나리오 실행 안내 “300억 ÷ 50억 = 6개소”, 배분표(지역·추가 수·순위 전→후·점수 전→후), 순위표에 +n 초록 배지 “300억 원으로 50억짜리 시설 6개를 지을 때, 한 개씩 격차 점수가 가장 많이 내려가는 곳에 배분한 결과입니다. 순위가 어떻게 움직이는지 전후가 보입니다. 단가는 가정값이라고 써 둡니다.”
65–80 ‘정책 제안’으로 스크롤 지역 제안 3건(근거 불릿 + 한계 문장) + 구조 제안 2건 “제안은 규칙 기반입니다. 왜 이 지역인지 근거 숫자가 붙고, 아래에 한계가 꼭 붙습니다. 생성형 AI 는 쓰지 않았습니다.”
80–90 상단 ‘데이터·방법론’ 클릭 about.html: 출처 표, 산식 표, 한계, 개인정보, 재현 명령 “모든 출처·산식·한계와 재현 명령이 이 페이지에 있습니다. 서버도 개인정보도 없습니다. 이상입니다.”

백업 플랜

  • 인터넷 불가: 로컬 서버(python3 -m http.server 4180)로 같은 화면. Leaflet CDN 이 막히면 “지도 라이브러리를 불러오지 못했습니다” 안내와 함께 표로 진행(E2E 로 검증된 상태).
  • 시간 부족: 45–65초(시나리오) 유지, 10–25초(비교) 생략.
