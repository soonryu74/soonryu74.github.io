MVP 기능 (요구 A~H)

  • A 지역 선택 + 지도(Leaflet) + 지도 불가 시 표 대체
  • B 3개 지표(공급량·추정거리·취약인구) + 대중교통 밀도
  • C 취약집단: 고령자·아동 지원, 장애인 평가불가 표시
  • D 우선순위 + 근거 있는 제안 3건 이상(점수 산식·가중치·기준일 표시)
  • E 시나리오 모드(예산·시설 유형·대상 집단 → 순위 변화, 탐욕 배분)
  • F 출처·한계·방법론·개인정보 페이지(about.html)
  • G 반응형(390/1440), 키보드 조작(표 행 Enter/Space), 로딩/오류/평가불가/지도 불가 상태
  • H 배포 주소 — BLOCKED: main 병합은 사용자 승인 필요. 병합 후 https://soonryu74.github.io/sportsgap/
