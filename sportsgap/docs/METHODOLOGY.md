# METHODOLOGY — 산식·한계·불확실성

화면 `about.html` 의 내용을 개발자·심사위원용으로 더 자세히 적는다. 구현은 `js/score.js`, 데이터 생성은 `scripts/build_sportsgap.py`.

## 1. 분석 단위와 기준 시점
- 단위: 경기도 31개 시군. 수원·성남·안양·안산·고양·용인의 일반구는 시로 합산(인구는 시 코드 행, 경계는 구 폴리곤 면적 합).
- 시설 2024-12-31 / 인구 2026-09 / 정류장 2025-10-31 / 경계 2018. **기준 시점이 서로 다르다**는 점을 화면 배지로 항상 표시.

## 2. 시설 집계 규칙
1. 문체부 현황 xlsx 의 23개 분류 시트(육상경기장 … 기타체육시설)에서 헤더 행(시도·시군구·주소·시설명)을 찾는다.
2. '소 계/계/합계' 행에서 시도를 갱신하고, 시도가 '경기'인 블록의 시설명이 있는 행만 센다.
3. 시군은 시군구 열(예: `고양시\n덕양구` → 고양시)에서, 없으면 주소에서 31개 시군명을 찾아 매칭. 매칭 실패 0건.
4. 검증: 시트별 '경기 소계' 캐시값과 전부 일치, 합계 2,463 = 시도별현황의 경기 5,029 − 간이운동장 2,566.
5. 간이운동장(마을공터·도시공원·아파트단지 운동시설 등)은 성격이 달라 `simple_grounds` 로 따로 보여주고 점수에는 넣지 않는다.
6. 시설 범위(scope): 전체 / 생활밀착형 / 고령친화형 / 아동친화형. 분류는 `build_sportsgap.py` 의 `LIFE_TYPES`·`ELDER_TYPES`·`CHILD_TYPES` 집합(전문가 검토 전 작업 가정).

## 3. 지표
| 키 | 산식 | 분자·분모·단위 | 방향 |
|---|---|---|---|
| supply_per_10k | n_fac ÷ pop × 10,000 | 선택 범위 시설 수 ÷ 주민등록 총인구, 개/1만 명 | 작을수록 격차↑ |
| est_km | 0.5 × √(A ÷ n_fac) | A = 시군 면적(㎢, 경계에서 계산), km | 클수록 격차↑ |
| vuln_ratio | pop_group ÷ pop × 100 | 65세 이상 또는 0~14세, % | 클수록 격차↑ |
| transit_density | n_stop ÷ A | 버스정류장 수 ÷ 면적, 개/㎢ | 작을수록 격차↑ |

`est_km` 근거: 밀도 λ 의 균일 포아송 점과정에서 임의 지점에서 최근접 점까지의 평균거리는 1/(2√λ) = 0.5√(A/n). 시설이 실제로는 도심에 몰리므로 도시 지역은 과소, 산지·수면이 많은 군은 과대 추정된다. n_fac = 0 이면 null(평가불가).

## 4. 정규화
- 31개 값에서 P5·P95(선형보간)를 구해 그 범위로 자른 뒤 (v−P5)/(P95−P5)×100. 역방향 지표는 100−s. 소수 1자리 반올림.
- 이상치 처리는 이 윈저라이즈가 전부. 로그 변환은 쓰지 않았다(해석 단순화 우선).
- null 은 null 로 유지(재가중 없음).

## 5. 합성·순위
- composite = Σ_i (w_i / Σw) × s_i, 가중치 기본 35/30/20/15. 사용자가 0~100 으로 바꿀 수 있고 합계가 100 이 아니면 비율로 환산.
- 가중치 > 0 인 지표가 null 이면 그 지역은 `status='na'` → 순위 제외. 지표를 빼려면 가중치 0(명시적 축소모형).
- 순위: composite 내림차순, 동점은 가나다순.
- 장애인 집단: `GROUPS.disabled.available=false` → 모든 지역 na.

## 6. 예산 시나리오
- n = min(60, ⌊예산 ÷ 단가⌋).
- 탐욕: 매 단계 후보 지역마다 "+1 시설" 가정으로 전체를 다시 점수화해 Δ = composite_before − composite_after 를 구하고, objective 가 `people`(기본)이면 Δ × (인구/1만), `score` 면 Δ 로 최댓값 지역에 배분. Δ ≤ 0 이면 중단.
- 단가는 가정값. 원자료 건설사업비는 경기도 생활체육관 4건, 축구장 48건, 구기체육관 47건 등만 기재되고 편차가 커(생활체육관 중앙값 약 243억, 사분위 80~656억) 기본값으로 쓰지 않았다.

## 7. 규칙 기반 제안
- 상위 3개 지역: 가중치 > 0 인 지표 중 점수 상위 3개를 근거 문장으로, 집단별 권장 유형(고령: 게이트볼장·파크골프장·생활체육관·수영장 / 아동: 수영장·풋살장·생활체육관·구기체육관) 중 1만 명당 가장 적은 유형을 제안. est_km 이 도 중앙값의 1.5배 초과면 분산형·순회형 문구.
- 구조 제안: (거리 ≥70 ∧ 교통 ≥70) → 접근수단 우선, (부족도 ≥70 ∧ 거리 ≤30) → 운영·회전율 우선.
- 모든 제안에 `caveat`(한계) 문장을 붙인다.

## 8. 불확실성·민감도
- 가중치를 바꾸면 순위가 크게 바뀐다. 예: 기본값에서 1위 광주시, 대중교통 0% 축소모형에서도 상위권이지만 군 지역 순위는 취약인구 가중치에 민감.
- 면적 기반 거리의 불확실성이 가장 크다. 시설 좌표를 확보하면 `est_km` 을 읍면동 중심점 기준 실제 최근접거리로 교체하는 것이 1순위 개선.
- 개소 수는 규모를 반영하지 않는다. 연면적·수용인원 열이 일부 시트에 있으나 결측이 많아 사용하지 않았다.
