SaGA 영상 제작실 — 처음 설치 안내 (함께 쓰시는 분께)
==========================================================

영상 제작실은 내 컴퓨터 안에서만 돌아가는 프로그램이에요.
영상·사진은 인터넷에 올라가지 않고, 내 컴퓨터 폴더에 저장됩니다.
모두 같은 프로그램을 쓰므로, 누가 만들어도 썸네일 모양·색이 똑같이 나와요.


1. 프로그램 받기 (Windows · Mac 같음)
----------------------------------------------------------
아래 주소를 브라우저에 붙여 넣으면 ZIP 파일이 바로 내려받아져요.

  https://github.com/soonryu74/soonryu74.github.io/archive/refs/heads/claude/youtube-automation-platform-3rb80k.zip

받은 ZIP 을 풀고, 안의  yt-studio → pipeline  폴더로 들어가세요.
  · Windows: C 드라이브 바로 아래에 풀고, 풀린 긴 이름의 폴더를
    짧게 바꾸세요 (예: C:\saga). 경로가 길면 설치 중 오류가 날 수 있어요.
  · Mac: 문서 폴더 등 편한 곳에 풀면 돼요.


2. 파이썬 설치 (처음 한 번만)
----------------------------------------------------------
[Windows]
  1) https://www.python.org/downloads/ 에서 내려받아 설치
  2) 설치 도중 나오는 질문
       - "paths longer than 260 characters" 설정 → y
       - "Add commands directory to your PATH" → y
       - "Install CPython now?" → y
  3) 컴퓨터를 한 번 다시 시작

[Mac]
  1) https://www.python.org/downloads/ 에서 macOS 설치 파일(.pkg)을 받아 설치
  2) 설치가 끝나면 열리는 폴더의 "Install Certificates.command" 도 한 번 더블클릭


3. 실행
----------------------------------------------------------
[Windows]  pipeline 폴더의  시작하기  (Windows 배치 파일) 더블클릭
           · "게시자를 확인할 수 없습니다" / "PC 보호" 창 → 추가 정보 → 실행

[Mac]      pipeline 폴더의  시작하기.command  더블클릭
           · "확인되지 않은 개발자" 창이 뜨면: 파일을 오른쪽 클릭 → 열기 → 열기
           · 그래도 안 열리면: 터미널을 열고  bash  (한 칸 띄우기) 입력 후
             시작하기.command 파일을 터미널 창에 끌어다 놓고 Enter

처음 한 번은 설치 때문에 5~10분 걸려요. 검은 창은 닫지 마세요.
브라우저에 "SaGA 영상 제작실"이 열리면 성공입니다.
(안 열리면 브라우저 주소창에  127.0.0.1:7860  입력)


4. 썸네일은 이렇게 (통일된 모양)
----------------------------------------------------------
  썸네일 탭 → 틀 고르기: "재생목록 고정 틀" → 재생목록 고르기
  → 사진 올리기 → 큰 말 적기 → 썸네일 만들기

  재생목록마다 정해진 모양:
    일터아카데미 소개(응원)  쇼츠: 말풍선·자막상자   가로: 여러 얼굴 모음
    극동방송 1분 칼럼        쇼츠: 질문-답·자막상자  가로: 3분 미라클형
    비전트립                 쇼츠: 자막상자          가로: DAY 여행 일지형
    학장 특강 · SCIC         쇼츠: 말풍선·자막상자   가로: 인용형
    강의                     쇼츠: 자막상자·질문-답  가로: 예능 자막형
    추천 영상                쇼츠: 카드·자막상자     가로: 얼굴 + 큰 두 줄

  · 큰 말에서 줄바꿈은 \n, 색을 바꿀 단어는 *별표* 로 감싸기 (예: 일이 *선교*다!)
  · 글자는 얼굴을 피해서 자동으로 자리를 잡아요.


5. 새 버전이 나왔을 때
----------------------------------------------------------
  검은 창을 닫고 → 1번 주소로 ZIP 을 다시 받아 → 같은 자리에 덮어쓰기
  → 시작하기 실행. (내가 만든 영상은 pipeline\projects 폴더에 그대로 남아요)


6. 끄기 · 다시 켜기
----------------------------------------------------------
  끄기: 검은 창(터미널)을 닫기
  다시 켜기: 시작하기 더블클릭 (두 번째부터는 몇 초면 열려요)
