1. 전체 흐름

단계하는 일쓰는 도구
대본주제 → 제목 후보·대본·장면·썸네일 문구로컬 AI (LM Studio·Ollama) 또는 Gemini
음성장면마다 한국어 낭독 + 문장별 자막 시간edge-tts (무료)
장면배경 그림·영상, 또는 내 화면 녹화기본 카드 / 로컬 Stable Diffusion / 이미지·영상 생성 API
영상자막 입히기, 천천히 확대 효과, 이어 붙이기, 배경음ffmpeg (자동 설치)
썸네일레이아웃 3종 · 영상마다 다른 시리즈 색블랙한산스·프리텐다드 글꼴
업로드비공개로 올리고, 사람이 확인한 뒤 공개YouTube Data API

웹 스튜디오(index.html)는 기획·대본 수정·썸네일 미리보기용이고, 실제 영상은 내 컴퓨터의 파이썬 프로그램이 만듭니다.

2. 파이썬 설치 (처음 한 번)

Windows

  1. python.org에서 3.12 이상 설치 파일 받기
  2. 설치 첫 화면에서 Add python.exe to PATH 반드시 체크
  3. 시작 메뉴 → PowerShell 열고 확인
py --version

Mac

  1. python.org에서 macOS 설치 파일 받기
  2. 설치가 끝나면 Install Certificates.command도 한 번 실행
  3. Spotlight(⌘+Space) → 터미널 열고 확인
python3 --version
어렵지 않아요숫자가 3.10 이상으로 나오면 준비 끝이에요. 윈도우는 py, 맥은 python3라고 부르는 것만 기억하세요.

3. 스튜디오 설치

GitHub 저장소 화면에서 Code → Download ZIP으로 받아 압축을 풀거나, git 을 쓰신다면 clone 해 주세요. 그다음 yt-studio/pipeline 폴더에서 아래를 차례로 입력합니다.

Windows (PowerShell)

cd 다운로드폴더\yt-studio\pipeline
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy config.example.json config.json
python studio.py doctor

빨간 글씨로 "스크립트를 실행할 수 없습니다"가 나오면 한 번만:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Mac (터미널)

cd ~/Downloads/yt-studio/pipeline
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp config.example.json config.json
python3 studio.py doctor

doctor가 준비 상태를 ✔ / ✖ 로 보여 줘요. ffmpeg·글꼴은 자동으로 준비됩니다.

다음부터는터미널을 새로 열 때마다 cd로 폴더에 들어간 뒤 가상환경만 켜면 돼요. 윈도우는 .venv\Scripts\Activate.ps1, 맥은 source .venv/bin/activate 입니다.

4. 로컬 AI 연결 (대본 작가)

방법 A · LM Studio (화면으로 쉽게)

  1. lmstudio.ai에서 설치 → 검색창에서 한국어가 되는 모델을 받기 (예: Qwen3 8B, Gemma 3 12B. 메모리 16GB 이상 권장)
  2. 왼쪽 Developer 탭 → 모델 Load → Start Server (주소 http://localhost:1234)
  3. 웹 스튜디오에서도 쓰려면 서버 설정의 Enable CORS를 켜기
  4. config.json의 "provider": "lmstudio" 그대로 두면 끝

방법 B · Ollama (명령어 한 줄)

Windows

ollama pull qwen3:8b
setx OLLAMA_ORIGINS "*"
# 작업표시줄의 Ollama 를 종료했다 다시 켜기

Mac

ollama pull qwen3:8b
launchctl setenv OLLAMA_ORIGINS "*"
# 메뉴 막대의 Ollama 를 종료했다 다시 켜기

config.json에서 "provider": "ollama", "model": "qwen3:8b"로 바꿔 주세요. OLLAMA_ORIGINS는 웹 스튜디오에서 부를 때만 필요해요.

방법 C · Gemini API (컴퓨터 사양이 낮을 때)

Google AI Studio에서 키를 만들고 환경변수로 넣어 둡니다.

Windows

setx GEMINI_API_KEY "여기에_키"
# PowerShell 창을 닫고 새로 열기

Mac (zsh)

echo 'export GEMINI_API_KEY="여기에_키"' >> ~/.zshrc
source ~/.zshrc
웹 스튜디오 주의인터넷 주소(https)의 웹 스튜디오에서 내 컴퓨터(localhost) AI를 부르면 크롬·엣지가 "로컬 네트워크 접근" 허용을 물을 수 있어요. 허용을 눌러 주세요. 사파리는 막는 경우가 있어 크롬·엣지를 권장합니다.

5. 첫 영상 만들기

한 번에 (주제 → 완성 영상)

Windows

python studio.py auto "엑셀 반복작업 무료 AI 자동화" --minutes 5
python studio.py auto "노트북LM 숨은 기능" --shorts

Mac

python3 studio.py auto "엑셀 반복작업 무료 AI 자동화" --minutes 5
python3 studio.py auto "노트북LM 숨은 기능" --shorts

나눠서 (대본을 직접 다듬고 싶을 때, 추천)

Windows

python studio.py plan "주제"
notepad projects\날짜-주제\project.json
python studio.py make projects\날짜-주제

Mac

python3 studio.py plan "주제"
open -e projects/날짜-주제/project.json
python3 studio.py make projects/날짜-주제

결과는 projects/날짜-주제/ 폴더에 생겨요.

  • video.mp4 또는 shorts.mp4 — 완성 영상 (자막 포함)
  • thumbnail.jpg, thumbnail_2.jpg, thumbnail_3.jpg — 썸네일 3종
  • subtitles.srt — 자막 파일
  • 업로드정보.txt — 제목·설명(챕터 포함)·태그

대본을 고치고 make를 다시 하면, 바뀐 장면의 음성만 새로 만들어요. 전부 새로 만들려면 끝에 --fresh를 붙입니다.

AI 서버 없이 하고 싶다면 config.json의 provider 를 "manual"로 바꾸세요. 화면에 나온 프롬프트를 ChatGPT·Claude 에 붙여 넣고, 답을 다시 붙여 넣으면 됩니다.

6. 내 화면 녹화 넣기 (실전 시연)

엑셀·PPT 시연처럼 실제 화면이 들어가야 신뢰가 생겨요. 장면마다 녹화 파일을 지정할 수 있습니다.

Windows 11 화면 녹화

캡처 도구 실행 → 녹화(비디오) 선택 → 영역 지정. 또는 게임 바 Win + Alt + R

Mac 화면 녹화

⌘ + Shift + 5 → 화면 기록 → 저장 위치 선택

녹화 파일을 프로젝트 폴더의 rec 폴더에 넣고, project.json의 해당 장면에 한 줄 추가하세요.

{ "narration": "첫 번째 단계입니다. …", "keyword": "1단계 복사", "media": "rec/step1.mp4" }
  • 가로 녹화를 세로 쇼츠에 넣으면 잘리지 않게 흐린 배경 위에 통째로 들어가요.
  • 녹화가 대본보다 짧으면 마지막 화면에서 멈춰 있고, 길면 대본 길이에서 잘립니다.
  • 첫 녹화 화면은 썸네일의 ‘메인 화면’으로도 자동 사용돼요. 특정 캡처를 쓰려면 "thumbnail_image": "rec/result.png"를 적어 주세요.

7. 그림·글씨·썸네일 바꾸기 (config.json)

장면 그림 visual.provider

값설명비용
card핵심어가 크게 들어간 깔끔한 카드 (기본)무료·오프라인
sd-webui내 컴퓨터 Stable Diffusion (AUTOMATIC1111·Forge 를 --api로 실행)무료·그래픽카드 필요
pollinations무료 온라인 이미지 생성무료·속도 들쭉날쭉
geminiGemini 이미지 생성 (GEMINI_API_KEY)유료 요금제 기준
veo구글 Veo 영상 클립 생성 (pip install google-genai)유료, 가장 비쌈
folder내가 모아 둔 이미지·영상 폴더를 차례로 사용무료

어떤 방식이 실패해도 그 장면은 카드로 대신 만들어서 영상 제작이 멈추지 않아요.

목소리 tts.voice

예: ko-KR-SunHiNeural(여성), ko-KR-InJoonNeural(남성). 전체 목록은 studio.py voices로 볼 수 있어요. 빠르기 "rate": "+10%".

글씨체

  • 썸네일·장면 핵심어: 블랙한산스 (굵은 제목체)
  • 자막: 프리텐다드 SemiBold, 줄마다 검은 상자 (video.subtitle_style: boxed / outline / box)
  • 다른 글꼴을 쓰려면 "fonts": {"title": "C:/Windows/Fonts/글꼴.ttf"}처럼 경로를 적기

썸네일 thumbnail

항목설명
layoutsplit 메인 화면 강조(기본) · impact 강한 3색 글씨 · series 인물·시리즈형. 세 가지가 모두 만들어지고, 여기서 고른 것이 1번이 됩니다.
theme시리즈 색 고정: 보라·초록·남색·주황·청록·와인·먹색. 비워 두면 영상마다 자동으로 바뀝니다.
person_image내 얼굴 사진 경로. 배경을 지운 PNG 가 가장 좋아요 (캔바 ‘배경 제거’ 등). pip install rembg를 해 두면 자동으로 지워요.
잘 눌리는 썸네일 공식메인 대상(얼굴·결과 화면)은 가리지 않고 크게, 글자는 한쪽에 2~3줄, 마지막 줄만 강조색. 영상마다 색은 바꾸되 배치는 같게 해서 ‘내 채널’로 알아보게 합니다.

8. 유튜브 업로드 연결 (선택)

  1. Google Cloud 콘솔 → 새 프로젝트 만들기
  2. ‘API 및 서비스’ → 라이브러리 → YouTube Data API v3 사용 설정
  3. ‘OAuth 동의 화면’ → 외부 → 테스트 사용자에 내 유튜브 계정 이메일 추가
  4. ‘사용자 인증 정보’ → OAuth 클라이언트 ID → 유형 데스크톱 앱 → JSON 다운로드
  5. 받은 파일 이름을 client_secret.json으로 바꿔 pipeline 폴더에 넣기

Windows

pip install google-api-python-client google-auth-oauthlib
python studio.py upload projects\날짜-주제

Mac

pip install google-api-python-client google-auth-oauthlib
python3 studio.py upload projects/날짜-주제

처음 한 번 브라우저가 열리면 채널 계정으로 로그인해 주세요. 영상은 비공개로 올라가고, 썸네일과 자막 파일도 함께 등록돼요. 예약 공개는 --publish-at 2026-10-01T09:00:00+09:00를 붙이면 됩니다.

꼭 알아 두세요구글의 감사(audit)를 받지 않은 API 프로젝트로 올린 영상은 비공개로 잠겨요. 공개하려면 ‘YouTube API Services 감사 신청’을 통과해야 합니다. 그 전까지는 make로 만든 파일을 유튜브 스튜디오에서 직접 올리는 방법을 권장해요. 하루 업로드 횟수에도 한도(할당량)가 있고, 썸네일 등록은 채널 전화번호 인증이 필요합니다.

client_secret.json과 token.json은 비밀번호와 같아요. 절대 공유하거나 GitHub 에 올리지 마세요. 이 저장소는 자동으로 제외되게 설정돼 있습니다.

SaGA 일터아카데미 캠페인 영상 만들기

결과는 projects/saga/재생목록/ 폴더에 쌓입니다. 재생목록 이름은 intro(소개), column(극동방송 칼럼), scic, trip(비전트립), dean(학장 특강), lecture(강의), referral(추천 영상)입니다. 목록마다 색과 꼬리표가 정해져 있어요.

① 응원 릴레이 영상 → 쇼츠 (예: 남군산교회 "일이 선교다!")

여러 사람이 한 명씩 외치는 영상을 넣으면, 외칠 때마다 큰 글자가 튀어나옵니다. 영상을 여러 개 주면 "한 번 더!" 화면으로 이어 붙여요. 가로 영상은 가운데 인물을 세로로 잘라 얼굴을 크게 보여 줍니다.

Windows

python studio.py cheer C:\영상\남군산1.mp4 C:\영상\남군산2.mp4 --shout "일이 *선교*다!" --sub "Business is Mission!" --label "남군산교회에서 보내온 응원" --tag "남군산교회" --outro "당신의 일터도\n*선교지*입니다"

Mac

python3 studio.py cheer ~/Movies/남군산1.mp4 ~/Movies/남군산2.mp4 --shout "일이 *선교*다!" --sub "Business is Mission!" --label "남군산교회에서 보내온 응원" --tag "남군산교회" --outro "당신의 일터도\n*선교지*입니다"

외치는 순간을 소리로 찾습니다. 어긋나면 --at 1,3.8,6.8/1.4,5.5 처럼 초를 직접 적어 주세요(영상 사이는 /).

② 극동방송 1분 칼럼 녹음 → 쇼츠

녹음 파일과 원고(.txt)를 함께 주면 자막이 원고 그대로 정확하게 들어갑니다. 원고가 없으면 AI가 받아쓰고, 폴더에 생긴 자막.srt를 메모장으로 고친 뒤 같은 명령을 다시 실행하면 반영돼요.

Windows

python studio.py column C:\녹음\칼럼12.mp3 --title "월요일 사무실이\n*첫 번째 선교지*입니다" --name "칼럼니스트 이름" --role "직함" --photo C:\사진\얼굴.jpg --script C:\녹음\칼럼12.txt

Mac

python3 studio.py column ~/녹음/칼럼12.mp3 --title "월요일 사무실이\n*첫 번째 선교지*입니다" --name "칼럼니스트 이름" --role "직함" --photo ~/사진/얼굴.jpg --script ~/녹음/칼럼12.txt

장면 사진을 넣고 싶으면 --images 사진폴더. 썸네일도 함께 만들려면 --quote "인용 *강조*" --shot 배경사진.jpg.

③ 긴 강의·특강 → 핵심 쇼츠 여러 편

받아쓰기 후 AI가 30~60초 구간과 "맨 앞에 먼저 보여 줄 한 문장"을 고릅니다. 결과 폴더의 clips.json에서 구간·제목을 고치고 다시 실행하면 그대로 다시 만듭니다.

Windows

python studio.py clip C:\강의\바이블에센셜.mp4 --series dean --count 5 --name "이돈주 학장" --source-url "원본 강의 주소"

Mac

python3 studio.py clip ~/강의/바이블에센셜.mp4 --series dean --count 5 --name "이돈주 학장" --source-url "원본 강의 주소"

화면: --fit blur(기본, 슬라이드까지 전체) 또는 --fit crop --crop-x 0.3(화자만 크게, 0 왼쪽~1 오른쪽).

④ 추천 영상 0~7번

처음에 틀을 만들고, media 폴더에 사진·인터뷰 영상을 넣을 때마다 다시 만들면 됩니다. 파일이 아직 없으면 "[촬영 예정]" 화면으로 대신 들어가서, 촬영 전에도 전체 흐름을 볼 수 있어요.

Windows

python studio.py referral init
notepad projects\saga\referral\media\필요한_파일.txt
python studio.py referral make --format both

Mac

python3 studio.py referral init
open -e projects/saga/referral/media/필요한_파일.txt
python3 studio.py referral make --format both

장면 대본은 projects/saga/referral/recipes/*.json. 인터뷰 구간은 "start": "0:12", "end": "0:31", 동문 이름은 "name"에 적어 주세요.

⑤ 새롭게하소서형 썸네일

실제 장면 사진 한 장에 인용 제목을 얹습니다. *별표*로 감싼 단어만 강조색이 됩니다.

Windows

python studio.py thumb C:\사진\장면.jpg --quote "주일엔 제자,\n월요일엔 *그냥 직장인*" --name "홍길동 집사" --role "6기 동문" --kicker "20년 차 직장인의 고백" --notes "공감…|눈물 주의" --series intro

Mac

python3 studio.py thumb ~/사진/장면.jpg --quote "주일엔 제자,\n월요일엔 *그냥 직장인*" --name "홍길동 집사" --role "6기 동문" --kicker "20년 차 직장인의 고백" --notes "공감…|눈물 주의" --series intro
새롭게하소서에서 배운 썸네일 원칙실제 장면 속 인물은 크게, 제목은 그 사람이 한 말(1인칭 인용), 강조는 단어 한두 개만, 이름·직함은 작게. 인용형(글자 한쪽)과 최근형(아래 두 줄 + 손글씨 이름표·반응 자막) 두 가지가 함께 만들어집니다.
받아쓰기 준비처음 한 번 pip install faster-whisper가 필요하고, 첫 실행 때 AI 받아쓰기 모델(약 500MB)을 내려받습니다. 더 정확하게 하려면 config.json의 transcribe.model을 medium으로 바꾸세요.

9. 매일 자동 실행

topics.example.txt를 topics.txt로 복사하고 주제를 한 줄에 하나씩 적어 두세요. batch는 아직 안 만든 주제를 위에서부터 하나씩 처리합니다.

Windows — 작업 스케줄러

copy topics.example.txt topics.txt
schtasks /create /tn "YT자동화" /sc daily /st 09:00 /tr "C:\경로\yt-studio\pipeline\run_batch.bat"

확인·삭제: schtasks /query /tn "YT자동화" · schtasks /delete /tn "YT자동화"

Mac — crontab

cp topics.example.txt topics.txt
crontab -e
# 아래 한 줄 추가 (매일 오전 9시)
0 9 * * * /Users/내이름/yt-studio/pipeline/run_batch.sh

확인: crontab -l · 처음 실행 때 ‘전체 디스크 접근’ 허용을 물을 수 있어요.

예약 시각에 컴퓨터가 켜져 있고, LM Studio 서버(또는 Ollama)가 켜져 있어야 해요. 결과 기록은 batch.log에 쌓입니다. 업로드까지 자동으로 하려면 스크립트 안의 명령 끝에 --upload를 붙이세요 (비공개로 올라가요).

10. 수익화를 지키는 원칙

  • 사람이 확인하고 공개해요. 자동화는 초안까지, 공개 버튼은 내가 누릅니다. 기본값이 비공개인 이유예요.
  • 내 시연과 해설을 넣어요. 유튜브는 똑같은 틀로 찍어 낸 반복·대량 생산 영상을 수익 창출에서 제외합니다. 화면 녹화, 내 경험, 내 목소리를 섞어 ‘내 영상’으로 만드세요.
  • AI 사용을 밝혀요. 업로드 때 ‘변형·합성 콘텐츠’ 표시를 켜고, 설명란 끝에 AI 사용 문구를 자동으로 넣습니다.
  • 과장하지 않아요. 대본 규칙에 "확실하지 않은 숫자·가격은 지어내지 않기"가 들어 있어요. 그래도 수치는 꼭 직접 확인해 주세요.
