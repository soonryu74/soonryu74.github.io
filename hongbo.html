📣 매물 홍보 소재 만들기

릴스·유튜브 쇼츠·카톡·블로그에 바로 쓰는 홍보 문구와 대본. 광고비 0원으로 우리 매물을 알려요.

이 페이지 목차
  • ① 매물 홍보 문구 자동 생성
  • ② 릴스·쇼츠 대본 템플릿
  • ③ 시선 끄는 첫 문장(훅)
  • ④ 해시태그 세트
  • ⑤ 매일 자동 홍보(다음 단계)

① 매물 홍보 문구 자동 생성

매물을 고르면 SNS·카톡에 붙여넣을 홍보 캡션이 자동으로 만들어집니다. 복사해서 릴스 설명, 카톡, 블로그에 바로 쓰세요.

복사됐어요!

② 릴스·쇼츠 대본 템플릿 (15~30초)

[0~3초] 훅
"집값 비싸서 힘드시죠? 😮‍💨 이런 집은 어떠세요?"
[3~10초] 매물 보여주기
현관 → 거실(채광) → 방 → 주방 순서로 짧게. 자막으로 보증금/월세·전용면적·층 표시.
[10~20초] 포인트 3개
"① 남향 채광 ② 역세권 도보 7분 ③ 즉시입주 가능"
[20~30초] 콜투액션
"댓글·카톡 주시면 바로 안내해 드려요! 저장해두세요 📌"
[전세사기 불안 공략]
"전세 무서우시죠? 😨 보증보험 되는 안전 매물만 골라 왔어요."
본문
등기부·시세 확인 도와주는 모습 + 매물 소개.
CTA
"안전한 집 찾고 계시면 프로필 링크로 오세요!"
[사회초년생 첫 자취]
"첫 자취, 뭐부터 봐야 할지 모르겠다면? 🛏️"
본문
풀옵션 원룸 소개 + 관리비 포함 항목 강조.
CTA
"예산만 알려주세요. 딱 맞는 집 찾아드려요!"
🎬 촬영 팁 세로영상(9:16), 밝은 낮 촬영, 첫 3초에 가격·핵심을 자막으로. 매물주·세입자 동의 후 촬영하고, 개인정보(문패·차량번호)는 가리세요.

③ 시선 끄는 첫 문장(훅) 모음

  • "집값 비싸서 힘드시죠? 이런 집은 어떠세요?"
  • "이 가격에 이 위치? 오늘 나온 급매입니다 🔥"
  • "전세 무서운 분들, 보증보험 되는 집만 모았어요 🛡️"
  • "사회초년생 첫 자취, 이 원룸이면 충분해요"
  • "신혼집 고민? 학군·채광 다 잡은 투룸 발견 💍"
  • "반려동물 가능한 집, 생각보다 많지 않아요 🐶"
  • "월세 아끼는 법: 관리비에 뭐가 포함됐는지 보세요 👀"

④ 해시태그 세트 (복사용)

지역명을 넣어 쓰면 노출에 유리합니다. 【지역】을 실제 동네로 바꾸세요.

⑤ 매일 자동 홍보 (다음 단계 설계)

"매일 자동으로 홍보"를 만들려면 아래 구조가 필요합니다. 지금 만든 매물 데이터를 그대로 활용할 수 있어요.

  1. 매일 홍보 카드 자동 생성
    GitHub Action이 매일 오늘의 추천 매물을 골라 홍보 이미지(카드)와 캡션을 자동 생성.
  2. 자동 게시(선택)
    인스타그램·유튜브 등은 공식 API 또는 예약 발행 도구(메타 크리에이터 스튜디오 등)로 연결. 완전 자동 게시는 각 플랫폼 정책·인증이 필요.
  3. 가장 현실적인 방법
    매일 완성된 카드+문구를 만들어두면, 사장님이 아침에 탭 한 번으로 릴스·스토리에 올리는 '반자동' 방식이 가장 안전하고 빠릅니다.
💡 추천 순서 먼저 ①(자동 카드·문구 생성)까지 만들어 매일 소재를 자동으로 준비하고, 반응을 보면서 ②(자동 게시)를 붙이는 게 좋습니다. 원하시면 다음 단계로 만들어 드릴게요.
