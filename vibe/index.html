누구를 위한 강의인가

이런 분께 맞습니다

이런 분

  • 엑셀·PPT는 쓰지만 코딩은 한 줄도 모르는 직장인
  • 내 업무·내 동네·내 가게에 필요한 작은 서비스를 직접 만들고 싶은 분
  • 유튜브에서 "되는 건 알겠는데 처음부터 끝까지가 없다"고 느낀 분
  • 50대 이상, 천천히 따라가되 결과물은 확실히 갖고 싶은 분

이런 분은 맞지 않습니다

  • 이미 개발자라서 코드 문법을 깊게 배우고 싶은 분
  • 앱스토어 출시용 네이티브 앱을 원하는 분 (이 과정은 웹 서비스입니다)
  • 주 3시간을 낼 수 없는 분. 강의만 보면 안 되고 직접 만들어야 합니다

해당된다면 신청하지 마세요. 돈과 시간이 아깝습니다.

커리큘럼

8주, 매주 하나씩 실제로 만듭니다

모든 명령어는 맥(터미널)과 윈도우(PowerShell)를 나란히 보여드립니다. 강의 시점의 최신 버전 기준입니다.

1주준비

도구 세팅과 첫 대화

클로드 코드·코워크 설치, 깃허브 계정, 폴더 구조. "AI에게 어떻게 말해야 하는가"를 여기서 익힙니다.
결과물: 내 컴퓨터에서 AI가 파일을 만들고 고치는 것을 직접 확인
2주배포

내 사이트를 인터넷에 올리기

GitHub Pages로 무료 배포, 내 도메인 연결, 검색 노출(사이트맵·네이버 등록).
결과물: 주소를 남에게 보낼 수 있는 내 페이지 · 사례 도메인 가이드
3주자동화

공공데이터를 매일 자동으로 받기

공공데이터포털 API 키, GitHub Actions로 새벽마다 자동 수집, 실패했을 때 보는 법.
결과물: 매일 갱신되는 데이터 페이지 · 사례 실거래가 분석, 국정감사 DB
4주데이터

검색·필터·정렬이 되는 자료 페이지

엑셀을 JSON으로 바꾸고, 수천 건을 검색하는 페이지. 서버 없이 됩니다.
결과물: 내 분야 자료 DB · 사례 학과 1만 3천 개 검색
5주도구

계산기와 인쇄물 만들기

입력하면 계산해서 보여주고, 인쇄·PDF로 뽑는 페이지. 상담지·견적서·포스터.
결과물: 내 업무용 계산기 · 사례 영양제 상한 계산기, 성적표 분석 상담지
6주DB

로그인과 저장

Supabase로 회원가입·로그인, 내 것만 보이는 권한 설정. 서버 코드 없이.
결과물: 로그인되는 내 서비스 · 사례 목장 나눔터
7주AI

내 서비스에 AI 붙이기

AI API 키 발급, 키를 숨기는 프록시, 비용이 폭주하지 않게 하루 상한 걸기.
결과물: AI가 답하는 기능 하나 · 사례 눈치, 뉴스레터 메이커
8주수익

돈이 들어오는 구조

사전등록 페이지, 광고·제휴 안내 페이지, 결제 링크 연결, 이 사전판매 페이지를 만든 방법.
결과물: 신청·결제가 되는 내 서비스 · 사례 광고 제휴 모집, 사전등록, 이 페이지

강의 형식

매주 60~90분 영상 + 따라 하기 과제. 영상은 무기한 다시 보기.

질문

수강생 전용 질문 게시판. 막힌 화면 캡처를 올리면 답합니다.

수료 기준

8주 뒤 본인 서비스 주소 1개 제출. 제출자에게 수료증 발급.

왜 사전판매인가

강의는 아직 촬영 중입니다. 먼저 신청하신 분들의 질문을 받아 그 내용을 강의에 넣습니다. 그래서 먼저 오신 분께 싸게 드립니다. 낚시가 아니라 순서의 문제입니다.

환불

  • 개강 전: 이유 불문 전액 환불
  • 개강 후: 아직 공개되지 않은 주차 비율만큼 환불
  • 환불 요청은 이메일 한 통이면 됩니다

정가로 오를 때

마감일이 지나거나 정원이 차면 정가로 바뀝니다. 그 전에 신청하신 분은 계속 얼리버드 가격입니다.

신청 접수가 아직 열리지 않았습니다. 잠시 후 다시 확인해 주세요.
자주 묻는 질문

솔직하게 답합니다

정말 코딩을 몰라도 되나요?

됩니다. 대신 "AI에게 정확히 말하는 법"은 배워야 합니다. 그게 이 과정의 절반입니다. 코드는 읽을 줄만 알면 되고, 그것도 강의 중에 자연스럽게 됩니다.

AI 도구 비용은 얼마나 드나요?

강의비와 별도로 AI 구독료가 듭니다. 클로드 유료 요금제 기준 월 2~3만 원대부터 시작할 수 있습니다. 요금은 바뀌므로 개강 시점 기준으로 다시 안내합니다. 배포·DB는 무료 범위로 충분합니다.

맥이 아니라 윈도우인데요.

모든 명령어를 맥과 윈도우 나란히 보여드립니다. 만든 사람도 두 환경을 다 씁니다.

8주 안에 못 따라가면요?

영상은 무기한 다시 볼 수 있고 질문 게시판도 계속 열려 있습니다. 8주는 권장 속도이지 마감이 아닙니다.

만든 걸로 돈을 벌 수 있나요?

보장하지 않습니다. 8주차에 신청·결제·광고 제휴 페이지 만드는 법은 가르치지만, 팔리는 건 여러분 아이템에 달렸습니다. "수익 보장"이라고 말하는 강의는 피하세요.

영상은 언제부터 볼 수 있나요?

개강일부터 매주 하나씩 공개됩니다. 사전판매 기간에는 영상이 없습니다. 그래서 개강 전 전액 환불입니다.

만든 사람

왜 제가 가르치나

개발자가 아닙니다. 위에 있는 14개 서비스를 전부 AI에게 말로 시켜서 만들었습니다. 막힌 곳, 돌아간 곳, 돈 낭비한 곳을 다 겪었기 때문에 어디서 여러분이 막힐지 압니다.

유튜브 노모어매뉴얼에서 AI 도구를 발굴하고 조합하는 영상을 올립니다. 이 강의는 그 영상들에서 "처음부터 끝까지"가 빠져 있다는 댓글에 대한 답입니다.

과장하지 않겠습니다. 위 14개를 눌러 보고, 이 정도면 배울 만하다고 느끼실 때 신청하세요.
