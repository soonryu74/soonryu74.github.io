🗺️ 실거래가 지도

지역별 아파트 실거래가를 지도와 목록으로 함께 봅니다. 현재 샘플 데이터(데모)

💡 이 지도의 데이터 원칙 — 크롤링 아님, 공공데이터 기반 이 기능은 민간 포털 매물을 긁어오지 않습니다. 국토교통부 공공데이터포털 실거래가 Open API(공식·무료)를 근거로 하도록 설계됐습니다. 아래 지도는 개념 확인용 샘플 데이터이며, 실데이터 연결 방법은 맨 아래에 정리했습니다.
⚠️ 표시 데이터 주의 실거래가는 신고 기반으로 해제(취소)·특수관계 거래가 섞일 수 있고 신고까지 최대 30일 지연됩니다. 협상·판단 전 반드시 국토부 실거래가 공개시스템 원문과 현장 확인을 병행하세요. 실거래가 해석법은 실거래가 확인·활용 참고.

🔌 실데이터로 연결하는 방법 (다음 단계)

이 데모를 실제 국토부 실거래가로 바꾸려면 아래가 필요합니다. 모두 무료·합법이며 서버 없이 GitHub Pages만으로 운영할 수 있습니다.

  1. 공공데이터포털 API 신청
    data.go.kr에서 「국토교통부 아파트 매매 실거래가 자료」 활용 신청 → 서비스키 발급(무료).
  2. GitHub Action으로 정기 수집
    매일/매주 실행되는 워크플로우가 지역코드·계약월로 API를 호출해 결과를 data/deals.json 정적 파일로 저장(키는 GitHub Secrets에 보관 → 노출 없음).
  3. 주소 → 좌표 변환(지오코딩)
    도로명주소/지번을 좌표로 변환해 지도에 표시(카카오/네이버 또는 도로명주소 API 무료 사용).
  4. 지도에 렌더링
    이 페이지는 data/deals.json만 불러오도록 구성되어 있어, 데이터만 채우면 그대로 실서비스가 됩니다.
🏪 중개업소에 주는 이점 실거래가 지도 위에, 구독한 중개업소가 직접 등록한 매물을 얹으면 크롤링 없이도 광고 채널이 됩니다(로그인·DB는 Supabase 무료 등으로 확장 가능). 원하시면 이 단계도 설계해 드립니다.
⚖️ 본 지도의 샘플 데이터는 기능 시연용 예시이며 실제 거래가 아닙니다. 실서비스 전환 시 국토교통부 공공데이터 이용약관 및 지도 API 약관을 준수합니다.
