[다락방 나눔터 — 순장님 안내]

다락방 이야기와 순원 기도제목을 휴대폰으로 쉽게 정리하는 곳입니다.
설치할 것은 없어요. 아래 주소만 누르시면 됩니다.

▶ https://mokjang.app/darak/

━━━━━━━━━━━━━━━━━━━━
처음 시작하기 (3분)
━━━━━━━━━━━━━━━━━━━━
1. 주소를 누르고 [순장으로 시작하기]를 누릅니다.
2. 가입 코드
   · 목사님께 받은 코드가 있으면 넣어 주세요. (일기가 목사님께 전달됩니다)
   · 없으면 비워 두세요. 나 혼자 쓰는 다락방으로 시작합니다.
3. 내 이름과 다락방 이름만 넣고 [가입하기] — 아이디·비밀번호는 없어요.
4. '열쇠 코드'가 나옵니다. 꼭 사진으로 찍어 두세요.
   · 이 휴대폰에서는 다음부터 주소만 누르면 바로 열립니다.
   · 다른 휴대폰·컴퓨터에서 들어갈 때나 로그아웃한 뒤에는
     로그인 화면의 [열쇠 코드로 들어가기]에 이 코드를 넣습니다.

━━━━━━━━━━━━━━━━━━━━
매주 쓰는 법
━━━━━━━━━━━━━━━━━━━━
1. [순원 명단] — 순원 이름을 한 번만 넣어 두면 매주 그대로 나옵니다.
2. [이번 주 일기] — 모인 날, 모인 사람 수, 다락방 이야기, 순원별 기도제목을 적습니다.
   · '지난주 기도제목 불러오기'를 누르면 지난주 것을 이어서 쓸 수 있어요.
3. [저장] (혼자 쓰는 경우) 또는 [목사님께 제출] (교회에 속한 경우)
4. [지난 일기]에서 예전 기록을 언제든 다시 볼 수 있습니다.

━━━━━━━━━━━━━━━━━━━━
나중에 교회에 연결하기
━━━━━━━━━━━━━━━━━━━━
혼자 쓰다가 교회에서 가입 코드를 받으면
[내 계정] → '우리 교회에 연결하기'에 코드를 넣으세요.
순원 명단과 지금까지 쓴 일기가 그대로 교회로 옮겨집니다.

━━━━━━━━━━━━━━━━━━━━
앱처럼 쓰기 (홈 화면에 추가)
━━━━━━━━━━━━━━━━━━━━
· 안드로이드: 크롬(또는 삼성 인터넷)으로 열고 ⋮ 메뉴 → '홈 화면에 추가'
· 아이폰: 사파리로 열고 아래 공유 단추 → '홈 화면에 추가'
(카카오톡 안에서 열린 화면에서는 잘 안 돼요. 오른쪽 위 ⋮ → '다른 브라우저로 열기')

━━━━━━━━━━━━━━━━━━━━
열쇠 코드를 잃어버렸을 때
━━━━━━━━━━━━━━━━━━━━
· 처음 가입한 휴대폰에서: [내 계정] → [새 열쇠 코드 받기]
· 교회에 속한 순장님: 목사님께 말씀하시면 새 열쇠 코드를 만들어 주십니다.
