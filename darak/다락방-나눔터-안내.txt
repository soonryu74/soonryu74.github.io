① 목사님께 (처음 한 번)
━━━━━━━━━━━━━━━━━━━━
목사님, 다락방 나눔터 등록 주소입니다.
https://mokjang.app/darak/?new=BJ-V3DEXG

1. 주소를 누르면 '새 교회 등록' 화면이 열립니다. (초대 코드는 이미 들어가 있어요)
2. 교회 이름, 목사님 이름, 아이디, 비밀번호를 넣고 [교회 등록하기]
3. 화면에 나오는 '복구 코드'는 꼭 사진으로 찍어 두세요. (비밀번호를 잊었을 때 씁니다)
4. 들어가신 뒤 [다락방·순장 관리] 탭 → '순장이 스스로 가입하기' → [가입 코드 만들기]
5. 나오는 '가입 주소'를 [복사]해서 순장님들께 보내 주세요.
6. 순장님들이 다 가입하면 [가입 끄기]를 눌러 주세요.

② 순장님께 (목사님이 보내는 글)
━━━━━━━━━━━━━━━━━━━━
순장님, 다락방 나눔터 가입 주소입니다.
(여기에 목사님 화면의 '가입 주소'를 붙여 넣으세요)

1. 주소를 누르면 '순장으로 시작하기' 화면이 열립니다. (가입 코드는 이미 들어가 있어요)
2. 내 이름과 다락방 이름만 넣고 [가입하기] (아이디·비밀번호는 없어요)
3. 나오는 '열쇠 코드'를 사진으로 찍어 두고 [시작하기]. 바로 내 화면이 열립니다.
   · [순원 명단]에서 순원 이름을 넣어 주세요.
   · [이번 주 일기]에 다락방 이야기와 기도제목을 쓰고 [목사님께 제출]
4. 이 휴대폰에서는 다음부터 주소만 누르면 바로 열립니다.
   다른 기기나 로그아웃한 뒤에는 [열쇠 코드로 들어가기]에 열쇠 코드를 넣습니다.

③ 목사님 없이 순장 혼자 시작할 때
━━━━━━━━━━━━━━━━━━━━
다락방 나눔터 주소입니다.
https://mokjang.app/darak/

1. [순장으로 시작하기]를 누르고, 가입 코드 칸은 비워 둡니다.
2. 내 이름과 다락방 이름만 넣고 [가입하기]
3. 화면에 나오는 '열쇠 코드'를 꼭 사진으로 찍어 두세요. (다른 기기에서 들어갈 때 씁니다)
4. 순원 명단, 기도제목, 다락방 일기를 혼자 관리합니다. (제출 없이 [저장]만 있어요)
5. 나중에 교회에서 가입 코드를 받으면 [내 계정] → '우리 교회에 연결하기'에 넣으세요.
   순원 명단과 지금까지 쓴 일기가 그대로 교회로 옮겨지고, 그때부터 목사님께 제출할 수 있습니다.

④ 함께 알아 두실 것

· 휴대폰 홈 화면에 추가하면 앱처럼 씁니다.
  - 안드로이드: 크롬(또는 삼성 인터넷)으로 열고 ⋮ 메뉴 → '홈 화면에 추가'
  - 아이폰: 사파리로 열고 아래 공유 단추 → '홈 화면에 추가'
  (카카오톡 안에서 열린 화면에서는 홈 화면 추가가 잘 안 됩니다)

  혼자 쓰는 순장님은 처음 가입한 휴대폰의 [내 계정] → [새 열쇠 코드 받기]로 새로 받습니다.
