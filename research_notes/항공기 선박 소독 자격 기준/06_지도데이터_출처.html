2-1. “13 검역소 + 12 지소”와의 대조

  • travelhealth 현황표(2026-10 열람) = 본소 13 + 지소 12(김포공항·속초·고성·대산·청주공항·무안공항·광양·제주공항·대구공항·신항·통영·거제). 사용자 전제(13+약12)와 일치.

4. 좌표 산출 방법과 정밀도

  • Nominatim(https://nominatim.openstreetmap.org/search, format=json&accept-language=ko&countrycodes=kr), User-Agent kdca-disinfection-map-research/1.0, 요청 간격 1.1초, 총 4회 패스(원주소 → 괄호·건물명 제거 → 특별자치도 명칭 변환 → 도로명만 → 명칭/인근 랜드마크 → 시 중심).
  • 결과 요약
    • 검역소·지소 25: geocode 10(building 9, poi 1) / approx 15(road 9, poi 5, area 1) / city 0.
    • 업체 47: geocode 7(building 7) / approx 38(road 31, poi 2, area 5) / city 2.
    • 한국 OSM은 도로명주소 건물번호 수록률이 낮아 다수가 “도로 중심(road)”으로만 매칭됨. road·area 매칭은 수백 m~수 km 오차가 가능하므로 전부 coord_source:"approx"로 표기했다. 지도에서는 approx 마커를 다른 모양·투명도로 그리고, 정확한 위치는 address로 네이버·카카오 지도에서 재검색하도록 안내할 것.

  • 지오코딩 오매칭을 걸러낸 사례: 포항 본소 주소 “해안로 27”이 포항시 북구 청하면의 동명 도로로 매칭됨(폐기), “속초항”이 서울 동작구 상도로의 동명 상호로 매칭됨(폐기).

5. 검증하지 못한 것 / 한계

  1. 「질병관리청과 그 소속기관 직제 시행규칙」 별표 2·3(검역항·지소 위치) 원문 미확인 → 지소 12개는 질병관리청 현황표 기준.
  2. 고성지소의 실제 운영 여부(전화 “-“).
  3. 하나방역·네이처가드·거륭: 홈페이지 접근 차단으로 주소·전화·실적 미확인. 거륭은 업체 실재 자체가 미검증.
  4. 아시아나에어포트·스위스포트코리아·한국공항(주) 주소는 기업정보 사이트(공공데이터 기반)이며 법인등기 대조 안 함. 샤프에비에이션케이 주소 미확인으로 제외.
  5. 검역소 선박 소독대행자(검역법 시행규칙) 지정 명단은 어떤 공개 자료에도 없음 → capabilities.ship은 전 업체 null. 훈증 방제업체의 선박 훈증 수행 여부도 업체별 근거 없음.
  6. pathogen_tags·disinfectants는 업체별 공개 근거가 없어 전부 빈 배열. (약제 정보는 시설 단위로만 공개: 창원사무소 시설의 EF(에틸포메이트)+CO2/N2 등, 미수록 업체)
  7. 방제업체현황은 수시 변동(검색엔진 캐시에는 36건 표시 이력) → 재생성 시 4쪽 재열람 필요.
  8. 전화번호는 2026-10-17 열람 시점 값이며 현황표와 찾아오시는길 페이지가 다른 경우 note에 병기.

6. 재생성 방법

스크래치 스크립트(geocode.py, build.py)는 세션 임시 디렉터리에 있었으며 저장소에는 포함하지 않았다. 재생성 시: ① 위 출처 URL에서 주소 재수집 → ② Nominatim 1 req/s로 지오코딩(캐시 파일 유지) → ③ coord_precision이 building/poi가 아니면 coord_source=approx → ④ python3 -I -c 'import json,sys; json.load(open(sys.argv[1]))' 06_지도데이터.json 으로 검증.
