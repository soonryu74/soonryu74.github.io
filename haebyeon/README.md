# 해변, 잠깐 달려요 (`/haebyeon/`)

말없이 파도 옆을 달리는 온라인 해변. 경쟁·기록·서버 없이 브라우저만으로 돌아가는 힐링 러닝 장면.

- 열기: https://soonryu74.github.io/haebyeon/
- 파일: `index.html` 하나 (Three.js 0.160 CDN, 모델·음원 파일 없음 — 모래·구름 텍스처와 파도·갈매기·발소리·야옹을 코드로 생성)
- 캐릭터: 머리 큰 둥근 아이. 파스텔 민트·피치 팔레트(산사의 차분한 흙색과 의도적으로 다르게)

## 조작
| 입력 | 동작 |
| --- | --- |
| 달리기 버튼 한 번 탭 / `Space` | 계속 달리기, 다시 누르면 멈춤. 길게 누르면 누르는 동안만. 속도는 설정에서 시속 6~16 km |
| `←` `→` / 물가 쪽·모래 쪽 버튼 / 화면 쓸기 | 물가 쪽 · 마른 모래 쪽 (물가에선 발이 젖고 발소리가 바뀜) |
| 통나무·바위 | 앞에 있으면 저절로 옆으로 비껴 달림 |
| `R` / 10초 가만히 서 있기 | 잠깐 쉬어가기: 앉기 · 눕기 · 모래에 한 줄 쓰기(파도가 지움) |
| `B` | 호흡 안내 (4초 들이쉬고 6초 내쉬기) |

## 꾸미기
머리색 6 · 옷 색 6 · 머리띠/캡모자/밀짚모자 · 포인트 색 6. 이 기기(localStorage)에만 저장.

## 같이 달리는 친구
| 친구 | 행동 |
| --- | --- |
| 말티즈 · 골든 · 시바 · 푸들 | 옆에서 같이 달림. 쉬면 옆에 앉음 |
| 고양이 | **미션**: 달리다 보면 풀숲/물가로 샘. 가까이(1.3m) 가면 다시 따라옴. 10초 넘게 안 오면 앉아서 야옹. 데려온 횟수만 셈 |
| 갈매기 | 머리 위에서 같이 낢 |
| 혼자 | 조용히 |

## 힐링 요소
- 조개·바다유리: 지나가면 저절로 주움 (종소리)
- 유리병 편지: 가끔 떠내려옴, 주우면 짧은 편지 10종 중 하나
- 발자국: 시간과 파도에 지워짐. 모래에 쓴 글도 파도가 지움
- 500 m마다 한마디. 해는 20분 주기로 저물고 별·달·등대 불이 켜졌다 다시 뜸(앉거나 누우면 4배 빠름)
- 오늘의 러닝 카드: 현재 장면 + km·시간·조개·편지(또는 고양이 데려옴) + 한마디 → 모바일은 공유 시트, PC는 PNG 저장 + 링크 복사

## 함께 달리기 (Supabase Realtime)
- 서버 코드 없음. Supabase 프로젝트의 Realtime 채널(broadcast + presence)만 쓴다. DB·테이블 없음, 위치는 저장되지 않는다.
- 공개 방: `beach:1`, `beach:2`… 방당 30명. 가득 차면 다음 방. 아바타만 보이고 이름·채팅 없음.
- 초대 방: `?room=코드` → `beach:priv:코드`. 설정 → "초대 링크 복사". 이 방에서만 머리 위에 닉네임이 보이고, 내 머리 위엔 "나" 표시.
- 해변은 1 km 로 이어져(LOOP_LEN) 멀리 간 사람도 다시 만난다. 새로 들어오면 먼저 온 사람 9 m 앞에서 시작.
- 전송: 상태 바뀔 때 + 1.5초마다 1번, 12초마다 presence 갱신. 20초 넘게 소식 없으면 사라짐.
- 비용 주의: Supabase 무료 구간은 월 200만 메시지. 30명 방이 꽉 차면 **1시간에 약 300만 메시지**라 무료로는 가벼운 사용만 가능. 사람이 몰리면 Cloudflare Durable Objects(산사 방식)로 옮기는 게 맞다.
- `?bot=1`: 화면을 그리지 않고 자동으로 달리는 테스트 모드(영상 촬영용).

## 장소 프리셋
같은 엔진에 `?scene=` 으로 장소를 바꾼다. 시작 화면에서도 고를 수 있다.
| 장소 | 주소 | 바뀌는 것 |
| --- | --- | --- |
| 해변 (기본) | `/haebyeon/` | 모래·파도·조개·등대·갈매기 |
| 한강 | `/haebyeon/?scene=hangang` | 잔디·둑·자전거길·강(잔잔)·건너편 아파트(밤에 창불)·한강 다리(밤에 전구)·가로등·버드나무·벚나무·벤치·클로버·참새 소리 |

장소마다 방(공개·초대)이 따로다. 초대 링크에 장소가 같이 담긴다.
