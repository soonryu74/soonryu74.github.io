# 해변, 잠깐 달려요 (`/haebyeon/`)

말없이 파도 옆을 달리는 온라인 해변. 경쟁·기록·서버 없이 브라우저만으로 돌아가는 힐링 러닝 장면.

- 열기: https://soonryu74.github.io/haebyeon/
- 파일: `index.html` 하나 (Three.js 0.160 CDN, 모델·음원 파일 없음 — 모래·구름 텍스처와 파도·갈매기·발소리를 코드로 생성)

## 조작
| 입력 | 동작 |
| --- | --- |
| `Space` / 달리기 버튼 길게 | 누르는 동안 달리기, 손을 떼면 걷다가 멈춤 |
| `←` `→` / 화면 좌우 쓸기 | 물가 쪽 · 마른 모래 쪽 (물가에선 발이 젖고 발소리가 바뀜) |
| `R` / 6초 가만히 서 있기 | 잠깐 쉬어가기 (바다 바라보기, 유목에 앉기) |
| `B` | 호흡 안내 (4초 들이쉬고 6초 내쉬기) |

조개·바다유리는 지나가면 저절로 줍고 작은 종소리가 난다. 500 m마다 짧은 말 한마디. 해는 약 8분 주기로 천천히 저물고 다시 뜬다(앉아 있으면 4배 빠름).

## 산사(sansatemple.com)에서 가져온 구조
| 산사 | 해변 |
| --- | --- |
| 부팅 화면 "법당을 여는 중" → 15초 뒤 "다시 들어가기" | "파도를 불러오는 중" → 동일 |
| 염주 108알 돌리기(반복 행위) | 누르는 동안 달리기(반복 행위) |
| 절하기 · 향 올리기 | 조개 줍기 · 유목에 앉기 |
| 바람·새·목탁 소리 선택 | 파도·갈매기·발소리 슬라이더 |
| "잠깐 쉬어가기" · "편안히 쉬어 가셨나요" 종료 화면 | "잠깐 쉬어가기" · "편안히 달리셨나요" |
| 산사 서버 · 함께 있는 사람 (WebSocket) | 미구현 — 서버가 필요해 1인 버전 |
