📖 사이트 운영 매뉴얼

갈매역삼성부동산 홈페이지 — 무엇이 자동이고, 무엇을 언제 해야 하는지

기준일 2026년 8월 · 운영자용

1. 한눈에 보기 — 자동 vs 사람이 할 일

항목어떻게 되나누가 · 언제
매물 (전세·월세·매매)실시간 자동유진 님이 구글시트에 입력 → 사이트 즉시 반영 (코드 X)
홍보 글 (블로그·카톡·당근)셀프 생성유진 님이 시세 소식 생성기에서 버튼 → 복사 → 게시
사이트 배포자동변경사항을 올리면(push) 1~2분 뒤 자동 반영
실거래가 시세 (갈매동 카드·구리 표)수동 갱신담당자(대표님/Claude)가 월 1회 데이터 새로 반영
문구·색·디자인요청 시필요할 때 담당자에게 요청 (또는 LM Studio 무료 수정)
도메인 주소1회 설정유진 님이 도메인 구매 → 담당자가 연결 (한 번만)
핵심 한 줄 유진 님이 평소에 하는 일은 딱 2가지 — ① 매물 올리기(구글시트) ② 홍보 글 올리기(생성기). 나머지는 자동이거나 담당자 몫입니다.

2. 관리 주기 (달력)

주기할 일담당
수시새 매물 나오면 시트에 추가 / 나간 매물은 '거래완료' 표시나 삭제유진 님
주 3회 (월·수·금)홍보 글 1개씩 생성해서 블로그·당근·카톡에 게시 (각 3분)유진 님
월 1회실거래가 시세 데이터 갱신 (갈매동 카드·구리 표 최신화)담당자
분기 1회전화번호·상호·소개 문구 등 기본 정보 점검, 매물 사진 정리유진 님 + 담당자
연 1회도메인 자동갱신 결제 확인 (구매한 경우)유진 님

3. 유진 님이 하는 일 — 방법

① 매물 올리기·내리기 (구글시트) 실시간

  1. 운영자 홈에서 매물 시트 열기 (즐겨찾기 해두면 편함)
  2. 한 줄에 매물 하나씩 입력: 거래유형·단지·보증금/월세·면적·층·특징 등
  3. 저장 → 우리동네 매물 페이지에 바로 반영 (새로고침)
  4. 거래 끝난 매물은 그 줄을 지우거나 상태를 '거래완료'로
📝 글까지 자동으로 매물 홍보 문구가 필요하면 매물 글쓰기에서 칸만 채우면 블로그·카톡 글이 완성됩니다.

② 홍보 글 올리기 (시세 소식 생성기) 셀프

  1. 시세 소식 자동 글 열기
  2. 주제 고르고 「글 만들기」 → 「복사」
  3. 네이버 블로그·당근·카톡에 붙여넣기 → 사진 1~2장 추가 → 게시
🗓️ 주 3회 루틴 월 = 블로그(이번 주 시세 소식) · 수 = 당근(거래 많은 단지 or 새 매물) · 금 = 카톡(단지 하나 소개). 글마다 이달의 부동산 캘린더(세금·이사철)가 자동으로 들어갑니다.

4. 담당자가 하는 일 — 실거래가 시세 갱신 (월 1회)

⚠️ 지금 상태 (솔직하게) 갈매동 카드와 구리 실거래가 표의 시세는 고정 데이터라 저절로 바뀌지 않습니다. 최신 시세로 보이려면 월 1회 데이터 갱신이 필요합니다.

갱신 방법 (담당자용):

  1. 국토교통부 실거래가 공개시스템에서 구리시 아파트 매매(최근 1년) 자료 확보
  2. 담당자(Claude)에게 전달 → data/complexes.js(갈매동)·data/guri-complexes.js(구리 전체) 재생성
  3. 올리면(push) 자동 배포 → 카드·표·홍보 글에 최신 시세 반영
💡 완전 자동으로 만들려면 (선택) 공공데이터포털(data.go.kr)에서 무료 서비스키를 발급받아 GitHub 비밀값 DATA_GO_KR_KEY로 등록하면, 매주 자동 수집 워크플로를 카드·표까지 자동 갱신하도록 담당자가 연결할 수 있습니다. (지금은 원자료만 받고 화면 데이터는 수동입니다.)

5. 문구·디자인 바꾸기

  • 간단한 것(전화번호·문구·색): 담당자에게 요청, 또는 LM Studio 무료 수정
  • 새 페이지·기능: 담당자(Claude)에게 요청 (가끔·필요 시)

6. 문제가 생기면

  • 사이트가 이상해졌다 → 모든 변경은 기록(git)이 남아 언제든 되돌릴 수 있습니다. 담당자에게 "이전으로 돌려줘"
  • 매물이 안 보인다 → 구글시트 저장 확인 → 페이지 새로고침 → 그래도면 담당자
  • 주소가 안 열린다 → 잠시 후 재시도, 지속되면 담당자

7. 운영자(대표님) 월간 체크리스트

  • ☐ 실거래가 시세 갱신 반영 (월 1회)
  • ☐ 매물 시트에 오래된/거래완료 매물 정리됐는지
  • ☐ 유진 님 홍보 루틴(주 3회) 잘 돌아가는지 확인
  • ☐ (도메인 구매 시) 자동갱신·만료일 확인
  • ☐ 상호·등록번호·연락처 표기 정확한지 (광고 법정 표기)
