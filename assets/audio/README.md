# 음악 파일 두는 곳

> 파일이 없어도 소리는 납니다. `assets/js/quiet-horn.js`가 브라우저 안에서
> 조용한 나팔 선율(자체 작곡, 약 77초 반복)을 직접 연주합니다.
> 진짜 연주 녹음이나 Suno 음악이 생기면 아래 방법으로 파일을 넣으세요.
> 파일 경로를 채우는 순간 합성 나팔 대신 파일이 재생됩니다.

모바일 부고장(`sangjo/bugojang.html`)에서 유족이 **직접 눌렀을 때만** 재생되는
조용한 음악을 여기에 둡니다. 자동 재생은 하지 않습니다.

## 넣는 방법

1. 파일을 이 폴더에 `gomaum.mp3` 로 저장합니다.
2. `assets/js/site-keys.js` 의 이 줄을 고칩니다.

```js
window.MUSIC_SRC = "";                          // 지금 (합성 나팔이 연주됨)
window.MUSIC_SRC = "../assets/audio/gomaum.mp3"; // 이렇게
```

홈(자동 시작, 오른쪽 위 소리 단추)과 부고장(눌러야 재생) 모두 이 파일을 틉니다.

## 지켜야 할 것

- **자동 재생 금지.** 빈소나 병원에서 열어 보는 분이 많습니다. 조용한 곳에서
  갑자기 소리가 나면 큰 실례입니다. 기본은 항상 정지 상태입니다.
- **음량 32%로 시작.** 코드에 그렇게 잡아 두었습니다.
- **용량은 2MB 이하로.** 모바일 데이터로 여는 분을 위해 128kbps 정도면 충분합니다.
  `ffmpeg -i 원본.wav -b:a 128k -ac 2 gomaum.mp3`
- **길이는 60~90초 정도**에 자연스럽게 이어지도록(loop) 만드는 편이 좋습니다.

## 지금 들어 있는 파일

- `gomaum.mp3` — Suno 생성곡 "고마움 상조" (3분 34초, 약 4.9MB, 48kHz 스테레오). 2026-09-02 반영.

## 저작권

- `gomaum.mp3`는 Suno **유료 요금제** 가입 상태에서 생성한 곡입니다 (2026-09-02 확인, 소유자 진술).
  Suno는 유료 요금제로 생성한 곡에 상업적 이용 권리를 부여합니다.
- 나중에 문제가 생겼을 때를 위해 남겨 둘 것: 생성 당시의 요금제 결제 영수증,
  Suno 계정의 해당 곡 페이지 링크(제목 "고마움 상조"). 곡을 만든 뒤 요금제를
  해지해도 그 곡의 권리는 유지되는 것이 Suno 약관의 취지이지만, 약관은 바뀔 수
  있으니 영수증은 보관하세요.
- 다른 AI 음악으로 바꿀 때도 같은 원칙입니다. 요금제·생성일·곡 링크를 여기에 적어 두세요.
